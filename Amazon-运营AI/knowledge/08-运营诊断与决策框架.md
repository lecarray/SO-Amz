# 运营诊断与决策框架

从问题走到动作的顺序是：**口径与目标→经营分解→流量/承接/成本分层→提出可证伪原因→选择一个可控变量→按利润与自然增量复盘**。这是【顾问推论】的落地框架，课程提供分析思路与观察案例，没有替用户完成账户诊断。

统一定义见[11-指标口径与公式校验](11-指标口径与公式校验.md)，争议见[12-矛盾与待验证观点](12-矛盾与待验证观点.md)，业务事实与待数据见[13-业务应用与数据需求](13-业务应用与数据需求.md)。本页的预期方向是试验假设，停止条件由实际利润、预算、库存与样本确定，不编造US/JP目标竞价。

## 诊断入口与分流树

```text
开始：站点/ASIN/阶段/时间/目标/约束是否明确，数据是否可比？
├─ 否 → M08-01：补最小数据与口径，输出条件判断
└─ 是 → 主要问题落在哪一层？
   ├─ 利润/现金变差 → M08-06：量、价、毛利、广告成本、库存拆解
   ├─ 曝光缺失/流量不足 → M08-02：触发→资格→预算→位置有效出价
   ├─ 有曝光但点击/成交不足 → M08-03：意图→同位CTR→同口径CVR→商品承接
   ├─ 有订单但CPA过高/预算错配 → M08-04：CPC/CVR→搜索词→位置→架构
   └─ 广告有单但自然入口不增长/主推错位 → M08-05：词与位置→真实购买子体→增量假设

各分支完成后共同返回：是否改善总贡献利润/可验证的投资回报？
├─ 达到预设目标且边际效果仍可承受 → 小步扩量并复核
├─ 样本/归因尚不成熟 → 等回补或补样本，暂不宣布成功/失败
└─ 达到损失/现金/库存上限，或假设被反证 → 停止、回退或换路径
```

自然入口不足可以同时来自词量、位置、需求季节与商品承接；CPA高也可与其共存。每轮先选对利润影响最大、证据最充分且可控制的瓶颈，记录其他可能原因，避免多个变量同时更改后无法解释。

## 数据前置与优先级

| 层级 | 必须先有的证据 | 能回答什么 | 缺失时处理 |
|---|---|---|---|
| 身份与范围 | 站点/币种、父子ASIN、广告产品、时间、目标、预算与可承受损失 | 哪个产品在什么范围出了什么问题 | 不混US/JP，不把父体工具数据与单子体广告直接拼接 |
| 销售与供给 | 日销售额/订单/件数、Session、价格/券、库存/配送、状态与变更时间 | 需求变化、商品承接与可售条件 | 先排可售与数据异常，不能直接归因竞价 |
| 广告路径 | 搜索词/投放/位置/活动/已购商品，出价策略/倍率/预算/时段 | 钱从哪个实际搜索需求流向哪个购买子体 | 没有路径数据先补导出，不凭活动名判断 |
| 利润与边界 | 净收入、完整非广告成本、退货与促销、广告花费、库存/现金 | CPA与毛利、TACoS容量、边际扩量空间 | 不把毛利率当金额、不把贡献利润称会计净利润 |
| 市场参照 | 同站同意图词量、可比竞品价格/排名/评价、工具日期和口径 | 是否有漏词、位置或成本偏差 | 工具值仅生成假设；不能按课程美元阈值套当前站点 |

【顾问推论】P0先处理口径、归因回补、库存/资格与供给障碍；P1处理已证明的超支或高损失路径，并按既有经营授权采取可回退动作；P2做能区分竞争原因的小试验；P3在真实增量与边际贡献成立后扩量。P0/P1/P2/P3是本库的排序方法，不是课程原有分级，也不构成此次修改真实广告的授权。

## M08-01｜先把症状变成同口径问题

1. **思想**：先确定变化对象与目标，再判断“好/差”；总表异常不直接变成操作命令。
2. **原理**：【数学定义/条件恒等式】CPA=CPC/CVR；TACoS=ACoS×广告归因收入占比。不同时间、币种、子体或归因口径拼接会造出假驱动。
3. **场景**：任何诊断的P0，尤其广告与销售报表不一致、聚合ACoS跳变、只知道“利润差”。
4. **判断/数据前置**：身份与日期完整；用SUM基础量再相除；订单≠件数；近期订单回补、零分母、跨SKU归因、漏入广告类型分别标记。写出基线、变化幅度、目标与允许损失。
5. **执行/优先级**：P0建立最小对账表→比较相同日期/站点/粒度→拆流量、转化、客单价、成本/广告→列2–3个竞争解释→再选分支。预期是减少无法解释的口径差异，而非立即提高销量。
6. **限制/停止条件**：销售/花费不能对账、成本未完整、归因未成熟时，停止精确获客目标与因果结论；补数据或给区间。没有样本/权限时不写已完成的业务诊断。
7. **案例**：【假设算例】S224把同价30、自然210、CPA7、TACoS10%与361/151单拼在一起，无法同时成立；正确情景是总367.5、广告157.5。S226总300→280与“总单不变”标题冲突，展示即使课件也要先对账。
8. **课程依据**：[S004](sources/S-slides.md#page-004)、[S224](sources/S-slides.md#page-224)、[S226](sources/S-slides.md#page-226)、[S227](sources/S-slides.md#page-227)、[R13 P0109](sources/R13.md#p0109)、[11复算](11-指标口径与公式校验.md)。深读：G13-04、G19-05。

## M08-02｜曝光不足按触发、资格、预算、出价逐层排除

1. **思想**：没有曝光先找在哪个环节失去机会，避免把所有问题理解为出价低。
2. **原理**：【课程简化模型】匹配产生候选→筛资格→按有效出价竞争位置→曝光→点击计费。配置Bid、位置倍率、动态系数与实际CPC是不同量。
3. **场景**：新品无量、老活动突然归零、大词没曝光而小长尾有量、TOS加价无效。
4. **判断/数据前置**：核真实匹配/否定、活动及产品资格、库存/配送/预算与耗尽时点；分词/位置看曝光、策略和所有倍率。ABCD只在可比数据上作为经验分类，PP/ROS2–5倍不能当通用真值。
5. **执行/优先级**：P0排除数据与资格障碍→P1区分全天竞价不足还是预算早耗尽→P2固定条件下测目标位置有效出价，或先补漏词/独立预算→看目标曝光及总成本是否按预期变化。先修能直接证实的设置，不同时改匹配、策略、变体和价格。
6. **限制/停止条件**：加价后无目标曝光，应回查资格、触发与竞争门槛，不能无限加价；达到测试损失上限、库存不足或目标位置CPA越界即停止/回退。多组Auto、混大小词和商品投放不直接套ABCD。
7. **案例**：【讲师现场观察】底价2.05+TOS30%仍没有TOS曝光，说明只“设置加价”不等于买到位置；【教学示例】三词共预算的第二词独立后Bid2.2不变、花费15→35，提示预算分配也是瓶颈。
8. **课程依据**：[S158拍卖图](sources/figures/S158.png)、[R11 P0133](sources/R11.md#p0133)、[R18 P0173](sources/R18.md#p0173)、[R18 P0179](sources/R18.md#p0179)、[R18 P0285](sources/R18.md#p0285)、[R18 P0287](sources/R18.md#p0287)。深读：GS-01、G11-02、G18-04–06。

## M08-03｜点击与成交分开，比较相同意图和位置

1. **思想**：有展示不点击与有点击不购买是两类问题；先确认流量是否属于真实需求。
2. **原理**：CTR/CVR受词、位置、设备、价格/券、创意、评价、配送和变体流转影响；课程P×CTR×CVR只是同位收益代理，不能当官方排名算法。
3. **场景**：高曝光低点击、低CVR、降价不涨排名、精准看似比广泛差。
4. **判断/数据前置**：广告曝光CTR不能与ABA搜索点击占比混用；品牌零售CVR不能直接代替单词广告CVR；同词同位置看CTR/CVR，再看净售价、库存、配送和真实规格/意图。低订单率先等归因回补并记录样本不确定性。
5. **执行/优先级**：P0对齐分母→P1排错词/错规格与可售问题→P2每次测试价格、素材或流量范围一个变量→比较同类流量下CTR/CVR与总贡献利润。预期是承接改善、CPA下降，不能只看点击率上升。
6. **限制/停止条件**：样本不足不凭23/30点击建固定否词规则；CPA改善若由低价降低毛利抵消，应停止扩量并复算贡献。价格降低10%，CTR×CVR需超过11.11%增幅才提高原乘积，不能按10%口算。平台与Listing规则另核当前官方。
7. **案例**：【讲师自述实案】标品9.99→8.99自然位上升，再降7.99反而下降；无CTR/CVR底表，支持价格效果非单调，不能证明具体算法。【课堂局部前后观察】游戏耳机大包23点击0单，二级无线包23点击3单，样本小。
8. **课程依据**：[R03 P0083](sources/R03.md#p0083)、[R03 P0084](sources/R03.md#p0084)、[R09 P0108](sources/R09.md#p0108)、[R12 P0151](sources/R12.md#p0151)、[R12 P0153](sources/R12.md#p0153)、[R15 P0193](sources/R15.md#p0193)、[11口径](11-指标口径与公式校验.md)。深读：G03-04、G09-04、G10-01、G15-04。

## M08-04｜CPA偏高先分CPC与CVR，再追钱的路径

1. **思想**：先找到搜索需求和位置层的成本来源，再选择降出价、缩范围、调位或重分预算。
2. **原理**：【数学定义】CPA=CPC/CVR；同搜索词可能由多个投放触发。汇总搜索词用于定方向，活动/投放/位置用于实施；相同底价也可能因倍率导致位内层级相反。
3. **场景**：ACoS/CPA高、活动多而不可解释、一个词多路径重复、预算集中大词。
4. **判断/数据前置**：搜索词总花费/订单、路径占比、位内有效出价、CPA与完整单均毛利、自然位与历史；市调建议Bid仅作参考，不能等同竞品CPC。零订单CPA写未定义/未出单，不填0。
5. **执行/优先级**：P1先看高花费且高损失路径→核意图和低CVR原因→将表现较差位置缩量同时保好位置出价→可解释的冗余覆盖简化→P2有降价证据时小步试低，优先保留主承接路径。预期为边际CPA下降且总贡献改善，花费可不降。
6. **限制/停止条件**：不要从重叠就断言同账号自抬价；也不把低价探路花费当唯一市场价格。曝光/订单/自然入口损失超过允许值或主层预算先耗尽导致假分流时，停止原解释并回退/重测。
7. **案例**：【学员转述】关重复后ACoS33%→18%，但CPC85→67、CPA1000多→500多的单位不清；【课程示例】9.48与7.15同期分流提示可试降，原稿明确先排除主层预算耗尽。二者不是同一个账户实验。
8. **课程依据**：[R09 P0098](sources/R09.md#p0098)、[R14 P0077](sources/R14.md#p0077)、[R16 P0237](sources/R16.md#p0237)、[R16 P0239](sources/R16.md#p0239)、[R19 P0011](sources/R19.md#p0011)、[R19 P0045](sources/R19.md#p0045)。深读：G14-03–05、G16-02–04、G19-01。

## M08-05｜自然位瓶颈先核投资价值与真实主推

1. **思想**：广告出了单，不代表已经买到需要的自然入口，也不代表再加预算就有效。
2. **原理**：【课程观点】排名投资要词准、位置有效、承接正常、干预量足且未到瓶颈；多变体还需实际购买与目标子体对应。广告与自然同步只是关联。
3. **场景**：有广告单自然位不动、排名高却仍重亏、主推颜色/尺码与买家真实购买错位。
4. **判断/数据前置**：目标词与市场量、现位/历史可达位、广告位置、搜索词订单和实际购买ASIN、价格/促销/评价/库存时间线；CPR仅第三方估计，不能作为一定成功的订单门槛。
5. **执行/优先级**：P0核数据与供给→P1主推错位则先独立测候选并修词根分工→P2投资词写目标位置/收益假设、限额与复查条件→已高位或瓶颈时试缩量/降CPA/移向空白入口→新词与旺季准备按需求曲线安排。预期应是可测自然增量或更高贡献，不是单次位次截图好看。
6. **限制/停止条件**：达到预设投资损失/期限而无足够自然收益，停止加码；归因不明先缩成可解释试验。2–3周复查/1–2周瓶颈收手是课程不同场景经验，观察窗还需看样本和归因，不硬套日历。新增变体若只分流，重新评估。
7. **案例**：【现场诊断+假设毛利】夏威夷衬衫毛利设8，CPA12且自然第6拟缩；CPA17且现33曾前10则先找退位原因再决定投资。【讲师自述】粉色台灯100→粉50+灰50后自然位下滑，提示变体并非总能扩量。
8. **课程依据**：[R13 P0164](sources/R13.md#p0164)、[R13 P0175](sources/R13.md#p0175)、[R13 P0177](sources/R13.md#p0177)、[R13 P0179](sources/R13.md#p0179)、[R15 P0259](sources/R15.md#p0259)、[R17 P0109](sources/R17.md#p0109)、[R17 P0129](sources/R17.md#p0129)。深读：G13-05、G15-05、G17-01–06。

## M08-06｜利润瓶颈用四个杠杆做条件情景

1. **思想**：利润是终点指标，量、价、毛利和广告成本必须一起看；降低广告订单占比不天然等于改善经营。
2. **原理**：【条件模型】广告后贡献≈总销×(广告前贡献毛利率−TACoS)。利润可来自同结构增量、降获客成本、组合提客单或重设价格/投入模式，各变量会互相影响。
3. **场景**：成熟利润薄、成长期有销量目标、单量增长却亏损扩大、降广告自然单也掉。
4. **判断/数据前置**：净收入、完整成本、广告/总销售、分变体销量/价格、库存/现金；先区分固定花费与固定TACoS。无销量新品先定可承受金额，比例分母为0时不能硬算。
5. **执行/优先级**：P1用贡献表定位最大缺口→先测低损失杠杆：漏词/低CPA盈利增量、无效花费、真实差异变体客单→前三方向无空间时才P2测试高价高广告或低价低广告→按产品目标设置总预算，纯利活动按边际效果动态进出。预期是总贡献和可持续现金改善，未必是销量最高。
6. **限制/停止条件**：价格/毛利变化后原预算目标须重算；目标TACoS必须低于纳入口径的毛利才有利润空间。达到预算/现金/库存界限、边际贡献转负，或广告缩量同步损失自然回报超过预设范围则停止扩量/回退。组合限额当前功能未核实，不承诺绝对不超花。
7. **案例**：【假设算例】S223的300→400单需自然210→280，不是加预算承诺；S226从300降280单，贡献1350→1400，说明增利可伴随减量。【讲师转述实案】高价亏损链接降价缩广告，日销150→30后转盈利，缺完整成本和同期对照。
8. **课程依据**：[R05 P0004](sources/R05.md#p0004)、[R19 P0095](sources/R19.md#p0095)、[R19 P0141](sources/R19.md#p0141)、[R19 P0169](sources/R19.md#p0169)、[R19 P0183](sources/R19.md#p0183)、[S223](sources/S-slides.md#page-223)、[S226](sources/S-slides.md#page-226)、[11复算](11-指标口径与公式校验.md)。深读：G05-01–03、G19-03–08。

## 输出与复盘最小记录

每项建议记录：问题和站点/ASIN→基线与数据期→方法ID/原段→竞争解释→本轮单次改动→预算与允许损失→预期指标方向→样本/归因观察要求→停止/回退条件→结果及是否保留。停止金额和最低可接受量由业务实际约束确定，课程案例数字不能代填。

没有实际数据时，输出“已知/未知、优先补什么、若A则B的条件路径”；有数据后才逐步写成可执行方案。本次仅完成知识库框架，未执行任何Listing、价格、广告、库存或业务数据调整。

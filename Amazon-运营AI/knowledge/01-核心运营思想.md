# 核心运营思想

因果主线：**经营目标与资源约束 → 商品竞争力与流量缺口 → 策略选择 → 小规模执行 → 贡献利润及增量验证 → 扩量、修正或退出**。自然位、广告曝光与订单占比是过程指标；最终应能解释它们如何改善可持续利润。【顾问推论】不能从“广告后自然位提高”直接推出广告是原因，也不能从“广告占比高”直接推出经营差。

证据标记遵循[AGENTS](../AGENTS.md)：【数学定义/条件恒等式】可在声明口径下复算；【课程观点】与【课程案例】来自讲师，算法与固定阈值均待验证；【顾问推论】为本知识库的应用归纳。本页没有【官方已核实】的平台规则。完整阅读与版本差异见[第1–4章深读笔记](reading/01-04-深读笔记.md)。

## M01-01｜把目标、策略与动作写成一条可检验的链

1. **核心思想**：【课程观点】先定方向，再定策略，最后定执行；“怎么卡TOS”必须回答为什么要卡以及付出的成本。
2. **底层原理**：预算、售价、评价、阶段、资金和目标不同，同一动作的价值不同；推广不存在脱离前提的统一打法。
3. **适用场景**：新品计划、老品优化、团队运营周会和问题诊断。
4. **指标/判断**：目标是否有站点、ASIN、时间、基线、利润与现金约束；动作与目标之间能否写出可观察的中间结果。
5. **操作步骤**：写问题 → 标未知变量 → 定目标/约束 → 列2–3个可能原因 → 选可证伪策略 → 定执行、观察窗和停止条件 → 复盘而非只记录动作。
6. **风险限制**：【顾问推论】把课程的“演绎法”当成组织思路即可，其算法大前提仍须证据。不得把课程中的刷单、评论或历史价操纵转为执行指令。
7. **课程案例**：“服装怎么打广告”变量过多；“用7天秒杀降低CPA，何时降、注意什么”更能获得具体答复。第4章把“ACOS约束15%、销量200到300”作为方向，再拆策略和广告通道测试；仅是教学目标例，非用户目标。
8. **来源**：[C01 P0017–P0037](sources/C01.md#p0017)，原稿[R01同段](sources/R01.md#p0017)；[C04 P0357–P0379](sources/C04.md#p0357)，原稿[R04 P0117–P0120](sources/R04.md#p0117)。R01与C01原文件完全相同，不能作独立互证；第4章此段无独立时间戳。

## M01-02｜先拆流量缺口，再决定买什么

1. **核心思想**：【课程观点】自然流增长从词宽、词体量和排名找缺口；广告另看类型、位置与有效时长。
2. **底层原理**：相关查询需求、搜索可见性、点击与成交形成不同层级；有自然位并不等于位置能获得足够访问。
3. **适用场景**：头部/腰部对标、自然流不足、盈利广告扩量和变体分工。
4. **指标/判断**：可比词集合、搜索体量、自然位、真实访问与订单；工具流量得分和“有效自然位建议”只是估算代理，不是官方流量或点击数据。
5. **操作步骤**：选同站同意图竞品 → 比较词集及位置 → 下钻词和小时 → 找最可能产生有效访问的缺口 → 检查商品是否能承接 → 用可承受测试验证。
6. **风险限制**：词重叠、抓取范围、设备、地区及个性化会影响比较；填满位置不保证盈利。课程400%获得率是多展示机会的工具示意，不是市场份额或官方上限。
7. **课程案例**：淋浴头月销26,000与4,200的ASIN，反查约1805与1102词；showerhead工具建议107/25，止吠项圈词27/6。讲师据此解释前者流量宽与位置更好，未给完整数据证明销量差由其造成。
8. **来源**：[C01 P0051–P0077](sources/C01.md#p0051)、[P0106–P0176](sources/C01.md#p0106)，原稿[R01同段](sources/R01.md#p0051)。段号非视频时间，16:14–16:15只在自然位示例附近出现。

## M01-03｜区分广告直接盈利与投资回报

1. **核心思想**：【课程观点】广告能直接盈利就考察边际放量；广告亏损则必须证明有足够额外回报，而非把亏损长期称为战略。
2. **底层原理**：【数学定义/条件恒等式】同口径下CPA=CPC/CVR；设单均广告前贡献毛利g、订单均价P，则广告后单贡献=g−CPA，盈亏线ACOS=g/P。归因订单并不自动等于增量订单。
3. **适用场景**：预算分类、活动扩量、广告亏损复盘、新品投资额度。
4. **指标/判断**：完整贡献毛利、CPA、ACOS、总贡献利润、现金回收期；价格变化/退货/优惠费用须入账。金额CPA不能直接与毛利率相比。
5. **操作步骤**：统一成本与归因口径 → 分活动核算 → 盈利型逐步扩量、跟踪边际CPA → 投资型设金额/期限上限及自然增量假设 → 到期按总利润检验 → 不兑现则调整或停止。
6. **风险限制**：补亏自然单要与自然基线区分；季节、促销、库存和品牌需求会混淆归因。本章没有给出统计止损阈值，需按实际单量与风险设计。
7. **课程案例**：ACOS230%、广告前毛利率30%，每广告单亏2P，每自然单赚0.3P，需6.667个自然单补亏，课堂约称7:1平本。这是条件算例，没有证据表明该广告实际带来7个增量自然单。
8. **来源**：[C02 P0025–P0083](sources/C02.md#p0025)、[P0430起](sources/C02.md#p0430)，原稿[R02 P0007起（01:34）](sources/R02.md#p0007)、[P0022–P0026](sources/R02.md#p0022)、[P0157起](sources/R02.md#p0157)。详见深读卡G02-01/02。

## M01-04｜把“坑产”用作假设框架，分别检验商品表现和订单规模

1. **核心思想**：【课程观点/待验证】课程区分“预期坑产”和“实际坑产”：前者强调目标词表现，后者强调一段时间的总订单；不能据此认为广告一定拉自然位。
2. **底层原理**：P×CTR×CVR可作同口径每曝光销售额的分解；将它等同排名函数、认为总量必带动全部收录词，都是未经独立验证的机制假说。
3. **适用场景**：广告有单自然位不动、短期促销后回落、识别商品承接与流量投入问题。
4. **指标/判断**：同词同位CTR/CVR、价格、排名、广告和自然订单、总利润；正向/足量响应、停止后的落点；7–14天、3–7天、三次回落均非保证。
5. **操作步骤**：建无操作基线 → 记录价格/库存/促销/竞对 → 单独测试一个主要变量 → 看词级与全商品结果 → 区分数据不足和商品竞争力不足 → 必要时做对照或逐步撤量验证。
6. **风险限制**：广告类型报表范围、URL是否带词、自然排序信号是三个问题；不可从前两者推出“仅SP加权、SB绝不加权”的确定规则。
7. **课程案例**：某自然130→20后停滞；某链接广告使70多→120，停后回80–90；站外每日100多单使140–150→10、停后约36。均是匿名口述曲线，缺因果对照。
8. **来源**：[C02 P0325–P0350](sources/C02.md#p0325)，原稿[R02 P0123–P0132](sources/R02.md#p0123)；[C03 P0085–P0145](sources/C03.md#p0085)，原稿[R03 P0034–P0054](sources/R03.md#p0034)；[C04 P0008–P0038](sources/C04.md#p0008)，原稿[R04 P0002–P0014](sources/R04.md#p0002)。

## M01-05｜遇到瓶颈，先找到最短的板，再追加流量

1. **核心思想**：【课程观点】商品数据没变时，扩大广告可能只放大原来的低效；应检查价格、评价、属性与可见性最主要的缺口。
2. **底层原理**：同曝光下价格、点击率和转化率的乘积共同影响销售额；评价、品牌、配送、功能差异也会影响用户选择。【顾问推论】每次改动应有明确假设和可测结果。
3. **适用场景**：老品反复卡位、新品明显弱于竞品、低客单高CPA、促销后回落。
4. **指标/判断**：真实同位CTR/CVR、净贡献利润、竞争价格和评价、商品退货问题；不能只用自然位判断成功。
5. **操作步骤**：列可比竞争差异 → 选对购买决策影响最大的可控项 → 核算改变成本 → 小步测试 → 达可承接位置后检查是否仍需亏广告 → 阶段内利润优先于无止境追排名。
6. **风险限制**：课程“主图通常没问题”“2000与2050评无区别”只属经验；降价有全量毛利损失，并非免费。当前业务未知根因时，不可擅判是主图、价格或评论问题。
7. **课程案例**：$24、15评钱包面临同价品牌品和更便宜多评品；标品9.99→8.99排名升，继续7.99反降；AC掉标后3–4→10位。没有完整对照证明单一原因。
8. **来源**：[C03 P0194–P0280](sources/C03.md#p0194)，原稿[R03 P0077–P0098](sources/R03.md#p0077)；[C04 P0223–P0229](sources/C04.md#p0223)，原稿[R04 P0069–P0071](sources/R04.md#p0069)。

## M01-06｜让每个变体和每笔预算承担明确任务

1. **核心思想**：【课程观点】主推接流量，其他变体可扩意图入口、补必要尺码、提高客单价或买盈利订单；无需子体销量相等。
2. **底层原理**：【数学定义/条件恒等式】订单=访问×转化率；变体既可能影响入口，也可能影响页面内选择。【课程观点/待验证】一词只展最高子体、子体权重独立、同页互斥等须另核。
3. **适用场景**：多变体广告、颜色/主题/尺码扩充、主推与购买错位。
4. **指标/判断**：词×子体流量、实际购买ASIN、贡献利润、库存；80%流量作单主推是经验，不是平台标准。
5. **操作步骤**：写词意图 → 指定主推或明确以广告盈利为目标 → 查投放和购买流向 → 给其他变体写清任务 → 只有扩大真实需求/利润才扩变体 → 复查位置与分流。
6. **风险限制**：C/D广告引流A购买、黑白同词双主推是课程明确例外，不能机械要求所有ASIN相同；组合与变体关系须按实际站点现行政策核实。
7. **课程案例**：裙子按Blue/Pink/Yellow Dress；蜡烛按姐姐、护士、新婚礼物；小车粉色768词多含girl、绿色接其他场景；M/L尺码比无线充电器多颜色更可能补必要需求。无新增变体的因果盈利表。
8. **来源**：[C04 P0381–P0431](sources/C04.md#p0381)、[P0479–P0557](sources/C04.md#p0479)、[P0600–P0668](sources/C04.md#p0600)，原稿[R04 P0121–P0134](sources/R04.md#p0121)、[P0159–P0182](sources/R04.md#p0159)、[P0194–P0209](sources/R04.md#p0194)。

边界：本页是课程知识框架，不是对US iPUTPRT或JP乒乓球发球机的现状诊断。应用需分别取得同站点、同币种、同时间与归因窗的价格、成本、订单、搜索、广告及库存数据；不得把两站数据合并推理。当前授权限知识建设，不修改真实业务。退货、供应链、质量改进、税务与品牌长期增量等并未在这4章完整覆盖；遇到这些问题应补证据，不能用坑产模型包办解释。

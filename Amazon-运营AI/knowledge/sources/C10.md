**P0005** 一、CTR 衡量指标：后台 ABA 搜索绩效表现

<a id="p0006"></a>
**P0006** （一）为什么不能用广告活动的 CTR 来衡量？

<a id="p0007"></a>
**P0007** 广告活动有三个广告位（TOS/ROS/PP），这三个位置的 CTR 只能横向跟竞品比对（昨天讲过不能纵向比较），没有一个客观的"达标标准"。

<a id="p0008"></a>
**P0008** 最客观的 CTR 衡量方式：后台 ABA 搜索绩效表现的 ASIN 视图。

<a id="p0009"></a>
**P0009** （二）操作路径

<a id="p0010"></a>
**P0010** 路径：品牌分析 → 搜索词 → 搜索绩效表现 → ASIN 视图

<a id="p0011"></a>
**P0011** 1. 进入 ASIN 视图，输入自己的主推 ASIN（多变体选流量最大或主推 ASIN）；

<a id="p0012"></a>
**P0012** 2. 反查出来 100 个词（按相关性排序，1 最相关，100 最弱）；

<a id="p0013"></a>
**P0013** （三）搜索绩效表现页面各字段含义

<a id="p0014"></a>
**P0014** | 字段 | 含义 |

<a id="p0015"></a>
**P0015** |---|---|

<a id="p0016"></a>
**P0016** | 搜索查询分数（1-100） | 在你链接内的相关性排名，1最相关；不代表词大词小 |

<a id="p0017"></a>
**P0017** | 搜索查询数量 | 该词在本平台的搜索量（最准的搜索量数据） |

<a id="p0018"></a>
**P0018** | 搜索漏斗展示量（总数） | 大盘数据：买家搜了这个词，全平台一共出现多少曝光量 |

<a id="p0019"></a>
**P0019** | 搜索漏斗展示量（ASIN 计数） | 你的 ASIN 在这个词产生的曝光量 |

<a id="p0020"></a>
**P0020** | 展示份额（ASIN 份额） | 你的 ASIN 曝光量 ÷ 总曝光量 |

<a id="p0021"></a>
**P0021** | 搜索漏斗点击量（总数） | 大盘数据：买家搜完这个词总共点了多少次 |

<a id="p0022"></a>
**P0022** | 点击率 | 大盘点击率 = 点击量总数 ÷ 搜索量（衡量这个词的"购买型"程度，不是你自己的 CTR） |

<a id="p0023"></a>
**P0023** | 搜索漏斗点击量（ASIN 计数） | 你的 ASIN 在这个词被点了多少次 |

<a id="p0024"></a>
**P0024** （四）如何计算自己的 CTR

<a id="p0025"></a>
**P0025** 导出数据后，自己插入两列：

<a id="p0026"></a>
**P0026** 1. **ASIN CTR（你自己的点击率）**

<a id="p0027"></a>
**P0027** = ASIN 点击量 ÷ ASIN 曝光量

<a id="p0028"></a>
**P0028** 2. **大盘 CTR（对比基准）**

<a id="p0029"></a>
**P0029** = 点击量总数 ÷ 展示量总数

<a id="p0030"></a>
**P0030** 对比这两个数字：

<a id="p0031"></a>
**P0031** • 你的 ASIN CTR > 大盘 CTR → 点击率有优势；

<a id="p0032"></a>
**P0032** • 你的 ASIN CTR < 大盘 CTR → 点击率不足；

<a id="p0033"></a>
**P0033** 规律：

<a id="p0034"></a>
**P0034** • 点击率有优势的产品，在各个词下基本都是偏高的（不会一个词特别高、另一个关联词特别低）；

<a id="p0035"></a>
**P0035** • 所以看一个词的 CTR 情况基本可以代表整体；

<a id="p0036"></a>
**P0036** （五）导出搜索绩效表现数据

<a id="p0037"></a>
**P0037** 路径：右上角 → 生成下载项 → 导出

<a id="p0038"></a>
**P0038** 建议：导出前点击"自定义列"，展开所有隐藏列，包含：

<a id="p0039"></a>
**P0039** • 商品价格中位数：买家在这段时间点击的所有商品中，倾向于点什么价位的产品；

<a id="p0040"></a>
**P0040** • 品牌价格中位数（ASIN 视图下为 ASIN 价格中位数）：你自己的定价中位数；

<a id="p0041"></a>
**P0041** （六）价格中位数的用途

<a id="p0042"></a>
**P0042** 商品价格中位数 = 市场上买家愿意点击的价格区间（存量市场客观数据）。

<a id="p0043"></a>
**P0043** 用途 1：对标自己的定价

<a id="p0044"></a>
**P0044** • 你的售价 < 商品价格中位数 → 价格有优势；

<a id="p0045"></a>
**P0045** • 你的售价 > 商品价格中位数 → 需要靠 CTR/CVR 的质量来弥补；

<a id="p0046"></a>
**P0046** 用途 2：验算坑产

<a id="p0047"></a>
**P0047** • 坑产粗略公式：售价 × CTR × CVR

<a id="p0048"></a>
**P0048** • 你的数据是否高于大盘 → 决定你能不能拿到更高的自然位；

<a id="p0049"></a>
**P0049** 二、用三项指标综合判断推广可行性

<a id="p0050"></a>
**P0050** （一）三项指标汇总

<a id="p0051"></a>
**P0051** 经过前面 CPC、CVR、CTR 三项市调，现在可以做出综合判断：

<a id="p0052"></a>
**P0052** 计算预估 CPA（标准值）：

<a id="p0053"></a>
**P0053** 从市调数据得出：

<a id="p0054"></a>
**P0054** • CPC 范围：$X ~ $Y

<a id="p0055"></a>
**P0055** • CVR 范围：a% ~ b%

<a id="p0056"></a>
**P0056** • 预估 CPA = CPC ÷ CVR

<a id="p0057"></a>
**P0057** 举例（吹尘器）：

<a id="p0058"></a>
**P0058** • 市调 CPC：$2.6 ~ $4.9

<a id="p0059"></a>
**P0059** • 市调 CVR：约 18%（参考 C服 数据）

<a id="p0060"></a>
**P0060** • 预估 CPA：约 $13 ~ $25

<a id="p0061"></a>
**P0061** 对比自己当前数据 → CPA 在范围内 → 基本合理。

<a id="p0062"></a>
**P0062** 注意：C服自带 CPA 估算功能，但由于竞价和转化率数据不准，参考价值有限，建议自己手动估算。

<a id="p0063"></a>
**P0063** （二）三项指标验算坑产

<a id="p0064"></a>
**P0064** 坑产（粗略）= 售价 × CTR × CVR

<a id="p0065"></a>
**P0065** 使用场景：判断我的产品表现是否有竞争力、能否推上去自然位。

<a id="p0066"></a>
**P0066** 举例对比：

<a id="p0067"></a>
**P0067** • 竞品：$40 × 2% × 20% = 0.016（正常水平）

<a id="p0068"></a>
**P0068** • 你：$45 × 1.5% × 10% = 0.00675（非常低）

<a id="p0069"></a>
**P0069** 虽然售价只比竞品高了一点，但 CTR × CVR 比对方低了很多 → 坑产数字远低于竞品 → 推不上去自然位。

<a id="p0070"></a>
**P0070** 结论：

<a id="p0071"></a>
**P0071** • 三项指标都偏低 → 不建议推自然位，直接转向盈利型广告；

<a id="p0072"></a>
**P0072** • 盈利型广告也搭不出来 → 这个产品本身选品有问题；

<a id="p0073"></a>
**P0073** • 三项指标都偏高 → 推广会非常顺滑（"丝滑型产品"）；

<a id="p0074"></a>
**P0074** 三、定价策略：流量款 vs 利润款

<a id="p0075"></a>
**P0075** （一）如何从市调数据倒推定价

<a id="p0076"></a>
**P0076** 在 ABA 搜索绩效表现页面的"商品价格中位数"，可以看到市场客观定价区间。

<a id="p0077"></a>
**P0077** 举例：某品类商品价格中位数 = $34.66

<a id="p0078"></a>
**P0078** （二）流量款定价策略

<a id="p0079"></a>
**P0079** 目标：推自然位、走量

<a id="p0080"></a>
**P0080** 定价参考：商品价格中位数 × 80%（约八折）

<a id="p0081"></a>
**P0081** • $34.66 × 80% = 约 $27.7

<a id="p0082"></a>
**P0082** • 这是一个具有价格优势的进入点，且其他参数（款式/功能）与竞品相当时，CTR/CVR 会达标或偏高，可以顺利推自然位；

<a id="p0083"></a>
**P0083** 适用情形：

<a id="p0084"></a>
**P0084** • 定价在 $24 ~ $32 之间（中低于中位数）；

<a id="p0085"></a>
**P0085** • CTR/CVR 测试结果持平或偏高；

<a id="p0086"></a>
**P0086** • 走量路线，单品利润可以薄一些；

<a id="p0087"></a>
**P0087** （三）利润款定价策略

<a id="p0088"></a>
**P0088** 目标：拿利润，不追求大自然流

<a id="p0089"></a>
**P0089** 利润款分为两个档次：

<a id="p0090"></a>
**P0090** 档次 1：略高于中位数（$38 ~ $45）

<a id="p0091"></a>
**P0091** • 广告出单 CPA 不一定比流量款差很多；

<a id="p0092"></a>
**P0092** • CTR 会略低，但在可接受范围；

<a id="p0093"></a>
**P0093** • 可以通过一定的广告亏损换自然位，但主要靠广告出单盈利；

<a id="p0094"></a>
**P0094** 档次 2：远高于中位数（$55 ~ $90）

<a id="p0095"></a>
**P0095** • CTR 会大幅下降；

<a id="p0096"></a>
**P0096** • CTR 低 → CPC 被亚马逊拉高 → CPA 爆掉；

<a id="p0097"></a>
**P0097** • 基本告别有效自然流；

<a id="p0098"></a>
**P0098** 利润款的流量来源：

<a id="p0099"></a>
**P0099** 1. **广告流（SB/SBB/SD 为主）**：这些广告类型不受 CTR 影响竞价（不像 SP 那样被排名推高竞价），适合高单价产品；

<a id="p0100"></a>
**P0100** 2. **品牌搜索词/品牌旗舰店**：有品牌效应后才有的流量通道；

<a id="p0101"></a>
**P0101** 3. **少量自然流**：会有，但不用大力去推；

<a id="p0102"></a>
**P0102** 利润款常见错误：

<a id="p0103"></a>
**P0103** • 既要高利润，又想要大自然流，还想广告跑出好数据 → 三者不可兼得；

<a id="p0104"></a>
**P0104** • 没有品牌效应就做高单价利润款 → 广告亏、自然流也没有；

<a id="p0105"></a>
**P0105** • 把流量款价格竞品的价格 $29.99，自己定 $39.99（材质好一点） → CTR 低 → CPC 涨 → CPA 爆；

<a id="p0106"></a>
**P0106** SB/SBB/SD 对高单价利润款的帮助：

<a id="p0107"></a>
**P0107** • SP 广告竞价会被 CTR 拉高（表现差则 CPC 贵）；

<a id="p0108"></a>
**P0108** • SB/SBB/SD 广告竞价相对稳定，不会因为 CTR 低而大幅被推高；

<a id="p0109"></a>
**P0109** • 所以高单价产品用 SB/SBB/SD 可以买到相对低 CPA 的广告单；

<a id="p0110"></a>
**P0110** （四）品牌视图的细分市场应用

<a id="p0111"></a>
**P0111** 搜索绩效表现里面有品牌视图（不是 ASIN 视图）：

<a id="p0112"></a>
**P0112** • 品牌视图可以看到该品牌下几百个流量词（比 ASIN 视图的 100 个更多）；

<a id="p0113"></a>
**P0113** • 可以发现细分市场（如某个词群代表一个细分人群）；

<a id="p0114"></a>
**P0114** • 根据不同细分市场的商品价格中位数，判断哪个细分定价区间最有机会；

<a id="p0115"></a>
**P0115** 四、产品推广难度预估（七个维度）

<a id="p0116"></a>
**P0116** 以下因素综合决定一个产品的推广难度：

<a id="p0117"></a>
**P0117** 维度一：流量离散程度

<a id="p0118"></a>
**P0118** • 流量越集中：新品白帽推广越难（集中型流量 CTR 竞争激烈、大词竞价高）；老链接越好守；

<a id="p0119"></a>
**P0119** • 流量越分散：新品白帽推广越容易；老链接竞争压力相对较小；

<a id="p0120"></a>
**P0120** 维度二：流量入口垄断程度

<a id="p0121"></a>
**P0121** 流量入口垄断：竞对已经有品牌词流量，且有旗舰店自然流。

<a id="p0122"></a>
**P0122** • 竞对有品牌词 → 这批流量你很难拿；

<a id="p0123"></a>
**P0123** • 自己做出品牌效应 → 也能有一批专属流量通道；

<a id="p0124"></a>
**P0124** 维度三：同质化程度

<a id="p0125"></a>
**P0125** 同质化程度越高越难推：

<a id="p0126"></a>
**P0126** • 有效自然位（坑位数量）越少（竞争激烈）；

<a id="p0127"></a>
**P0127** • TOS 竞价越贵（大家都在抢 TOS）；

<a id="p0128"></a>
**P0128** • 得靠价格和评论数量来竞争；

<a id="p0129"></a>
**P0129** 新品切同质化市场的建议：

<a id="p0130"></a>
**P0130** • 不要让买家为你的差异化支付溢价（功能/款式比别人好，但价格不涨）；

<a id="p0131"></a>
**P0131** • 靠这种差异化可能在词下面形成迭代；

<a id="p0132"></a>
**P0132** 注意：同质化产品迭代越慢，老品越好守；迭代越快，新品机会越大。

<a id="p0133"></a>
**P0133** 判断迭代速度：看老链接是不是还在靠广告大量买流量 → 是 → 说明迭代慢，老品权重高，新品很难进。

<a id="p0134"></a>
**P0134** 维度四：CPA vs 利润的关系

<a id="p0135"></a>
**P0135** CPA 比利润高得越多 → 推广风险越大 → 高风险理财型产品

<a id="p0136"></a>
**P0136** | CPA 与利润关系 | 推广选项 |

<a id="p0137"></a>
**P0137** |---|---|

<a id="p0138"></a>
**P0138** | CPA >> 利润 | 只能投资型广告；只能做预期坑产；风险极高 |

<a id="p0139"></a>
**P0139** | CPA ≈ 利润 | 广告基本平本；可做实际坑产或预期坑产 |

<a id="p0140"></a>
**P0140** | CPA < 利润 | 广告本身盈利；三种方式都可选；风险最低 |

<a id="p0141"></a>
**P0141** 结论：

<a id="p0142"></a>
**P0142** • 白帽卖家倾向于中高客单价的半标/非标（这类产品 CPA 更容易低于利润）；

<a id="p0143"></a>
**P0143** • 中低客单价标品 → 黑帽卖家往往更占优势（刷单成本低于广告成本）；

<a id="p0144"></a>
**P0144** 维度五：链接自身优势

<a id="p0145"></a>
**P0145** 产品本身决定链接约 70% 的上限：

<a id="p0146"></a>
**P0146** • 价格优势；

<a id="p0147"></a>
**P0147** • 评分（星级）；

<a id="p0148"></a>
**P0148** • CTR/CVR（坑产自然位天花板）；

<a id="p0149"></a>
**P0149** 如果链接已卡在瓶颈位，先看链接有没有优化空间（价格/评论/主图/文案等），再去谈广告放量。

<a id="p0150"></a>
**P0150** 维度六：目标销量

<a id="p0151"></a>
**P0151** • 目标销量越高 → 推广越难；

<a id="p0152"></a>
**P0152** • 目标销量越低 → 相对越好推（很多方式都可以达到）；

<a id="p0153"></a>
**P0153** 维度七：推广预算（TACoS 空间）

<a id="p0154"></a>
**P0154** 推广预算的衡量不是绝对值，而是 TACoS 上限：

<a id="p0155"></a>
**P0155** | TACoS 与 ACoS 差距 | 推广难度 |

<a id="p0156"></a>
**P0156** |---|---|

<a id="p0157"></a>
**P0157** | ACoS = 80%，TACoS = 10% | 需要 7 个自然单养 1 个广告单，极难 |

<a id="p0158"></a>
**P0158** | ACoS = 30%，TACoS = 10% | 广告单可占约 33%，压力较小 |

<a id="p0159"></a>
**P0159** | ACoS = 20%，TACoS = 15% | 广告单可占约 75%，轻松很多 |

<a id="p0160"></a>
**P0160** | ACoS ≤ TACoS | 广告随便花，推广最轻松 |

<a id="p0161"></a>
**P0161** 结论：TACoS 与 ACoS 差距越小 → 推广越难；差距越大（ACoS 低）→ 推广越轻松。

<a id="p0162"></a>
**P0162** 五、产品 CPA 预估的三种情形

<a id="p0163"></a>
**P0163** 情形一：CPA 远大于利润（高风险投资型）

<a id="p0164"></a>
**P0164** 举例：售价 $17.99，利润 $8，市调 CPA 估算 $14 ~ $20。

<a id="p0165"></a>
**P0165** 推广策略：

<a id="p0166"></a>
**P0166** 1. **只做投资型广告，全押 10 分准词**（10 分词最有可能正向干预自然位）；

<a id="p0167"></a>
**P0167** 2. **定好总亏损额度**（不要无限制亏）；

<a id="p0168"></a>
**P0168** 3. **找替代推广通道**：低单价刚需产品考虑超低价（降价直接出单，出单成本可能更低）、站外送等方式；

<a id="p0169"></a>
**P0169** 4. **不要盲目推大词**（亏不出结果）；

<a id="p0170"></a>
**P0170** 5. **CPA 偏高时先压 CPA，再放量**；

<a id="p0171"></a>
**P0171** 新品特别注意：不要新品上来就猛怼大词，CTR 差 → CPC 被拉高 → 越打越贵。

<a id="p0172"></a>
**P0172** 总亏损额度的计算：

<a id="p0173"></a>
**P0173** • 先定好愿意投入多少；

<a id="p0174"></a>
**P0174** • 广告单亏损 = (CPA − 利润) × 广告单量；

<a id="p0175"></a>
**P0175** • 亏损额度用完了就停，想好下一步再继续；

<a id="p0176"></a>
**P0176** 情形二：CPA ≈ 利润（平本型）

<a id="p0177"></a>
**P0177** 举例：售价 $66，利润 $20，预估 CPA $18 ~ $25。

<a id="p0178"></a>
**P0178** 推广选项：

<a id="p0179"></a>
**P0179** 方向 1：做实际坑产

<a id="p0180"></a>
**P0180** • 买平本广告 → 大量出单 → 总单量带动所有收录词的自然位；

<a id="p0181"></a>
**P0181** • 关键：总单量要够（一天 10 单不够，得给足够单量）；

<a id="p0182"></a>
**P0182** • 关键：ACoS 要维持在平本水平放量（不是随便买）；

<a id="p0183"></a>
**P0183** 方向 2：做预期坑产

<a id="p0184"></a>
**P0184** • 推自然位 → 需要 CTR/CVR 有优势；

<a id="p0185"></a>
**P0185** • 先测预期坑产，卡在某位后转实际坑产；

<a id="p0186"></a>
**P0186** 方向 3：清货

<a id="p0187"></a>
**P0187** • 产品实在卖不动 → 降价/买广告单慢慢清掉；

<a id="p0188"></a>
**P0188** 情形三：CPA < 利润（低风险/盈利型）

<a id="p0189"></a>
**P0189** 举例：利润 $40，预估 CPA $27 ~ $45（可能低于利润）。

<a id="p0190"></a>
**P0190** 推广选项最多：

<a id="p0191"></a>
**P0191** 方向 1：做预期坑产（老老实实推自然位）

<a id="p0192"></a>
**P0192** 方向 2：做实际坑产（靠总单量撑自然位）

<a id="p0193"></a>
**P0193** 方向 3：直接做广告盈利单量（不在乎自然位，靠低 CPA 广告流直接赚利润）

<a id="p0194"></a>
**P0194** 结论：CPA 越低（相对利润），推广选项越多，越主动；CPA 越高，越被动，选项越少。

<a id="p0195"></a>
**P0195** 六、推广计划：从测款到放量

<a id="p0196"></a>
**P0196** （一）新品推广路径示例

<a id="p0197"></a>
**P0197** | 时间 | 花费 | CPA | CVR | 说明 |

<a id="p0198"></a>
**P0198** |---|---|---|---|---|

<a id="p0199"></a>
**P0199** | 第 1 周 | $250 | $30 | 2% | 测款阶段，数据很差，不放量 |

<a id="p0200"></a>
**P0200** | 第 2 周 | $800 | $16 | 正常 | 测出正常数据，开始放量 |

<a id="p0201"></a>
**P0201** | 第 3 周 | $1,500 | $16 | 正常 | 继续放量，CPA 稳定 |

<a id="p0202"></a>
**P0202** | 第 4 周 | $1,700 | $16 | 正常 | 持续放量 |

<a id="p0203"></a>
**P0203** 关键：放量的同时 CPA 必须稳定。

<a id="p0204"></a>
**P0204** 如果放量时 CPA 同步上涨 → 运营问题（找不到稳定放量通道 / 只会靠加竞价放量）。

<a id="p0205"></a>
**P0205** 正确的放量方式：一边增加花费，CPA 保持不变。

<a id="p0206"></a>
**P0206** （二）老品优化路径示例

<a id="p0207"></a>
**P0207** | 时期 | CPC | CVR | CPA |

<a id="p0208"></a>
**P0208** |---|---|---|---|

<a id="p0209"></a>
**P0209** | 10 月（旺季前）| $1.54 | 8% | 偏高 |

<a id="p0210"></a>
**P0210** | 11 月（进入旺季，开始优化）| $1.3 | 8% | $16 |

<a id="p0211"></a>
**P0211** | 12 月（旺季高峰）| $1.2（旺季压价）| 12% | $9+ |

<a id="p0212"></a>
**P0212** | 1-2 月（淡季）| $1.3（稍抬回来）| 10% | $11-$12 |

<a id="p0213"></a>
**P0213** 说明：

<a id="p0214"></a>
**P0214** • 旺季 → CPC 可以压低，CVR 自然提升；

<a id="p0215"></a>
**P0215** • 淡季 → CPC 需要稍微抬回来；

<a id="p0216"></a>
**P0216** • 优化完成后，CPA 应该稳定在固定值（如 $11 上下），不应大幅波动；

<a id="p0217"></a>
**P0217** （三）旺季进价变动规律

<a id="p0218"></a>
**P0218** • 投资型广告为主的产品：旺季竞价可以下压（不需要随流量涨竞价，广告不是目标）；

<a id="p0219"></a>
**P0219** • 盈利型广告为主的产品：旺季预算随流量上升，竞价不动或略涨；

<a id="p0220"></a>
**P0220** 所以：旺季不太可能因为进入旺季而需要大幅上涨竞价。

<a id="p0221"></a>
**P0221** 七、放量方向：流量驱动 vs 转化驱动

<a id="p0222"></a>
**P0222** （一）先测款，再选择方向

<a id="p0223"></a>
**P0223** 不管选哪种放量方向，都需要先测表现：

<a id="p0224"></a>
**P0224** • 表现好 → 决定走流量驱动还是转化驱动；

<a id="p0225"></a>
**P0225** • 表现不好 → 先优化表现（价格/主图/文案）再测；

<a id="p0226"></a>
**P0226** （二）流量驱动型

<a id="p0227"></a>
**P0227** 适用情况：

<a id="p0228"></a>
**P0228** • 预算充足；

<a id="p0229"></a>
**P0229** • 产品承接能力有信心；

<a id="p0230"></a>
**P0230** • 时间较短（想快速拿到市场份额）；

<a id="p0231"></a>
**P0231** 核心做法：

<a id="p0232"></a>
**P0232** 1. 冲着大词直接干 → 测出表现后放量；

<a id="p0233"></a>
**P0233** 2. 根据 CPR 计算每天需要干预多少单：

<a id="p0234"></a>
**P0234** • CPR = 当词大盘 CPR 数值；

<a id="p0235"></a>
**P0235** • 每天所需单量 ≈ CPR ÷ 8；

<a id="p0236"></a>
**P0236** • 每天需要的预算 ≈ 每天单量 × CPA；

<a id="p0237"></a>
**P0237** 举例（showerhead）：

<a id="p0238"></a>
**P0238** • 大词 CPR 合计 895（617 + 278）；

<a id="p0239"></a>
**P0239** • 每天需要约 895 ÷ 8 ≈ 112 单；

<a id="p0240"></a>
**P0240** • 每天预算 ≈ 112 × $15 = $1,680；

<a id="p0241"></a>
**P0241** 常见于黑帽卖家（刷单精准控量）；白帽版需要表现好才能走流量驱动。

<a id="p0242"></a>
**P0242** （三）转化驱动型

<a id="p0243"></a>
**P0243** 适用情况：

<a id="p0244"></a>
**P0244** • 预算有限；

<a id="p0245"></a>
**P0245** • 追求稳定发展；

<a id="p0246"></a>
**P0246** • 测试周期较长；

<a id="p0247"></a>
**P0247** • 不确定哪个方向更好；

<a id="p0248"></a>
**P0248** 核心做法：

<a id="p0249"></a>
**P0249** 1. 先找到哪些词/哪些广告位是正向干预的；

<a id="p0250"></a>
**P0250** 2. 用预算除以 CPA，算出一天能出多少单；

<a id="p0251"></a>
**P0251** 3. 找到单量能干预动的词去打（小词 or 长尾词）；

<a id="p0252"></a>
**P0252** 举例（预算 $300/天，CPA $15）：

<a id="p0253"></a>
**P0253** • 一天能出 20 单；

<a id="p0254"></a>
**P0254** • 20 单拉不动大词（CPR 112 单/天）；

<a id="p0255"></a>
**P0255** • 先找长尾词/二级词覆盖 → 用二级词广泛去干（如 "showerhead filter"），覆盖约 197 个词；

<a id="p0256"></a>
**P0256** • 等这批词拿到站位后，再逐步往大词发育；

<a id="p0257"></a>
**P0257** 八、流量词分批测试的实操方法

<a id="p0258"></a>
**P0258** （一）根据词根批量覆盖

<a id="p0259"></a>
**P0259** 流量分散型产品（词根多）：

<a id="p0260"></a>
**P0260** 1. 把所有词根归类（核心词根 4-5 个）；

<a id="p0261"></a>
**P0261** 2. 每个词根开一个广泛活动；

<a id="p0262"></a>
**P0262** 3. 每个活动分别测这个词根的所有长尾词的表现；

<a id="p0263"></a>
**P0263** 举例（吹尘器产品）：

<a id="p0264"></a>
**P0264** • 词根 1："compressed air" → 广泛覆盖，覆盖量 15 万、208 个词；

<a id="p0265"></a>
**P0265** • 词根 2："air duster" → 广泛覆盖，覆盖量 18 万；

<a id="p0266"></a>
**P0266** • 词根 3："blower" → 广泛覆盖，继续测；

<a id="p0267"></a>
**P0267** 用颜色标注在准词表上 → 看哪些词被覆盖、哪些没有 → 没有的考虑是否补测。

<a id="p0268"></a>
**P0268** （二）流量集中型产品

<a id="p0269"></a>
**P0269** 大词占 70% 以上的产品（如纸盘 "paper plate"）：

<a id="p0270"></a>
**P0270** 活动架构：

<a id="p0271"></a>
**P0271** 1. **活动一**：大词精准（如 "paper plate" 精准）；

<a id="p0272"></a>
**P0272** 2. **活动二（可选）**：第二大词精准；

<a id="p0273"></a>
**P0273** 3. **活动三**：showerhead 广泛 + 精准否大词（跑剩余长尾词）；

<a id="p0274"></a>
**P0274** 这样三个活动可以完整覆盖大词和剩余词。

<a id="p0275"></a>
**P0275** （三）流量相对集中型产品

<a id="p0276"></a>
**P0276** 大词加起来 20-40% 的产品（如 showerhead）：

<a id="p0277"></a>
**P0277** 活动架构：

<a id="p0278"></a>
**P0278** 1. **活动一**：大词精准一；

<a id="p0279"></a>
**P0279** 2. **活动二**：大词精准二；

<a id="p0280"></a>
**P0280** 3. **活动三**：showerhead 广泛 + 精准否大词（覆盖剩余 30 万搜索量的词）；

<a id="p0281"></a>
**P0281** 可替代方案：活动三改为 Auto + 精准否大词（更省事）。

<a id="p0282"></a>
**P0282** （四）测试关键原则

<a id="p0283"></a>
**P0283** 不管哪种产品，测试阶段：

<a id="p0284"></a>
**P0284** 1. 不要开太多活动（保持简洁）；

<a id="p0285"></a>
**P0285** 2. 每批词对应一个活动，分批测；

<a id="p0286"></a>
**P0286** 3. 测出表现后再放量；

<a id="p0287"></a>
**P0287** 4. 确认正向干预后再加花费；

<a id="p0288"></a>
**P0288** 九、竞品流量分析（推广前必做）

<a id="p0289"></a>
**P0289** （一）为什么要做竞品流量分析？

<a id="p0290"></a>
**P0290** 直接照搬竞品的成功打法，比自己摸索效率高很多。

<a id="p0291"></a>
**P0291** （二）分析内容

<a id="p0292"></a>
**P0292** 对同类目不同档次销量（日销 1000、700、500、300、100）的竞品各做：

<a id="p0293"></a>
**P0293** 1. **单量构成**：广告单 vs 自然单占比；

<a id="p0294"></a>
**P0294** 2. **广告单构成**：SP / SB / SBV / SD 各占多少；以及打哪类词（准词 / 泛词）；

<a id="p0295"></a>
**P0295** 3. **自然单来源**：流量词数量、词根类型、准词泛词分布；

<a id="p0296"></a>
**P0296** 4. **推广路径判断**：做的是预期坑产 / 实际坑产？靠广告流还是自然流？

<a id="p0297"></a>
**P0297** （三）控制变量法分析

<a id="p0298"></a>
**P0298** 举例（骑行短裤，日销 1000 vs 日销 700 vs 日销 300）：

<a id="p0299"></a>
**P0299** | 竞品 | 日销 | 特征 |

<a id="p0300"></a>
**P0300** |---|---|---|

<a id="p0301"></a>
**P0301** | 头部 A | 1,000 | 拿了所有泛词的高自然位 + 广告占比 40% |

<a id="p0302"></a>
**P0302** | 头部 B | 1,000 | 低价路线 + 高自然占比 + 靠批量词根覆盖 |

<a id="p0303"></a>
**P0303** | 中部 C | 700 | 仅拿批量词的前 10 自然位，纯自然，无广告 |

<a id="p0304"></a>
**P0304** | 中部 D | 300 | 仅拿一个大词的头部自然位，单词取胜 |

<a id="p0305"></a>
**P0305** 控制变量得到结论：

<a id="p0306"></a>
**P0306** • 日销 1000 vs 日销 700（同自然流打法）→ 差 300 单来自广告单；

<a id="p0307"></a>
**P0307** • 日销 700 vs 日销 300（都是纯自然）→ 差在流量词数量和词位置；

<a id="p0308"></a>
**P0308** • 日销 300 → 单靠一个大词头部位置能产出 300 单；

<a id="p0309"></a>
**P0309** （四）根据自己目标单量选择复制对象

<a id="p0310"></a>
**P0310** 先定目标单量：

<a id="p0311"></a>
**P0311** • 日销 100 → 很多方式可以达到（变体流量/词的中下部自然位等）；

<a id="p0312"></a>
**P0312** • 日销 300 → 拿一个大词头部；

<a id="p0313"></a>
**P0313** • 日销 700 → 批量词的前 10 自然位；

<a id="p0314"></a>
**P0314** • 日销 1000 → 头部自然位 + 广告流；

<a id="p0315"></a>
**P0315** 找到与自己 ACoS 和广告单占比匹配的竞品，直接复制其打法。

<a id="p0316"></a>
**P0316** （五）广告单占比参考

<a id="p0317"></a>
**P0317** 调研竞品广告单占比的意义：

<a id="p0318"></a>
**P0318** 如果你的 ACoS = 50%，TACoS = 30% → 广告单占比最多可以 60%。

<a id="p0319"></a>
**P0319** 如果竞品广告单占比 90%，你的 TACoS 限制下复制不了 → 不要盲目照搬。

<a id="p0320"></a>
**P0320** 只复制广告单占比在自己能实现的范围内的竞品打法。

**P0321** 十、推广前调研工作完整流程

<a id="p0322"></a>
**P0322** 至此，推广前的调研工作全部完成：

<a id="p0323"></a>
**P0323** 1. **准词表**：H10 Cerebro 反查头部竞品 → 获取流量词（6-10 分）；

<a id="p0324"></a>

**P0331** 9. **竞品流量分析**：西柚反查竞品，分析单量构成和打法；

<a id="p0332"></a>
**P0332** 10. **确定放量方向**：流量驱动 / 转化驱动；

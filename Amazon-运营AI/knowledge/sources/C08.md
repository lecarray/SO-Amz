**P0002** 流量词与投放词、全词表制作、匹配方式原理、词根分类与投放预判

<a id="p0003"></a>
**P0003** 说话人2（宋之老师） 00:12

<a id="p0004"></a>
**P0004** 前面已经调研完了流量词——流量词就是我们希望去加权的词。到了我们的后台，就没有流量词了，后台叫"投放词"，所以我们这里要搞清楚投放词跟流量词的关系。

<a id="p0005"></a>
**P0005** 一、流量词 vs 投放词：两码事

<a id="p0006"></a>
**P0006** （一）基本区别

<a id="p0007"></a>
**P0007** | 维度 | 流量词 | 投放词 |

<a id="p0008"></a>
**P0008** |---|---|---|

<a id="p0009"></a>
**P0009** | 别名 | 搜索词（Search Term） | 投放词（Targeting） |

<a id="p0010"></a>
**P0010** | 作用 | 买家实际搜索的词，加权针对流量词 | 后台操作的词，是触发手段 |

<a id="p0011"></a>
**P0011** | 数量关系 | 一个流量词 ← 多个投放词触发 | 一个投放词 → 触发多个流量词 |

<a id="p0012"></a>
**P0012** 核心结论：搜索词是目的，投放词和匹配方式只是手段。

<a id="p0013"></a>
**P0013** 常见误区：

<a id="p0014"></a>
**P0014** • 把流量词直接当投放词往后台放 → 错；

<a id="p0015"></a>
**P0015** • 用 Auto 跑出出单词，把出单词全部扔进去再投 → 还是混淆了两者。

<a id="p0016"></a>
**P0016** （二）加权的归属

<a id="p0017"></a>
**P0017** 买家搜了什么词，点了你，买了你，你就在那个词加权——跟你投什么无关。

<a id="p0018"></a>
**P0018** 举例：买家搜索 ABC → 点击你的广告（不管是 AB 广泛还是 ABC 精准触发的）→ 出单 → 在 ABC 这个词加权。

<a id="p0019"></a>
**P0019** 二、三种广告匹配方式详解

<a id="p0020"></a>
**P0020** （一）广泛匹配

<a id="p0021"></a>
**P0021** 投 AB 广泛：针对的是"A 词根 + B 词根"的所有正序乱序长尾词的打包。

<a id="p0022"></a>
**P0022** • 投放词越短，触发范围越大；

<a id="p0023"></a>
**P0023** • 投放词越长，触发范围越小；

<a id="p0024"></a>
**P0024** 举例：

<a id="p0025"></a>
**P0025** | 投放词（广泛） | 触发范围 |

<a id="p0026"></a>
**P0026** |---|---|

<a id="p0027"></a>
**P0027** | AB | A 词根 + B 词根的所有正序/乱序长尾（含 AB 本身、ABC、ABCD、CAB 等） |

<a id="p0028"></a>
**P0028** | ABC | ABC 的长尾（含 ABC 本身、ABCD 等，范围更小） |

<a id="p0029"></a>
**P0029** | ABCD | ABCD 的长尾（范围更小） |

<a id="p0030"></a>
**P0030** 注意：当投放词很长时，触发量很小 → 亚马逊会帮你往短尾跑（为了让你花出去钱），导致短尾词出现。

<a id="p0031"></a>
**P0031** 解决方法：不要投过长的广泛词。

<a id="p0032"></a>
**P0032** （二）词组匹配

<a id="p0033"></a>
**P0033** 投 AB 词组：跑的是 AB 的正序长尾打包（不包含乱序）。

<a id="p0034"></a>
**P0034** 广泛 vs 词组的区别：只在于有没有乱序。

<a id="p0035"></a>
**P0035** • AB 广泛：AB 正序乱序长尾均有；

<a id="p0036"></a>
**P0036** • AB 词组：AB 正序长尾（无乱序）；

<a id="p0037"></a>
**P0037** 两者范围很接近时：选一个投就够了——千万不要词组和广泛都投，因为它们会重复跑相同的词，互相竞价（一个跑好了另一个就跑不出来）。

<a id="p0038"></a>
**P0038** （三）精准匹配

<a id="p0039"></a>
**P0039** 投 AB 精准：只跑 AB 本身及其单复数、介词形式。

<a id="p0040"></a>
**P0040** 举例：投 "k的 backpacks" 精准：

<a id="p0041"></a>
**P0041** • k的 backpacks 本身；

<a id="p0042"></a>
**P0042** • k的 backpack（单数）；

<a id="p0043"></a>
**P0043** • k的 for backpacks；

<a id="p0044"></a>
**P0044** • k的's backpacks；

<a id="p0045"></a>
**P0045** 精准的范围是最小的——AB 词根，但没有长尾，只有单复数和介词形式。

<a id="p0046"></a>
**P0046** （四）三种匹配方式没有高下之分

<a id="p0047"></a>
**P0047** 三种匹配方式都是范围区分，没有哪个更高贵或更低贱。

<a id="p0048"></a>
**P0048** > 常见误区："我要推自然位，所以只能投精准。"——不对，三个投法都可以，只是范围不同。

<a id="p0049"></a>
**P0049** 三、全词表：用于投放预判

<a id="p0050"></a>
**P0050** （一）全词表 vs 准词表的区别

<a id="p0051"></a>
**P0051** | 维度 | 准词表 | 全词表 |

<a id="p0052"></a>
**P0052** |---|---|---|

<a id="p0053"></a>
**P0053** | 包含内容 | 筛选过表现得分的准词（6-10 分） | 不做得分筛选，所有相关词 |

<a id="p0054"></a>
**P0054** | 用途 | 判断推广重点 / 哪些词可以推 | 预判投放范围 / 做否定预判 |

<a id="p0055"></a>
**P0055** | 制作方法 | H10 Cerebro 反查 + 筛分数 | 同上，但不筛分数 |

<a id="p0056"></a>
**P0056** 操作：把准词表创建一个副本 → 不做表现得分筛选 → 这就是全词表。

<a id="p0057"></a>
**P0057** 更全的全词表：不挑款式/价格，直接放 10 个卖得好的相关 ASIN（可以包含亚马逊自营）→ 扒到更多流量词。

<a id="p0058"></a>
**P0058** （二）全词表的用途

<a id="p0059"></a>
**P0059** 1. **投放预判（核心用途）**：预判投某个词会触发哪些搜索词、范围是否合理；

<a id="p0060"></a>
**P0060** 2. **判断投放范围大小**：扩词用大范围，重点培养用小范围；

<a id="p0061"></a>
**P0061** 3. **提前否定**：找出错词根，提前否定，不要边投边否；

<a id="p0062"></a>
**P0062** 4. **划分活动**（后续放量时使用）。

<a id="p0063"></a>
**P0063** （三）全词表使用方法（投放预判）

<a id="p0064"></a>
**P0064** 工具：WPS 表格（或 Excel）的筛选功能。

<a id="p0065"></a>
**P0065** 操作步骤：

<a id="p0066"></a>
**P0066** 1. 把**投放词**（去掉单复数）放入搜索框；

<a id="p0067"></a>
**P0067** 2. 点左边放大镜，选匹配类型：

<a id="p0068"></a>
**P0068** • 第一个（同时包含所有关键词） = 广泛匹配预判（正序 + 乱序）；

<a id="p0069"></a>
**P0069** • 第三个（包含整个字符串） = 词组匹配预判（正序）；

<a id="p0070"></a>
**P0070** • ~~第二个（包含任意关键词）~~= 后台无对应，不用；

<a id="p0071"></a>
**P0071** 注意：放入投放词时，要去掉介词、冠词、单复数、横杠、终止词。

<a id="p0072"></a>
**P0072** 举例（showerhead 产品）：

<a id="p0073"></a>
**P0073** 投 "showerhead fate for hot water"：

<a id="p0074"></a>
**P0074** • 放入词组选项 → 看词组范围；

<a id="p0075"></a>
**P0075** • 放入广泛选项 → 看广泛范围；

<a id="p0076"></a>
**P0076** • 两者差别不大 → 投词组就可以；

<a id="p0077"></a>
**P0077** • 差别大 → 考虑要不要乱序，要乱序就投广泛；

<a id="p0078"></a>
**P0078** 投长尾词的预判：投 "showerhead with filter for hard water"（很长的词）→ 广泛预判 → 跑不出来 → 这个词别投（投了会往短尾跑，与精准活动竞争，形成内耗）。

<a id="p0079"></a>
**P0079** （四）利用得分辅助否定

<a id="p0080"></a>
**P0080** 在全词表中，低得分词（2 分词）= 错词：

<a id="p0081"></a>
**P0081** 举例：showerhead 产品：

<a id="p0082"></a>
**P0082** • "rain showerhead"（rain shower head）= 2 分词 → 从高处淋下来的花洒头，不是手持的；

<a id="p0083"></a>
**P0083** • 说明 "rain" 这个词根是错词根；

<a id="p0084"></a>
**P0084** 处理方法：否定整个 "rain" 词根（词组否 rain）→ 所有带 rain 的长尾词都否掉。

<a id="p0085"></a>
**P0085** 但要注意：否 "rain" 可能会把 "rainfall"、"rainstorm" 等词也否掉 → 单独再加对应的精确否定。

<a id="p0086"></a>
**P0086** （五）全词表投放预判的完整流程

<a id="p0087"></a>
**P0087** 1. 打开全词表；

<a id="p0088"></a>
**P0088** 2. 放入拟投放词（去掉介词/复数/终止词）；

<a id="p0089"></a>
**P0089** 3. 选广泛预判 → 看能不能跑出词、跑出多少词；

<a id="p0090"></a>
**P0090** 4. 跑不出来 → 这个词别投（投了会往短尾跑）；

<a id="p0091"></a>
**P0091** 5. 跑出来的词里 → 找低分词（2 分）→ 找出错词根 → 加词组否定；

<a id="p0092"></a>
**P0092** 6. 找出品牌词 → 单独列一列（暂不否）；

<a id="p0093"></a>
**P0093** 7. 重复上述步骤完善词库；

<a id="p0094"></a>
**P0094** 四、无效重复投放（重要！）

<a id="p0095"></a>
**P0095** （一）什么叫无效重复投放？

<a id="p0096"></a>
**P0096** 在后台，以下这些投放词的触发范围完全相同，是重复投放：

<a id="p0097"></a>
**P0097** 规则 1：单复数相同

<a id="p0098"></a>
**P0098** • AB 广泛 = ABs 广泛（单复数是一样的）；

<a id="p0099"></a>
**P0099** • AB 词组 = ABs 词组；

<a id="p0100"></a>
**P0100** • AB 精准 = ABs 精准；

<a id="p0101"></a>
**P0101** 规则 2：介词/冠词/终止词相同

<a id="p0102"></a>
**P0102** • AB 广泛 = A for B 广泛（"for" 在后台是终止词，等于空格）；

<a id="p0103"></a>
**P0103** • AB 精准 = A for B 精准；

<a id="p0104"></a>
**P0104** • A-B 广泛 = AB 广泛（横杠也是终止词）；

<a id="p0105"></a>
**P0105** • A + B 广泛 = AB 广泛（加号也是终止词）；

<a id="p0106"></a>
**P0106** 规则 3：乱序词组同广泛

<a id="p0107"></a>
**P0107** AB 广泛 和 BA 广泛 → 触发范围完全一样（都是 A+B 词根的组合）。

<a id="p0108"></a>
**P0108** 举例：

<a id="p0109"></a>
**P0109** 下面这些投放词在广泛匹配下完全等价（不要重复投）：

<a id="p0110"></a>
**P0110** • backpack key

<a id="p0111"></a>
**P0111** • key backpack

<a id="p0112"></a>
**P0112** • backpack key's

<a id="p0113"></a>
**P0113** • key of backpack

<a id="p0114"></a>
**P0114** • backpack-key

<a id="p0115"></a>
**P0115** 规则 4：同匹配方式内不同长度的重复

<a id="p0116"></a>
**P0116** AB 广泛（触发 AB 所有长尾）≠ ABC 广泛（只触发 ABC 的长尾）

<a id="p0117"></a>
**P0117** 但 ABC 广泛 和 ACB 广泛 = 一样（词根顺序不影响广泛匹配）

<a id="p0118"></a>
**P0118** （二）重复投放的危害

<a id="p0119"></a>
**P0119** 左脚踩右脚——互相抬竞价

<a id="p0120"></a>
**P0120** 真实案例：

<a id="p0121"></a>
**P0121** • 某卖家先开了 "白牌K" 精准，给 $2.0 竞价；

<a id="p0122"></a>
**P0122** • 跑出了 "白牌K" 搜索词 → 把它作为投放词又投了一次，给 $2.0；

<a id="p0123"></a>
**P0123** • 新开的 $2.0 跑不过老活动（老活动权重高）；

<a id="p0124"></a>
**P0124** • 新活动加到 $2.5 → 老活动 $2.0 又跑不出来；

<a id="p0125"></a>
**P0125** • 老活动加到 $2.5 → 新活动跑不出来；

<a id="p0126"></a>
**P0126** • 如此循环加到 $14.0！

<a id="p0127"></a>
**P0127** 这就是"左脚踩右脚"——重复投放导致竞价螺旋上升。

<a id="p0128"></a>
**P0128** （三）如何避免重复投放？

<a id="p0129"></a>
**P0129** 1. **方法 1（出单词库检查）**：打开 ERP 出单词库 → 点某个搜索词旁边的小眼睛 → 看这个词在几个投放词/活动里出现 → 是否有重复；

<a id="p0130"></a>
**P0130** 2. **方法 2（全词表预判）**：提前通过全词表判断哪些词是重复的，不投重复词；

<a id="p0131"></a>
**P0131** 3. **方法 3（透视表查询）**：后台下载搜索词报表 → 透视表 → 查匹配类型 + 投放词 → 找出重复；

<a id="p0132"></a>
**P0132** 重复投放的几种状态：

<a id="p0133"></a>
**P0133** • 平摊状态：两个活动各花一半（白白分散）；

<a id="p0134"></a>
**P0134** • 坍缩状态：表现好的那个花得多，另一个高价捡漏（还算有救）；

<a id="p0135"></a>
**P0135** • 最差状态：不知道互相竞争还在加竞价（越加越贵）；

<a id="p0136"></a>
**P0136** 关于瀑布流：如果是故意的层级设计（同词在精准/词组/广泛/Auto 各打各的价位），是可以的；但不小心的重复最好关掉。

<a id="p0137"></a>
**P0137** > 后面会详细讲瀑布流的正确使用方式。

<a id="p0138"></a>
**P0138** 五、否定词的正确用法

<a id="p0139"></a>
**P0139** （一）否定的本质

<a id="p0140"></a>
**P0140** 否定 = 活动内的降权匹配方式——不是删除，是让这个活动更难触发该词。

<a id="p0141"></a>
**P0141** 注意：

<a id="p0142"></a>
**P0142** • 否定只影响该活动，不影响链接整体权重；

<a id="p0143"></a>
**P0143** • 精准否一个词 → 该词及其词根在这个活动内降权（不是灭绝）；

<a id="p0144"></a>
**P0144** • 过度使用精准否定 → 活动跑不出来东西了；

<a id="p0145"></a>
**P0145** （二）两种否定方式

<a id="p0146"></a>
**P0146** | 否定方式 | 触发范围 | 用途 |

<a id="p0147"></a>
**P0147** |---|---|---|

<a id="p0148"></a>
**P0148** | 词组否（Phrase Negative） | 否掉该词的正序长尾词 | 否错词根（最常用） |

<a id="p0149"></a>
**P0149** | 精准否（Exact Negative） | 否掉该词本身（及单复数/介词形式） | 否某个具体的差词 |

<a id="p0150"></a>
**P0150** 注意：没有"广泛否定"这一说法。

<a id="p0151"></a>
**P0151** （三）三种否定应用场景

<a id="p0152"></a>
**P0152** 场景 1：批量否错词根（最高效）

<a id="p0153"></a>
**P0153** 当某个词根是错的 → 词组否定这个词根。

<a id="p0154"></a>
**P0154** 举例：showerhead 产品不带过滤器：

<a id="p0155"></a>
**P0155** • "filter" 词根是错词根 → 词组否 "filter" → 所有带 filter 的词都否掉；

<a id="p0156"></a>
**P0156** 举例：手持花洒头不是顶喷的：

<a id="p0157"></a>
**P0157** • "rain" 词根是错词根 → 词组否 "rain" → 但注意 "rainfall" 要单独精准否；

<a id="p0158"></a>
**P0158** 关键原则：不要精准否错词根的长词（如精准否 "rain showerhead"），因为会影响 showerhead 本身的权重。要否的是词根 "rain"，用词组否。

<a id="p0159"></a>
**P0159** 场景 2：差词精准否（单个词表现差）

<a id="p0160"></a>
**P0160** 当某个词不是词根的问题，就是这个词本身跑出来效果差 → 精准否定该词。

<a id="p0161"></a>
**P0161** 这是唯一应该大量用精准否的场景。

<a id="p0162"></a>
**P0162** 场景 3：范围划分

<a id="p0163"></a>
**P0163** 人为圈定一个特定的触发范围。

<a id="p0164"></a>
**P0164** 举例：想只跑 ABC 的长尾词，不跑 ABC 本身：

<a id="p0165"></a>
**P0165** • 投 ABC 广泛；

<a id="p0166"></a>
**P0166** • 精准否 ABC 本身；

<a id="p0167"></a>
**P0167** • 剩余触发范围 = ABC 正序乱序长尾（去掉 ABC 本身）；

<a id="p0168"></a>
**P0168** 这种用法在后续分活动/搭广告结构时经常用到。

<a id="p0169"></a>
**P0169** （四）不建议的否定方式：边投边否

<a id="p0170"></a>
**P0170** 坚决不要：开了 Auto → 跑出出单词 AB → 拿 AB 去投精准 → 然后在 Auto 里精准否 AB。

<a id="p0171"></a>
**P0171** 这种做法的问题：

<a id="p0172"></a>
**P0172** 1. 极度麻烦；

<a id="p0173"></a>
**P0173** 2. 精准否用多了 → 活动慢慢跑不出来东西；

<a id="p0174"></a>
**P0174** 3. 词根之间加权和降权是相互的 → 精准否 ABC 多了以后，AB 相关词也跑不出来；

<a id="p0175"></a>
**P0175** 4. 后续想把词回到广泛里跑 → 还要把否定放出来，非常麻烦；

<a id="p0176"></a>
**P0176** 5. 如果不是用自动调控软件操作，这种方式时间投入产出比非常低；

<a id="p0177"></a>
**P0177** 六、分数字符在投放中的特殊处理

<a id="p0178"></a>
**P0178** 问题：怎么跑出 "1/2 inch" 这样的分数形式？

<a id="p0179"></a>
**P0179** • 斜杠（/）在亚马逊后台是终止词（相当于空格）；

<a id="p0180"></a>
**P0180** • 想跑 "1/2 inch" → 投 "1 2 inch"（1 空格 2 空格 inch）即可；

<a id="p0181"></a>
**P0181** • 投 "2 inch" 广泛 → 也能跑出 "1/2 inch"（因为 1/2 inch = 1 和 2 inch 的组合）；

<a id="p0182"></a>
**P0182** • 想否 "1/2 inch" → 精准否 "1"（自主否一个词根）即可；

<a id="p0183"></a>
**P0183** 七、流量词解构：词根分类体系

<a id="p0184"></a>
**P0184** （一）为什么要解构词根？

<a id="p0185"></a>
**P0185** 解构原因：一个流量词可以有很多种投放方式触发。

<a id="p0186"></a>
**P0186** 举例：流量词 ABCD，可以通过以下投放触发：

<a id="p0187"></a>
**P0187** • AB 广泛；

<a id="p0188"></a>
**P0188** • ABC 广泛；

<a id="p0189"></a>
**P0189** • ABCD 广泛；

<a id="p0190"></a>
**P0190** • ABCD 精准；

<a id="p0191"></a>
**P0191** • Auto；

<a id="p0192"></a>
**P0192** • ……

<a id="p0193"></a>
**P0193** 与其纠结具体投哪个词，不如先把词根解构出来，再自由组合。

<a id="p0194"></a>
**P0194** （二）词根的四个分类

<a id="p0195"></a>
**P0195** 1. 核心词（Core Keywords）

<a id="p0196"></a>
**P0196** 定义：描述你产品最短的、不可再被缩短的词根。

<a id="p0197"></a>
**P0197** • 搜索结果必须是同类产品；

<a id="p0198"></a>
**P0198** • 不可再被缩短（再短就不是这个东西了）；

<a id="p0199"></a>
**P0199** • 一般由较少的单词组成；

<a id="p0200"></a>
**P0200** 举例：

<a id="p0201"></a>
**P0201** • 瑜伽垫 → "yoga mat"（核心词）；

<a id="p0202"></a>
**P0202** • 淋浴头 → "showerhead"（核心词，注意连写和分开写是两个词根）；

<a id="p0203"></a>
**P0203** • 游戏耳机 → "gaming headset"（核心词）；

<a id="p0204"></a>
**P0204** 注意：如果一个产品有组合型核心词（如防水手机袋 = waterproof + phone + case），则需要把三个词根分别收集。

<a id="p0205"></a>
**P0205** 验证方法：到搜索框搜索这个词 → 搜索结果是否都是同类产品。

<a id="p0206"></a>
**P0206** 举例：搜 "shower" → 结果五花八门（各种配件）→ "shower" 是上位词，不是核心词；搜 "showerhead" → 都是淋浴头 → "showerhead" 是核心词。

<a id="p0207"></a>
**P0207** 核心词分为：

<a id="p0208"></a>
**P0208** • 强相关核心词：用来拓准词、测准词；

<a id="p0209"></a>
**P0209** • 弱相关核心词：用来拓泛词、测泛词；

<a id="p0210"></a>
**P0210** 核心词的验证：把核心词放入全词表做广泛预判 → 应该能覆盖你准词表里大部分词 → 盖不到的就是缺少的核心词，补收集。

<a id="p0211"></a>
**P0211** 2. 上位词（Category Keywords）

<a id="p0212"></a>
**P0212** 定义：比核心词更短、含义更泛的词（上位概念）。

<a id="p0213"></a>
**P0213** 举例：

<a id="p0214"></a>
**P0214** • 淋浴头（showerhead）的上位词 = "shower"；

<a id="p0215"></a>
**P0215** • 瑜伽垫（yoga mat）的上位词 = "mat"；

<a id="p0216"></a>
**P0216** 上位词的作用：

<a id="p0217"></a>
**P0217** 1. **跟词扩展成一级词**（对于一些组合型核心词）；

<a id="p0218"></a>
**P0218** 2. **否定上位词**（投 Auto 时上位词一定会跑出来，如果不准则精准否）；

<a id="p0219"></a>
**P0219** 3. **成熟期拓泛词**（后期可以用上位词去拓更泛的词，竞价低给 $0.5 左右）；

<a id="p0220"></a>
**P0220** 举例：投 "shower"（上位词）广泛 → 能触发 8,340 个词 → 范围极广，成熟期用。

<a id="p0221"></a>
**P0221** 3. 属性词 / 非核心词（Modifier Keywords）

<a id="p0222"></a>
**P0222** 定义：描述核心词的形容词/限定词，单独存在没有意义。

<a id="p0223"></a>
**P0223** 包含：

<a id="p0224"></a>
**P0224** • 人群词：girl、kids、men、women 等；

<a id="p0225"></a>
**P0225** • 场景词：outdoor、for bathroom、for hard water 等；

<a id="p0226"></a>
**P0226** • 功能词：handheld、high pressure、adjustable 等；

<a id="p0227"></a>
**P0227** • 材质词：stainless steel、aluminum 等；

<a id="p0228"></a>
**P0228** • 颜色词（可能是错词，单独列）；

<a id="p0229"></a>
**P0229** 属性词的处理原则：

<a id="p0230"></a>
**P0230** • 对的属性词 → 全部埋到文案里；

<a id="p0231"></a>
**P0231** • 错的属性词 → 词组否定（错词根）；

<a id="p0232"></a>
**P0232** • 中立属性词（不确定对错）→ 不否不投，看实际数据；

<a id="p0233"></a>
**P0233** 4. 否定词（Negative Keywords）

<a id="p0234"></a>
**P0234** 定义：触发出来但不是你产品的词根。

<a id="p0235"></a>
**P0235** 举例：手持花洒头（不是顶喷型）→ "rain"（rain showerhead 是顶喷）→ 否定词。

<a id="p0236"></a>
**P0236** 否定词的来源：

<a id="p0237"></a>
**P0237** • 全词表里的低分词（2 分词）；

<a id="p0238"></a>
**P0238** • 以往搜索词报表里的差词；

<a id="p0239"></a>
**P0239** （三）品牌词和竞品词的处理

<a id="p0240"></a>
**P0240** 品牌词单独列一列——是中性词，可能表现好也可能不好：

<a id="p0241"></a>
**P0241** • 先不投也不否；

<a id="p0242"></a>
**P0242** • 跑出来以后看数据 → 好的可以继续投，不好的否掉；

<a id="p0243"></a>
**P0243** 竞品品牌词同理：单独收集，后续看数据决定。

<a id="p0244"></a>
**P0244** 八、投放词的一/二/三级分类

<a id="p0245"></a>
**P0245** （一）一级词（核心词直接投放）

<a id="p0246"></a>
**P0246** 定义：直接投你的核心词，覆盖最大范围的准词长尾。

<a id="p0247"></a>
**P0247** 举例：直接投 "showerhead" 广泛 → 触发所有 showerhead 相关长尾。

<a id="p0248"></a>
**P0248** 一级词是主要拓准词的方式。

<a id="p0249"></a>
**P0249** （二）二级词（核心词 + 一个属性词）

<a id="p0250"></a>
**P0250** 定义：核心词 + 1 个非核心词。

<a id="p0251"></a>
**P0251** 举例：

<a id="p0252"></a>
**P0252** • "showerhead with filter" → showerhead（核心词）+ filter（属性词）；

<a id="p0253"></a>
**P0253** • "showerhead high pressure" → showerhead + high pressure；

<a id="p0254"></a>
**P0254** • "showerhead for hard water" → showerhead + hard water（场景词）；

<a id="p0255"></a>
**P0255** 作用：限制触发范围 → 投 "showerhead filter" 广泛，触发的是所有带 showerhead 和 filter 词根的词。

<a id="p0256"></a>
**P0256** （三）三级词（核心词 + 两个及以上属性词）

<a id="p0257"></a>
**P0257** 定义：核心词 + 2 个及以上非核心词。

<a id="p0258"></a>
**P0258** 举例：

<a id="p0259"></a>
**P0259** • "oversize bodycon bandage dress" → bodycon（核心词）+ oversize + bandage（两个属性词）= 三级词；

<a id="p0260"></a>
**P0260** 注意：判断级别看的是词根分类数量，不是单词数量。

<a id="p0261"></a>
**P0261** （四）一/二/三级词的关系

<a id="p0262"></a>
**P0262** • 级别越低（一级词），触发范围越广；

<a id="p0263"></a>
**P0263** • 级别越高（三级词），触发范围越精准；

<a id="p0264"></a>
**P0264** • 初期拓词 → 投一级词/二级词（范围大）；

<a id="p0265"></a>
**P0265** • 精细培养某个词 → 投三/四级词（范围小，更精准）；

<a id="p0266"></a>
**P0266** • 推荐：前期用一级词拓词，不要上来就全投长尾精准；

<a id="p0267"></a>
**P0267** 九、词根表的制作方法

<a id="p0268"></a>
**P0268** （一）手动收集（推荐）

<a id="p0269"></a>
**P0269** 1. 打开准词表（按搜索量倒序）；

<a id="p0270"></a>
**P0270** 2. 从搜索量最大的词开始，逐一提取词根：

<a id="p0271"></a>
**P0271** • 核心词（强相关/弱相关）；

<a id="p0272"></a>
**P0272** • 上位词；

<a id="p0273"></a>
**P0273** • 属性词（人群/场景/功能/材质等）；

<a id="p0274"></a>
**P0274** • 否定词；

<a id="p0275"></a>
**P0275** • 品牌词（单独列）；

<a id="p0276"></a>
**P0276** 3. 发现重复词根 → 不重复收集；

<a id="p0277"></a>
**P0277** 4. 搜索量下降到 1,000 左右时 → 差不多收集完了（越往下词根越小）；

<a id="p0278"></a>
**P0278** 技巧：越往上的词根越重要（覆盖量大），越往下词根越小。

<a id="p0279"></a>
**P0279** （二）AI 工具辅助（补充）

<a id="p0280"></a>
**P0280** 手动收集完核心词后 → 用 AI 工具（Claude/GPT）辅助分类属性词。

<a id="p0281"></a>
**P0281** 操作：

<a id="p0282"></a>
**P0282** 1. 把准词表扔给 AI + 配置提示词；

<a id="p0283"></a>
**P0283** 2. AI 自动分类核心词/上位词/属性词等；

<a id="p0284"></a>
**P0284** 3. 注意：AI 分的核心词容易出问题 → **核心词要自己手动收集确认，其余让 AI 分类**。

<a id="p0285"></a>
**P0285** （三）词根表验算

<a id="p0286"></a>
**P0286** 目的：确认核心词是否覆盖全了准词表。

<a id="p0287"></a>
**P0287** 操作：

<a id="p0288"></a>
**P0288** 1. 在全词表里搜第一个核心词（广泛预判）→ 标颜色（黄色）；

<a id="p0289"></a>
**P0289** 2. 搜第二个核心词 → 标颜色；

<a id="p0290"></a>
**P0290** 3. 清除筛选后 → 白底的就是核心词没覆盖到的词；

<a id="p0291"></a>
**P0291** 4. 白底词里 → 找新的核心词 → 补收集；

<a id="p0292"></a>
**P0292** 5. 循环直到白底词越来越少；

<a id="p0293"></a>
**P0293** 注意：太小的词根（如一些 5-6 分的弱相关词）可以先不管，它们会靠实际坑产自然带出来。

<a id="p0004"></a>
**P0004** 一、广告位缩放量应用

<a id="p0005"></a>
**P0005** （一）缩放量的核心原则

<a id="p0006"></a>
**P0006** 放量 = 让目标广告位花费更多 = 提高该位置的竞价

<a id="p0007"></a>
**P0007** 缩量 = 让目标广告位花费更少 = 降低该位置的竞价

<a id="p0008"></a>
**P0008** 关键思路：看到某个位置表现差，不要去给 TOS 加价，而要把差位置的竞价降低。

<a id="p0009"></a>
**P0009** 举例：某活动三个广告位中 TOS 的 ACoS 是 20%，PP 是 90%，ROS 是 100% → 目标是只保留 TOS 的预算 → 不加 TOS 竞价，而是降低 PP 和 ROS 的竞价，把预算让出来给 TOS。

<a id="p0010"></a>
**P0010** （二）实现只跑 TOS 位置

<a id="p0011"></a>
**P0011** 条件：

<a id="p0012"></a>
**P0012** • TOS 竞价 ≥ C 竞价（能稳定跑到 TOS）；

<a id="p0013"></a>
**P0013** • ROS 竞价 < B 竞价（跑不起 ROS）；

<a id="p0014"></a>
**P0014** • PP 竞价 < A 竞价（跑不起 PP）；

<a id="p0015"></a>
**P0015** 计算步骤：

<a id="p0016"></a>
**P0016** 假设 ABCD 四档竞价已知：A = $1.0，B = $1.3，C = $1.6，D = $2.0

<a id="p0017"></a>
**P0017** 目标：只跑 TOS（需要 TOS ≥ C = $1.6，PP / ROS < A = $1.0）

<a id="p0018"></a>
**P0018** → 设底价 X < A，即 X < $1.0，取 X = $0.8（打 8 折，安全）

<a id="p0019"></a>
**P0019** → TOS 实际竞价 = X × (1 + Y%) = $1.6

<a id="p0020"></a>
**P0020** → Y% = (1.6 − 0.8) ÷ 0.8 = 100%

<a id="p0021"></a>
**P0021** → 设置：底价 $0.8 + TOS 加价 100%

<a id="p0022"></a>
**P0022** 实操简便方案（一步到位）：

<a id="p0023"></a>
**P0023** 底价 $0.15 + TOS 加价 750% → TOS 实际竞价 = $0.15 × (1 + 750%) = $1.2（刚好达到 TOS 档）

<a id="p0024"></a>
**P0024** 注意：

<a id="p0025"></a>
**P0025** • 广告位加价最高上限是 900%；

<a id="p0026"></a>
**P0026** • 底价不要给得极低（否则整个活动可能跑不出任何数据）；

<a id="p0027"></a>
**P0027** • 建议底价 = A 竞价 × 0.7 ~ 0.8，这样 PP 和 ROS 一定跑不起来，TOS 通过加价达到目标；

<a id="p0028"></a>
**P0028** • 只跑 TOS ≠ 卡位：只跑 TOS 是把预算集中到 TOS；卡位还需要给到 D 竞价；

<a id="p0029"></a>
**P0029** TOS 跑不出来的四种原因：

<a id="p0030"></a>
**P0030** 1. 把 B 竞价误判为 C 竞价（B 竞价偶尔能捡漏到 TOS，但不等于稳定跑 TOS）；

<a id="p0031"></a>
**P0031** 2. 底价 × (1 + TOS 加价%) 的结果未达到 C 竞价（盲加没有算清楚）；

<a id="p0032"></a>
**P0032** 3. 活动使用了"只降低"策略（TOS 表现一般时亚马逊不愿意卖给你）；

<a id="p0033"></a>
**P0033** 4. 底价过低，整个活动跑不出任何数据；

<a id="p0034"></a>
**P0034** （三）TOS 卡位

<a id="p0035"></a>
**P0035** 适用前提：广告本身可以盈利（不建议为卡位而卡位，否则浪费预算）

<a id="p0036"></a>
**P0036** 卡位需要给到 D 竞价（让 TOS 曝光 ≥ ROS 曝光）。

<a id="p0037"></a>
**P0037** 卡位预算估算方法：

<a id="p0038"></a>
**P0038** 以某词为例（周搜索量 29,000，日搜索量约 4,000）：

<a id="p0039"></a>
**P0039** • TOS CTR 约 10% → 需要 400 个点击/天；

<a id="p0040"></a>
**P0040** • CPC 约 $1.23 → 日预算约 $500；

<a id="p0041"></a>
**P0041** 若日曝光只拿到 2,000（目标 4,000），说明没卡满，分析原因：

<a id="p0042"></a>
**P0042** • 预算不够 → 加预算（中午就花完了，下午没有曝光）；

<a id="p0043"></a>
**P0043** • 进价不够 → 往更便宜的时段卡（如凌晨 6 点开始卡，避开竞争最激烈的早高峰）；

<a id="p0044"></a>
**P0044** • 换位置 → 卡 ROS 高位而不是 TOS（花费更少，时间更长）；

<a id="p0045"></a>
**P0045** 理想卡位状态： 在第 2-4 位之间轮播（不是死卡第 1 位）→ 竞价不溢价，效率更高。

<a id="p0046"></a>
**P0046** （四）实现只跑 ROS（不跑 TOS 和 PP）

<a id="p0047"></a>
**P0047** 条件：

<a id="p0048"></a>
**P0048** • TOS 竞价 < C 竞价；

<a id="p0049"></a>
**P0049** • ROS 竞价 ≥ B 竞价；

<a id="p0050"></a>
**P0050** • PP 竞价 < A 竞价；

<a id="p0051"></a>
**P0051** 计算步骤：

<a id="p0052"></a>
**P0052** 设底价 X = A × 0.7 = $0.7

<a id="p0053"></a>
**P0053** ROS 目标竞价 = B = $1.3

<a id="p0054"></a>
**P0054** → Z% = (1.3 − 0.7) ÷ 0.7 ≈ 90%

<a id="p0055"></a>
**P0055** → 设置：底价 $0.7 + ROS 加价 90%（TOS 和 PP 均为 $0.7，无法跑起来）

<a id="p0056"></a>
**P0056** （五）自由组合广告位

<a id="p0057"></a>
**P0057** 可以根据需要任意组合，逻辑一致：

<a id="p0058"></a>
**P0058** • 想要跑的位置 → 竞价 ≥ 对应最低档（B 或 C）；

<a id="p0059"></a>
**P0059** • 不想要跑的位置 → 竞价 < A；

<a id="p0060"></a>
**P0060** 实操举例（只跑 TOS + ROS，不跑 PP）：

<a id="p0061"></a>
**P0061** • 底价 $2.8，TOS 加 100%，ROS 加 100% → 两位置各约 $5.6；

<a id="p0062"></a>
**P0062** • PP 底价 $2.8 能跑 → 说明底价需要继续降；

<a id="p0063"></a>
**P0063** • 降底价后重新计算加价即可；

<a id="p0064"></a>
**P0064** （六）广告位调控总结

<a id="p0065"></a>
**P0065** 操作逻辑：

<a id="p0066"></a>
**P0066** 1. 确定想保留的广告位（比如只要 TOS）；

<a id="p0067"></a>
**P0067** 2. 计算该位置的目标竞价（查 ABCD 档位）；

<a id="p0068"></a>
**P0068** 3. 设底价 = 其他位置跑不起来的最低竞价（A × 0.7~0.8）；

<a id="p0069"></a>
**P0069** 4. 对应加价 = (目标竞价 − 底价) ÷ 底价；

<a id="p0070"></a>
**P0070** 5. 不清楚 ABCD 就慢慢试：底价从低往高加，观察各广告位曝光变化；

<a id="p0071"></a>
**P0071** 二、广告预算的制定与控制

<a id="p0072"></a>
**P0072** （一）TACoS 要先定好

<a id="p0073"></a>
**P0073** 每日可用广告预算 = 总销售额 × TACoS

<a id="p0074"></a>
**P0074** （二）单品单店铺：用账号层级"顶级预算"

<a id="p0075"></a>
**P0075** 路径： 后台 → 设置 → 顶级预算 → 每日预算上限

<a id="p0076"></a>
**P0076** 操作方法：

<a id="p0077"></a>
**P0077** 1. 取近 3 天平均销售额；

<a id="p0078"></a>
**P0078** 2. 乘以 TACoS → 得到初始每日预算上限；

<a id="p0079"></a>
**P0079** 3. 当天实际销售额更高 → 回来加；

<a id="p0080"></a>
**P0080** 4. 当天实际销售额更低 → 回来减；

<a id="p0081"></a>
**P0081** 旺季必做设置： 后台"活动预算增长"选项默认允许超花 100%，必须改为 25%，否则月底会突然花钱飞起。

<a id="p0082"></a>
**P0082** （三）多品单店铺：用广告组合（Portfolio）预算上限

<a id="p0083"></a>
**P0083** 路径： 广告 → 广告组合 → 设置 → 预算上限 → 日期范围上限

<a id="p0084"></a>
**P0084** 操作方法：

<a id="p0085"></a>
**P0085** 1. 把同一产品的所有广告活动放进同一广告组合；

<a id="p0086"></a>
**P0086** 2. 设置开始日期 = 今天，结束日期 = 今天；

<a id="p0087"></a>
**P0087** 3. 每天修改开始日期 → 等效每日预算；

<a id="p0088"></a>
**P0088** 4. 该组合内所有活动总花费达到上限后，全部自动停止；

<a id="p0089"></a>
**P0089** 关键优势：

<a id="p0090"></a>
**P0090** • 单个活动预算不重要，重要的是组合总上限；

<a id="p0091"></a>
**P0091** • 旺季无需担心超花；

<a id="p0092"></a>
**P0092** • 如果花完得早 → 通过调整各活动预算分配来优化；

<a id="p0093"></a>
**P0093** （四）纯利型广告的独立组合

<a id="p0094"></a>
**P0094** 为纯利型广告单独开一个"不限预算组合"：

<a id="p0095"></a>
**P0095** • 正常活动 → 放在"限制预算"组合（根据 TACoS 控制花费）；

<a id="p0096"></a>
**P0096** • 纯利型广告（ACoS < 目标 TACoS）→ 移到"不限预算"组合，无上限放量；

<a id="p0097"></a>
**P0097** • 纯利型广告表现变差 → 移回限制预算组合；

<a id="p0098"></a>
**P0098** 三、利润瓶颈突破的四种方向

<a id="p0099"></a>
**P0099** 利润公式：

<a id="p0100"></a>
**P0100** 总利润 = 总单量 × 客单价 × (定价毛利 − TACoS)

<a id="p0101"></a>
**P0101** 提升利润有四个方向：

<a id="p0102"></a>
**P0102** 方向一：TACoS + 客单价不变 → 提升总单量

<a id="p0103"></a>
**P0103** 子方案 A：广告单和自然单同比例增长

<a id="p0104"></a>
**P0104** TACoS 不变 + ACoS 不变 → 广告单占比不变 → 两者同比例上升。

<a id="p0105"></a>
**P0105** 关键：找更多自然流量入口。

<a id="p0106"></a>
**P0106** 三种找法：

<a id="p0107"></a>
**P0107** 1. **推广洞察表中找盲区**：有准词没打到的词；

<a id="p0108"></a>
**P0108** 2. **拓泛词做收录**：有实际坑产以后，泛词会被带出来；

<a id="p0109"></a>
**P0109** 3. **等季节性流量 / 找潜力词**：搜索量上涨中的词；

<a id="p0110"></a>
**P0110** 子方案 B：降低 ACoS → 广告单占比上升 → 总单量上升

<a id="p0111"></a>
**P0111** 举例：

<a id="p0112"></a>
**P0112** • 原始：TACoS 10%，ACoS 33%，广告单占比 30%，300 单；

<a id="p0113"></a>
**P0113** • ACoS 降到 23%：广告单占比 ≈ 43%，361 单；

<a id="p0114"></a>
**P0114** • 总利润同步上升；

<a id="p0115"></a>
**P0115** 降低 ACoS 的两种手段：

<a id="p0116"></a>
**P0116** 1. **降低 CPC**（对比市调竞价，给高了的往下压）；

<a id="p0117"></a>
**P0117** 2. **提升 CVR**（选择 CPA 低的广告位集中放量，砍掉差位置）；

<a id="p0118"></a>
**P0118** 子方案 C：新搭纯利型广告活动

<a id="p0119"></a>
**P0119** 找到 ACoS 低于目标 TACoS 的广告通道 → 移入"不限预算组合"直接放量。

<a id="p0120"></a>
**P0120** 方向二：总单量 + 客单价不变 → 降低 TACoS

<a id="p0121"></a>
**P0121** 子方案 A：砍无效广告花费

<a id="p0122"></a>
**P0122** 适用于预期坑产稳定的链接（自然位不靠广告维持）：

<a id="p0123"></a>
**P0123** • 亏损的 SB/SBB 广告 → 直接关；

<a id="p0124"></a>
**P0124** • 已推到高自然位的词的投资型广告 → 缩量；

<a id="p0125"></a>
**P0125** 特征： 广告流量下降，自然流量基本不变。

<a id="p0126"></a>
**P0126** 子方案 B：降低广告单占比（最难，需两步同时成功）

<a id="p0127"></a>
**P0127** 先推自然单从 210 → 240，再砍广告单从 90 → 60，总量 300 不变。成功率不高，适合季节性产品。

<a id="p0128"></a>
**P0128** 子方案 C：直接降低 ACoS

<a id="p0129"></a>
**P0129** 不改变广告单占比，只把 ACoS 从 33% 压到 25% → TACoS 直接下降。

<a id="p0130"></a>
**P0130** 方向三：总单量 + TACoS 不变 → 提高客单价

<a id="p0131"></a>
**P0131** 方式 A：旺季涨价（仅限季节性机会）

<a id="p0132"></a>
**P0132** 方式 B：加变体提价（推荐）

<a id="p0133"></a>
**P0133** 核心思路：主推变体定低价占自然位，非主推变体定高价提综合客单价。

<a id="p0134"></a>
**P0134** 案例 1（尺码差价）：

<a id="p0135"></a>
**P0135** • L 码（热销）定 $19.99 → 主推，占自然位；

<a id="p0136"></a>
**P0136** • XS/XL/XXL 定 $23.99；

<a id="p0137"></a>
**P0137** • 买家必须买自己尺码 → 被迫接受高价；

<a id="p0138"></a>
**P0138** 案例 2（颜色差价）：

<a id="p0139"></a>
**P0139** • 主推色（男女通用）定低价 $9.88；

<a id="p0140"></a>
**P0140** • 男性偏好的深色定 $10 多；

<a id="p0141"></a>
**P0141** 注意： 差价不要太大（一般 $2-$5），否则非主推变体卖不动，买家直接去别家。

<a id="p0142"></a>
**P0142** 方向四：调整定价毛利和 TACoS 比例 → 改变产品盈利模式

<a id="p0143"></a>
**P0143** 适用情景：以上三个方向都走不通时，需要改变产品本身的定位。

<a id="p0144"></a>
**P0144** 方案 A：涨价 + 提高 TACoS（走高价高广告路线）

<a id="p0145"></a>
**P0145** 逻辑：

<a id="p0146"></a>
**P0146** • 涨价后定价毛利提升（如 40% → 50%）；

<a id="p0147"></a>
**P0147** • TACoS 也提高（如 25% → 40%）；

<a id="p0148"></a>
**P0148** • ACoS 低于 40% 的广告都可以放量 → 广告单大幅增加；

<a id="p0149"></a>
**P0149** • 用广告单带动实际坑产，自然位也上升；

<a id="p0150"></a>
**P0150** 极端形态： 定价毛利 50%，TACoS 40%，纯利 10%，完全靠广告出单，没有自然单。

<a id="p0151"></a>
**P0151** 方案 B：降价 + 降低 TACoS（走低价低广告路线）

<a id="p0152"></a>
**P0152** 逻辑：

<a id="p0153"></a>
**P0153** • 降价后定价毛利降低（如 30% → 15%），TACoS 也降低（如 20% → 5%）；

<a id="p0154"></a>
**P0154** • 低价 → 高 CTR 高 CVR → 预期坑产提升 → 自然位上升 → 自然单增多；

<a id="p0155"></a>
**P0155** • 广告少花钱，靠自然单盈利；

<a id="p0156"></a>
**P0156** 案例： 某产品原来卖 $20+ 打广告大量亏损，降价后广告越来越少，自然流量慢慢稳住，从日销 150 降到 30 但扭亏为盈。

<a id="p0157"></a>
**P0157** 极端形态： 几乎没有广告，只靠预期坑产维持自然位，靠低价自然单盈利。

<a id="p0158"></a>
**P0158** 四、选择方向的关键依据：商品价格中位数

<a id="p0159"></a>
**P0159** 路径： ABA 搜索绩效表现 → 自定义列 → 商品价格中位数

<a id="p0160"></a>
**P0160** | 定价与市场中位数的关系 | 推荐方向 |

<a id="p0161"></a>
**P0161** |---|---|

<a id="p0162"></a>
**P0162** | 售价 << 中位数（低价）| 走预期坑产路线：低价撬高自然流，广告花费少 |

<a id="p0163"></a>
**P0163** | 售价 ≈ 中位数 | 均衡：广告 + 自然流都可以做 |

<a id="p0164"></a>
**P0164** | 售价 >> 中位数（高价）| 走实际坑产路线：靠广告出单，广告需要本身盈利 |

<a id="p0165"></a>
**P0165** 警惕"尴尬中间价"： 如市场上主流是 $8.99 和 $19.99，你定 $15 → 两种打法都做不好：

<a id="p0166"></a>
**P0166** • 价格不够低 → 预期坑产不够高 → 自然流起不来；

<a id="p0167"></a>
**P0167** • 价格不够高 → 利润不够 → 广告买不起太多单；

<a id="p0168"></a>
**P0168** 建议： 调研竞品时要看清楚类目主流价位的分布，找准自己的定位，不要卡在中间。

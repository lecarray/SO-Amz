**P0002** 投放词放量与缩量实操：二级词扩充、重复投放排查、广告架构搭建

<a id="p0003"></a>
**P0003** 说话人1（宋之老师） 00:00

<a id="p0004"></a>
**P0004** 接着昨天晚上的内容来讲，昨天已经讲了关于投放词放量的最底层逻辑：需要遵从精准 > 广泛 ≈ 词组 > Auto ≥ 商品投放的出价结构，按这个竞价层级就可以实现成功的放量。

<a id="p0005"></a>
**P0005** 一、投放词放量的四种方式

<a id="p0006"></a>
**P0006** 前提：解决竞价层级错位问题

<a id="p0007"></a>
**P0007** 如果当前 Auto 竞价已经给得比较高了：

<a id="p0008"></a>
**P0008** • 着急放量 → 先往精准和广泛加竞价，往上放；

<a id="p0009"></a>
**P0009** • 不着急放量，想先控成本 → 先把 Auto 竞价往下压；

<a id="p0010"></a>
**P0010** • 放下一级词时，同时把上一级词的竞价往下压 → 保持层级差距，不需要一直往上抬竞价；

<a id="p0011"></a>
**P0011** 方式一：同级同匹配方式放量（拓词 + 测试）

<a id="p0012"></a>
**P0012** 适用目的： 拓词、覆盖推广盲区、做初期测试。

<a id="p0013"></a>
**P0013** 操作：

<a id="p0014"></a>
**P0014** 1. 先把收集好的一级词放到同一活动测试（同级同量）；

<a id="p0015"></a>
**P0015** 2. 测试后，发现哪个词表现好 → 拆活动单独放量；

<a id="p0016"></a>
**P0016** 3. 哪个词继续测试 → 拆出去到别的活动继续跑；

<a id="p0017"></a>
**P0017** 4. **保留原活动里花费大的词**，把花费小的词往外拆；

<a id="p0018"></a>
**P0018** 注意：

<a id="p0019"></a>
**P0019** • 拆活动的前提是你想放量；不想放量就不要拆；

<a id="p0020"></a>
**P0020** • 每个活动保证有 3-5 个 CPA 的预算作为打底；

<a id="p0021"></a>
**P0021** • 预算不够时先合活动，测完再拆；

<a id="p0022"></a>
**P0022** 强相关一级词优先投放，弱相关（泛词）留后期成熟期再投。

<a id="p0023"></a>
**P0023** 方式二：往二级词扩充放量（长尾扩充）

<a id="p0024"></a>
**P0024** 适用目的： 释放一级词打包下的长尾词曝光潜力。

<a id="p0025"></a>
**P0025** 组二级词的三种思路

<a id="p0026"></a>
**P0026** 思路 1：直接投放收集好的二级词（词根表横向组合）

<a id="p0027"></a>
**P0027** 在词根表里，用属性词 × 一级词直接组出二级词批量投放。

<a id="p0028"></a>
**P0028** 举例（吹尘器）：

<a id="p0029"></a>
**P0029** • 一级词：air、electric、blower 等；

<a id="p0030"></a>
**P0030** • 属性词：mini、computer、portable 等；

<a id="p0031"></a>
**P0031** • 组合 → "electric air"、"portable air duster" 等二级词；

<a id="p0032"></a>
**P0032** 投放前必须用全词表做覆盖量预判：

<a id="p0033"></a>
**P0033** | 判断 | 操作 |

<a id="p0034"></a>
**P0034** |---|---|

<a id="p0035"></a>
**P0035** | 覆盖量够（如 2.6 万+，73 个词）| 可以投 |

<a id="p0036"></a>
**P0036** | 覆盖量极小（如 computer 仅几百）| 不要投 —— 它会往短尾跑，跟一级词竞争 |

<a id="p0037"></a>
**P0037** 关于加号（+）能否限定广泛词：

<a id="p0038"></a>
**P0038** • B/SBD 广告中加号有用，SP 广告中加号不能锁定词根（无效）；

<a id="p0039"></a>
**P0039** • 如果想锁定特定词根不跑乱 → 改用词组匹配（范围更小但不会跑乱）；

<a id="p0040"></a>
**P0040** 思路 2：从后台已有广泛词中找表现好的一级词 → 往二级词拓充

<a id="p0041"></a>
**P0041** 操作：把后台所有广泛投放词拎出来，找花费大 + 表现好的词 → 加属性词 → 组成二级词放量。

<a id="p0042"></a>
**P0042** 举例（高腰短裤）：

<a id="p0043"></a>
**P0043** • "high waisted"（一级词）花费大、表现好；

<a id="p0044"></a>
**P0044** • 加属性词：+ woman、+ yoga、+ bar 等 → 组成二级词投放；

<a id="p0045"></a>
**P0045** • 体量合适 → 拆活动单独放量；

<a id="p0046"></a>
**P0046** 思路 3：从后台已有词中找表现好的属性词 → 跟所有一级词组合

<a id="p0047"></a>
**P0047** 操作：从搜索词报表里找某个属性词根的 CVR 比整体 CVR 高的情况 → 用这个属性词跟各一级词组合。

<a id="p0048"></a>
**P0048** 举例（夏威夷衬衫）：

<a id="p0049"></a>
**P0049** • 整体 CVR = 12%；

<a id="p0050"></a>
**P0050** • "pink" 词根相关词的 CVR = 16% → pink 属性词表现好；

<a id="p0051"></a>
**P0051** • 把 pink 跟所有一级词组合 → 投放 pink 相关二级词；

<a id="p0052"></a>
**P0052** 组二级词的注意事项

<a id="p0053"></a>
**P0053** 避免以下三种行为：

<a id="p0054"></a>
**P0054** 1. **过度组合**：所有属性词 × 所有一级词无脑组合 → 产生大量垃圾二级词；

<a id="p0055"></a>
**P0055** 2. **不做覆盖量预判就直接投**：词太小会往短尾跑，跟一级词产生内部竞争；

<a id="p0056"></a>
**P0056** 3. **不分活动**：把所有二级词堆同一活动 → 大打包吃小打包的预算，长尾照样发不出去；

<a id="p0057"></a>
**P0057** 建议：慢慢组、边分组边投；或先放同一活动测试，再拆出表现好的。

<a id="p0058"></a>
**P0058** 方式三：增加精准匹配投放词

<a id="p0059"></a>
**P0059** 适用目的： 在单个词上集中出单（盈利型或投资型均可）。

<a id="p0060"></a>
**P0060** 前提：

<a id="p0061"></a>
**P0061** • 这个词本身搜索量够大（值得单独投精准）；

<a id="p0062"></a>
**P0062** • 该词自然位还没到高位（如果已在高自然位且广告亏损 → 不用再开精准）；

<a id="p0063"></a>
**P0063** 精准比广泛竞价要高 10-20%（否则精准抢不过广泛，沦为捡漏位）。

<a id="p0064"></a>
**P0064** 精准放量的流程：

<a id="p0065"></a>
**P0065** 1. 从广泛里发现表现好的词；

<a id="p0066"></a>
**P0066** 2. 放到精准 Test 组先测；

<a id="p0067"></a>
**P0067** 3. 测出表现好且有进一步放量需求的 → 单词单组；

<a id="p0068"></a>
**P0068** 4. 精准单词单组开出后，精准进价要高于一级词广泛进价（精准才能接到这个词）；

<a id="p0069"></a>
**P0069** 5. 当精准拆出来足够多后，一级词广泛里的有价值词逐渐被掏空 → 可以开始降一级词广泛的竞价；

<a id="p0070"></a>
**P0070** 关于一级词广泛要不要及时降竞价：

<a id="p0071"></a>
**P0071** 个人风格问题：

<a id="p0072"></a>
**P0072** • 粗放型 → 等架构跑成熟后一次性调整；

<a id="p0073"></a>
**P0073** • 谨慎型 → 逐步降一级词，把差距维持出来；

<a id="p0074"></a>
**P0074** • 两种都对，只要层级分明即可；

<a id="p0075"></a>
**P0075** 方式四：增加短尾投放词（往上位词拓展）

<a id="p0076"></a>
**P0076** 适用目的： 成熟期想要拓展泛词，或准词已推完想拓大范围。

<a id="p0077"></a>
**P0077** 方式： 投上位词（比核心词更短的词）。

<a id="p0078"></a>
**P0078** 举例：

<a id="p0079"></a>
**P0079** • 核心词 = "hawaiian shirts" → 上位词 = "hawaii" 或 "shirts"；

<a id="p0080"></a>
**P0080** • 投 "hawaii" 广泛 → 只会出现服装类目相关词，不会出现装饰品等（节点决定范围）；

<a id="p0081"></a>
**P0081** 上位词竞价要给低（0.5X 甚至更低），不要给太高：

<a id="p0082"></a>
**P0082** • 上位词范围广、准确度低；

<a id="p0083"></a>
**P0083** • 只作为"捡漏/拓词"用，不是主力投放；

<a id="p0084"></a>
**P0084** • 成熟期才开，初期表现不好；

<a id="p0085"></a>
**P0085** 二、竞价层级结构参考

<a id="p0086"></a>
**P0086** 以市调竞价的中位值作为基准竞价（1X），各层级参考如下：

<a id="p0087"></a>
**P0087** | 投放层级 | 竞价倍数参考 |

<a id="p0088"></a>
**P0088** |---|---|

<a id="p0089"></a>
**P0089** | 精准 | 1.4X（最高） |

<a id="p0090"></a>
**P0090** | 二级词广泛 | 1.2X |

<a id="p0091"></a>
**P0091** | 一级词广泛（基准） | 1.0X |

<a id="p0092"></a>
**P0092** | Auto | 0.8X |

<a id="p0093"></a>
**P0093** | 上位词广泛 | 0.5-0.6X |

<a id="p0094"></a>
**P0094** | 商品投放（PT）| 0.6-0.8X（不高于一级词广泛） |

<a id="p0095"></a>
**P0095** 注意：

<a id="p0096"></a>
**P0096** • 每个层级之间差距 10-20% 即可，不需要差距很大；

<a id="p0097"></a>
**P0097** • 在活动名称上标注：这个活动在投什么词、当前给的竞价是多少；

<a id="p0098"></a>
**P0098** • 淡旺季整体调整时，统一抬或压各层级，保持层级差距不变；

<a id="p0099"></a>
**P0099** 三、重复投放的排查与处理

<a id="p0100"></a>
**P0100** （一）什么是重复投放？

<a id="p0101"></a>
**P0101** 同一个词的单复数、正序乱序、带不带介词，在广泛匹配下完全等价 → 投了多个等价的投放词 = 重复投放。

<a id="p0102"></a>
**P0102** 举例：

<a id="p0103"></a>
**P0103** • "bike shorts" 和 "shorts" 都是广泛 → 买家搜同一词会同时触发两个 → 重复；

<a id="p0104"></a>
**P0104** • "man hawaiian shirts" 和 "hawaiian shirts man" → 广泛乱序等价 → 重复；

<a id="p0105"></a>
**P0105** （二）重复投放的四种结果

<a id="p0106"></a>
**P0106** | 结果 | 说明 |

<a id="p0107"></a>
**P0107** |---|---|

<a id="p0108"></a>
**P0108** | 无效投放 | 新投的词发不出去（活动权重不足），花费为零 |

<a id="p0109"></a>
**P0109** | 互相平摊 | 两个投放分摊花费，各花一半，处于不稳定状态 |

<a id="p0110"></a>
**P0110** | 分化成一好一差 | 从平摊逐渐分化为：权重高的吃大头，另一个在捡漏，捡漏的 CPA 偏高 |

<a id="p0111"></a>
**P0111** | 互相抬价 | 发现新开的跑不出去就加竞价，被抬高的老活动又跟着加竞价，形成恶性循环 |

<a id="p0112"></a>
**P0112** 重复投放的实际案例：

<a id="p0113"></a>
**P0113** • 某学员把重复投放关掉后，一周内 ACoS 从 33% 降到 18%，CPC 从 $0.85 降到 $0.67，CPA 从 $1,000+ 降到 $500+；

<a id="p0114"></a>
**P0114** （三）如何检查重复投放

<a id="p0115"></a>
**P0115** 方法 1：在 ERP 出单词库查

<a id="p0116"></a>
**P0116** 领星 ERP：搜索词旁边点小眼睛 → 看这个词被几个投放词触发，是否有重复。

<a id="p0117"></a>
**P0117** 赛狐 ERP：因为不能排序，需要肉眼逐一查，或做透视表。

<a id="p0118"></a>
**P0118** 方法 2：在透视表中查

<a id="p0119"></a>
**P0119** 把透视表的"匹配类型"和"投放词"都拉到前面，把广泛词全部拎出来 → 看有没有单复数/正乱序的重复词。

<a id="p0120"></a>
**P0120** 操作步骤：

<a id="p0121"></a>
**P0121** 1. 在透视表中选匹配类型 = 广泛；

<a id="p0122"></a>
**P0122** 2. 把投放词排序；

<a id="p0123"></a>
**P0123** 3. 检查有没有语义相同的词；

<a id="p0124"></a>
**P0124** （四）如何处理重复投放

<a id="p0125"></a>
**P0125** 情况一：一个表现好、一个表现差（分化后状态）

<a id="p0126"></a>
**P0126** → 直接关掉表现差的那个；

<a id="p0127"></a>
**P0127** 情况二：两个还在平摊（没有分化）

<a id="p0128"></a>
**P0128** → 等一等，让它们自然分化；或者人为把一个进价降低，让它主动变成捡漏型；

<a id="p0129"></a>
**P0129** 情况三：互相抬价中

<a id="p0130"></a>
**P0130** → 立刻停止加竞价，先找出哪个是真正有价值的，保留一个，关掉其他重复的；

<a id="p0131"></a>
**P0131** 一般原则：

<a id="p0132"></a>
**P0132** • 精准不要用来捡漏（高竞价 + 差位置 → CPA 反而高）；

<a id="p0133"></a>
**P0133** • 捡漏广告要用低竞价 + 宽泛词（Auto / 广泛）；

<a id="p0134"></a>
**P0134** • 捡漏广告竞价要"够得到"——贴着可接到流量的最低竞价给，不是越低越好；

<a id="p0135"></a>
**P0135** 四、广告活动架构搭建实操

<a id="p0136"></a>
**P0136** （一）完整广告架构示意

<a id="p0137"></a>
**P0137** 以单主推 ASIN 为例，从外到内的活动层级结构：

<a id="p0138"></a>
**P0138** ```

<a id="p0139"></a>
**P0139** SP 广告（主推）

<a id="p0140"></a>
**P0140** ├── Auto（拓词 / 捡漏）

<a id="p0141"></a>
**P0141** │   ├── 正经拓词 Auto：1.0X 竞价

<a id="p0142"></a>
**P0142** │   └── 捡漏 Auto 系列：0.9X → 0.8X → 0.7X → 0.5X

<a id="p0143"></a>
**P0143** ├── 一级词广泛（定向大范围广撒网）

<a id="p0144"></a>
**P0144** │   ├── 初期测试：所有一级词放一个活动（Test）

<a id="p0145"></a>
**P0145** │   └── 表现好的一级词单独活动放量（如 AB 单独一个活动）

<a id="p0146"></a>
**P0146** ├── 二级词广泛（重点培养长尾词）

<a id="p0147"></a>
**P0147** │   ├── 测试组：多个二级词先放同一活动测

<a id="p0148"></a>
**P0148** │   └── 表现好的二级词单独活动（如 AB 二级词单独活动）

<a id="p0149"></a>
**P0149** ├── 精准词（单词单组 / 多词单组）

<a id="p0150"></a>
**P0150** │   ├── 精准 Test 组：多个候选词先测

<a id="p0151"></a>
**P0151** │   └── 表现好的精准词单词单组

<a id="p0152"></a>
**P0152** └── 商品投放（PT）

<a id="p0153"></a>
**P0153** └── 竞价 ≤ 一级词广泛

<a id="p0154"></a>
**P0154** ```

<a id="p0155"></a>
**P0155** SB/SBV/SD 广告 → 另立活动，竞价逻辑单独处理

<a id="p0156"></a>
**P0156** （二）活动命名规范

<a id="p0157"></a>
**P0157** 每个活动名称上必须标注：

<a id="p0158"></a>
**P0158** • 这个活动投的是什么词（一级词广泛 / 二级词广泛 / 精准等）；

<a id="p0159"></a>
**P0159** • 当前竞价大概是多少；

<a id="p0160"></a>
**P0160** • 如有广告位加价，也标注；

<a id="p0161"></a>
**P0161** 举例：

<a id="p0162"></a>
**P0162** • "SP-广泛-一级词-hawai-1.0" → 一级词广泛，竞价 $1.0；

<a id="p0163"></a>
**P0163** • "SP-精准-abd词-1.4" → abd 词精准，竞价 $1.4；

<a id="p0164"></a>
**P0164** （三）广告架构调整时机

<a id="p0165"></a>
**P0165** 什么时候可以整体调整竞价层级：

<a id="p0166"></a>
**P0166** • 淡旺季切换时（整体抬或压，保持层级差距）；

<a id="p0167"></a>
**P0167** • 表现持续稳定后（进一步压竞价换更低 CPA）；

<a id="p0168"></a>
**P0168** • 不需要频繁调整，每次调整的幅度以 10% 为单位；

<a id="p0169"></a>
**P0169** 使用 ERP 批量调整：

<a id="p0170"></a>
**P0170** • 领星等 ERP：把同类活动全选 → 左上角全选 → "竞价调整" → 全体加/减 10%；

<a id="p0171"></a>
**P0171** 五、广告活动放量的搜索词维度看法

<a id="p0172"></a>
**P0172** 从搜索词角度看投放词层级效果

<a id="p0173"></a>
**P0173** 以某个搜索词为例（如 gaming headset with microphone）：

<a id="p0174"></a>
**P0174** 该词同时触发了精准、广泛、词组三个层级：

<a id="p0175"></a>
**P0175** • 总花费 $300；

<a id="p0176"></a>
**P0176** • 精准花 $200（竞价 $1.36，吃大头）；

<a id="p0177"></a>
**P0177** • 广泛综合 $0.7-1.0（次之）；

<a id="p0178"></a>
**P0178** • 词组 $1.23（捡漏层）；

<a id="p0179"></a>
**P0179** 结论：每一层形成一个漏斗，精准在前面吃大头，后面逐层接漏。

<a id="p0180"></a>
**P0180** 关于是否需要在 Auto 里否精准词：

<a id="p0181"></a>
**P0181** • 一般不需要主动否；

<a id="p0182"></a>
**P0182** • 只有在前面那 100 块额外花费 CPA 极差时才否；

<a id="p0183"></a>
**P0183** • 否掉后只有精准来接，结构更纯净但可能损失一些捡漏；

<a id="p0184"></a>
**P0184** 六、投放词缩量方式

<a id="p0185"></a>
**P0185** （一）识别需要缩量的词

<a id="p0186"></a>
**P0186** 主要标准：

<a id="p0187"></a>
**P0187** • CPA 或 CVR 明显差于整体水平；

<a id="p0188"></a>
**P0188** • 花费大但没有推广价值（自然位已在有效位、已到瓶颈位）；

<a id="p0189"></a>
**P0189** • 重复投放中表现差的那个；

<a id="p0190"></a>
**P0190** 缩量前先排查以下三个可调整原因：

<a id="p0191"></a>
**P0191** | 原因 | 排查方法 | 解决方案 |

<a id="p0192"></a>
**P0192** |---|---|---|

<a id="p0193"></a>
**P0193** | 重复投放 | 看同一搜索词是否被多个投放词触发 | 关掉表现差的那个 |

<a id="p0194"></a>
**P0194** | 搜索词异常（错词） | 点开投放词查看其触发的搜索词列表 | 词组否掉错词根 |

<a id="p0195"></a>
**P0195** | 广告位异常 | 在 ERP 里查投放词的广告位 CVR 分布 | 压低该投放词竞价，让它退出 TOS 位置 |

<a id="p0196"></a>
**P0196** 注意： TOS 位置的广告位调整只能在活动层级做（会影响活动内所有词）；

<a id="p0197"></a>
**P0197** 如果想单独让某个投放词退出 TOS → 只能降这个投放词的竞价，让它排不到 TOS。

<a id="p0198"></a>
**P0198** （二）广泛/词组投放词的缩量方法

<a id="p0199"></a>
**P0199** 方法 1（最快）：直接关闭

<a id="p0200"></a>
**P0200** • 关闭后，该词的流量会流向上层（更大打包的词去承接）；

<a id="p0201"></a>
**P0201** • 若没有上层词 → 现场开一个一级词或 Auto 来承接；

<a id="p0202"></a>
**P0202** 方法 2：降低竞价（慢性缩量）

<a id="p0203"></a>
**P0203** • 逐步降竞价，直到 CPA 变好或花费为零；

<a id="p0204"></a>
**P0204** • 花不出去了就相当于自然关闭；

<a id="p0205"></a>
**P0205** • 适合不舍得直接关的情况；

<a id="p0206"></a>
**P0206** 方法 3：合并活动（减少曝光次数）

<a id="p0207"></a>
**P0207** • 把表现差的词从单词单组合并回多词活动；

<a id="p0208"></a>
**P0208** • 不改变广告位，但增加轮播竞争，花费自然减少；

<a id="p0209"></a>
**P0209** • 适合"不想关但想少花钱"的情况；

<a id="p0210"></a>
**P0210** 方法 4：短尾化（换回更大打包）

<a id="p0211"></a>
**P0211** • 把表现差的二三级词直接改投一级词；

<a id="p0212"></a>
**P0212** • 等于把它从小猪圈放回大猪圈；

<a id="p0213"></a>
**P0213** • 适合发现二级词覆盖量太小跑乱的情况；

<a id="p0214"></a>
**P0214** 举例（PS4 headphone 案例）：

<a id="p0215"></a>
**P0215** • 一级词 "PS4 headphone" 跑得不好 → 直接关掉，改成二级词 "wireless headphone PS4"；

<a id="p0216"></a>
**P0216** • 精确找到表现好的范围，避免浪费在大打包的错词上；

<a id="p0217"></a>
**P0217** 方法 5：缩短成广泛（精准改广泛）

<a id="p0218"></a>
**P0218** • 精准词表现差 → 关闭精准，让该词流回广泛层去跑；

<a id="p0219"></a>
**P0219** （三）精准投放词的缩量方法

<a id="p0220"></a>
**P0220** | 方法 | 适用场景 |

<a id="p0221"></a>
**P0221** |---|---|

<a id="p0222"></a>
**P0222** | 直接关闭 | 词小花不出去 / 重复投放中的差表现 |

<a id="p0223"></a>
**P0223** | 合并活动（回 Test 组） | 不舍得关，但希望少花钱 |

<a id="p0224"></a>
**P0224** | 降低竞价 | 希望让 CPA 慢慢变好，或让它退出 TOS 位置 |

<a id="p0225"></a>
**P0225** | 缩短成广泛（精准 → 广泛） | 发现精准覆盖范围太小跑不出数据 |

<a id="p0226"></a>
**P0226** 注意：降精准竞价时，不要低于上一层级（一级词广泛）；如果低于了，不如直接关掉。

<a id="p0227"></a>
**P0227** （四）精准投放词的常见问题：乱投

<a id="p0228"></a>
**P0228** 典型错误：从出单词库找到出单词 → 直接全部扔到精准里 → 产生一个精准活动有 1 万多个词的情况。

<a id="p0229"></a>
**P0229** 结果：

<a id="p0230"></a>
**P0230** • 只有前 1-2 个大词在花钱（$9,400、$1,200）；

<a id="p0231"></a>
**P0231** • 剩下全是零头（$10、$5 以下）；

<a id="p0232"></a>
**P0232** • 这些小词没有必要投精准，关掉即可；

<a id="p0233"></a>
**P0233** 更好的做法：大范围用广泛/词组覆盖，小范围重点词用精准单词单组。

<a id="p0234"></a>
**P0234** 七、本节总结

<a id="p0235"></a>
**P0235** | 方向 | 操作 |

<a id="p0236"></a>
**P0236** |---|---|

<a id="p0237"></a>
**P0237** | 放量 | 拆活动 / 加同级词 / 往二级词扩 / 加精准 / 加上位词（依顺序） |

<a id="p0238"></a>
**P0238** | 缩量 | 直接关闭 / 降竞价 / 合活动 / 换短尾词 / 缩短成广泛 |

<a id="p0239"></a>
**P0239** | 重复投放 | 通过 ERP 小眼睛或透视表排查 → 关掉表现差的 |

<a id="p0240"></a>
**P0240** | 整体架构 | 精准 > 广泛 ≈ 词组 > Auto ≥ PT，每层竞价分明，活动名称标注清楚 |

**P0241** 到目前为止，投放词层级的缩放量操作不需要用到搜索词透视表或推广洞察表 —— 只需要在后台投放层级操作即可。

<a id="p0005"></a>
**P0005** 一、搜索词触发的投放词漏斗结构

<a id="p0006"></a>
**P0006** （一）漏斗结构的比喻

<a id="p0007"></a>
**P0007** 把漏斗里的挡板长度理解为竞价高低：

<a id="p0008"></a>
**P0008** • 竞价越高 → 挡板越长，排序越靠上；

<a id="p0009"></a>
**P0009** • 竞价越低 → 挡板越短，排序越靠下；

<a id="p0010"></a>
**P0010** 单一搜索词能触发的层级从上到下大致为：

<a id="p0011"></a>
**P0011** 1. 精准匹配（最高竞价）

<a id="p0012"></a>
**P0012** 2. 三级词广泛/词组

<a id="p0013"></a>
**P0013** 3. 二级词广泛/词组

<a id="p0014"></a>
**P0014** 4. 一级词广泛/词组

<a id="p0015"></a>
**P0015** 5. Auto（自动）

<a id="p0016"></a>
**P0016** 6. 上位词广泛

<a id="p0017"></a>
**P0017** 7. 商品投放（PT）

<a id="p0018"></a>
**P0018** 这是最完善的层级结构，但一个词下可以只有一层，也可以有多层，不是必须搭到最完善。

<a id="p0019"></a>
**P0019** （二）往上搭 vs 往下搭的放量效果

<a id="p0020"></a>
**P0020** | 方向 | 操作 | 效果 |

<a id="p0021"></a>
**P0021** |---|---|---|

<a id="p0022"></a>
**P0022** | 往上搭（加精准/加高竞价）| 从广泛升级到精准 | 大量放量 |

<a id="p0023"></a>
**P0023** | 往下搭（加捡漏广告）| 在已有层级下面加更低竞价 | 小量放量（捡漏）|

<a id="p0024"></a>
**P0024** 结论：若想对一个词大幅放量 → 往上搭；若想小量放量 → 往下搭捡漏层。

<a id="p0025"></a>
**P0025** 二、广告架构的两种类型

<a id="p0026"></a>
**P0026** （一）简单型架构（推荐新手 / 预算有限）

<a id="p0027"></a>
**P0027** 结构：只有两层——Auto + 精准

<a id="p0028"></a>
**P0028** ```

<a id="p0029"></a>
**P0029** 精准（竞价 1.1X → 更高）

<a id="p0030"></a>
**P0030** ↓ 捡漏层

<a id="p0031"></a>
**P0031** Auto（竞价 1.0X）

<a id="p0032"></a>
**P0032** ```

<a id="p0033"></a>
**P0033** 使用流程：

<a id="p0034"></a>
**P0034** 1. Auto 跑出搜索词（ABC、ABD、ACD 等）；

<a id="p0035"></a>
**P0035** 2. 跑出来表现好的词 → 放到精准组；

<a id="p0036"></a>
**P0036** 3. Auto 里不需要否定；

<a id="p0037"></a>
**P0037** 4. 精准组里放多个词 → 形成精准组 1、2、3……；

<a id="p0038"></a>
**P0038** 5. 精准组里表现特别好且需要深度放量的词 → 拆成单词单组；

<a id="p0039"></a>
**P0039** 扩展：Auto 可以分成高低两个竞价层级

<a id="p0040"></a>
**P0040** • Auto 高竞价（如 0.8X）+ Auto 低竞价（如 0.6X）；

<a id="p0041"></a>
**P0041** • 精准里跑差的词 → 降级到精准低竞价 → 再降到 Auto 高竞价 → 再降到 Auto 低竞价 → 直到关闭；

<a id="p0042"></a>
**P0042** • 捡漏广告可以在 Auto 低竞价之下继续叠：0.5X → 0.4X → ……；

<a id="p0043"></a>
**P0043** 简单型架构的特点：

<a id="p0044"></a>
**P0044** • 省事，活动量少；

<a id="p0045"></a>
**P0045** • 对单个词的缩放量比较粗暴（要么开精准花大钱，要么进 Auto 花小钱，中间调节空间小）；

<a id="p0046"></a>
**P0046** • 词少的产品或预算有限时首选；

<a id="p0047"></a>
**P0047** （二）丰富型架构（推荐中高级玩家 / 词多 / 预算充足）

<a id="p0048"></a>
**P0048** 结构：多层次——Auto + 一级词广泛 + 二级词广泛 + 精准

<a id="p0049"></a>
**P0049** ```

<a id="p0050"></a>
**P0050** 精准单词单组（竞价 1.4X）

<a id="p0051"></a>
**P0051** ↓

<a id="p0052"></a>
**P0052** 精准多词组（竞价 1.3X）

<a id="p0053"></a>
**P0053** ↓

<a id="p0054"></a>
**P0054** 三级词广泛（竞价 1.3X）

<a id="p0055"></a>
**P0055** ↓

<a id="p0056"></a>
**P0056** 二级词广泛（竞价 1.2X）

<a id="p0057"></a>
**P0057** ↓

<a id="p0058"></a>
**P0058** 一级词广泛（基准竞价 1.0X）

<a id="p0059"></a>
**P0059** ↓

<a id="p0060"></a>
**P0060** Auto（竞价 0.8X）

<a id="p0061"></a>
**P0061** ↓ 捡漏层

<a id="p0062"></a>
**P0062** Auto 低竞价（0.7X → 0.6X → 0.5X……）

<a id="p0063"></a>
**P0063** ```

<a id="p0064"></a>
**P0064** 整体调整的方法：

<a id="p0065"></a>
**P0065** 如果希望整体 CPC 控制在 1.0X 左右：

<a id="p0066"></a>
**P0066** • 把一级词广泛设为 X（基准）；

<a id="p0067"></a>
**P0067** • Auto 设为 0.8X；

<a id="p0068"></a>
**P0068** • 二级词 1.2X；

<a id="p0069"></a>
**P0069** • 精准 1.4X；

<a id="p0070"></a>
**P0070** • 不想竞价太高 → 整体往下缩（如一级词降到 0.7X，精准到 1.0X），层级差距保持即可；

<a id="p0071"></a>
**P0071** 丰富型架构的特点：

<a id="p0072"></a>
**P0072** • 对每个词调控精细；

<a id="p0073"></a>
**P0073** • 活动量大（10 个以上活动是正常的，甚至几十个）；

<a id="p0074"></a>
**P0074** • 适合大预算、半标/非标、词多的产品；

<a id="p0075"></a>
**P0075** 三、搜索词放量

<a id="p0076"></a>
**P0076** （一）搜索词放量的前提条件

<a id="p0077"></a>
**P0077** 条件 1：花费路径可控

<a id="p0078"></a>
**P0078** 在 ERP 出单词库或透视表里，展开某个搜索词，能看到其主要花费集中在哪个投放词/活动里（不是分散在自动、广泛、精准里各花一点）。

<a id="p0079"></a>
**P0079** ✅ 花费路径可控（正确示例）：某词花费集中在精准（$880），Auto 捡漏（$310）；

<a id="p0080"></a>
**P0080** ❌ 花费路径不可控（错误示例）：广泛 $16,000，精准 $6,900，且两者竞价差距很小（如广泛 $3.9，精准 $3.77）。

<a id="p0081"></a>
**P0081** 条件 2：竞价符合层级结构

<a id="p0082"></a>
**P0082** 精准竞价 > 广泛竞价 > Auto 竞价。

<a id="p0083"></a>
**P0083** 如果精准和广泛竞价相近（如 $3.77 vs $3.9），说明层级结构乱了，需要先修复。

<a id="p0084"></a>
**P0084** （二）搜索词放量的操作步骤（六步排查）

<a id="p0085"></a>
**P0085** 找到想放量的词后，按顺序检查以下六步，找到最简单的方法执行即可：

<a id="p0086"></a>
**P0086** 第 1 步：活动预算是否充足？

<a id="p0087"></a>
**P0087** • 充足 → 继续往下排查；

<a id="p0088"></a>
**P0088** • 不充足 → 直接加活动预算即可；

<a id="p0089"></a>
**P0089** 第 2 步：该词是否在单词单组？

<a id="p0090"></a>
**P0090** • 不是单词单组（在多词活动里，被别的词压制曝光）→ 先把这个词拆出来，开单词单组；

<a id="p0091"></a>
**P0091** • 已是单词单组 → 继续往下排查；

<a id="p0092"></a>
**P0092** 第 3 步：投放词是否完整（可以增加匹配方式）？

<a id="p0093"></a>
**P0093** • 只有精准，没有广泛/词组 → 往下搭一层广泛（小量放量）；

<a id="p0094"></a>
**P0094** • 既有精准又有广泛 → 不能再靠增加匹配方式放量了（已有精准的情况下再加广泛 = 往下搭捡漏，增量少），继续往下；

<a id="p0095"></a>
**P0095** • 只有广泛没有精准 → 加精准（大量放量）；

<a id="p0096"></a>
**P0096** 第 4 步：整体竞价是否可以上调？

<a id="p0097"></a>
**P0097** • 对该词的精准竞价加价（让精准抢到更多曝光）；

<a id="p0098"></a>
**P0098** • 注意：加精准竞价比加广泛竞价更精准（广泛加价会带动所有长尾词，不只是目标词）；

<a id="p0099"></a>
**P0099** 第 5 步：竞价层级是否凌乱？（先修复再放量）

<a id="p0100"></a>
**P0100** • 发现自动竞价 > 广泛竞价 → 自动把词都吃了，精准/广泛接不到 → 先把 Auto 竞价降到广泛以下；

<a id="p0101"></a>
**P0101** • 或在 Auto 里精准否定该词 → 让该词只走精准层；

<a id="p0102"></a>
**P0102** 第 6 步：广告位局部加价

<a id="p0103"></a>
**P0103** • 适合单词单组 → 后续单独讲；

<a id="p0104"></a>
**P0104** 最简便放量方式：直接开单词单组

<a id="p0105"></a>
**P0105** • 单词单组 = 同时完成了：加投放词 + 拆活动 + 加预算三个动作；

<a id="p0106"></a>
**P0106** • 不擅长分析的卖家直接开单词单组即可；

<a id="p0107"></a>
**P0107** （三）案例演示（夏威夷衬衫）

<a id="p0108"></a>
**P0108** 案例 1：想放量的词 "hawaiian shirts for men"

<a id="p0109"></a>
**P0109** 花费路径：精准花大头，后面有词组、广泛捡漏层。

<a id="p0110"></a>
**P0110** 操作：

<a id="p0111"></a>
**P0111** 1. 已是单词单组 → 不用拆；

<a id="p0112"></a>
**P0112** 2. 已有精准 + 广泛 → 投放词完整；

<a id="p0113"></a>
**P0113** 3. 加精准竞价即可（$2.15 → $2.2+）；

<a id="p0114"></a>
**P0114** 案例 2：表现好但花费少的词 "flamingo shirt"

<a id="p0115"></a>
**P0115** 花费路径：广泛 $1.34 + Auto $1.58（Auto 竞价反而高于广泛，层级乱）。

<a id="p0116"></a>
**P0116** 操作：

<a id="p0117"></a>
**P0117** • 方案 A：加精准，竞价给到 $1.58 以上，把该词完全接过来；精准稳定后再慢慢降 Auto 和广泛竞价；

<a id="p0118"></a>
**P0118** • 方案 B：把广泛竞价抬到 $1.58 以上，让广泛承接（不加精准）；

<a id="p0119"></a>
**P0119** • 最简便：直接开精准，给到 $1.6+，无视下面的乱摊子，新开的精准自然把词抢走；

<a id="p0120"></a>
**P0120** 四、搜索词缩量

<a id="p0121"></a>
**P0121** （一）缩量前提

<a id="p0122"></a>
**P0122** 与放量相同：需要花费路径可控 + 竞价层级清晰。

<a id="p0123"></a>
**P0123** 层级乱的产品缩量很麻烦。

<a id="p0124"></a>
**P0124** （二）搜索词缩量的方式

<a id="p0125"></a>
**P0125** | 方式 | 适用场景 |

<a id="p0126"></a>
**P0126** |---|---|

<a id="p0127"></a>
**P0127** | 降低精准竞价 | 有明确精准花费大头的词；逐步降直到花不出去 |

<a id="p0128"></a>
**P0128** | 关闭精准投放 | 让该词从精准降级到广泛/Auto |

<a id="p0129"></a>
**P0129** | 合并活动 | 把单词单组合回多词精准组，增加轮播竞争，减少曝光 |

<a id="p0130"></a>
**P0130** | 降低活动预算 | 精准减少花费，但不改变表现 |

<a id="p0131"></a>
**P0131** | 精准否定（Exact Negative） | 在广泛/Auto 里精准否定该词，让词只走精准层（注意：否完后架构变复杂，后续难维护） |

<a id="p0132"></a>
**P0132** | 广告位局部缩量 | 后续单独讲 |

<a id="p0133"></a>
**P0133** （三）案例演示

<a id="p0134"></a>
**P0134** 正常架构下的缩量（ASIN 投放案例）：

<a id="p0135"></a>
**P0135** • 某 ASIN 被"ASIN 精准"和"类目投放"触发，花费大头在 ASIN 精准（$84 → 想降到 $40）；

<a id="p0136"></a>
**P0136** • 方案 1：降 ASIN 精准竞价（从 $1.55 降到 $1.15，花不出去就关闭）；

<a id="p0137"></a>
**P0137** • 方案 2：关闭 ASIN 精准投放（让 ASIN 降级到类目里跑）；

<a id="p0138"></a>
**P0138** • 方案 3：合并活动（把该 ASIN 精准合并回别的活动）；

<a id="p0139"></a>
**P0139** • 方案 4：降活动预算（简单直接）；

<a id="p0140"></a>
**P0140** 竞价层级乱的产品缩量（难）：

<a id="p0141"></a>
**P0141** 某词广泛 $16,000 + 精准 $6,900，广泛竞价 $3.9，精准竞价 $3.77（精准<广泛，层级乱）：

<a id="p0142"></a>
**P0142** • 方案 1：降广泛竞价

<a id="p0143"></a>
**P0143** → 把广泛降到 $3.77 以下 → 精准承接该词；

<a id="p0144"></a>
**P0144** → 缺点：广泛是大打包，降了会影响所有长尾词；

<a id="p0145"></a>
**P0145** • 方案 2：精准否定

<a id="p0146"></a>
**P0146** → 在广泛里精准否该词 → 词只走精准层；

<a id="p0147"></a>
**P0147** → 见效快，但后续维护麻烦（否定积累多了忘了有什么）；

<a id="p0148"></a>
**P0148** • 方案 3（推荐）：先提精准竞价 > 广泛，再慢慢降广泛

<a id="p0149"></a>
**P0149** 1. 把精准提到 $3.96+（高于广泛）→ 精准抢过来花费；

<a id="p0150"></a>
**P0150** 2. 控精准活动预算；

<a id="p0151"></a>
**P0151** 3. 预算不够花时开始整体降竞价（精准 + 广泛同步降）；

<a id="p0152"></a>
**P0152** 4. 层级修复完成后，再缩量；

<a id="p0153"></a>
**P0153** 个人建议：方案 3 虽然慢，但以后调整最顺手；方案 2 短期爽，长期麻烦。

<a id="p0154"></a>
**P0154** 五、CTR 异常导致层级倒挂的识别与处理

<a id="p0155"></a>
**P0155** 识别特征：高竞价层级花费少，低竞价层级花费多

<a id="p0156"></a>
**P0156** 举例：

<a id="p0157"></a>
**P0157** • Auto 竞价 $2.84，花费大头；

<a id="p0158"></a>
**P0158** • 广泛竞价 $4.18，花费少；

<a id="p0159"></a>
**P0159** 表面看是"进价越高越花不出去"，实际是广告位问题。

<a id="p0160"></a>
**P0160** 原因分析：

<a id="p0161"></a>
**P0161** 假设广泛 $2.1 + TOS 加价 100%，实际 TOS 竞价 = $4.2。

<a id="p0162"></a>
**P0162** 买家搜索 ABC：

<a id="p0163"></a>
**P0163** • TOS 位置：广泛 $4.2 vs Auto $2.84 → 广泛抢到 TOS（花费少但高价）；

<a id="p0164"></a>
**P0164** • ROS/PP 位置：Auto $2.84 vs 广泛 $2.1 → Auto 抢到 ROS/PP（花费多但低价）；

<a id="p0165"></a>
**P0165** 结果：Auto 花费大、进价低；广泛花费小、进价高 → 但广泛只在 TOS 捡漏，效率极低。

<a id="p0166"></a>
**P0166** 识别方法： 把 CTR 拉出来对比

<a id="p0167"></a>
**P0167** • 自动 CTR = 4%（在 ROS/PP 正常）；

<a id="p0168"></a>
**P0168** • 广泛 CTR = 17%（只跑了 TOS，CTR 虚高）；

<a id="p0169"></a>
**P0169** 解决方案：

<a id="p0170"></a>
**P0170** • 不要给广泛加高 TOS 加价，让广泛全面承接所有位置；

<a id="p0171"></a>
**P0171** • 或者直接精准否定该词 → 让词走精准层；

<a id="p0172"></a>
**P0172** • 避免"广泛只跑 TOS" 的情况 → 会导致大量 ROS/PP 流量浪费给 Auto；

<a id="p0173"></a>
**P0173** 六、精准的"故意瀑布流"

<a id="p0174"></a>
**P0174** 什么是故意开重复精准？

<a id="p0175"></a>
**P0175** 对单个词精意开多个精准，竞价从高到低排列：

<a id="p0176"></a>
**P0176** • 精准 $1.91（花大头，放量层）；

<a id="p0177"></a>
**P0177** • 精准 $1.62（捡漏层）；

<a id="p0178"></a>
**P0178** • 精准 $1.47 → $1.4 → $1.3……（继续捡漏）；

<a id="p0179"></a>
**P0179** 这与"意外重复投放"的区别：

<a id="p0180"></a>
**P0180** • 意外重复：单复数、正乱序的同义词 → 关掉差的；

<a id="p0181"></a>
**P0181** • 故意瀑布流：同一个词，有意用不同竞价开多次 → 分层承接，没有问题；

<a id="p0182"></a>
**P0182** 注意：捡漏广告要看表现，ACoS 过高的捡漏层（如 100%+ ACoS）→ 该否则否，该关则关。

<a id="p0183"></a>
**P0183** 捡漏的目的是低成本买订单或拉权重，表现差的捡漏 = 钱打水漂。

<a id="p0184"></a>
**P0184** 七、两种推广顺序的选择

<a id="p0185"></a>
**P0185** （一）转化驱动型：从下到上（先广撒网 → 重点培养 → 定点捕捞）

<a id="p0186"></a>
**P0186** 推广顺序：Auto → 广泛一/二级词 → 精准组 → 单词单组

<a id="p0187"></a>
**P0187** 适用产品：

<a id="p0188"></a>
**P0188** • 红海类目、竞价高、广告大多亏损（投资型广告为主）；

<a id="p0189"></a>
**P0189** • 长尾词很多的产品（需先拓词，再精选）；

<a id="p0190"></a>
**P0190** • 推广预算有限（先找有效词，再放量）；

<a id="p0191"></a>
**P0191** • 推广速度要求稳定；

<a id="p0192"></a>
**P0192** • 流量离散型产品（词根多，无大词可直接打）；

<a id="p0193"></a>
**P0193** 特点：

<a id="p0194"></a>
**P0194** • 不容易跑崩；

<a id="p0195"></a>
**P0195** • 预算花费节奏稳；

<a id="p0196"></a>
**P0196** • 速度慢；

<a id="p0197"></a>
**P0197** • 初期表现差的词会被自然淘汰（流向低竞价层）；

<a id="p0198"></a>
**P0198** （二）流量驱动型：从上到下（先定点捕捞 → 广撒网 → 捡漏）

<a id="p0199"></a>
**P0199** 推广顺序：精准组 → 单词单组 → 广泛 → Auto

<a id="p0200"></a>
**P0200** 具体操作：

<a id="p0201"></a>
**P0201** 1. 把准词按搜索量大小分成 3-4 个精准组（如 62 万总搜索量分成大、中、小组）；

<a id="p0202"></a>
**P0202** • 每个组控制体量相当（防止大词吃小词）；

<a id="p0203"></a>
**P0203** • 同复数词合并，避免重复；

<a id="p0204"></a>
**P0204** 2. 每个精准组用相同竞价（如 1.1X）先测；

<a id="p0205"></a>
**P0205** 3. 表现好的词 → 拎出来开单词单组放量；

<a id="p0206"></a>
**P0206** 4. 表现差的词 → 降竞价 → 再差则关闭 → 降级到广泛层 → 继续差则降级到 Auto → 最终关闭或精准否；

<a id="p0207"></a>
**P0207** 5. 最后补开 Auto 低竞价接那些精准/广泛不要的词；

<a id="p0208"></a>
**P0208** 适用产品：

<a id="p0209"></a>
**P0209** • 竞争小、竞价低的蓝海产品（先打大词，成本低）；

<a id="p0210"></a>
**P0210** • 流量相对集中的产品（有明确大词可以先打）；

<a id="p0211"></a>
**P0211** • 推广预算充足（需要给所有词花钱测试）；

<a id="p0212"></a>
**P0212** • 广告本身可以盈利（前期以盈利型广告为主）；

<a id="p0213"></a>
**P0213** • 想推广速度快；

<a id="p0214"></a>
**P0214** 风险提醒：

<a id="p0215"></a>
**P0215** • 新品权重低 → 精准 CPC 会偏高 → 初期可能跑出高 ACoS；

<a id="p0216"></a>
**P0216** • 若表现差又一味加竞价打 TOS → 竞价会飙到极高（案例：某产品 TOS 给到 $10）；

<a id="p0217"></a>
**P0217** • 表现好可以先打高价抢位再降，表现差则不建议走这条路线；

<a id="p0218"></a>
**P0218** （三）两种推广顺序的核心区别

<a id="p0219"></a>
**P0219** | 维度 | 转化驱动 | 流量驱动 |

<a id="p0220"></a>
**P0220** |---|---|---|

<a id="p0221"></a>
**P0221** | 起始层级 | Auto（低竞价大范围）| 精准（高竞价精准词）|

<a id="p0222"></a>
**P0222** | 放量方式 | 往上升级（广泛→精准）| 往下降级（精准→广泛→Auto）|

<a id="p0223"></a>
**P0223** | 初期花费 | 少 | 多 |

<a id="p0224"></a>
**P0224** | 速度 | 慢稳 | 快但风险大 |

<a id="p0225"></a>
**P0225** | 适合预算 | 有限 | 充足 |

<a id="p0226"></a>
**P0226** | 跑崩风险 | 低 | 中等 |

<a id="p0227"></a>
**P0227** 最终架构相同，只是搭建顺序不同。

<a id="p0228"></a>
**P0228** 八、广告预算在各层级的分布规律

<a id="p0229"></a>
**P0229** | 放量阶段 | 预算分布 |

<a id="p0230"></a>
**P0230** |---|---|

<a id="p0231"></a>
**P0231** | 初期 | Auto 占 50-70%，广泛词组占 30-50%，精准极少 |

<a id="p0232"></a>
**P0232** | 成长期 | Auto 占 30%，广泛词组占 50%，精准逐渐增加 |

<a id="p0233"></a>
**P0233** | 成熟期 | 精准占 60-70%，广泛词组占 20-25%，Auto/捡漏 15%+ |

<a id="p0234"></a>
**P0234** 花费从 Auto/广泛 转移到精准，就代表放量进度成熟了。

<a id="p0235"></a>
**P0235** 如果花费大多还在广泛层 → 仍有大量放量空间；

<a id="p0236"></a>
**P0236** 如果花费已集中在精准 → 放量空间减少，剩下的只能靠拆活动/广告位放量/多变体放量。

<a id="p0237"></a>
**P0237** 九、本节总结

<a id="p0238"></a>
**P0238** 1. **每个搜索词对应一个漏斗结构**，竞价越高层级越靠上，放量往上搭，缩量往下撤；

<a id="p0239"></a>
**P0239** 2. **简单型架构（Auto + 精准）** 适合新手/预算有限，缩放量比较粗放；

<a id="p0240"></a>
**P0240** 3. **丰富型架构（Auto + 广泛一/二级词 + 精准）** 适合中高级/词多/预算充足，缩放量精细；

<a id="p0241"></a>
**P0241** 4. **搜索词放量六步排查**：预算 → 拆活动 → 加投放词 → 加竞价 → 修复层级 → 广告位加价；

<a id="p0242"></a>
**P0242** 5. **搜索词缩量**：核心是找到花费路径，从最高花费层降起；

<a id="p0243"></a>
**P0243** 6. **两种推广顺序**：转化驱动（从 Auto 到精准，稳）vs 流量驱动（从精准到 Auto，快但贵）；

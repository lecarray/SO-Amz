<a id="p0007"></a>
**P0007** 一、COSMO 算法解读

<a id="p0008"></a>
**P0008** 说话人2（宋之老师） 01:04

<a id="p0009"></a>
**P0009** 我们上午讲了关于 A9 算法下的排名逻辑。我们现在的自然位大多数还是由 A9 算法去主导的，有少部分的时候 COSMO 算法会影响到。

<a id="p0010"></a>
**P0010** 现在买家在前台所看到的自然排位都是由 A9 + COSMO 算法叠加影响的。

<a id="p0011"></a>
**P0011** （一）两个算法的关系

<a id="p0012"></a>
**P0012** • A9 算法：传统的关键词匹配搜索，基于关键词和产品的性能指标去综合排序——也就是我们前面讲的预期坑产或实际坑产。

<a id="p0013"></a>
**P0013** • COSMO 算法：基于用户的意图去做个性化推荐，使用大语言模型和知识图谱去分析用户的搜索意图。

<a id="p0014"></a>
**P0014** （二）什么叫"用户搜索意图"？

<a id="p0015"></a>
**P0015** 具象化一点：

<a id="p0016"></a>
**P0016** 第一类：基于用户搜索词的同义匹配

<a id="p0017"></a>
**P0017** 比如用户去搜索 "Portable" 这个词，也会匹配到 "Easy to Carry" 这样的词——它俩是同义的。亚马逊会推断买家想要便携式的，所以这种近义词其实都可以匹配。

<a id="p0018"></a>
**P0018** 第二类：基于买家过往的搜索、点击和购买行为去推断他想要什么

<a id="p0019"></a>
**P0019** 举个简单的例子：用两套账户去搜索同一个词。

<a id="p0020"></a>
**P0020** • 账户1（未登录买家账号）：搜 "mirror"。出来的结果是基于 A9 算法的正常结果——会有大镜子、小镜子、梳妆台镜子，还会有各种墙上贴的镜子等等，结果会有很多。

<a id="p0021"></a>
**P0021** • 账户2（已登录买家账号）：搜 "mirror"，看一下广告位和自然位全部呈现大镜子。是因为这个买家账号点过很多浴室镜和全身镜（我们也做这个产品线）。

<a id="p0022"></a>
**P0022** 在这样的结果下，自然位和广告位都呈现大镜子（浴室镜和全身镜）——这就是 COSMO 算法的影响。

<a id="p0023"></a>
**P0023** （三）算法对排序的影响维度

<a id="p0024"></a>
**P0024** 如果想要拿到更好的流量的话，需要基于用户的搜索意图去匹配。这种排序的打乱基于：

<a id="p0025"></a>
**P0025** 1. **历史点击行为**：你点过什么东西；

<a id="p0026"></a>
**P0026** 2. **历史订单**：亚马逊会分析这个用户喜欢购买什么价位；

<a id="p0027"></a>
**P0027** 3. **使用场景**；

<a id="p0028"></a>
**P0028** 4. **人群定位**。

<a id="p0029"></a>
**P0029** 所以这种排序对于有些词影响是比较大的。

<a id="p0030"></a>
**P0030** （四）从后台搜索绩效表现页面看 COSMO 影响

<a id="p0031"></a>
**P0031** 回到 ABA 的搜索绩效表现页面（上午讲过），反查自己的 ASIN（ASIN视图）或品牌视图，能看到一堆反查词。

<a id="p0032"></a>
**P0032** 往右边看有一个"点击率"指标——这个非常重要。

<a id="p0033"></a>
**P0033** 注意：这个点击率不是 CTR（曝光点击率）。

<a id="p0034"></a>
**P0034** 我们平时所说的点击率是 曝光点击率 = 点击量 ÷ 曝光量，但这里显示的点击率指的是 搜索点击率 = 点击量 ÷ 搜索量——也就是买家搜这个词搜了多少遍，他点了多少遍。

<a id="p0035"></a>
**P0035** 举例：第一排买家搜这个词搜了 14 万次，点击数量是 21,000 → 21,000 ÷ 14万 = 14%。

<a id="p0036"></a>
**P0036** 14% 这个点击率好不好？对于平台来说是非常不好的。

<a id="p0037"></a>
**P0037** 因为平台做所有的变革都是希望增加销售额、增加买家粘性、增加购物决策速度。如果一个词搜索完以后搜索点击率只有 14%，说明买家搜完都没有看到自己想要的东西。

<a id="p0038"></a>
**P0038** 对于这种词，COSMO 算法的影响会非常大，对你的自然排位影响非常大。

<a id="p0039"></a>
**P0039** （五）浏览型关键词 vs 购买型关键词

<a id="p0040"></a>
**P0040** • 浏览型关键词：搜索点击率低（比如 14%、17%、30%）——以前的称呼。

<a id="p0041"></a>
**P0041** • 购买型关键词：搜索点击率高（50%+、60%+ 这种）。

<a id="p0042"></a>
**P0042** 如果你做的是标品（很多比较标品的词），点击率都是偏高的，大概在 40%-70% 之间。

<a id="p0043"></a>
**P0043** 如果你做的是非标/半标，会有一些泛词，这些泛词的点击率都偏低（14%、30%、17%）。

<a id="p0044"></a>
**P0044** 这些泛词下面，亚马逊为了加强买家的购物决策，就会基于搜索意图、过往点击、过往购买，去给你重新排序。

<a id="p0045"></a>
**P0045** （六）贴合 COSMO 算法的两个建议

<a id="p0046"></a>
**P0046** 建议一：把场景词、人群、属性词全部埋清楚

<a id="p0047"></a>
**P0047** 也就是上午跟大家讲到的 Keep Shopping For 里面的 For You 板块——所有标签全部打清楚。

<a id="p0048"></a>
**P0048** 用自己登录的买家账号往下拉，看 For You 这里的所有筛选属性（材质、方式、颜色、风格等等）全部埋清楚，方便亚马逊帮你定位到特定的买家。

<a id="p0049"></a>
**P0049** 建议二：泛词不要用力打

<a id="p0050"></a>
**P0050** 打词的时候，泛词不用用力去打，因为这些泛词用力打了没什么用——这种泛词下面的自然位很多都是靠买家的搜索意图来排序的。

<a id="p0051"></a>
**P0051** 泛词要打收录，但不要用力去推排位——推不动，用力打是推不动的。

<a id="p0052"></a>
**P0052** （七）案例：COSMO 如何精准匹配人群

<a id="p0053"></a>
**P0053** 举个简单的例子：

<a id="p0054"></a>
**P0054** • 现在如果是一个孕妇去搜索 "casual short dress"，如果你的产品能匹配到孕妇（比如它比较宽松，或者就是孕妇穿的），那么你的裙子会更加容易地出现在 "casual short dress" 这种泛词的高位。

<a id="p0055"></a>
**P0055** • 如果家里有三岁女孩，去搜索 "toy for kids"，那么适用于三岁女孩的玩具也会排位更高。

<a id="p0056"></a>
**P0056** 所以这些词不用去打，只需要做收录，并且把自己的准词去拉——准词、长尾人群词、属性词，把这些词的数据做好，你在这些词下面的自然排位就不会差。

<a id="p0057"></a>
**P0057** （八）COSMO 算法的局限性

<a id="p0058"></a>
**P0058** 我们想要专门去迎合 COSMO 算法、专门去做某个人群——其实没什么办法。

<a id="p0059"></a>
**P0059** 为什么？因为如果你是做孕妇群的，跟你有一群竞品也在做孕妇群，那么孕妇搜 dress、casual short dress 也会推荐一堆孕妇群——所以你不一定会有这个优势。

<a id="p0060"></a>
**P0060** 你没有相比别人有更多的人群优势或属性优势，你只能更加去贴合更多的属性词，去做到泛词下的高自然位、针对某些人群的高自然位。

<a id="p0061"></a>
**P0061** 这点也是比较"千人千面"的——不同的人来搜，看到的结果是不一样的。

<a id="p0062"></a>
**P0062** 像我前面跟你们讲，我已经点过了一些预设性的——

<a id="p0063"></a>
**P0063** 说话人1 09:06

<a id="p0064"></a>
**P0064** 浴室镜，所以这两类的产品就会出现。

<a id="p0065"></a>
**P0065** 说话人2 09:10

<a id="p0066"></a>
**P0066** 同样，如果是另外一个——

<a id="p0067"></a>
**P0067** 说话人1 09:12

<a id="p0068"></a>
**P0068** 买家，他点到了——

<a id="p0069"></a>
**P0069** 说话人2 09:13

<a id="p0070"></a>
**P0070** 桌面的化妆镜，那么他现在出来的排序结果推荐就是桌面化妆镜了。

<a id="p0071"></a>
**P0071** （九）登录买家账号后的几个排序加权

<a id="p0072"></a>
**P0072** 加权一：点击/加购过的商品自然位会靠前

<a id="p0073"></a>
**P0073** 登了买家账号以后会发现：自己曾经点击过、加购过的商品，再次搜索以后自然排位会靠前。

<a id="p0074"></a>
**P0074** 举例：搜 showerhead 这个词，再搜一遍 showerhead，有些产品左上角会出现 "Black 标"——还有"分466"这种的（就是我们刚刚点过的产品）。它的自然位天生没有这么靠前，但是由于我点过它，所以自然位往前靠了。

<a id="p0075"></a>
**P0075** 包括广告位也会往前靠。所以投广告的时候你会发现：有些时候竞价给得并不高，但是在 TOS 位置或者一些好的广告位是有曝光的——也是因为你更贴合买家的需求。这个是靠原先的点击或加购行为去排序的。

<a id="p0076"></a>
**P0076** 加权二：后台广告里的"受众"加价

<a id="p0077"></a>
**P0077** 后台广告里面有个"受众"，受众加价里面默认有三种受众：

<a id="p0078"></a>
**P0078** 1. **加购过的用户**

<a id="p0079"></a>
**P0079** 2. **买过你品牌的用户**

<a id="p0080"></a>
**P0080** 3. **后视/Remarketing —— 高意向购买人群**

<a id="p0081"></a>
**P0081** 重点提醒：

<a id="p0082"></a>
**P0082** • 前两个受众不用给加价——因为如果买家有前两个行为，你的自然位天生就排得高，广告位也天生在他们下面排得高；

<a id="p0083"></a>
**P0083** • 第三个受众（高意向购买人群）才是后台默认受众里唯一有必要加价的地方。

<a id="p0084"></a>
**P0084** 这些就是关于 COSMO 算法下的解读了，其实没有这么复杂——大家做好自己的产品，填充好描述、图片就可以了。

<a id="p0085"></a>
**P0085** 二、广告干预自然位的两种方式

<a id="p0086"></a>
**P0086** 接下来说一下关于广告干预自然位的几个方式。前面有跟大家讲过，广告干预自然位有两种方式：预期坑产 和 实际坑产。

<a id="p0087"></a>
**P0087** （一）先说预期坑产：广告的三种干预效果

<a id="p0088"></a>
**P0088** 我通过用广告去在某个词下做自然位、做广告位的效果。

<a id="p0089"></a>
**P0089** 1. 正向干预效果

<a id="p0090"></a>
**P0090** 如果广告是正向干预的话，会产生正向干预效果。

<a id="p0091"></a>
**P0091** 案例：这是西柚里面拉的每日时间数据：

<a id="p0092"></a>
**P0092** • 粉色：广告

<a id="p0093"></a>
**P0093** • 蓝色：自然位

<a id="p0094"></a>
**P0094** • 黄色：SB广告

<a id="p0095"></a>
**P0095** 从 6 月初开始，自然位比较低，在 130 位左右。打着广告，自然位开始往上走：120 → 90多 → 50多 → 中断一段时间 → 又开始打 → 到第 20 名左右就不再上升了。

<a id="p0096"></a>
**P0096** 前面这半段就是广告正向干预的效果。

<a id="p0097"></a>
**P0097** 结论：用广告去拉自然位，7-14 天就够了。

<a id="p0098"></a>
**P0098** 7-14 天他就能到该在的位置——这个动作的意思是你向亚马逊证明你的表现是怎么样的。7-14 天以后你会到一个本来就配得上的位置。

<a id="p0099"></a>
**P0099** 类比：有点像是一个本来就成绩不错的学生上来考试——你初始分班分到了 100、130 名这种 F 班，到这里以后你开始考试（等于买数据的考试），你向亚马逊证明"我配得上更好的班级"——F 班升到 D 班，B 班继续考试考到 C 班，C 班再考到 A 班，最后留在 A 班。这就是广告正向干预的效果。

<a id="p0100"></a>
**P0100** 所以如果有些老师跟你们讲他的产品 7 天内打上首页、7 天内打上前 4 个自然位——这些都是靠产品本身争气。如果产品本身不争气，你就会卡在一个比较尴尬的位置——20 位、30 位、40 位、50 位都有可能。

<a id="p0101"></a>
**P0101** 因为做预期增长的本质就是先要把数据放大——买广告就是在放大数据。

<a id="p0102"></a>
**P0102** 2. 无效干预效果

<a id="p0103"></a>
**P0103** 案例一：广告一直买在高位（第一第二位买了一长段时间），但自然位从初始的 30几 位涨到 20几 位以后就不再动了，停在 20几 位。

<a id="p0104"></a>
**P0104** 无效干预的意思：广告在放大数据，但放大的数据向亚马逊证明"我就配在 20 位"，所以你就一直留在 20 位。

<a id="p0105"></a>
**P0105** 所以大家不要觉得"广告一定开着、一定能拉动、一定能往高拉自然位"——这不现实。

<a id="p0106"></a>
**P0106** 案例二：产品广告一直给到高位，自然位一直在 70几 位徘徊。这也是广告无效干预——广告并没有证明数据更好、配得上更高位置，所以停在这里。不管买 1 个月、2 个月、4 个月、5 个月，会发现卡在这个位置很久——因为链接本身没有预期坑产的变化。

<a id="p0107"></a>
**P0107** 案例三：广告"有一搭没一搭"地给——自然位就在 90 多到 100 之间徘徊。

<a id="p0108"></a>
**P0108** 3. 反向干预效果

<a id="p0109"></a>
**P0109** 广告的反向干预：广告越打反而投喂给亚马逊更差的数据，证明我越烂。

<a id="p0110"></a>
**P0110** 案例：产品在 2 月份的时候没有打广告，自然位在 70几 位不动。然后开始打广告，自然位边打边掉——70几 位掉到 80几 → 90几 → 120。掉到 120 以后广告就停下来不打了，然后自然位慢慢恢复到 90几 → 80几。

<a id="p0111"></a>
**P0111** 核心提醒：

<a id="p0112"></a>
**P0112** • 你的自然位也能进数据——只不过广告进的数据可能比自然位更烂；

<a id="p0113"></a>
**P0113** • 如果广告表现差就别开——不开的效果都比开得好。

<a id="p0114"></a>
**P0114** 4. 案例对比：刷单与广告差数据的对冲

<a id="p0115"></a>
**P0115** 案例：拉的是西柚里面的小时趋势——每天 24 小时每个小时抓一次。一般判定自然位稳不稳定就看小时趋势。

<a id="p0116"></a>
**P0116** 稳定的小时趋势：自然位一直在第一、第二位，波动非常小。

<a id="p0117"></a>
**P0117** 不稳定的案例：在前 3 天每天都是大量广告在打，广告顶 Top 位、大量数据在打，但自然位抖得非常厉害，没有上升趋势——从无到有，时不时闪现、时不时不见。

<a id="p0118"></a>
**P0118** 这个问题是：广告数据并不好。这个时候卖家停止广告了，然后他直接去刷单。

<a id="p0119"></a>
**P0119** 这个产品其实是前后都在刷单——一边刷单边开广告。本来刷单的数据应该波浪形慢慢往上抖、往上走。但前面出不来，是因为广告数据太烂——你刷单刷好数据，广告买烂数据，两个数据一对冲，数据就出不来，自然位就很难往上走。

<a id="p0120"></a>
**P0120** 所以他直接把广告停了，再刷的时候自然位就直接往上窜了，到后面稳定在高位——这个时候之后再开广告才是合适的。

<a id="p0121"></a>
**P0121** 结论：不管是刷数据还是用广告给数据，目的都是为了让它往上走。如果广告是差数据的话，相当于是在反向刷单。

<a id="p0122"></a>
**P0122** （二）正向干预 ≠ 自然位一定会持续上升

<a id="p0123"></a>
**P0123** 我广告给正向数据，站位是不是一定会上升？也不是。

<a id="p0124"></a>
**P0124** 市场竞争视角

<a id="p0125"></a>
**P0125** 假设有一个月搜索量 50 万的大词，三个卖家通过广告干预：

<a id="p0126"></a>
**P0126** • 卖家1：每天出 5 单，低点击低转化；

<a id="p0127"></a>
**P0127** • 卖家2：每天出 5 单，高点击高转化；

<a id="p0128"></a>
**P0128** • 卖家3：每天出 50 单，高点击高转化。

<a id="p0129"></a>
**P0129** 谁能往上走？卖家2 数据好，但市面上不只是你两家，还有卖家3——这个时候卖家2 就不一定能往上走。

<a id="p0130"></a>
**P0130** 因为自然位往上升的前提是要把别人替掉。如果你的数据没有办法证明你能把别人踢掉的话，这个时候你就没有办法往上走。

<a id="p0131"></a>
**P0131** 为什么头部卖家不打广告

<a id="p0132"></a>
**P0132** 如果市面上有很多卖家3，但卖家3 不一定是通过广告出单的——因为自然位也在进数据，自然位也在进流量。

<a id="p0133"></a>
**P0133** 所以已经在高自然位的产品（尤其是词比较大的，像 showerhead 这种大词），这些产品有自然流，这些卖家甚至可以不打广告。你会见到很多卖家——如果词足够大的话，自然位推上去以后广告就停下来或给得很少——是因为它的自然位数据进得足够多，而且自然位进的数据是好的。

<a id="p0134"></a>
**P0134** 所以这个时候你进的广告数据如果跟一堆竞品相比是少的，你也很难往上升。

<a id="p0135"></a>
**P0135** （三）正向干预 + 足量干预：水温与火候的类比

<a id="p0136"></a>
**P0136** 正向干预是推广自然排名的必要但不充分的条件。

<a id="p0137"></a>
**P0137** 如果希望自然排名往上走，得有充足的干预量。

<a id="p0138"></a>
**P0138** 类比：

<a id="p0139"></a>
**P0139** • 蓝色（自然位）= 水温

<a id="p0140"></a>
**P0140** • 红色（广告）= 火，加热用

<a id="p0141"></a>
**P0141** 如果是大词的话，得给到充足的火量。同样的干预量，一天出 5 单：

<a id="p0142"></a>
**P0142** • 可以烧得开一小壶水

<a id="p0143"></a>
**P0143** • 可以烧得开一壶水

<a id="p0144"></a>
**P0144** • 但是烧不开一桶水，也烧不开一盆水

<a id="p0145"></a>
**P0145** 所以一天 5 单的量它只够拉动小词，如果是大词的话，得给到大干预量。

<a id="p0146"></a>
**P0146** （四）用 CPR 量化干预量

<a id="p0147"></a>
**P0147** 干预量得是多少呢？

<a id="p0148"></a>
**P0148** SPR 数据：来自卖家精灵——"如果你希望这个词到第一页的话，8 天得干预多少单"。

<a id="p0149"></a>
**P0149** 我举这个例子不是说这个数据准——SPR 数据不准，所以我们一般不参考 SPR，一般用的是 H10 里面的 CPR 数据。

<a id="p0150"></a>
**P0150** 对比：

<a id="p0151"></a>
**P0151** • 卖家精灵的 SPR：57

<a id="p0152"></a>
**P0152** • H10 的 CPR：521

<a id="p0153"></a>
**P0153** 差距很大。我们实际做产品时，我们知道这个词是非常大体量、非常难推的，所以这边用 SPR 这个概念迁移到 CPR 上面来。其实是因为 CPR 是先出的，SPR 是后出的——SPR 像是没"抄"好的感觉，数据做得不准。

<a id="p0154"></a>
**P0154** CPR 指标的含义：是衡量一个词"是多大一桶水"的概念。

<a id="p0155"></a>
**P0155** 比如 CPR = 521，代表的是：8 天需要干预 521 单，能上到第一页中部以上的位置。

<a id="p0156"></a>
**P0156** > SPR 的解释只是"第一页"，没说中部；CPR 是"第一页中部"。

<a id="p0157"></a>
**P0157** CPR 数据的三个用途

<a id="p0158"></a>
**P0158** 1. **预估这个词的价值**：这个词推到中部能拿到多少单；

<a id="p0159"></a>
**P0159** 2. **做实际坑产**：要给多少单；

<a id="p0160"></a>
**P0160** 3. **做预期坑产**：要给多少单。

<a id="p0161"></a>
**P0161** 预期坑产计算公式：

<a id="p0162"></a>
**P0162** 需要给到的单量 = CPR ÷ 8 ÷ 2

<a id="p0163"></a>
**P0163** 比如 CPR = 521：

<a id="p0164"></a>
**P0164** • 521 ÷ 8 = 65（每天的实际坑产单量）

<a id="p0165"></a>
**P0165** • 再 ÷ 2 ≈ 30（预期坑产需要的单量）

<a id="p0166"></a>
**P0166** > ÷8：因为 CPR 数据是 8 天的；

<a id="p0167"></a>
**P0167** > ÷2：因为预期坑产只需要"干预动这个词"就行——你不需要给满。

<a id="p0168"></a>
**P0168** 而且这 60 单并不代表广告一定要给 60 单——因为广告和自然在一起进数据，所以用广告干预的话其实不用给到这么多。如果是正向干预的话，你给到一定的预期干预以后，自然位会上升，所以这个时候自然加广告会有总流量进来。

<a id="p0169"></a>
**P0169** （五）如何判断一个词"动没动"？看小时趋势

<a id="p0170"></a>
**P0170** 我们对于怎么判断一个词有没有动——给大家看案例。

<a id="p0171"></a>
**P0171** 不被干预的小时趋势：自然位非常稳定、不怎么动。

<a id="p0172"></a>
**P0172** 被干预的小时趋势：以 ASIN 在某词为例：

<a id="p0173"></a>
**P0173** • 没给广告时，自然位在 48 位左右抖动；

<a id="p0174"></a>
**P0174** • 给了广告以后，第二天走到 18 位；

<a id="p0175"></a>
**P0175** • 第三天继续给广告，到 15 位；

<a id="p0176"></a>
**P0176** • 第四天再继续给，到 11 位；

<a id="p0177"></a>
**P0177** • 后面相对来说比较平稳。

<a id="p0178"></a>
**P0178** 结论：自然位如果不受外力干预，会保持匀速行驶（不动）；如果给的是正向的力，它就会开始往上走，且抖动着往上走，不会一下子窜到该在的高位。

<a id="p0179"></a>
**P0179** 它会慢慢从 48 → 20几 → 10几 → 第10位，可能这个地方就已经不动了。

<a id="p0180"></a>
**P0180** 这是判断自然位有没有受干预的最具体的方式。甚至不用看 CPR 都没关系——一天给个 5 单，看他动不动。如果动不起来，说明单量不够或者数据不够好。

<a id="p0181"></a>
**P0181** 反例：广告给得满但自然位不动

<a id="p0182"></a>
**P0182** 第二个产品：自然位抖得非常厉害，全程广告给得很满（粉色线）——广告给的位置又高、时间又长，广告数据量很够。

<a id="p0183"></a>
**P0183** 广告把它从 48 位拉到 20 位左右，到 19 位算高点了——平时大概在 40几 → 30几 → 20几。

<a id="p0184"></a>
**P0184** 到了某个时间节点广告就没再给了，当广告一停以后，还是在原地抖动——那就说明你的广告没有什么作用，给了跟没给差不多。

<a id="p0185"></a>
**P0185** 大词不必给：自然抖动也能上

<a id="p0186"></a>
**P0186** 再看自然排名第 30 的另一个词：每天的抖动幅度很大。最近这两天广告没怎么给了，自然排名跟原来一样——所以这个词它不受外力干预，给不给都是在 10几 位左右抖动，这种词可以不给广告。

<a id="p0187"></a>
**P0187** 包括后面如果想要往回撤广告、缩广告，也是用这个来判断。

<a id="p0188"></a>
**P0188** CPR 失效的场景

<a id="p0189"></a>
**P0189** 如果你已经到了第一页中部，还想再往上推的话，CPR 指标就没什么参考的了。这时候只需要看：现在给了广告单以后，自然排名动不动就可以了。

<a id="p0190"></a>
**P0190** 也就是说看广告是不是在"加热水温"——如果是的话，加热跟不加热的区别会很大；如果不是，给不给都一样。

<a id="p0191"></a>
**P0191** 泛词案例

<a id="p0192"></a>
**P0192** 下面 "doc supply" 这个泛词（产品是狗项圈、电击项圈），supply 是个泛词——在这个泛词里面，广告也是不用给的。广告不给的情况下，它会自己在原地抖动，在 30 位左右抖动，它在某一天突然出现，然后在原地抖动。

<a id="p0193"></a>
**P0193** 所以你的自然位都有自己调节的机制，不是一定要靠广告才能动起来——自然位也在进数据，自然位进的数据也算数。

<a id="p0194"></a>
**P0194** 三、自然位的瓶颈位（坑位上限）

<a id="p0195"></a>
**P0195** 到这儿为止，已知：广告想拉自然位，需要满足两个条件：

<a id="p0196"></a>
**P0196** 1. **正向干预**

<a id="p0197"></a>
**P0197** 2. **足量干预**

<a id="p0198"></a>
**P0198** 第三个：正向干预 + 足量干预，自然排名是不是能一直稳步上升？不一定。

<a id="p0199"></a>
**P0199** （一）案例：永远推不到头部的产品

<a id="p0200"></a>
**P0200** 举例：左边这个产品我们在推——基础款，售价 $24，15 个评论。假设每天给到足量的干预 + 正向干预，它能否推到这个词下面的顶部？

<a id="p0201"></a>
**P0201** 这个词叫"男士皮钱包"，右边这一堆是已经在头部的产品。能不能推到头部？不能。

<a id="p0202"></a>
**P0202** 为什么？前面讲过坑产这个概念——你要上去就得把它顶掉。要顶掉，意味着你在这个坑位的产出要比别人多。

<a id="p0203"></a>
**P0203** • 同样售价 $24：有一个产品是 Levi's，国际大牌、有品牌效应，评论数量也比咱们多——你没法替代；

<a id="p0204"></a>
**P0204** • 同款式：下面有人比咱们更便宜，评论数量又多——你顶不掉。

<a id="p0205"></a>
**P0205** 会发现谁都顶不了。

<a id="p0206"></a>
**P0206** 如果让你左边这个产品到这个位置，只会让亚马逊坑位遭受损失。所以即使你每天刷足够的、好的单量——一定能上来，但上来以后会马上下去。因为亚马逊感觉不对劲，这个坑位赚得没以前多了，他就会把你拽下去。

<a id="p0207"></a>
**P0207** （二）瓶颈位的判定方式

<a id="p0208"></a>
**P0208** 即使是正向干预 + 足量干预，依然会有推广瓶颈，叫"自然位上限"。

<a id="p0209"></a>
**P0209** 判定方式非常简单：

<a id="p0210"></a>
**P0210** 在同一个位置短期内被下拽 3 次，就能判断出来。

<a id="p0211"></a>
**P0211** 案例：广告位一直给到顶且全天给得足量，看自然位——前面到 25 位时被拽到 47 位，又到 30 位、又被拽到 45 位，又到 30 位、又被拽下去——会发现这个产品没办法超过 30 位。

<a id="p0212"></a>
**P0212** 每到 30 位都会往下拽——这个有点像"无形的大手在宏观调控"，把你往下拽。这个时候不管你给的干预数据有多好都没用，因为已经被卡在这儿了——这个位置就是这个链接当前的瓶颈位置。

<a id="p0213"></a>
**P0213** 大多数老链接都已经遇到了。推了好多年的链接、或接近一年的链接，在大部分的词估计都会长这个样子——不是广告给得不够，也不是给得不好，是实际到了那个位置以后自然数据不够，再往上走亚马逊要承受损失，所以会把你往下拽。

<a id="p0214"></a>
**P0214** （三）实例：巴克尔（Buckle）这个词的瓶颈

<a id="p0215"></a>
**P0215** 我们看 buckle（巴克尔）这个词现在在 30 位，点开来看——广告前面一直在给。然后我们看每日趋势，把价格拉进来——价格变化会影响上限。

<a id="p0216"></a>
**P0216** 只拿 8 月 28 号到现在的时间（价格涨上去以后），就能看清楚自然坑位上限：大概 20 位。

<a id="p0217"></a>
**P0217** 因为从 8 月 26 号 20 位被拽到 45 → 又到 20 位被拽到 33 → 又到 26 又被往下拽 → 又到 25 → 在 20几 维持几天又被拽下来。

<a id="p0218"></a>
**P0218** 所以你想要继续往上冲——可以努力地冲，但亚马逊也会努力把你往下拽。会起到一个非常有趣的反效果：推得越用力，被拽得越狠。可能今天在 22，明天到 56，但是后天会恢复——因为亚马逊也急了，不想让你上去，所以拽得比较厉害。

<a id="p0219"></a>
**P0219** 这种波动很正常——已经被卡住了，这种词不用再去做过多努力了。

<a id="p0220"></a>
**P0220** （四）想突破瓶颈：改变 售价 × CTR × CVR

<a id="p0221"></a>
**P0221** 如果遇到这种词还想往上推，回顾坑产公式：

<a id="p0222"></a>
**P0222** 坑产 = X(曝光) × 售价 × CTR × CVR

<a id="p0223"></a>
**P0223** 要把"售价 × CTR × CVR"的乘积变大才行。如果这个乘积不变，X 不会再变大。

<a id="p0224"></a>
**P0224** 很多卖家遇到这种卡点的第一反应：降价。

<a id="p0225"></a>
**P0225** 可以做活动，但做完活动会回去的——做活动的时候能到高位，做完活动会下来。本质的售价 × CTR × CVR 没变。

<a id="p0226"></a>
**P0226** 个人不喜欢 LD（Lightning Deal）：是因为 LD 当天能上去，但 LD 过完会下来，而且 LD 时间太短不足以影响什么数据，但又会干预到你的判断。7DD 好一点。

<a id="p0227"></a>
**P0227** 所以现在我们看到自然位波动数据时，往往会点每日趋势再带上"价格"一起判断。

<a id="p0228"></a>
**P0228** 举例：某产品某段时间在做 7DD，价格会下来一段时间、自然位上去——但实际上这个词不管价格上来下来，已经卡在 14 位左右动不了，再怎么努力也动不了。他要去改变的是"售价 × CTR × CVR"这三者，而不是广告数据越大越好——是 CTR、CVR 得往上走。

<a id="p0229"></a>
**P0229** （五）降价的逻辑

<a id="p0230"></a>
**P0230** 降价是一种方式。降价能涨自然位的本质在于：售价的降幅小于 CTR × CVR 的涨幅。

<a id="p0231"></a>
**P0231** 这种情况下也就是售价降了 10%，CTR × CVR 涨幅超过了 10%，让坑产成绩变大，自然位就能涨。

<a id="p0232"></a>
**P0232** 实战案例：降价过头反而掉

<a id="p0233"></a>
**P0233** 我们之前做过一个标品：竞品平均价格 $11.99，我们上架价格 $9.99 就是很有优势的价格了。推到一个瓶颈位置以后发现到了前 4 上不去了——

<a id="p0234"></a>
**P0234** • 降到 $8.99：自然位涨了，非常好；

<a id="p0235"></a>
**P0235** • 觉得还想再推，再降到 $7.99：自然位反而掉了。

<a id="p0236"></a>
**P0236** 因为这个情况下其实就跟前面讲的一样：你需要让"售价 × CTR × CVR"的乘积是变大的，而不是单纯让价格变低。售价变低只是涨 CTR、CVR 的一种方式，不是唯一的方式，也不是必定的方式。

<a id="p0237"></a>
**P0237** 同样的，有些时候在旺季的时候可能会涨价——你的价格肯定是不动的，对吧？因为那个时候你涨价 CTR、CVR 可能不变，那么这三者的成绩会变大，自然位会浮动甚至往上涨。这就是涨价降价的逻辑。

<a id="p0238"></a>
**P0238** （六）瓶颈词的广告策略

<a id="p0239"></a>
**P0239** 到现在为止，大家已经知道怎么去判断瓶颈位置了——所以你们可以找到这类型的词，广告不需要太用力了，因为广告数据不足以去拉动它了。

<a id="p0240"></a>
**P0240** 等于说你在放大的是数据，但即使再怎么放大数据，或者刷单也好、给他硬往上刷，他也会往下掉到他配在的位置。

<a id="p0241"></a>
**P0241** （七）坑位上限会随短期因素变化

<a id="p0242"></a>
**P0242** 坑位上限不是不动的——会跟随你的短期因素变化（自然坑位是短期内的坑位天花板，是短期内的坑产）：

<a id="p0243"></a>
**P0243** 因素一：价格变化

<a id="p0244"></a>
**P0244** • 你跟竞对都没降，你降价了 → CTR 上升、坑位上限上升；

<a id="p0245"></a>
**P0245** • 竞对降价你不降 → 站位会掉。

<a id="p0246"></a>
**P0246** 因素二：活动

<a id="p0247"></a>
**P0247** 做 7DD、BD、LD 时。

<a id="p0248"></a>
**P0248** 因素三：评论星级

<a id="p0249"></a>
**P0249** 因素四：标（BSR、AC、有色标等）

<a id="p0250"></a>
**P0250** （八）案例：BSR/AC 标对坑位上限的影响

<a id="p0251"></a>
**P0251** 案例一：AC 标掉了

<a id="p0252"></a>
**P0252** 这个产品原先自然位全部在前 4，很稳定。广告也不是一直顶着给的，广告位不高。

<a id="p0253"></a>
**P0253** 到 8 月 25 号，自然位从第三第四突然掉到了第十，而且后面再怎么都回不来——一直稳在第十。

<a id="p0254"></a>
**P0254** 原因：AC 标掉了。原先售价偏高一点点，有 AC 标的时候 CTR 还 OK，但掉了 AC 标以后 CTR 不太行了。

<a id="p0255"></a>
**P0255** 这个时候再给更多广告有没有用？没用。因为产品本身的坑产变了，给再多广告数据只是在放大这个数据而已，自然位也上不去。

<a id="p0256"></a>
**P0256** 现在基本上是缺什么补什么：

<a id="p0257"></a>
**P0257** • 缺数据 → 买；

<a id="p0258"></a>
**P0258** • 缺 CTR → 想别的办法。

<a id="p0259"></a>
**P0259** 举个最简单例子：可以考虑降价；第二种方式把 AC 标弄回来。还有一些卖家如果产品在 BS2，而且距离第一名不远，建议你不管怎么样把单量买到、把 BS 标拿过来——有这个标跟没这个标，CTR、CVR 差距非常大，赶紧去买。

<a id="p0260"></a>
**P0260** 案例二：涨价掉坑位

<a id="p0261"></a>
**P0261** 这个产品在某天突然涨了几美金的价格：

<a id="p0262"></a>
**P0262** • 涨价前：自然坑位上限 30 位左右；

<a id="p0263"></a>
**P0263** • 涨价后：自然坑位上限变成 40-45 位左右，甚至 50 位。

<a id="p0264"></a>
**P0264** 调度非常明显——自然位的坑产变化很快：7 天内能拉上去，7 天内也能掉下来。

<a id="p0265"></a>
**P0265** 案例三：换节点拿 BSR 标

<a id="p0266"></a>
**P0266** 某段时间换节点出了一个 BSR 标：

<a id="p0267"></a>
**P0267** • 没 BSR 标时：自然位在 20 位左右；

<a id="p0268"></a>
**P0268** • 有 BSR 标后：突然涨到第 10 位左右，卡在第 10 位（不是无限上涨）；

<a id="p0269"></a>
**P0269** • 标掉了以后：又慢慢掉回原来的 20 位。

<a id="p0270"></a>
**P0270** 结论：缺什么补什么——

<a id="p0271"></a>
**P0271** > 有卖家问："老师我原来有 BS 标的时候在第 8 位，现在到了 20 位，怎么样回到第 8 位？"

<a id="p0272"></a>
**P0272** > 答：跟之前相比你就缺个 BS 标，把那个标拿过来。

<a id="p0273"></a>
**P0273** 同样的：

<a id="p0274"></a>
**P0274** • 缺数据 → 买数据；

<a id="p0275"></a>
**P0275** • 价格不一样 → 换回来。

<a id="p0276"></a>
**P0276** 案例四：抢 BSR 标

<a id="p0277"></a>
**P0277** 之前有一个产品跟竞对一直在抢 BS 标——两个人一直是第一名第二名。但有 BSR 标跟没 BSR 标的数据差很多，而且有了 BSR 标如果能稳定住的话，CTR、CVR 会比对方高很多。在 CTR、CVR 高很多的情况下，自然位会跟对方拉开，对方再去追就很难了。

<a id="p0278"></a>
**P0278** 所以这种抢标的情况，头部几家会抢得比较焦灼，甚至亏钱都可能要去把这个标拿下来。

<a id="p0279"></a>
**P0279** （九）链接的瓶颈由本身承接决定

<a id="p0280"></a>
**P0280** 你能到哪个位置是由链接本身的承接决定的。

<a id="p0281"></a>
**P0281** 四、广告并不是维稳自然流量的必要因素

<a id="p0282"></a>
**P0282** 广告是干预表现同时去放大数据的。

<a id="p0283"></a>
**P0283** 如果一个链接的自然位已经被干预到瓶颈了以后，可以不给广告。

<a id="p0284"></a>
**P0284** 案例：达到瓶颈位后停广告

<a id="p0285"></a>
**P0285** 这个链接：

<a id="p0286"></a>
**P0286** • 原先自然位在 120-130；

<a id="p0287"></a>
**P0287** • 给了广告以后，大概一周多干预到第 40 多位；

<a id="p0288"></a>
**P0288** • 广告给到顶部给了一个多月，发现自然位大概在 42 位左右就是瓶颈位置；

<a id="p0289"></a>
**P0289** • 直接停掉广告——停掉以后自然位掉不掉？也不掉。

<a id="p0290"></a>
**P0290** 因为你本来就配在 52，你开广告只为了向亚马逊证明"我配在 52"。现在把广告一关它还在 52。在 11 月份这个时段还上升了——是因为做活动上升上去，做完活动又会调回原来配在的 50几 位。

<a id="p0291"></a>
**P0291** 缩广告的实操方法

<a id="p0292"></a>
**P0292** 很多运营的问题不在于不会放广告，而在于不会缩广告。广告表现还行，就不舍得关、不敢关、不舍得降——其实可以通过慢慢砍花费去实现。

<a id="p0293"></a>
**P0293** 像这个例子是砍得有点快了——你们可以砍慢一点：减少广告流量进量，看自然位变化。这个变化用小时趋势去看：

<a id="p0294"></a>
**P0294** • 小时趋势如果开始抖着往下掉 → 先别看了（广告还要给）；

<a id="p0295"></a>
**P0295** • 小时趋势在原地抖动不变 → 可以再继续砍。

<a id="p0296"></a>
**P0296** 自然位已在有效位 → 不需要广告维持

<a id="p0297"></a>
**P0297** 广告只是在买额外的数据进来。自然位如果已经在一个有效位置的话，就不太需要广告了。

<a id="p0298"></a>
**P0298** 举例：某词带的链接，如果在 42 位——它是不是有效位置？用积木去查这个词的有效坑位是 14-62 位。所以如果占 50 位的话，是有效坑位。

<a id="p0299"></a>
**P0299** 如果继续干预自然位不会再上升，这时候就可以考虑不太干预它了——再亏钱去打它，性价比不会太高：再亏钱、给的反馈自然流量并不会进得更多。

<a id="p0300"></a>
**P0300** 注意：如果广告不赚钱的话，广告就是个投资行为——你要往这种词上面投资，得看到持续投资的性价比在哪里。如果没有性价比就开始往回撤。

<a id="p0301"></a>
**P0301** 广告与自然位的总结

<a id="p0302"></a>
**P0302** 如果不进行广告干预的话，在链接没有发生坑产变化的情况下，自然位会基本稳定。

<a id="p0303"></a>
**P0303** 广告可以放大短期内的坑产数据，从而干预预期坑产，但是无法控制自然位上限。

<a id="p0304"></a>
**P0304** 怎么讲？

<a id="p0305"></a>
**P0305** 举例：之前在旺季的时候买三个广告位（TOS、ROS、PP），发现只有 TOS 位置好那么一点，所以开始只买 TOS 位置——自然位确实从 100 多涨到了 20几、涨到第 10几。但到了第 10几 以后自然位开始掉——

<a id="p0306"></a>
**P0306** 到了第 10几 位以后，真正如果你的 ROS 位置表现不行的话就是不行。因为 ROS 位置是体现你在自然位的表现。所以即使用 TOS 位置买到了很多好数据，但实际上 ROS 表现不行，到了高位以后会开始掉。

<a id="p0307"></a>
**P0307** 掉下来其实就是无法控制自然坑位上限——自然坑位上限是由链接本身的承接能力决定的。所以我们很多时候推广都是用最小的成本推到能推到的最高位置，然后开始控花费、把当前阶段的盈利做到最大化，再开始蓄力做下个阶段的推广。

<a id="p0308"></a>
**P0308** 7-14天周期案例

<a id="p0309"></a>
**P0309** 自然坑位的干预周期大概是 7-14 天。看一个数据：短期内把一个新链接拉到高位的数据——

<a id="p0310"></a>
**P0310** 新链接 $9.69、66 个评论（评论比较少的情况下），但产品本身比较好。前面先进的是广告——先进了广告以后过了两天开始出自然位，自然位的干预时间是 1 月 14 号到 1 月 21 号左右就到了一个高位。

<a id="p0311"></a>
**P0311** 所以 7 天足量又正向的干预，他就可以到自己配在的位置。但是每个链接配在的位置不一样——这条链接能推上去不是因为咱们打法多高明，纯粹是因为他配在高位置——本身就是个优等生，所以干预起来很容易。

<a id="p0312"></a>
**P0312** 五、干预预期坑产的两种方式

<a id="p0313"></a>
**P0313** （一）方式一：投喂数据

<a id="p0314"></a>
**P0314** 用广告花钱去投喂数据。比如花广告费用 SP 广告去干预某个词下的 CTR、CVR 数据，影响平台对你产品的预期坑产判断——投喂了好的 CTR、CVR，亚马逊就给我更大的曝光量、给更高的位置。

<a id="p0315"></a>
**P0315** 如果做的是刷单，刷这个词也是在投喂数据——同理一模一样的道理，只不过用白帽的方式。白帽既然叫做合规刷单，就代表着不能控制数据是好是坏——可能数据是差的，差的就上不去；但刷单的话刷的一定是好数据，所以更容易上得去。但最后能不能稳在那个位置，取决于链接本身。

<a id="p0316"></a>
**P0316** （二）方式二：直接改变

<a id="p0317"></a>
**P0317** 不投喂也行——直接改变。

<a id="p0318"></a>
**P0318** 最常见做法：降价

<a id="p0319"></a>
**P0319** 比如做 7DD 时——什么广告都不投，自然位也会往上走——这叫直接改变。因为虽然没有广告数据进来，但是有自然数据，有自然数据以后预期 CTR、CVR 变了，自然位就会提。

<a id="p0320"></a>
**P0320** 包括：

<a id="p0321"></a>
**P0321** • 提价、降价 → 直接改变预期坑产；

<a id="p0322"></a>
**P0322** • 来差评、好评 → 直接改变；

<a id="p0323"></a>
**P0323** • 有没有 BSR 标、有没有变色标 → 直接改变。

<a id="p0324"></a>
**P0324** （三）两种方式的选择

<a id="p0325"></a>
**P0325** 总结：动用预期坑产、动自然位的方式有两个：

<a id="p0326"></a>
**P0326** 1. **买数据**（不管合规不合规，反正买数据进来，自然位就能动）；

<a id="p0327"></a>
**P0327** 2. **直接改变**（最常见的是降价，还有做活动、搞好评、搞标）。

<a id="p0328"></a>
**P0328** 做活动的话做完活动会回去。

<a id="p0329"></a>
**P0329** 优先级建议：哪个更容易、性价比更高就选哪个。

<a id="p0330"></a>
**P0330** • 一般最容易的方式：降价。

<a id="p0331"></a>
**P0331** • 差评比较多 → 搞好评，先不买流量；

<a id="p0332"></a>
**P0332** • 黑标掉了 → 搞黑标；

<a id="p0333"></a>
**P0333** • 缺 BS 标 → 搞 BS 标；

<a id="p0334"></a>
**P0334** • 看哪个对你来说更容易。

<a id="p0335"></a>
**P0335** 有些卖家会换图片（换主图）——也是改变 CTR 的方式，但效果不能保证。

<a id="p0336"></a>
**P0336** 反例：低效操作

<a id="p0337"></a>
**P0337** 有些卖家动作做得很慢——一个产品推着推着推不上去了，觉得是不是主图有问题，找美工弄了 7 天把主图弄出来，又上架又测了一个月——非常低效。

<a id="p0338"></a>
**P0338** 一般来说亚马逊做到现在，你的产品只要是个腰部产品主图一般没什么太大问题，所以换主图的效果并不会太明显。找关键的地方去动，不要在每个环节都动很多。

<a id="p0339"></a>
**P0339** （四）7DD 后的维稳问题

<a id="p0340"></a>
**P0340** 有卖家问：老师我做 7DD 的时候自然排名很高，做完就掉下来了，有没有办法维稳在高位？

<a id="p0341"></a>
**P0341** 只能降价。

<a id="p0342"></a>
**P0342** 为什么？做 7DD 的时候自然位高，是因为做活动相当于是开"挂"的状态——CTR、CVR 都高。现在活动完掉下来了就是因为 CTR、CVR 掉下来了。所以如果想要维持，就人为把这个拔高就行了——但人为拔高（降价）值不值得？

<a id="p0343"></a>
**P0343** 要么人为拔高，要么直接买单量——都可以维稳那个位置。

<a id="p0344"></a>
**P0344** 但其实大家问这个问题的时候，你不是想要那个位置——你是想要"无痛"维稳那个位置，不付出任何代价就轻轻松松回到原位。位置是在变的，会上去也会下来——不能只接受降价上去、不接受涨价掉下来。

<a id="p0345"></a>
**P0345** 六、直接改变（降价打法）案例实操

<a id="p0346"></a>
**P0346** （一）案例一：低价螺旋打法

<a id="p0347"></a>
**P0347** 这个产品是阔腿裤，原先售价 $16-17。推了很久推不上去——自然位一直在很无效的位置（50-60位）。广告怎么打最好也就到 20-30 位，而且广告亏、自然流量进不来。

<a id="p0348"></a>
**P0348** 所以这个链接直接采用了"低价"的方式：在某个节点直接降到 $9.99——大概过了几天自然位就出来了，慢慢到了前 5 位。

<a id="p0349"></a>
**P0349** 其实就是直接改变 CTR、CVR——CTR、CVR 高了，"售价 × CTR × CVR"整体数据变高，自然位就可以往上涨，都不需要投喂、广告是不开的。

<a id="p0350"></a>
**P0350** 下面有一条橙色的线——是 AC 标的意思，不是广告位的意思。所以这个产品从头到尾这个过程是没有广告的。

<a id="p0351"></a>
**P0351** （二）案例二：清货式降价

<a id="p0352"></a>
**P0352** 这个产品本来卖 $20 左右，他想清货，所以直接降到 $9.99——降下去以后自然位就出来了，又涨到顶部，有了 AC 标就一直在第一第二位。

<a id="p0353"></a>
**P0353** 其实都是直接降价，从而改变预期坑产。

<a id="p0354"></a>
**P0354** （三）适用范围与原理

<a id="p0355"></a>
**P0355** 这个做法很多老链接都可以用，适用于：

<a id="p0356"></a>
**P0356** • 单价比较低；

<a id="p0357"></a>
**P0357** • CPA 又高的产品。

<a id="p0358"></a>
**P0358** 举例：原裤 $19.99 售价，CPA 要 $10——出一单实际到手 $6.99（广告实际出单 $6.99）。这个时候不如直接降价：降到 $9.99 实际亏的还更少，而且不需要额外投入——是链接本身出了单才花这个钱，本身没出单的不用花。

<a id="p0359"></a>
**P0359** 所以广告 CPA 偏高的、标品/半标的老链接、单价又低的，建议直接降价——这是推广手段。

<a id="p0360"></a>
**P0360** 降价以后的资源优势是被刺激出来的——低价螺旋打法。

<a id="p0361"></a>
**P0361** （四）低价螺旋打法对比

<a id="p0362"></a>
**P0362** 低价螺旋打法对于新品：问题在于价格涨不上去。

<a id="p0363"></a>
**P0363** 对于老链接：可以用这个方式。评论基础好、收录词越多，效果越好。

<a id="p0364"></a>
**P0364** 强烈推荐：单价比 CPA 高的产品去做。

<a id="p0365"></a>
**P0365** 举例：现在一个产品 $19.99，最简单的打法：降到 $9.99——所有收录词都会根据现在降价后的超高 CTR、CVR 数据往上拉，广告不需要给他就会直接往上拉。

<a id="p0366"></a>
**P0366** （五）使用前提：要有收录词

<a id="p0367"></a>
**P0367** 如果想要用这个方式，有一个前提：要有收录词。

<a id="p0368"></a>
**P0368** 如果没收录词的话就出不来。所以做低价之前得打个收录。

<a id="p0369"></a>
**P0369** 收录的最简单方式：SP 自动广告（Auto）

<a id="p0370"></a>
**P0370** 最简单的收录方式就是 SP 的自动广告（Auto）——很简单的打收录方式。

<a id="p0371"></a>
**P0371** 这种 Auto 的目的不是为了出单，是为了在更多的词产生曝光和点击——前面讲过曝光、点击就能收录。

<a id="p0372"></a>
**P0372** 所以只需要先有相关性——不需要有什么单量，自然位靠超低价就可以了，只需要有收录。

<a id="p0373"></a>
**P0373** 这种收录不管用什么方式，最好是：

<a id="p0374"></a>
**P0374** • 100 个点击；

<a id="p0375"></a>
**P0375** • 一天预算少、竞价低；

<a id="p0376"></a>
**P0376** • 100 个点击能分配到 100 个词——那是最好的。

<a id="p0377"></a>
**P0377** 千万不要在这种情况下开 Auto 还说"我出了多少单"——单量不重要！

<a id="p0378"></a>
**P0378** 如果 100 个点击点到 10 个词的话，那就亏；但如果能点到 100 个词的话，就达到 100 个词的收录。

<a id="p0379"></a>
**P0379** 这个时候 SP Auto 投的目的是为了跟更多词产生关系——超低价是为了跟产生关系的词，直接拉出一个高 CTR、高 CVR，从而拉动自然位。

<a id="p0380"></a>
**P0380** （六）低价后涨价的逻辑

<a id="p0381"></a>
**P0381** 之后才会去考虑拉动售价——拉售价也很有讲究。绿色是售价：这个产品大概过了一小段时间就开始往上涨价。

<a id="p0382"></a>
**P0382** 涨价的逻辑

<a id="p0383"></a>
**P0383** 因为低价是用于"高刺激"的，CTR、CVR 都是被拉得非常高的，所以涨价的时候自然位可能会掉，但是没关系——只要掉下来以后比原来高你就是赚了，因为它是一种推广手段。

<a id="p0384"></a>
**P0384** 所以低价用于高刺激——高低价刺激完了以后，等自然位平稳后开始涨价。这个非常要讲究的点。

<a id="p0385"></a>
**P0385** 涨价的常见错误

<a id="p0386"></a>
**P0386** 很多卖家会出现问题：

<a id="p0387"></a>
**P0387** • 有些卖家不舍得自己的高价位，不舍得涨价；

<a id="p0388"></a>
**P0388** • 有些卖家涨价以后疯狂连着涨——这都不对。

<a id="p0389"></a>
**P0389** 涨价时机判断：看小时趋势

<a id="p0390"></a>
**P0390** 如果想要达到最好的效果，自然位看小时趋势。

<a id="p0391"></a>
**P0391** 正常来讲：

<a id="p0392"></a>
**P0392** • 小时趋势抖动很厉害 → 站位不稳；

<a id="p0393"></a>
**P0393** • 小时趋势相对稳定 → 可以涨价。

<a id="p0394"></a>
**P0394** 比如自然位在第 1-2-3-4 位这样抖动，就不算抖——这个情况下可以涨价。

<a id="p0395"></a>
**P0395** 而且要一点点涨——当天涨了一点，看自然位有没有在波动下跌：

<a id="p0396"></a>
**P0396** • 自然位还是稳的 → 可以继续涨；

<a id="p0397"></a>
**P0397** • 自然位但凡波动起来 → 等它停下来再继续。

<a id="p0398"></a>
**P0398** 所有的动作都尽量等一个词稳在原地再开始动。比如某条链接前面这段时间是抖的，后面这段时间稍微平了一点，再等两天还是这样的就可以开始动了。

<a id="p0399"></a>
**P0399** 七、推广方式选择：性价比为先

<a id="p0400"></a>
**P0400** 我们一般来说会选择性价比最高的推广方式——不要执着于某一种打法（比如"我就要干大词""我就要从小词开始打"）。

<a id="p0401"></a>
**P0401** 不同类型产品的选择

<a id="p0402"></a>
**P0402** 做刷单性价比最高的产品：

<a id="p0403"></a>
**P0403** • 流量词集中、词根少（方便小词带大词、大词带小词）；

<a id="p0404"></a>
**P0404** • 评论多——评论多的产品用刷单去给一个单量刺激，让它刺激到高位它就不会掉下去。

<a id="p0405"></a>
**P0405** 评论少的产品：刷了也没用，上去又会掉回来。

<a id="p0406"></a>
**P0406** 单价低、CPA 高的产品：要去衡量——广告出来的 CPA 和直接降价相比怎么样。

<a id="p0407"></a>
**P0407** 关于"活动价"的问题

<a id="p0408"></a>
**P0408** 有卖家会说："我会影响我的活动价"——咱们就暂时先不要管活动价了：

<a id="p0409"></a>
**P0409** • 现在刺激自然位比较重要——活动前后站位不动，但你刺激了站位肯定是动的；

<a id="p0410"></a>
**P0410** • 暂时活动价格弄得很低，就先别做活动了——这个问题不是很大的。

<a id="p0411"></a>
**P0411** 八、预期坑产推广的特征：做完后的产品长什么样？

<a id="p0412"></a>
**P0412** 预期坑产影响总结：两个方式——投喂、直接改变——哪个对你来说性价比最高就选哪个。

<a id="p0413"></a>
**P0413** 但如果自然位已经卡在了一个瓶颈位的话，不要再投喂了——投喂不上去了。

<a id="p0414"></a>
**P0414** 接下来跟大家总结一下：如果一条链接做的是预期坑产的推广，会呈现什么效果？

<a id="p0415"></a>
**P0415** （一）西柚反查竞品的方法

<a id="p0416"></a>
**P0416** 回到西柚页面：如果有变体的话，点附体（变体），点完以后就可以看到这个产品的推广周期过程——最远可以看两年。所以两年内上架的产品你是比较明显的能看到它的数据的。

<a id="p0417"></a>
**P0417** （二）案例：圣诞节冰箱门把手装饰

<a id="p0418"></a>
**P0418** 拉一个圣诞节的冰箱门把手装饰：

<a id="p0419"></a>
**P0419** 看断货情况

<a id="p0420"></a>
**P0420** 这个产品季节性强，中间断了好多次——在旺淡季的时候断货。

<a id="p0421"></a>
**P0421** 看推广方式

<a id="p0422"></a>
**P0422** 上架以后采用什么方式来推广？在某个点直接降价——这个时候他开始推广的节点。

<a id="p0423"></a>
**P0423** 如果你看到竞对足够多的话，会很容易判断这个竞对想干嘛——他们做的每个动作都是有理由的，一定是想要达成什么目的才做这个动作。

<a id="p0424"></a>
**P0424** 去年圣诞季推广路径

<a id="p0425"></a>
**P0425** 看去年他在圣诞季的推广方式：

<a id="p0426"></a>
**P0426** • 自然流居多，广告流非常少；

<a id="p0427"></a>
**P0427** • 上架以后是否有给广告流——拉短一点看，发现他从头到尾好像都没有广告，都是自然流，而且自然流是从低往高去给的；

<a id="p0428"></a>
**P0428** • 有一点点广告流，浅色部分有一点，但给得不多——给的"广告流量得分"很少。

<a id="p0429"></a>
**P0429** 所以这个产品的打法可以理解为：低价刺激 + 小量广告拓词的措辞。

<a id="p0430"></a>
**P0430** 涨价节点

<a id="p0431"></a>
**P0431** • 9 月 12 号开始涨价：从 $19.9 涨到 $11.9；

<a id="p0432"></a>
**P0432** • 后面又涨到 $13；

<a id="p0433"></a>
**P0433** • 又到大概 $15 左右；

<a id="p0434"></a>
**P0434** • 再往后涨到 $19.99 → $20.99（最高峰）；

<a id="p0435"></a>
**P0435** • 后面开始降价（要清货了——圣诞季快过了）；

<a id="p0436"></a>
**P0436** • 黑五过后没货了，今年就结束了。

<a id="p0437"></a>
**P0437** 这就是他去年的整体历程——涨价涨到后面就是断货。整个圣诞季应该 12 月还得卖，但他没货了。

<a id="p0438"></a>
**P0438** 今年的推广走势

<a id="p0439"></a>
**P0439** 今年上来：先给一个高价 → 降价降到 $9.99 → 给一波广告（但是推早了，6 月 5 月份明显推早了，咱们不管他）。

<a id="p0440"></a>
**P0440** 大家可以通过这个方式来看竞品的推广。

<a id="p0441"></a>
**P0441** （三）判断白帽推广的方法

<a id="p0442"></a>
**P0442** 判断一个产品是不是白帽推的有一个方式——看它的流量：

<a id="p0443"></a>
**P0443** • 流量是自然先进的、广告流逝一点点出来的 → 大概率是白帽推广；

<a id="p0444"></a>
**P0444** • 先进的自然流，或者给一点广告自然流就蹭着往上涨 → 大概率不是白帽。

<a id="p0445"></a>
**P0445** （四）做预期坑产产品的特点

<a id="p0446"></a>
**P0446** 特点一（流量结构）：用广告去撬自然——用一点好的广告数据把自然流量慢慢撬出来

<a id="p0447"></a>
**P0447** 所以产品在全程中：

<a id="p0448"></a>
**P0448** • 广告流量占比都是低的；

<a id="p0449"></a>
**P0449** • 自然流在不停地涨；

<a id="p0450"></a>
**P0450** • 涨到后面广告流占比还是低的；

<a id="p0451"></a>
**P0451** ——这是做预期坑产产品的非常大的特点。

<a id="p0452"></a>
**P0452** 特点二（关键词走势）：自然位梯度式上涨

<a id="p0453"></a>
**P0453** 具体到关键词走势：

<a id="p0454"></a>
**P0454** • 上架以后先进了一点自然流，但不大也不稳定；

<a id="p0455"></a>
**P0455** • 开始给广告——大概两三天后开始出一个正常的自然位；

<a id="p0456"></a>
**P0456** • 慢慢往上推、慢慢往上走；

<a id="p0457"></a>
**P0457** • 自然位一定是梯度式的往上走；

<a id="p0458"></a>
**P0458** • 走到一个位置就卡住了，稳在卡住的位置。

<a id="p0459"></a>
**P0459** 这就是非常典型的"合规推广"——正常的白帽推广，表现还不错的就长这样子。

<a id="p0460"></a>
**P0460** 类比：从 F 班开始考试，本来还没进班——先考试考了以后分配进 F 班 → 升到 B/C 班 → 升到 B 班 → 想往 A 班考考不动了 → 一直卡在 B 班。再怎么给广告，自然位就是在 12 位不动了。

<a id="p0461"></a>
**P0461** 特点三（小时趋势）：自然位稳定

<a id="p0462"></a>
**P0462** 一个产品如果是预期坑产推起来的话，小时趋势就是稳的。

<a id="p0463"></a>
**P0463** 所以这条链接广告给得多给得少都已经没关系了——这就是典型的预期增长干预的特点。

<a id="p0464"></a>
**P0464** （五）预期坑产推广总结

<a id="p0465"></a>
**P0465** 1. **广告撬动自然流量，且广告占比不会太高、会偏低**——它不需要太高；

<a id="p0466"></a>
**P0466** 2. **自然位推上去以后，小时趋势是稳定的**；

<a id="p0467"></a>
**P0467** 3. **所需要的广告单比较少，且后期可以降广告花费**——它是先有 CTR、CVR 再有曝光量的。

<a id="p0468"></a>
**P0468** 类比：从 F 班考进 C 班，慢慢考进 B 班，到了 B 班以后就卡在 B 班——可以利用 B 班现在的位置去把利润做大，而不是再继续给广告。

<a id="p0469"></a>
**P0469** 像卖家比较聪明的点在于他没有继续给广告、没有怼得很大——每天广告给得很零散——他其实不需要打广告去干预了。他就是接受当前自己这个位置，不会说"我非要推到前 4"什么的——这样就挺好的。

<a id="p0470"></a>
**P0470** （六）实战分析：如何用此特征反推竞品打法

<a id="p0471"></a>
**P0471** 回到圣诞节冰箱门把手装饰，可以大致尝试分析：

<a id="p0472"></a>
**P0472** • 上架以后断货了一段时间；

<a id="p0473"></a>
**P0473** • 上架以后给了一小段时间的广告流；

<a id="p0474"></a>
**P0474** • 一般这时候会把"瑞庭（Reviews）"评论数量拉进来，去判断他是不是有做合并评论的动作；

<a id="p0475"></a>
**P0475** • 看到 1000 多个评论 → 做了合并评论。但他初始上来就有 1000多 个，是去年的（去年评论数量已经涨到 1100多 了），所以他是用了去年的链接继续做的。

<a id="p0476"></a>
**P0476** 再看推广走势：

<a id="p0477"></a>
**P0477** • 进来以后自然流很少，先给的广告流——前面说推早了；

<a id="p0478"></a>
**P0478** • 这样的推广很大概率也是做的预期坑产。

<a id="p0479"></a>
**P0479** 因为做预期坑产的话，很多卖家会搭配上低价这个点——用初期低价去撬，撬上去以后等流量涨上去以后再开始涨价。卖家到现在为止还是没涨价的，因为他今年其实还没到高峰、产品还没进入旺季。

<a id="p0480"></a>
**P0480** 把小时趋势打开是稳的——稳的就说明他配在这个位置；如果抖得很厉害，就不配在这个位置、是硬撑。

**P0481** （七）案例总结：典型预期坑产链接

<a id="p0482"></a>
**P0482** 再看这个产品的推广路径：

<a id="p0483"></a>
**P0483** • 广告给了以后，自然位是慢慢往上走的：100多 → 90几 → 60几 → 20几 → 10几 → 前 5、前 10；

<a id="p0484"></a>
**P0484** • 这个链接也是很典型的做预期坑产做出来的。

**P0005** 我前面已经讲过了关于预期坑产的干预所产生的效果，接下来说一下实际坑产。

<a id="p0006"></a>
**P0006** 一、实际坑产的发现与原理

<a id="p0007"></a>
**P0007** （一）站外刺激发现实际坑产

<a id="p0008"></a>
**P0008** 先说我们怎么发现这个事情的——首先是一种我们做站外的时候发现的。

<a id="p0009"></a>
**P0009** 案例：站外刺激带来自然位变化

<a id="p0010"></a>
**P0010** 这个产品我们前段时间做了一次站外。原先单量大概是 0 单，每天没有单。然后做了一次站外，当时一天大概出了 100 多单，连出了 3 天。但是出完以后自然位上去了，单量出来了。

<a id="p0011"></a>
**P0011** 具体看实际的站外出单对自然位变化的效果：

<a id="p0012"></a>
**P0012** • 8 月 8 号、9 号做站外前：原先自然位是 100 多位，开了广告以后更差了——广告买的数据不太好，所以从 100 多位掉到了 140-150 位左右；

<a id="p0013"></a>
**P0013** • 8 月 8 号、9 号做站外这两天：由于站外订单，自然位直接升到了第 10 位左右；

<a id="p0014"></a>
**P0014** • 8 月 10 号停止做站外：自然位掉到了 36 位左右——但没有再往下掉了，就维持在这个位置。

<a id="p0015"></a>
**P0015** 也就是说这种站外的刺激对于这条链接来说是属于"未知的刺激"——他到了第 10 位以后，靠实际单量出到 100 多单，这个单量是配在前 10 位的，所以亚马逊给了我们第 10 位。但后面几天我们不做站外了，单量就不配在第 10 位了——这几天的位置就是它的预期坑产该在的位置。

<a id="p0016"></a>
**P0016** 这是实际坑产的影响。

<a id="p0017"></a>
**P0017** 我们原先发现这一点是因为：新品上来做站外，自然位起得很快，但能不能维稳取决于这条链接能不能维稳。

<a id="p0018"></a>
**P0018** （二）实际坑产的另一种发现：词带词

<a id="p0019"></a>
**P0019** 第二点就是我们之前是只知道预期坑产的，所以会推词、所有的广告都是冲着推自然位去的。推词的时候我们会发现：

<a id="p0020"></a>
**P0020** 案例：ABC 词的瓶颈被别的词突破

<a id="p0021"></a>
**P0021** 比如 ABC 这个词，自然位卡在了第一页的第 20 位左右上不去了——也就是前面所说的瓶颈位置。这个位置上不去，再推也动不了。

<a id="p0022"></a>
**P0022** 这个时候我们去推 BD、推 EF——发现别的词给我们的总链接带来单量：BD 一天 10 单、EF 一天 10 单。总单量增加了，ABC 的自然位也涨了——从 20 位涨到了第 15 位。

<a id="p0023"></a>
**P0023** 这个就是实际坑产——总单量靠别的方式上去以后，卡住的自然位也能涨。

<a id="p0024"></a>
**P0024** 所以前面跟大家讲：你们自然位如果在瓶颈位置卡住了，他不是不能动了——还能动，但得通过别的方式动：

<a id="p0025"></a>
**P0025** • 要么直接改变自己链接的预期坑产；

<a id="p0026"></a>
**P0026** • 要么去搞点实际坑产出来，把实际单量做起来。

<a id="p0027"></a>
**P0027** （三）站内 LD 也能体现实际坑产

<a id="p0028"></a>
**P0028** 如果说我们站内做一天 LD 的话，也会呈现这样的效果。

<a id="p0029"></a>
**P0029** 案例：LD 当天对自然位的影响

<a id="p0030"></a>
**P0030** 某产品自然位原先大概卡在 20几 位，最高 23 位上不去。

<a id="p0031"></a>
**P0031** • 做 LD 当天：由于单量上升或 CTR、CVR 上升，自然位涨到了第 10 位；

<a id="p0032"></a>
**P0032** • 第二天：掉到 13 位（如果是预期坑产上升的话，第二天就应该调回原位 30几 位）；

<a id="p0033"></a>
**P0033** • 第三天：掉到 26 位；

<a id="p0034"></a>
**P0034** • 第四天：才掉回 36 位。

<a id="p0035"></a>
**P0035** 也就是说大概花了好几天的时间才回去——这是实际坑产的具体体现。

<a id="p0036"></a>
**P0036** 实际坑产的算法：

<a id="p0037"></a>
**P0037** 实际坑产不是算的这一秒的单量，也不是算的这一天的单量，而是算最近一小段时间的实际单量——大概可以理解为是 3-7 天（具体是几天我也不太清楚），最近 3-7 天的总单量都会影响到你的占位。

<a id="p0038"></a>
**P0038** 做 LD 这一天就是实际坑产的具象影响：LD 由于折扣导致站内出单增加，实际坑产上升、自然位突然上升；折扣结束以后，链接本身的预期坑产没有变化、实际单量也回落，所以坑位会降回原位——两个坑产都不变的情况下，自然位没有理由会上升。

<a id="p0039"></a>
**P0039** 二、用实际坑产做自然位的方式

<a id="p0040"></a>
**P0040** （一）短期方式：仅刺激上限再回落

<a id="p0041"></a>
**P0041** 短期方式（如 LD 单天、做站外）只能起到一个通过实际跟涨刺激自然位拉到一个上限再回落的作用，没有办法让自然位稳在高位。

<a id="p0042"></a>
**P0042** （二）站外做实际坑产

<a id="p0043"></a>
**P0043** 如果想稳在高位，可以用别的方式——前面讲到站外搞单量做实际坑产。

<a id="p0044"></a>
**P0044** 实际坑产可以站内也可以站外做：

<a id="p0045"></a>
**P0045** • 站内：通过做活动、用广告去买；

<a id="p0046"></a>
**P0046** • 站外：

<a id="p0047"></a>
**P0047** • 一些卖家做 TK 导流到亚马逊——亚马逊新品就有订单；

<a id="p0048"></a>
**P0048** • 私域 CRM 系统；

<a id="p0049"></a>
**P0049** • 自建站；

<a id="p0050"></a>
**P0050** • 刷单量；

<a id="p0051"></a>
**P0051** • 站外折扣。

<a id="p0052"></a>
**P0052** 全部都可以实现实际单量。只要这链接有单就行。

<a id="p0053"></a>
**P0053** 但单分为短期单和长期单：

<a id="p0054"></a>
**P0054** • 短期单：效果一下子起来，一定会回落；

<a id="p0055"></a>
**P0055** • 长期单：可以稳在高位。

<a id="p0056"></a>
**P0056** （三）案例：季节性产品的站外打法

<a id="p0057"></a>
**P0057** 刚刚看到的案例是新品通过 3 天站外刺激，从 100 多位涨到第 10 位，又掉回 30几 位的过程。

<a id="p0058"></a>
**P0058** 还有一些链接是老链接——链接本身资质就还不错，评论也不错，可以稳在高位。

<a id="p0059"></a>
**P0059** 案例：季节性产品的同质化打法

<a id="p0060"></a>
**P0060** 某季节性产品，原先给的是广告干预：

<a id="p0061"></a>
**P0061** • 前面给了一小段时间，自然位出不来；

<a id="p0062"></a>
**P0062** • 又给了一小段时间，自然位从 130 拉到 45；

<a id="p0063"></a>
**P0063** • 但越给广告越打位置越差——掉到 140 位去了。

<a id="p0064"></a>
**P0064** 这时候我们发现 SP 的干预是无效的——当你发现 SP 越打位置越差的时候，SP 就不用打了。

<a id="p0065"></a>
**P0065** 我们这时候开始考虑用站外介入——从站外出单、站外送，反正单价也不高，大不了就免费送。

<a id="p0066"></a>
**P0066** 免费送了以后，连续出了 3-4 天左右，自然位从 30几 位到了第 10 位、到了第 6 第 7 位。到后面这里就已经停止站外了，但自然位依然稳在第 6 第 7 位。

<a id="p0067"></a>
**P0067** 主要是因为这个产品是偏同质化的产品，也是季节性产品。

<a id="p0068"></a>
**P0068** 季节性产品的方便做法：

<a id="p0069"></a>
**P0069** 刚需季节性产品很方便的做法就是：通过送让它吊在高位。吊在这个高位以后，自然流变大——自然流越大，进来的流量越多，就能用站内的单量做实际坑产，可能就能稳在原位。

<a id="p0070"></a>
**P0070** 而且这个产品还属于比较同质化的产品——比较同质化的产品谁在前面买家就买谁，他不会太在意你们之间的性能对比，你只要在前面就行了。

<a id="p0071"></a>
**P0071** 所以这类型的产品我们当时是做了一个站外的 0 元购送的——但不一定要 0 元购，你可以 5 折、7 折，只要你能送得出去就行。

<a id="p0072"></a>
**P0072** （四）站外刺激前必做：广告打收录

<a id="p0073"></a>
**P0073** 这个时候建议你们配合另外一个动作：广告打收录。

<a id="p0074"></a>
**P0074** 广告打收录的意思就是：如果用实际坑产去干预自然位的话，前提是这个词你先有收录。

<a id="p0075"></a>
**P0075** 这跟前面做低价刺激是一样的——大站外大单量刺激一般做 3-7 天，而这个刺激是针对已收录的词。

<a id="p0076"></a>
**P0076** （五）如何查"已收录的词"？

<a id="p0077"></a>
**P0077** 方法一：西柚反查流量词

<a id="p0078"></a>
**P0078** 用西柚直接去反查流量词就行了。比如查到这个产品的流量词是 134 个——算是比较少的流量词数量了。

<a id="p0079"></a>
**P0079** 方法二：H10 的 Index Tracker

<a id="p0080"></a>
**P0080** 如果想要知道自己具体在多少词有收录，可以到 H10 这里来——

<a id="p0081"></a>
**P0081** H10 里面有一个功能叫做 Index Checker / Index Tracker——大家自己回去用。在搜索框搜 "index"，这个功能就能查到你的产品跟这个词的相关性到底收录了没有。你们回去用这个功能就行。

<a id="p0082"></a>
**P0082** （六）做实际坑产前必做收录词

<a id="p0083"></a>
**P0083** 如果你是个新品什么收录都没有就直接去做站外，效果是比较低效的。

<a id="p0084"></a>
**P0084** 包括做大降价去做超低价——如果没有收录也是比较低效的。

<a id="p0085"></a>
**P0085** 举例：

<a id="p0086"></a>
**P0086** • 这个产品有 100 个词 → 现在每天给他做 100 单，作用范围就是这 100 个词；

<a id="p0087"></a>
**P0087** • 如果有 1000 个词 → 每天出 100 单，作用就作用于这 1000 个词。

<a id="p0088"></a>
**P0088** 所以在做这种实际坑产前尽量去做收录词，尽量去打收录。

<a id="p0089"></a>
**P0089** （七）实际坑产的核心规律

<a id="p0090"></a>
**P0090** 只要你出够单量，自然位一定能起来——这是百分百的事情。

<a id="p0091"></a>
**P0091** 但现在的问题在于：如果停止站外干预的话，站内就只能靠自己链接的实际坑产情况决定自然位。

<a id="p0092"></a>
**P0092** 所以有的卖家做完一波站外下来掉得很厉害——比如原来在 100 位，做完一次站外涨到 10 位，又掉回 100 位——这个做了真的等于没做。

<a id="p0093"></a>
**P0093** 但如果调回来以后能在 30 位、20 位、第 10 位，咱们都会认为是有效的刺激——只不过把站内广告的费用挪到站外去用了。

<a id="p0094"></a>
**P0094** 适用产品：刚需 + 中低单价 + 高 CPA + 链接资质 OK + 季节性——这种产品最容易停在高位。

<a id="p0095"></a>
**P0095** 不符合以上情况的话，可能站外第一个送不出去；第二个即使送出去了链接资质不行，做完以后也会掉到很低的位置。

<a id="p0096"></a>
**P0096** （八）站内购买单量做实际坑产

<a id="p0097"></a>
**P0097** 最后再说一个：如果一直干预实际坑产也可以——做成站内购买单量做实际坑产。

<a id="p0098"></a>
**P0098** 案例：广告单占比很高的产品

<a id="p0099"></a>
**P0099** 有的卖家产品广告单占比一直很高，广告单远大于自然单。大家会好奇说这类型产品是不是做得不好？是不是广告单占比越高越不好？

<a id="p0100"></a>
**P0100** 也不是——你看广告是亏的还是赚的：

<a id="p0101"></a>
**P0101** • 广告亏损/赔本 → 广告单占比越高越差；

<a id="p0102"></a>
**P0102** • 广告不亏损/盈利 → 广告单占比高是没有问题的。

<a id="p0103"></a>
**P0103** 所以我们最终要考量的是这个链接的利润，而不是这个链接的单量占比。

<a id="p0104"></a>
**P0104** 案例分析

<a id="p0105"></a>
**P0105** 某产品广告单占比一直很高，且 SP 广告打得并不多。具体的广告分类情况：

<a id="p0106"></a>
**P0106** • 前面这一段时间广告基本上都靠 SB 广告；

<a id="p0107"></a>
**P0107** • 中间这一段时间有 SB 和 SBV；

<a id="p0108"></a>
**P0108** • 再到后面改成 SBV 和 SB 广告；

<a id="p0109"></a>
**P0109** 但不管用什么广告，只要实际坑产是在的、实际单量是在的，自然位就会被吊在高位。

<a id="p0110"></a>
**P0110** 这个属于"吊在高位"——有点像作弊了。

<a id="p0111"></a>
**P0111** （九）站内做实际坑产的三个特点

<a id="p0112"></a>
**P0112** 特点一：总流量中广告流量占比比较高，甚至可能没有 SP 广告

<a id="p0113"></a>
**P0113** 因为它不用 SP 广告去做词的数据了，他只要总单量。

<a id="p0114"></a>
**P0114** 特点二：广告单一缩自然位暴跌

<a id="p0115"></a>
**P0115** 有些卖家会跟我讲："老师我广告单降不下来，我一降自然单就掉"——大概率你做的是实际坑产。

<a id="p0116"></a>
**P0116** 特点三：小时趋势里面自然位每天起伏很大

<a id="p0117"></a>
**P0117** 这个产品其实自然位大概在第 10 位左右，然后上下波动得很厉害——达成了一个动态平衡。

<a id="p0118"></a>
**P0118** 跟大家讲一下为什么：

<a id="p0119"></a>
**P0119** 假设产品平时在第 5 位，他通过总单量买到了第 5 位。但到了第 5 位以后，亚马逊觉得你在第 5 位不行——影响这个坑位的产出，所以把他拽下来。拽下来以后他又继续买，硬买到第 5 位他又拽下来——所以每天这个过程会循环好几次：亚马逊不想让你上去，但你的实际坑产硬要让你上去。所以上去、下来——每天的自然位就是这样的比较有规律的、波动起伏比较大。

<a id="p0120"></a>
**P0120** 判断方法：所以你们看到一些头部卖家的链接在一些词长这样子的话，大概率是通过实际坑产去做。要么是广告还在干预预期坑产但是干预不动，要么就是已经在稳定的做实际坑产——就是长这个样子。

<a id="p0121"></a>
**P0121** 这种链接一般无法稳定在大词的前 4 位（头部位置），一般来说没法稳住。

<a id="p0122"></a>
**P0122** （十）站内实际坑产的代价：必须持续买

<a id="p0123"></a>
**P0123** 这种情况有点像什么？有点像我家这个小孩——他本来正常水平是从 F 班考到 D 班就已经结束了，但是我硬给他买到 A 班：

<a id="p0124"></a>
**P0124** • 第一：得买够单量——总单量得够；

<a id="p0125"></a>
**P0125** • 第二：每天都考试——所以你不能只买一天，你得每天都买。

<a id="p0126"></a>
**P0126** 所以你看他每天广告单量占比都高——他一旦掉下来就回到他该在的位置了。

<a id="p0127"></a>
**P0127** 所以这种卖家可能得通过持续的站内广告干预，从而实现自己的自然位吊在一个高位、每天被他吊在高位。

<a id="p0128"></a>
**P0128** 但吊在高位这个动作如果广告是亏损的，能不能做？做不了。

<a id="p0129"></a>
**P0129** 所以如果想要做实际坑产的话：

<a id="p0130"></a>
**P0130** 1. 广告得最起码平本，能盈利是最好的；

<a id="p0131"></a>
**P0131** 2. 要有清楚的认知——**我的广告就是用来把自然位吊高的**；

<a id="p0132"></a>
**P0132** 3. 不能说在站位稳了以后想砍广告——一砍广告自然位就掉。

<a id="p0133"></a>
**P0133** （十一）反例：不知道自己在做实际坑产

<a id="p0134"></a>
**P0134** 否则的话会像下面这个产品：

<a id="p0135"></a>
**P0135** 某产品原先自然位大概在 100 多位，某一天他开始 SBV 买单量——买了以后自然位到了 40 位左右、稳在 40 位（类目小，大概一天买 10 单就能到这个位置）。

<a id="p0136"></a>
**P0136** 到了某一天他觉得"我自然位稳了，我就开始停 SB 广告"——SB 广告就停掉了。一停广告自然位开始猛跌。

<a id="p0137"></a>
**P0137** 他为什么要停广告？

<a id="p0138"></a>
**P0138** 1. 广告亏；

<a id="p0139"></a>
**P0139** 2. 觉得"我自然位高了我就能停广告"。

<a id="p0140"></a>
**P0140** 这两种想法都不对：

<a id="p0141"></a>
**P0141** 首先 SBV 对自然位的"在这个词出单"是没有加权作用的——所以 SB 的作用就是买单量：

<a id="p0142"></a>
**P0142** • 要么靠 SBV 买一单挣一单；

<a id="p0143"></a>
**P0143** • 要么靠 SBV 把总单量做起来去吊自然位。

<a id="p0144"></a>
**P0144** 但是如果广告是亏损的话，到后期你总会不想买的——自然单赚的钱很难跟广告单亏的钱达成平衡，所以你会想砍。但一砍自然位就调回原位。

<a id="p0145"></a>
**P0145** 这个链接的问题在于：他实际上在做实际坑产，但他不知道自己在做实际坑产，所以前前后后自己很纠结，来来回回的。

<a id="p0146"></a>
**P0146** 同样的别的词也是一样：他买订单的时候自然位能到 30，他不买了以后自然位掉回了原来的 100 多，可能在 60 多。

<a id="p0147"></a>
**P0147** （十二）站内做实际坑产的注意事项

<a id="p0148"></a>
**P0148** 总而言之：站内如果打算干预实际坑产的话，最好一直这么做——也就是最好尽快找到一个能够稳步买单量的地方。

<a id="p0149"></a>
**P0149** 这个到底是在 SP、SB、SD、SBV 买全都无所谓，甚至你在站外一直进都无所谓——你只要总单量。

<a id="p0150"></a>
**P0150** 而总单量一天，比如说一个大词一天买个两三单肯定是不够的。

<a id="p0151"></a>
**P0151** 反例：很多卖家 SBV 广告是亏的，每天又买不了几单——这种广告就是废的，打了跟没打一样。因为他们：

<a id="p0152"></a>
**P0152** • 不加权（不影响词权重）；

<a id="p0153"></a>
**P0153** • 又不加总单量；

<a id="p0154"></a>
**P0154** 可以不打。

<a id="p0155"></a>
**P0155** 还有一些卖家 SB 是持续在打的，但是没有"我在做实际坑产"的概念，所以他打着觉得"我要不一缩"——他一缩自然位也掉。

<a id="p0156"></a>
**P0156** 所以这个情况下要先认清楚自己是不是这个情况——如果是的话就稳定持续去买就可以了。

<a id="p0157"></a>
**P0157** 三、预期坑产 vs 实际坑产：推广方式总结

<a id="p0158"></a>
**P0158** （一）预期坑产推广

<a id="p0159"></a>
**P0159** 适合做预期坑产的链接：本身数据就很不错的链接

<a id="p0160"></a>
**P0160** 可以用广告低成本地促进——广告大就推得快，小预算就推得慢，但是一定能推得动。

<a id="p0161"></a>
**P0161** 这种链接如果他本来就配在 B 班，就让他去到 B 班；本来配在 C 班就让他到 C 班。

<a id="p0162"></a>
**P0162** 但是如果你遇到这种链接：你用这个方式推、链接本来配在 C 班，你非要他去 A 班——你就会很痛苦，因为后来发现他怎么都达不到，广告就会亏。

<a id="p0163"></a>
**P0163** 预期坑产的推广流程：

<a id="p0164"></a>
**P0164** 1. **关键词调研** —— 知道我想要在什么词往上拉；

<a id="p0165"></a>
**P0165** 2. **埋词**；

<a id="p0166"></a>
**P0166** 3. **广告投放对应的干预目标**：

<a id="p0167"></a>
**P0167** • 投放的目的是让我们在这些词去点击出单——所以需要有效的干预数据；

<a id="p0168"></a>
**P0168** • 在搜索→点击→购买这个过程中，广告得被搜索词触发、产生有效曝光、再被点击、再出单；

<a id="p0169"></a>
**P0169** • 出了单以后还得保证这个数据是正向干预——如果出单是反向干预，再多也没用；

<a id="p0170"></a>
**P0170** • 但如果干预数据足够多，它就变成实际坑产干预了。所以你会发现"出来一个不怎么样的位置，但是你一砍广告它又掉"——这一定要搞清楚自己是不是正向干预。

<a id="p0171"></a>
**P0171** 4. **自然位**：正向干预以后，自然位得上升到**有效位置**才能拉动自然流量；

<a id="p0172"></a>
**P0172** • 什么叫有效位置？前面有讲过——用积木查的数据就算是有效位置（比如这个产品有效位置是 7-30 位）；

<a id="p0173"></a>
**P0173** • 你的自然位推到第 40 位就瓶颈卡住了——前面花的钱也白花，因为它不在有效位置。

<a id="p0174"></a>
**P0174** 5. **自然单获得有效增长**。

<a id="p0175"></a>
**P0175** 所以预期坑产的干预是一个比较长的过程，条件比较苛刻：

<a id="p0176"></a>
**P0176** • 但凡干预单量不够；

<a id="p0177"></a>
**P0177** • 或者是反向干预；

<a id="p0178"></a>
**P0178** • 或者干预到一个差的位置；

<a id="p0179"></a>
**P0179** —— 都没有用。

<a id="p0180"></a>
**P0180** 所以如果要做预期坑产干预，需要去判断我的链接数据本身就不错。

<a id="p0181"></a>
**P0181** （二）实际坑产推广

<a id="p0182"></a>
**P0182** 实际坑产干预：用单量去带动收录词占位。

<a id="p0183"></a>
**P0183** 需要克服两个问题：

<a id="p0184"></a>
**P0184** 问题一：哪里去做稳定持续且不亏损的单量？

<a id="p0185"></a>
**P0185** • 站外：不稳定、不持续、亏损；

<a id="p0186"></a>
**P0186** • 目前最好的办法：做站内的盈利广告。

<a id="p0187"></a>
**P0187** 如何判断你能不能做盈利广告？

<a id="p0188"></a>
**P0188** • 如果毛利 30%、ACOS 是 40% → 可以搭得出来；

<a id="p0189"></a>
**P0189** • 如果毛利 30%、ACOS 是 100% → 大概率搭不出来。

<a id="p0190"></a>
**P0190** 问题二：怎么样拿到更多的词？

<a id="p0191"></a>
**P0191** 实际坑产是带动所有收录词的，所以你得拓词。

<a id="p0192"></a>
**P0192** 实际坑产干预的推广流程：

<a id="p0193"></a>
**P0193** 1. **关键词调研 + 埋词**；

<a id="p0194"></a>
**P0194** 2. **广告跑收录**；

<a id="p0195"></a>
**P0195** 3. 完了以后通过**盈利或平本型的广告大量出单**，或通过**站外大量出单**，从而带动所有收录词的位价上升；

<a id="p0196"></a>
**P0196** 4. **自然位获得自然单的有效增长**。

<a id="p0197"></a>
**P0197** （三）总结：拉动一个词的自然位的两种方式

<a id="p0198"></a>
**P0198** 简单来说就这两个方式：

<a id="p0199"></a>
**P0199** 1. **预期坑产**

<a id="p0200"></a>
**P0200** 2. **实际坑产**

<a id="p0201"></a>
**P0201** 不管你天天是降价、还是打螺旋、还是做站外、还是刷单——说白了就这么两个方式。

<a id="p0202"></a>
**P0202** 四、推广组合搭配（自然排名短期提升 + 维稳）

<a id="p0203"></a>
**P0203** 我们推广上面其实有很多种比较好用的组合。跟大家讲一下自然排名的短期提升和维稳的搭配组合。

<a id="p0204"></a>
**P0204** （一）拉动自然坑位的两个底层方式

<a id="p0205"></a>
**P0205** 1. **干预预期坑产** → 用 SP 广告（合规刷单）；也可以通过不合规的刷单去完成。

<a id="p0206"></a>
**P0206** 2. **干预实际坑产** → 搞单量。

<a id="p0207"></a>
**P0207** （二）干预预期坑产的两种方式

<a id="p0208"></a>
**P0208** 方式 A：投喂数据

<a id="p0209"></a>
**P0209** 方式 B：直接改变数据

<a id="p0210"></a>
**P0210** 直接改变的方式（小组讨论补充）：

<a id="p0211"></a>
**P0211** • 降价（最常见）；

<a id="p0212"></a>
**P0212** • 优化 Listing（包括主图）；

<a id="p0213"></a>
**P0213** • 评论数量、评论星级；

<a id="p0214"></a>
**P0214** • BS 标、AC 标；

<a id="p0215"></a>
**P0215** 前台标的颜色识别（增加点击率）：

<a id="p0216"></a>
**P0216** • 黄色：购物车标；

<a id="p0217"></a>
**P0217** • 红色：低油标（Limited Time Deal）；

<a id="p0218"></a>
**P0218** • 黑色：AC 标（如果是新品也可能获得 Black 标）；

<a id="p0219"></a>
**P0219** • 普瑞s6（Prime）等；

<a id="p0220"></a>
**P0220** • 橙色：BSR 标；

<a id="p0221"></a>
**P0221** • 绿色：Coupon 标。

<a id="p0222"></a>
**P0222** 便宜增加点击率的方式：加个 5%、10% 的 Coupon——也是便宜的增加点击率的方式，主要是装饰作用。

<a id="p0223"></a>
**P0223** （三）选择最缺的那个去做

<a id="p0224"></a>
**P0224** 哪个对你来说是最缺陷的，你就去做哪个：

<a id="p0225"></a>
**P0225** • 新品没评论：你跟我说要去打广告——别人都是几千个评论你没有，肯定得去做评论，不然你买数据有什么用，投喂的数据也是烂的；

<a id="p0226"></a>
**P0226** • 已经有 2000 个评论：再加 50 个也没用，2000 和 2050 没有区别；

<a id="p0227"></a>
**P0227** • 评论也不行、价格也高：你跟我说去优化图片——浪费时间。

<a id="p0228"></a>
**P0228** • 你得知道自己短板在哪——发现降价最容易，就去做降价；

<a id="p0229"></a>
**P0229** • 广告里面：表现好的去买，表现不好先别买、先找原因优化。

<a id="p0230"></a>
**P0230** （四）干预实际坑产的方式

<a id="p0231"></a>
**P0231** 搞单量：

<a id="p0232"></a>
**P0232** 1. **站内任意一种广告**：只要能做到盈利就可以放大、可以持续买；

<a id="p0233"></a>
**P0233** 2. **站外**：网站、群组、TK、私域等等——能做就做。但这些都是辅助，没办法长期带来单量，**一般是短期激活的作用**；

<a id="p0234"></a>
**P0234** 3. **刷单**：跟前面讲的不一样——前面是刷数据/刷词，这里是刷量。但要衡量成本——如果刷量的话可以考虑是不是站内广告会送得更容易、买得更便宜；

<a id="p0235"></a>
**P0235** 4. **秒杀活动**：只能是短期激活——没办法帮你突破当前瓶颈。

<a id="p0236"></a>
**P0236** （五）干预完后的维稳问题

<a id="p0237"></a>
**P0237** 干预完了能上去，但维稳可能稳不住——会遇到两种情况：

<a id="p0238"></a>
**P0238** 情况一：能够承接 → 留在原位（最好）

<a id="p0239"></a>
**P0239** 情况二：硬买单量、做活动、刷单，做完后下降

<a id="p0240"></a>
**P0240** 如果有所下降，说明亚马逊认为你不配在那个位置——要么接受，要么继续干预实际坑产。

<a id="p0241"></a>
**P0241** 因为这个时候你如果有所下降，就知道调到什么位置就是配在什么位置——所以你不接受这个位置的话，只能决定要干预实际坑产。

<a id="p0242"></a>
**P0242** 干预实际坑产的方式：

<a id="p0243"></a>
**P0243** • 持续做活动：连秒、做 BD（一个月做两周）——能实现你有一半的时间在做活动的效果；

<a id="p0244"></a>
**P0244** • 广告干预单量：不亏损的广告直接去买、给他买上去。

<a id="p0245"></a>
**P0245** 举例：通过刷单刷上去到第一页第 5 位，停止刷单后到第 20 位——要么接受 20 位；不接受的话就干预实际坑产。这个时候干预预期坑产没什么用，因为预期坑产就是在 20 位。

<a id="p0246"></a>
**P0246** 五、推广搭配的几种组合

<a id="p0247"></a>
**P0247** 不同的产品适用的推广搭配不一样，我们从简单的开始讲。

<a id="p0248"></a>
**P0248** （一）方案一：链接本身就很优秀 → SP 广告稳步干预预期坑产

<a id="p0249"></a>
**P0249** 最简单的方式：链接本身就不错的情况下，用 SP 广告稳步干预预期坑产——买数据让它慢慢往上腾挪，到一个它配的位置就可以收手了，开始做利润。

<a id="p0250"></a>
**P0250** 注意点：链接本身数据要不错（CTR、CVR 都得不错）。

<a id="p0251"></a>
**P0251** （二）方案二：SP 干预到瓶颈位 → 三个突破方向

<a id="p0252"></a>
**P0252** 大部分卖家会用到的方式：用 SP 广告干预预期坑产，但是干预到了一个不怎么样的位置（比如 25 位就卡住了，瓶颈位是 25 位）。

<a id="p0253"></a>
**P0253** 接下来可以做的事情：

<a id="p0254"></a>
**P0254** 突破方向 1：用盈利型广告干预实际坑产，拉升瓶颈位

<a id="p0255"></a>
**P0255** 问题在于得找到盈利型广告的通道——有些卖家上架以后除了 SP 就没开过别的类型的广告，可能不知道别的广告类型是能盈利的。我们后面会教大家找到盈利型广告的通道。

<a id="p0256"></a>
**P0256** 第二个得放够量、足够的单量——如果你有盈利型广告每天买个一两单三四单，对总链接的自然位提升是没有用的。

<a id="p0257"></a>
**P0257** 很多链接都可以用这种情况——尤其是卡在一个很尴尬的位置时。比如这个词在第 8 位不动了，但是想让它上升到第 3-4 位，就可以去买了。

<a id="p0258"></a>
**P0258** 突破方向 2：直接改变预期坑产

<a id="p0259"></a>
**P0259** 老师我找不到盈利广告——可以直接改变预期坑产。

<a id="p0260"></a>
**P0260** 通过：

<a id="p0261"></a>
**P0261** • 降价（你先卡在 25 位，降价提到 15 位）；

<a id="p0262"></a>
**P0262** • 优化链接；

<a id="p0263"></a>
**P0263** • 做 BS 标、AC 标；

<a id="p0264"></a>
**P0264** —— 都可以改变预期坑产、突破当前的瓶颈位置。

<a id="p0265"></a>
**P0265** 适用情况：

<a id="p0266"></a>
**P0266** • 找不到盈利广告；

<a id="p0267"></a>
**P0267** • 不善于做广告——建议降价会来得更好一点。

<a id="p0268"></a>
**P0268** 案例：流量结构的不同打法

<a id="p0269"></a>
**P0269** 这个产品是无线充电器，两个 ASIN 售价分别 $21 和 $46，几乎是一模一样的东西（下面带的充头几乎一样）——他俩为什么都能卖？流量结构不一样：

<a id="p0270"></a>
**P0270** • $21.9 低价款：流量几乎全是自然流——把售价压得比较低，靠低售价做高预期坑产；

<a id="p0271"></a>
**P0271** • $45 高价款：全是广告流——把利润拉高，然后拿利润去打广告。

<a id="p0272"></a>
**P0272** 他比较善于做这个事情——所以咱们善于做哪个就往哪边去靠。两个利润可能是一样的——这个是走量的，那个是走利润的。

<a id="p0273"></a>
**P0273** （三）方案三：BD/连秒突破瓶颈位（仅适用季节性产品）

<a id="p0274"></a>
**P0274** 如果产品没办法改变预期坑产、又没办法做盈利型广告——

<a id="p0275"></a>
**P0275** SP 干预预期坑产到一个初步的位置（比如先考进 D 班，到 30 位）→ 用 BD 或连秒突破自然位瓶颈。

<a id="p0276"></a>
**P0276** 但这个动作很难实现长期产品的突破——很难说做完这个活动不会掉下来。所以这个动作比较适合季节性产品：

<a id="p0277"></a>
**P0277** • 季节性产品做这个会比较有效；

<a id="p0278"></a>
**P0278** • 尤其是季节前去做一波降价、做一波活动都会起得很快；

<a id="p0279"></a>
**P0279** • 包括做一波站外都会起得非常快——强季节性产品，每年的季节都是重新洗牌的结果。

<a id="p0280"></a>
**P0280** 案例：圣诞装饰

<a id="p0281"></a>
**P0281** 现在去搜圣诞装饰——会发现有很多评论数量少的产品也待在前面。往下拉评论数量参差不齐：有几千、有几十、甚至像一些没有评论数量的产品也待在这儿——都是因为这个词下面重新洗牌了一轮。

<a id="p0282"></a>
**P0282** 包括前面给大家看的冰箱门把手装饰，也是断货了一整段时间，7 月份才开始推、8-9 月才开始推的——大家重新洗牌。

<a id="p0283"></a>
**P0283** 所以搞得越快越好——但一定要在旺季前夕搞，不要搞太早，搞太早承接不住。

<a id="p0284"></a>
**P0284** （四）方案四：初始预期坑产触发不出来 → 先做盈利型广告买单量触发起始站位

<a id="p0285"></a>
**P0285** 初始位置差就是表现差的链接：用 SP 广打打出来 100 多位的位置就上不去。

<a id="p0286"></a>
**P0286** 建议先去做盈利型广告——买单量触发起始站位。

<a id="p0287"></a>
**P0287** 买单量的方法

<a id="p0288"></a>
**P0288** 不管用什么方式——后面会跟大家讲很多广告类型，找到便宜的广告类型即可。

<a id="p0289"></a>
**P0289** 关于竞价的提醒：

<a id="p0290"></a>
**P0290** • SP 广告竞价可能比较高；

<a id="p0291"></a>
**P0291** • 但在同一个类目里面 SB 竞价可能偏低一些；

<a id="p0292"></a>
**P0292** • SD 竞价可能更低；

<a id="p0293"></a>
**P0293** —— 所以这些都可以帮你做出一个初始的单量。

<a id="p0294"></a>
**P0294** 注意：买的话一定要买够。单量买够——不要说一天买个三四单又停在那也没用。得一天买个几十单才能触发出来一个起始自然位。

<a id="p0295"></a>
**P0295** 同时用 SP 打收录

<a id="p0296"></a>
**P0296** 接下来再同时用 SP 打收录——SP 是一定要打的，因为它能帮你收录。所以单要买够的情况下，SP 开个收录广告（范围广 + 竞价低 + 每天低预算）——这样就可以帮你持续打收录了。

<a id="p0297"></a>
**P0297** 持续打收录 + 单量买够 → 一定能有自然位。

<a id="p0298"></a>
**P0298** 如果能够初始触发：

<a id="p0299"></a>
**P0299** • 一方面可以持续买单量维持；

<a id="p0300"></a>
**P0300** • 如果发现有不错的位置，开始用 SP 广告承接——这是比较理想的状态；

<a id="p0301"></a>
**P0301** • 比较不理想的状态：没有什么词有高位能用 SP 承接 → 后续就一直苟着、用这种盈利型广告一直买、做到持续高广告占比的情况。

<a id="p0302"></a>
**P0302** （五）方案五：连预期坑产都打不出来 + 找不到盈利广告 → 站外送 0 元购

<a id="p0303"></a>
**P0303** 老师我的产品自然位预期坑产打算我也打不出来，盈利型广告也找不到——

<a id="p0304"></a>
**P0304** 接下来你就送：0 元购送出来，有单量一定能触发一个高自然位。

<a id="p0305"></a>
**P0305** 触发一个高自然位以后，它会往下掉——这时候挑那些掉了以后还有一个居中位置的词去打它，以及在这中挑盈利型广告。

<a id="p0306"></a>
**P0306** 适用产品：低单价、刚需、中低单价的刚需产品——其他情况下你可能站外都送不出去。

<a id="p0307"></a>
**P0307** （六）方案六：苛刻条件下的物质打法

<a id="p0308"></a>
**P0308** 苛刻的条件：触发高位以后，连找不到能做预期坑产的词，也找不到能做盈利广告的词——

<a id="p0309"></a>
**P0309** 你要不就一直做秒杀（连秒）。

<a id="p0310"></a>
**P0310** 但这个产品已经很糟糕了到这一步。如果你的产品到这一步的话，建议这产品就不要做了——因为对你来讲：

<a id="p0311"></a>
**P0311** • 又做不出自然位；

<a id="p0312"></a>
**P0312** • 又买不到赚钱的广告。

<a id="p0313"></a>
**P0313** 物质（亚马逊代发）打法补充

<a id="p0314"></a>
**P0314** 如果你是要持续做物质的话，建议初始定价就高一点：

<a id="p0315"></a>
**P0315** • 拉高定价；

<a id="p0316"></a>
**P0316** • 找人刷几个免评单，把历史售价刷出来；

<a id="p0317"></a>
**P0317** • 拉高历史售价 → 采购价就会变高；

<a id="p0318"></a>
**P0318** • 拉高采购价；

<a id="p0319"></a>
**P0319** • 可以用物质起码帮你清个货，或搞个 Vine（华星家）出几单清货。

<a id="p0320"></a>
**P0320** 或者如果物质的采购价是盈利的，可以持续用物质去出——其实也不失为一种长久之计，只要不亏就行。

<a id="p0321"></a>
**P0321** （七）方案七：低价螺旋（直接改变数据）

<a id="p0322"></a>
**P0322** 用低价去刺激高位——前面我们讲用 SP 也好、用盈利型广告也好，都是在投喂数据。低价螺旋直接改变数据。

<a id="p0323"></a>
**P0323** 适用情况：

<a id="p0324"></a>
**P0324** • 广告怎么打数据都不好；

<a id="p0325"></a>
**P0325** • 盈利广告都买不出来；

<a id="p0326"></a>
**P0326** • 但产品刚需；

<a id="p0327"></a>
**P0327** • 标品/半标，特别适合中低单价的标品/半标；

<a id="p0328"></a>
**P0328** 直接做低价触发自然位。

<a id="p0329"></a>
**P0329** 具体一点：低价刺激高 CTR 高 CVR → 刺激高自然位 → 刺激完再去慢慢涨价 → 涨价过程注意一下就可以了 → 能涨到多少是多少 → 最后会有一个比较稳定的盈利模式。

<a id="p0330"></a>
**P0330** 条件：

<a id="p0331"></a>
**P0331** • 中低单价的标品和半标；

<a id="p0332"></a>
**P0332** • 链接评论数量要多——因为这种打法比较高调，如果评论数量很少会非常招差评。

<a id="p0333"></a>
**P0333** 评论少的卖家慎用

<a id="p0334"></a>
**P0334** 举例：你 5 个评论在这里搞低价，谁不想弄你？竞争对手忍不住给你扔两个直评差评——会想把你搞下去。

<a id="p0335"></a>
**P0335** 建议大家在血比较厚的时候、产品已经是要死不活的老链接的时候，这样刺激一下其实非常有效——而且不需要投入任何成本，只需要降价就可以直接拉出高自然位。

<a id="p0336"></a>
**P0336** 低价螺旋打法实例

<a id="p0337"></a>
**P0337** 季节性产品我们只有一个短季节（比如圣诞季），平时卖不动。如果过了 12 月以后链接可能就是断货状态不补了——到了第二年 9 月可以正常推，但如果想推得快的话，可以搞一波非常低的售价去刺激它。

<a id="p0338"></a>
**P0338** 举例：

<a id="p0339"></a>
**P0339** • 某条链接的推广路径：补完货以后高价 → 出了几单以后降价到 $9.99 → 一直到旺季再涨价；

<a id="p0340"></a>
**P0340** • 这个做法还比较温和；

<a id="p0341"></a>
**P0341** • 做极端一点：定价应该是 $19.99，但有点高了，所以定 $15.99。然后上架后想要快速刺激的话，又想数据好又想刺激大——直接 $7.99，甚至更极端 $5.99 直接上去卷。

<a id="p0342"></a>
**P0342** • 这个 $5.99 不用持续很久，大概 3 天时间——拉出基础自然位以后，自然位代码还在涨，就可以开始涨价；

<a id="p0343"></a>
**P0343** • 一直涨到可能 $9.99 就停下来先稳一波；

<a id="p0344"></a>
**P0344** • 流量再涨的话就继续涨价。

<a id="p0345"></a>
**P0345** 低价可以刺激你所有的已收录词——适用于已收录词较多的产品。

<a id="p0346"></a>
**P0346** 案例：怎么判断竞品在做预期坑产还是实际坑产？

<a id="p0347"></a>
**P0347** 很简单：比如 "book supplies" 这个词，这个词在 22 位没有广告——没有广告的词，怎么样去拉动它的自然位？

<a id="p0348"></a>
**P0348** 方式一：通过相关长尾词去出单——用词根带动它（大词带小词、小词带大词，他们得是同词根）。比如包含 shock collar 出单可以给 shock collar for dog 加权。

<a id="p0349"></a>
**P0349** 但 "doc surprise"（"dog supplies"？） 这个词没有什么长尾词，所以排除了词之间互相带动。

<a id="p0350"></a>
**P0350** 方式二：那么就只能是预期坑产或实际坑产。

<a id="p0351"></a>
**P0351** 可能是实际坑产——这种泛词如果你不开广告：

<a id="p0352"></a>
**P0352** • 首先得有收录；

<a id="p0353"></a>
**P0353** • 有了收录以后有收录不代表有自然位——有收录的词的自然位怎么出来？靠你某一次低价它就出来了。

<a id="p0354"></a>
**P0354** 所以你看这个自然位是在 9 月 7 号这一波有一次降价以后就开始冒出来了。

<a id="p0355"></a>
**P0355** 大部分产品的泛词都是这样的——你不会去专门打它，但到了某个节点它就会开始冒。看这个产品的某个词什么时候开始冒——大概率都是跟它的价格有关系，价格一降泛词就出。

<a id="p0356"></a>
**P0356** 总之这种就是当你去刺激高 CTR、高 CVR 的时候，已收录的词都会被你刺激到。

<a id="p0357"></a>
**P0357** 六、定方向 → 定策略 → 定执行

<a id="p0358"></a>
**P0358** 我们今天讲这些是为了跟大家先定一个方向。所有的推广做推广：先把方向定出来——一般是公司层面去定的。

<a id="p0359"></a>
**P0359** 三个层级

<a id="p0360"></a>
**P0360** 1. 方向

<a id="p0361"></a>
**P0361** 举例：ACOS 限制 15% 内、销量从 200 涨到 300——这就是方向性的东西。

<a id="p0362"></a>
**P0362** 2. 策略

<a id="p0363"></a>
**P0363** 根据方向定几个策略：

<a id="p0364"></a>
**P0364** • 用预期坑产拉动自然位（这是一个方式）；

<a id="p0365"></a>
**P0365** • 用实际坑产拉动自然位（如果要用实际坑产去拉的话，还有个 ACOS 限制，所以你还得再去给更具体的东西）；

<a id="p0366"></a>
**P0366** • 降价改变坑产，拉动自然位也可以的；

<a id="p0367"></a>
**P0367** 3. 执行

<a id="p0368"></a>
**P0368** 选定一个策略以后会有具体执行：

<a id="p0369"></a>
**P0369** 举例：选用做实际坑产策略 → 执行就是：

<a id="p0370"></a>
**P0370** • 测试广告通道：开 SB、SBV、SD 广告，去开不同的方向和不同的通道，测出来什么广告是不亏的；

<a id="p0371"></a>
**P0371** • 总单量目标：需要多少单量？总单量从 200 拉到 300——你买也可以买出来；

<a id="p0372"></a>
**P0372** • 注意 ACOS 限制：买的话 ACOS 要空下来，这两个动作一起做。

<a id="p0373"></a>
**P0373** 执行方面的问题到明天下午和后天会具体讲，所以今天和明天上午到明天中午都会在讲方向和策略的问题。

<a id="p0374"></a>
**P0374** 今天大家不着急问 "我 ACOS 怎么降"——不着急，你先去想想我这次来具体的问题是什么。

<a id="p0375"></a>
**P0375** 一般大家要想推广的话就是降本增效：

<a id="p0376"></a>
**P0376** • 初期可能想要拉销量；

<a id="p0377"></a>
**P0377** • 中期和后期可能都是想要降本增效；

<a id="p0378"></a>
**P0378** —— 所以咱们给个具体的方向出来。

<a id="p0379"></a>
**P0379** 讲完这些，大家会大概定几个方向和策略——这是接下来去做优化的前提。

<a id="p0380"></a>
**P0380** OK，我们到这一部分自然排名的短期拉升和维稳就结束了。你的产品不管处于任何一个情况，想要拉升自然排名也就是那几个方式，看哪个对你性价比最高。

<a id="p0381"></a>
**P0381** 七、多变体推广

<a id="p0382"></a>
**P0382** 刚刚讲的全部都是单链接的情况，再接下来说一下多变体的情况。

<a id="p0383"></a>
**P0383** 多变体的推广跟单链接推广是不太一样的。

<a id="p0384"></a>
**P0384** （一）多变体的差异

<a id="p0385"></a>
**P0385** 差异一：自然坑位

<a id="p0386"></a>
**P0386** 多变体在一个词下，自然坑位只有一个，且展示的是子体而不是父体。

<a id="p0387"></a>
**P0387** 决定你自然排名的也不是父体总权重，而是子体权重。

<a id="p0388"></a>
**P0388** 案例

<a id="p0389"></a>
**P0389** 某链接有 1、2、3 三个变体：

<a id="p0390"></a>
**P0390** 词 A 下的自然位：

<a id="p0391"></a>
**P0391** • 变体1 在第 1 位

<a id="p0392"></a>
**P0392** • 变体2 在第 5 位

<a id="p0393"></a>
**P0393** • 变体3 在第 50 位

<a id="p0394"></a>
**P0394** → 三个一合变体，自然位只剩下第 1 位（只展示最高的）

<a id="p0395"></a>
**P0395** 词 B 下的自然位：

<a id="p0396"></a>
**P0396** • 变体1 在第 10 位

<a id="p0397"></a>
**P0397** • 变体2 在第 2 位

<a id="p0398"></a>
**P0398** • 变体3 在第 30 位

<a id="p0399"></a>
**P0399** → 三个一合变体，展示变体2 在第 2 位

<a id="p0400"></a>
**P0400** 多变体逻辑：长板理论

<a id="p0401"></a>
**P0401** 如果想要拉高多变体的自然位——该去拉所有变体的自然排名吗？不是。

<a id="p0402"></a>
**P0402** 多变体遵从长板理论——只需要把最高自然位的变体拉得更高就行了。

<a id="p0403"></a>
**P0403** 也就是当我们想要推自然位的时候，需要推自然位的链接都需要定一个主推。但如果你不需要推自然位的话就可以不用主推。

<a id="p0404"></a>
**P0404** （二）有主推 vs 无主推的两种推法

<a id="p0405"></a>
**P0405** 1. 单主推链接

<a id="p0406"></a>
**P0406** 如果要定主推，主推有"单主推"和"多主推"两种。

<a id="p0407"></a>
**P0407** 单主推链接的特征：在西柚找词反查时，某个子体的流量占链接总流量的 80%+。

<a id="p0408"></a>
**P0408** 举例：链接总流量 6,400，子体一的流量 5,700——这个链接就是很典型的单主推。单主推链接只靠子体去承接流量，自然位就得拉这个子体，其他子体都不用管。

<a id="p0409"></a>
**P0409** 很多链接其实你选一个主推就行了，后面推广的目的都是为了把它在所有持续拉高。

<a id="p0410"></a>
**P0410** 2. 多主推链接（推不同的词）

<a id="p0411"></a>
**P0411** 第二种情况是有多个主推去推不同的词——前面讲过每个词下只有一个自然坑位、只展示一个权重最高的子体，但是在不同词下可以有不同的子体占到高排名。

<a id="p0412"></a>
**P0412** 案例：裙子产品

<a id="p0413"></a>
**P0413** 流量词比较散——没有单一的哪个 ASIN 占大流量，是 600多、200多、60几。

<a id="p0414"></a>
**P0414** 点击附体往下拉，能看到不同的词下有不同的变体在站：

<a id="p0415"></a>
**P0415** • "Floral Lace Dress" 这个词：由 ASIN 占流量入口（深绿色）；

<a id="p0416"></a>
**P0416** • "Yellow Dress" 这款黄色的裙子：由黄色的去站；

<a id="p0417"></a>
**P0417** • "Pink Dress"：由粉色去站；

<a id="p0418"></a>
**P0418** • "Blue Dress"：由蓝色去站；

<a id="p0419"></a>
**P0419** 所以推多变体的时候，你可以不只有一个主推——可以有多个主推分别推不同的词。注意他们不要推一样的词——不同的子体要找到自己的分工去推不同的词。

<a id="p0420"></a>
**P0420** 对比：

<a id="p0421"></a>
**P0421** • 单主推链接：所有词可以用一个变体拿到高位；

<a id="p0422"></a>
**P0422** • 服装类：人家搜蓝色裙子不可能想要点你的黑色裙子，所以得用蓝色变体推 "Blue Dress"。

<a id="p0423"></a>
**P0423** 案例：香薰蜡烛的多主题主推

<a id="p0424"></a>
**P0424** 某蜡烛产品做的是不同主题的香薰蜡烛——比如"最好的姐姐""最好的妈妈""最好的 Couple"等。他用这些变体分别推不同词：

<a id="p0425"></a>
**P0425** • 用姐姐的款推姐姐生日礼物；

<a id="p0426"></a>
**P0426** • 用护士款推护士礼物；

<a id="p0427"></a>
**P0427** • 用 Couple 款推新婚夫妇的礼物；

<a id="p0428"></a>
**P0428** 所以多变体的优势在于：可以用不同的变体拿不同的流量入口，从而扩大流量入口。

<a id="p0429"></a>
**P0429** 这个方式适合于做主题款式的卖家——如果单链接遇到瓶颈的时候找一找有没有变体可拓，去拿不同的流量入口。比如说现在推姐姐礼物推到 39 位卡住了——开一个 Couple、开一个狗的、开一个小孩的、开一个孕妇的——大家都需要 gift。

<a id="p0430"></a>
**P0430** 反之，如果变体拿不到更多流量入口了——那就考虑把一个变体推到极致、推到最高位。剩下几个变体在这里承接（变体二三承接）就行。

<a id="p0431"></a>
**P0431** 大家做多变体千万不要有"几个变体都得出一样的订单"的思路——这个肯定不会的。得有一个主推去承接流量，剩下那些是帮你消化的。

<a id="p0432"></a>
**P0432** （三）多变体的广告坑位规则

<a id="p0433"></a>
**P0433** 多变体广告坑位：一个父体只有一个自然坑位，但是每个子体 ASIN 都可以单独有广告坑位。

<a id="p0434"></a>
**P0434** 意思就是可以用变体一占一个、变体二再占一个坑——同一个词下面比单链接有优势的地方就是广告坑位更多。

<a id="p0435"></a>
**P0435** 重要规则：互为变体的广告坑位"同板块同页互斥"

<a id="p0436"></a>
**P0436** 多变体链接的劣势：互为变体的 ASIN 的广告坑位不能在同个板块的同个页面出现——它们是互斥的。

<a id="p0437"></a>
**P0437** 也就是：

<a id="p0438"></a>
**P0438** • 多变体一个变体在第二页；

<a id="p0439"></a>
**P0439** • 另一个变体必定得去第一页；

<a id="p0440"></a>
**P0440** • 再来一个必定得去第三页；

<a id="p0441"></a>
**P0441** • 不可能在同一页出现。

<a id="p0442"></a>
**P0442** 案例：同板块互抢

<a id="p0443"></a>
**P0443** 这个链接是在一个互抢的状态——

<a id="p0444"></a>
**P0444** 某词下有红色、粉色、白色、黄色等变体：

<a id="p0445"></a>
**P0445** • 0:00-6:00：粉色变体在；

<a id="p0446"></a>
**P0446** • 7:00-8:00：白色变体在；

<a id="p0447"></a>
**P0447** • 9:00：粉色；

<a id="p0448"></a>
**P0448** • 10:00 以后：黄色；

<a id="p0449"></a>
**P0449** 请问他想主推哪个颜色？他自己也不知道。

<a id="p0450"></a>
**P0450** 问题一：不确定主推。

<a id="p0451"></a>
**P0451** 问题二：粉色在前几个小时已经在 Top 位上了，那么黄色想要上来的话竞价就给得比较高——这样粉色就会被挤到第二页。后面黄色的时候想要上来，竞价之前就给得比粉色高，所以他俩又会被挤到第二、第三页。

<a id="p0452"></a>
**P0452** 所以多变体在同板块下抢同一页的坑位的话，后台竞价是这样的：竞价右脚踩左脚——多变体的广告坑位互斥会出现互相抬价的情况，尤其是你们自己不知道互斥的情况下会出现互抬。

<a id="p0453"></a>
**P0453** 解决方法：主推确定

<a id="p0454"></a>
**P0454** 主推确定了以后，广告位是给主推的——这个词要推主推、广告给主推，其他变体就跟在主推后面出现，或者其他变体不出现也可以。

<a id="p0455"></a>
**P0455** 因为其他变体要出来就是为了占坑或买订单。

<a id="p0456"></a>
**P0456** 商品页面也是同样规则

<a id="p0457"></a>
**P0457** 商品页面里面的板块（比如 "Featured from Our Brands"）也是一样：第二页出现变体一、第二页出现变体二，互为变体也不能在同一排同一个板块出现，也互斥。

<a id="p0458"></a>
**P0458** 所以一个多变体链接能不能把竞品商品页面下面的坑位占满（霸屏）？不可能。

<a id="p0459"></a>
**P0459** 这一排不可能是同一条链接在霸屏，因为同一条链接的广告位是互斥的。最多可能在这个地方出现一回，隔页再出现——已经不会实现霸屏的效果了。

<a id="p0460"></a>
**P0460** 同一活动投两个变体的数据差异

<a id="p0461"></a>
**P0461** 你们可能在同一个活动里面会投两个变体，同一组会投两个变体——会发现它俩数据有差异。

<a id="p0462"></a>
**P0462** 比如它俩在同一个组投同一堆词、竞价一样，但数据不一样。有些卖家会根据数据来选主推——这个不对。因为它俩一个在好位置、另外一个必定在差位置。

<a id="p0463"></a>
**P0463** 所以你看点击率差异：

<a id="p0464"></a>
**P0464** • 这个 4.59 → 位置好；

<a id="p0465"></a>
**P0465** • 这个 1.26 → 位置被挤下去了；

<a id="p0466"></a>
**P0466** 这就是 TOS 位置好（点击率高）、ROS 位置差一点、PP 更差的体现。多变体共同投放必定是这样的结果——一定会有好的和差的。

<a id="p0467"></a>
**P0467** 案例：占坑做得好的链接

<a id="p0468"></a>
**P0468** 一个占坑做得好的链接：

<a id="p0469"></a>
**P0469** • 看变体流量分布非常有规律：绿色色块占的最多，其次黄色色块，其次蓝色色块；

<a id="p0470"></a>
**P0470** • 自然位是白色在站；

<a id="p0471"></a>
**P0471** • 但是白色、粉色、绿色都占广告坑位——白色粉色既去 SP 位置也去 SP 独立板块位置；

<a id="p0472"></a>
**P0472** 这种就是刻意在占坑——前提是主推是白色、白色得在高位、剩下两个去低位。

<a id="p0473"></a>
**P0473** 通过小时趋势看占坑情况——如果在同一个小时出现了多个广告位，就是故意在占坑。如果是在不同的小时分布，这种趋势打得不太好。

<a id="p0474"></a>
**P0474** 举例：9 月 2 号 8:00 这个时段：

<a id="p0475"></a>
**P0475** • 自然位：白色；

<a id="p0476"></a>
**P0476** • 广告位：白色在前、粉色在后；

<a id="p0477"></a>
**P0477** • SP 独立板块：绿色在前、白色在后；

<a id="p0478"></a>
**P0478** 下面也得是白色在前、粉色在后——这样就能保持白色作为主推。

<a id="p0479"></a>
**P0479** （四）多变体广告的加权规则

<a id="p0480"></a>
**P0480** 多变体广告加权：先确定好主推，用广告给主推加权去推主推的自然位。

<a id="p0481"></a>
**P0481** 加权得通过搜索→点击→加购→购买来实现：

<a id="p0482"></a>
**P0482** • 买家搜了 ABC 以后点进变体一购买变体一 → 变体一是顺利加权；

<a id="p0483"></a>
**P0483** • 买家点进变体二购买变体二 → 变体二在 ABC 加权了；

<a id="p0484"></a>
**P0484** 所以有些卖家广告开的是变体一，但是自然位是变体二——是因为买家买的是变体二。

<a id="p0485"></a>
**P0485** 两个错误示范

<a id="p0486"></a>
**P0486** 错误示范一：主推是变体 A，广告打变体 A，但买家点进变体 B 购买。

<a id="p0487"></a>
**P0487** 错误示范二：主推是变体 A，广告打的是变体 B，出在变体 B。

<a id="p0488"></a>
**P0488** 这两个都不行——投放 ASIN 跟主推目标不一致。

<a id="p0489"></a>
**P0489** 要避免买家收到变体 B：

<a id="p0490"></a>
**P0490** • 出单 ASIN 和目标主推 ASIN 不一致；

<a id="p0491"></a>
**P0491** • 平时广告不亏损还好，广告亏的话尽量让每一笔钱都亏在主推上面，而不要回馈到变体 B 上面；

<a id="p0492"></a>
**P0492** • 变体 B 的自然位只要不超过变体 A 它都出现不了，这个钱都是白花、被隐藏掉的。

<a id="p0493"></a>
**P0493** 三种正确示范

<a id="p0494"></a>
**P0494** 主推是变体 A 的情况下，有几种广告可以打：

<a id="p0495"></a>
**P0495** 正确做法 1：通过变体 A 的广告进入购买变体 A——可以实现主推变体 A 的结果。一般要通过你的选款和定价让买家真的买变体 A。

<a id="p0496"></a>
**P0496** 正确做法 2：通过变体 C/D 引流进来去买变体 A。

<a id="p0497"></a>
**P0497** 怎么做？用售价引导向变体 A：

<a id="p0498"></a>
**P0498** • 比如变体 C/D 卖 $13.99，变体 A 卖 $9.99；

<a id="p0499"></a>
**P0499** • 用 $13.99 去打广告，大家点进来去买 $9.99；

<a id="p0500"></a>
**P0500** 这相当于给变体 A 增加了广告位——如果没有 C/D，只有一个广告位；但有了 C/D，可以有第二、第三页的广告位。但要好用不好的话不如别打。

<a id="p0501"></a>
**P0501** 正确做法 3：投变体 E/F——给变体 E/F 打广告，让买家进入 E/F 直接买订单去盈利。

<a id="p0502"></a>
**P0502** 一般是链接里面有高单价的变体的时候，给高单价变体打广告——让他们去买一点零散的订单去养活自己或增加整条链接的利润。

<a id="p0503"></a>
**P0503** 打广告的三个目的

<a id="p0504"></a>
**P0504** 不管要干嘛，咱们打广告最终就是这三个目的，看是不是能实现这三个目的就行：

<a id="p0505"></a>
**P0505** 1. **提高站位**：是不是想提高准确的站位？那么动作是不是在帮主推出单？要核实；

<a id="p0506"></a>
**P0506** 2. **占坑**：把别人挤走——第一页用变体一占坑，第二、第三页用变体 2、3 占坑——这样多变体可以占更多的坑；

<a id="p0507"></a>
**P0507** 3. **出单**：多变体的广告会更多——一个词下面几个变体就有几个位置——可以做盈利平本广告或做实际坑产。

<a id="p0508"></a>
**P0508** 实际坑产 + 多变体的注意

<a id="p0509"></a>
**P0509** 最后强调一点：如果是做实际坑产的话，预期坑产和实际坑产都是存在于子体（变体）里面的。

<a id="p0510"></a>
**P0510** 也就是说现在变体一是主推：

<a id="p0511"></a>
**P0511** • 你可以给变体一做预期坑产或实际坑产；

<a id="p0512"></a>
**P0512** • 但给变体二买订单对变体一是没有帮助的——它俩是单独的，自然位是单独的。

<a id="p0513"></a>
**P0513** 所以你要做实际坑产的话，得让单量到变体一上面去——这是最简单的。

<a id="p0514"></a>
**P0514** （五）多变体的多种分工总结

<a id="p0515"></a>
**P0515** 多变体的几种分工：

<a id="p0516"></a>
**P0516** 分工一：占有自然流量入口

<a id="p0517"></a>
**P0517** 谁去占流量入口谁就是主推——可以单主推也可以多主推。多主推尽量去占不同的流量入口。

<a id="p0518"></a>
**P0518** 案例：平衡车（BSR）

<a id="p0519"></a>
**P0519** 看流量结构：

<a id="p0520"></a>
**P0520** • 反查词里面绿色这一款是它的主推；

<a id="p0521"></a>
**P0521** • 粉色这款的流量也很多（流量词也多）；

<a id="p0522"></a>
**P0522** • 白色这些就很少了；

<a id="p0523"></a>
**P0523** • 变体 X 光机里面绿色占大头、粉色也占一头；

<a id="p0524"></a>
**P0524** ——这种情况并不一定是坏事——如果他俩分别去占不同的词就是好事，如果占一个词就是坏事。

<a id="p0525"></a>
**P0525** 往下拉看变体流量份额：

<a id="p0526"></a>
**P0526** • 粉色站的：全是 girl 的长尾词（girl birthday gift、gift for one year old girl 等）；

<a id="p0527"></a>
**P0527** • 绿色站的：除了 girl 以外的所有场景词；

<a id="p0528"></a>
**P0528** 所以分工很明确——所有带 girl 的词都得是粉色去拿。点进粉色变体看到 768 个词几乎全都是 girl。

<a id="p0529"></a>
**P0529** 判断方法：如果想要确认一个竞品的多变体是否有不同分工——就看他有没有一个固定词根。有固定词根 = 故意的；没固定词根 = 打得不好。

<a id="p0530"></a>
**P0530** 分工二：增加整体 CVR（提升转化率）

<a id="p0531"></a>
**P0531** 有些变体不占流量入口，但是增加整体 CVR。

<a id="p0532"></a>
**P0532** 举例：服装的尺码。没有这个尺码、没有 M 码、没有 L 码——转化率就会掉。所以这些变体的作用就是增加 CVR。

<a id="p0533"></a>
**P0533** 分工三：增加整体利润（提客单价）

<a id="p0534"></a>
**P0534** 变体可能有另外一个作用：提客单价。

<a id="p0535"></a>
**P0535** 举例：

<a id="p0536"></a>
**P0536** • 主推是 $35；

<a id="p0537"></a>
**P0537** • 绿色 $32.99；

<a id="p0538"></a>
**P0538** • 粉色 $35.99；

<a id="p0539"></a>
**P0539** • 后面这些售价 $42、$42、$42；

<a id="p0540"></a>
**P0540** 也就是这些变体在说："你不买我的主推可以，但是你得多付点钱、让我的链接多点利润——要么你给我主推加权，要么你给我的链接加利润。"

<a id="p0541"></a>
**P0541** 低单价标品的涨价技巧

<a id="p0542"></a>
**P0542** 低单价标品涨价很困难——竞品都是卖 $9.99，你也只能卖 $9.99。怎么办？加梯度。

<a id="p0543"></a>
**P0543** 一般我们都喜欢加梯度——不会在主体上面涨价，去别的梯度上面：

<a id="p0544"></a>
**P0544** • 主体甚至可以降价（降到 $8.99 给你们打价格战）；

<a id="p0545"></a>
**P0545** • 辅推变成 $10.99、$12.99；

<a id="p0546"></a>
**P0546** 这样组合完以后：

<a id="p0547"></a>
**P0547** • 自然位由谁决定？由主推决定；

<a id="p0548"></a>
**P0548** • $8.99 去拿自然位，剩下 $10 和 $12 在里面转化就行了；

<a id="p0549"></a>
**P0549** • $8.99 留出来给 $10 和 $12 去消化——客单价就变相提升了；

<a id="p0550"></a>
**P0550** • 综合出来的客单价还是 $9.99 左右；

<a id="p0551"></a>
**P0551** 所以低单价标品想涨价，不会直接去涨——会去加变体去涨。

<a id="p0552"></a>
**P0552** 分工四：占有付费流量入口

<a id="p0553"></a>
**P0553** 有的变体就是为了去占坑——头部卖家变体开得很满，第一页要占、第二页也要、第三页也要。

<a id="p0554"></a>
**P0554** 分工五：广告盈利（用辅推买广告单）

<a id="p0555"></a>
**P0555** 用辅推去买广告单——因为辅推不会多，广告单也可以买到。

<a id="p0556"></a>
**P0556** 分工六：辅助推动

<a id="p0557"></a>
**P0557** 但这个作用不是每个产品都能做到辅助推动——这个另讲。大家不要抱着这个目的去，尽量抱着前两个目的去。

<a id="p0558"></a>
**P0558** （六）案例：单主推 vs 多主推链接

<a id="p0559"></a>
**P0559** 案例一：单主推链接

<a id="p0560"></a>
**P0560** 特征：某个子体占 80%+ 的流量入口，其余子体几乎不占流量入口。

<a id="p0561"></a>
**P0561** 举例：狗尿垫——总流量得分 1300，第一个垫子占 95%——典型的单主推。

<a id="p0562"></a>
**P0562** 案例二：多主推占多流量入口

<a id="p0563"></a>
**P0563** 某包包链接：

<a id="p0564"></a>
**P0564** • 总流量 4,700；

<a id="p0565"></a>
**P0565** • 流量散：1,800、1,000、400 多；

<a id="p0566"></a>
**P0566** 怎么判断有没有清晰的多主推？看各个词：

<a id="p0567"></a>
**P0567** • "Black bug" 这个词：黑色变体占据；

<a id="p0568"></a>
**P0568** • "ASS Pass"：粉色变体；

<a id="p0569"></a>
**P0569** • "WiFi"：白色变体；

<a id="p0570"></a>
**P0570** • "Pink"：粉色变体；

<a id="p0571"></a>
**P0571** • "Blue"：蓝色变体；

<a id="p0572"></a>
**P0572** ——不同变体非常好地承接了不同的流量入口——这种是多主推链接做到比较标准的情况。

<a id="p0573"></a>
**P0573** 如果链接也是这样子但没有明确分工——就推得是乱的。

<a id="p0574"></a>
**P0574** 对比效果：

<a id="p0575"></a>
**P0575** • 多主推清晰分工：花 5 分钱拿 5 个流量入口；

<a id="p0576"></a>
**P0576** • 推得乱：花 5 分钱拿 1 个流量入口；

<a id="p0577"></a>
**P0577** 事半功倍 vs 事倍功半。

<a id="p0578"></a>
**P0578** 所以如果你不会推的话，尽量只做一个主推——做成单主推不会有错，虽然不出彩但绝对没错。

<a id="p0579"></a>
**P0579** 如果做成多主推，可能比较出彩——可以低成本地通过增加变体获得很多流量入口，位置都不高但流量入口多。

<a id="p0580"></a>
**P0580** （七）变体占付费流量入口的几种思路

<a id="p0581"></a>
**P0581** 思路一：单主推 + 单广告

<a id="p0582"></a>
**P0582** 适用于广告本身不盈利——只开一个变体去推就可以了。

<a id="p0583"></a>
**P0583** 举例：苹果手表表带，有很多变体——选择只做单主推，广告就只投这一个子体。

<a id="p0584"></a>
**P0584** 思路二：明确主推 + 主推靠前 + 辅推占坑

<a id="p0585"></a>
**P0585** 适用于有明确主推、广告出单不亏损——所有变体都用于占坑或买订单。

<a id="p0586"></a>
**P0586** 案例：橙色猫脖套

<a id="p0587"></a>
**P0587** 主推很明显是橙色猫脖套：

<a id="p0588"></a>
**P0588** • 广告位第一页：橙色在前；

<a id="p0589"></a>
**P0589** • 第一页下面：粉色、红色、黄色都在下面；

<a id="p0590"></a>
**P0590** • SB 广告：橙色在前面；

<a id="p0591"></a>
**P0591** • SBV、SP 独立板块：都是橙色；

<a id="p0592"></a>
**P0592** 所以所有的广告都先布局的橙色——主推的广告流布局好了以后，再去添辅推到别的页面买订单——这样能让广告盈利订单翻番。

<a id="p0593"></a>
**P0593** 思路三：无主推

<a id="p0594"></a>
**P0594** 所有的广告都可以负责拍广告买订单，所有的 ASIN 都可以买订单。

<a id="p0595"></a>
**P0595** 适用情况：

<a id="p0596"></a>
**P0596** • 不需要推自然位；

<a id="p0597"></a>
**P0597** • 推不上去自然位；

<a id="p0598"></a>
**P0598** • 广告本身盈利；

<a id="p0599"></a>
**P0599** 飞镖（非标品）都可以这样做。

<a id="p0600"></a>
**P0600** 案例：双主推

<a id="p0601"></a>
**P0601** 某产品单价 $100-300：自然位也不稳定、广告位也不稳定——可能广告会开很多。

<a id="p0602"></a>
**P0602** 仔细看：这个链接其实有主推的——主推是 1、2 两个颜色（双主推），广告也是看 1、2 两个颜色。

<a id="p0603"></a>
**P0603** 双主推的情况：在买家无法控制推哪个买哪个的时候——比如产品又有白色又有黑色，买家一半要白色、一半要黑色——你控不了，黑白就双主推，没办法。

<a id="p0604"></a>
**P0604** 反面案例：无清晰逻辑

<a id="p0605"></a>
**P0605** 某产品我们看变体定价猜他想推什么：

<a id="p0606"></a>
**P0606** • 可能想推变体 1、3、5（低价的）；

<a id="p0607"></a>
**P0607** • 但自然位是变体 4——跟 1、3、5 没关系；

<a id="p0608"></a>
**P0608** • 广告又是 2、7、9（看左上角变体编号）；

<a id="p0609"></a>
**P0609** 这个产品到底在开什么？看不懂——这就是属于推广水平比较次的情况。

<a id="p0610"></a>
**P0610** 为什么？

<a id="p0611"></a>
**P0611** • 定价上面会让买家倾向于买 1、3、5；

<a id="p0612"></a>
**P0612** • 自然位推出了 4（代表买家买 4 买得多）；

<a id="p0613"></a>
**P0613** • 广告又不推 4 又不推 1、3、5、推的是 2、7、9；

<a id="p0614"></a>
**P0614** 唯一可能的解释：广告本身是盈利的。但如果广告盈利想要做无主推，为什么只开 2、7、9？应该把 1-9 全部开了。

<a id="p0615"></a>
**P0615** 所以这个产品无论从什么角度讲都开得很烂——不管是有主推还是无主推都不符合逻辑——事倍功半的效果。

<a id="p0616"></a>
**P0616** （八）多变体推广作业

<a id="p0617"></a>
**P0617** 今天因为后面要讲广告的具体放量，所以你们得先把"主推"这个事情定下来。

<a id="p0618"></a>
**P0618** 首先你要不要有主推——先定一下。如果要有主推的话：

<a id="p0619"></a>
**P0619** 1. **目标主推 ASIN 是什么？**

<a id="p0620"></a>
**P0620** 2. **目标主推定好以后，是否有单价倾斜？**

<a id="p0621"></a>
**P0621** 3. **实际投放的 ASIN 是什么？**

<a id="p0622"></a>
**P0622** 4. **实际出单 ASIN 是什么？**

<a id="p0623"></a>
**P0623** 5. **实际占自然位的 ASIN 是什么？**

<a id="p0624"></a>
**P0624** 这 4 个东西（2、3、4、5）得一致——如果有任何一个不一致，就找到问题在哪了。

<a id="p0625"></a>
**P0625** 举例：刚刚截图的链接——目标主推不知道，但实际投放、实际出单、实际占自然位都不一样——所以这条链接推得很差。

<a id="p0626"></a>
**P0626** 回去先检查自己的；没有主推的话，先把主推定出来；或者干脆做无主推也行。

<a id="p0627"></a>
**P0627** （九）分工三补充：仅提升转化率（不占自然/广告流）

<a id="p0628"></a>
**P0628** 第三种分工：不占自然流也不占广告流，只是提升转化率。

<a id="p0629"></a>
**P0629** 提升转化率会分为两种类型的变体：

<a id="p0630"></a>
**P0630** 1. 刚需型变体

<a id="p0631"></a>
**P0631** 有了这些变体以后，转化率能从 10% → 20%。

<a id="p0632"></a>
**P0632** 举例：服装的同颜色多尺码——就是刚需型的变体。

<a id="p0633"></a>
**P0633** 2. 非刚需型变体

<a id="p0634"></a>
**P0634** 有了这些变体以后，转化率能从 20% → 22%——甚至转化率根本不变。

<a id="p0635"></a>
**P0635** 举例：无线充电器的红橙黄绿青蓝紫——非刚需型，没有他们你的产品照样卖、有了他们以后转化率可能提了那么一点点。

<a id="p0636"></a>
**P0636** 链接初期，建议多开刚需型变体。

<a id="p0637"></a>
**P0637** 非刚需型变体一般是链接流量很充足的情况下，想提升单量——可能靠这些变体增加 1-2 个点的转化率。

<a id="p0638"></a>
**P0638** （十）销量公式与变体策略

<a id="p0639"></a>
**P0639** 销量 = 流量 × 转化率

<a id="p0640"></a>
**P0640** 很简单——销量等于流量乘转化。

<a id="p0641"></a>
**P0641** 缺什么补什么：

<a id="p0642"></a>
**P0642** • 缺流量 → 搞流量；

<a id="p0643"></a>
**P0643** • 缺转化 → 搞转化；

<a id="p0644"></a>
**P0644** • 现在做变体可能是因为这个变体能多搞流量去扩大流量口子；

<a id="p0645"></a>
**P0645** • 也可能是因为变体在里面去做转化；

<a id="p0646"></a>
**P0646** 每个环节都可能会用到变体的。

<a id="p0647"></a>
**P0647** 大家千万不要在初期没流量的时候去搞一堆非刚需型变体——他们对你来说起不到什么作用。

<a id="p0648"></a>
**P0648** （十一）分工四补充：提升客单价

<a id="p0649"></a>
**P0649** 提升客单价——前面跟你们讲过：

<a id="p0650"></a>
**P0650** • 一个变体负责推自然位（比如手表表带的金色变体）；

<a id="p0651"></a>
**P0651** • 别的变体卖 $13、$10、$13-14——为了增加转化率/客单价；

<a id="p0652"></a>
**P0652** 同样像 $5.99 标品的主推：怎么样提升客单价？卷不过卷——就是低价已经很低了，所以可以靠增加数量类型的变体做组合：装 2 个 $7、$8、$11、$14、$19——用这些变体来增加客单价。他们也是不影响主推的，咱们也不需要在后面那些开广告。

<a id="p0653"></a>
**P0653** 所以现在你们就算做的是刚需型的同质化的标品，也可以靠不同的组合形式来做高客单价。

**P0654** 八、多变体推广总结

<a id="p0655"></a>
**P0655** 推自然位 vs 不推自然位

<a id="p0656"></a>
**P0656** 先看：咱们的目的是为了推自然位还是不用推自然位？

<a id="p0657"></a>
**P0657** 推自然位的链接

<a id="p0658"></a>
**P0658** 今天把以下事情整合一下：

<a id="p0659"></a>
**P0659** 1. 每个词主推的 ASIN 是否明确；

<a id="p0660"></a>
**P0660** 2. 每个 ASIN 开广告的子体是否明确；

<a id="p0661"></a>
**P0661** 3. 出单 ASIN 是否明确；

**P0662** 这三个东西定下来。

**P0663** 无主推链接（以出单为目的的广告）

<a id="p0666"></a>
**P0666** 1. 是否把所有能用上的变体全用上了？

<a id="p0667"></a>
**P0667** 2. 变体是不是都去买广告单了？

**P0668** 这两点回去分别去定。

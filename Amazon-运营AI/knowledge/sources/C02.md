**P0008** 一、单品利润公式：从推广角度拆解盈利

<a id="p0009"></a>
**P0009** （一）单品利润的基本构成

<a id="p0010"></a>
**P0010** 首先我们的单品利润，做推广其实不是为了打广告而打广告，而是为了最后的利润更高而打广告。所以我们单品利润可以这样去算：

<a id="p0011"></a>
**P0011** 单品利润 = 总单量 × 客单价（销售额）− 各方面成本

<a id="p0012"></a>
**P0012** 其中我标黑的这些成本都是可预估的，比如说你的头程、尾程、采购、佣金、仓储、破损等等，这些在你推广过程当中可能是一个定值，或者是相对固定的值，是可以预估出来的。但是后面的推广成本是你不可预估的，也就是说我标红的"广告单、自然单和推广成本"这三块都是不可预估的。

<a id="p0013"></a>
**P0013** 所以我们会把所有可控的成本全部都压缩到一起，把常用项压缩，只剩变量。当我们只从推广角度看单品盈利的时候：

<a id="p0014"></a>
**P0014** 总利润 = 广告单利润 + 自然单利润

<a id="p0015"></a>
**P0015** 其中你的自然单——出一单就挣一单，对吧？我们管它叫"单品的——

<a id="p0016"></a>
**P0016** 说话人3 01:30

<a id="p0017"></a>
**P0017** 定价毛利"。

<a id="p0018"></a>
**P0018** 说话人2 01:34

<a id="p0019"></a>
**P0019** "定价毛利"，这就是我的自然单乘上定价毛利，就是自然单利润。广告单利润得减去你的广告费。

<a id="p0020"></a>
**P0020** （二）总利润的展开公式

<a id="p0021"></a>
**P0021** 我们总利润再展开来讲：

<a id="p0022"></a>
**P0022** 总利润 = 自然单利润 + 广告单利润

<a id="p0023"></a>
**P0023** • 自然单利润 = 定价毛利 × 自然单量

<a id="p0024"></a>
**P0024** 所以如果想要增加自然单利润，要去做好"增加自然单量"的动作。

<a id="p0025"></a>
**P0025** • 广告单利润 = (单个定价的毛利 − 广告CPA) × 广告单量

<a id="p0026"></a>
**P0026** （三）CPA与ACOS的关系

<a id="p0027"></a>
**P0027** 这时候我们要区分一下你的广告单本身是否盈利。我们对单次出单成本定义为CPA：

<a id="p0028"></a>
**P0028** CPA（Cost Per Acquisition）的意思就是 cost per order，有些工具软件会把它叫CPO（cost per order）。

<a id="p0029"></a>
**P0029** CPA = 广告花费 ÷ 广告订单

<a id="p0030"></a>
**P0030** 把CPA做一个拆分：

<a id="p0031"></a>
**P0031** • 广告花费 = CPC × 点击数量

<a id="p0032"></a>
**P0032** • 广告订单 = 点击数量 × CVR（转化率）

<a id="p0033"></a>
**P0033** 所以上下都可以互相抵消掉以后：

<a id="p0034"></a>
**P0034** CPA = CPC ÷ CVR

<a id="p0035"></a>
**P0035** 这是CPA的指标。具体指标在你们的后台用ERP都是可以看到的。但如果你们没有ERP的话，一般我们会用ACOS指标去判定。

<a id="p0036"></a>
**P0036** ACOS = 广告花费 ÷ 广告总销售额

<a id="p0037"></a>
**P0037** 对ACOS也做一个拆分：

<a id="p0038"></a>
**P0038** • 广告花费 = CPC × 点击量

<a id="p0039"></a>
**P0039** • 广告总销售额 = 广告单量 × 单价 = 点击 × CVR × 售价

<a id="p0040"></a>
**P0040** 所以最后你的ACOS指标 = CPC ÷ (CVR × 售价)

<a id="p0041"></a>
**P0041** 从这点上面来看，CPA跟ACOS的关系也非常简单：

<a id="p0042"></a>
**P0042** CPA = ACOS × 售价

<a id="p0043"></a>
**P0043** ACOS = CPA ÷ 售价

<a id="p0044"></a>
**P0044** 这就是这两条公式的关系。其实就是因为CPA是除以广告订单，ACOS是除以广告总销售额，它俩就差一个单价，这样理解就可以了。

<a id="p0045"></a>
**P0045** 现在如果想要通过ACOS高低来判定广告是否盈利也OK，用CPA来判定广告是否盈利也OK。

<a id="p0046"></a>
**P0046** （四）广告盈利判定标准

<a id="p0047"></a>
**P0047** 我先用CPA的指标跟大家讲：

<a id="p0048"></a>
**P0048** 1. CPA ≥ 定价毛利 → 投资型广告

<a id="p0049"></a>
**P0049** 当CPA大于定价毛利、或CPA等于定价毛利的时候，这个时候你的广告出多少单都是不盈利的，对吧？不盈利。所以你这个广告单出得再多，利润都是个0或者是个负数。这种情况下出广告单出得再多，本身对于利润来说没有意义，除非你的广告单的目的是为了拉自然单。

<a id="p0050"></a>
**P0050** 所以当广告本身是亏损或不产生盈利的情况下，我们管它叫投资型广告。投资型广告的目标就是未来自然单带来的利润，这是你做这类型广告的目的。

<a id="p0051"></a>
**P0051** 2. CPA < 定价毛利 → 盈利型广告

<a id="p0052"></a>
**P0052** CPA小于毛利的话，你广告出一单都是盈利的。所以这种类型的广告它的目的在于两个地方：

<a id="p0053"></a>
**P0053** • 一种是广告出单盈利，本身带来的利润OK，所以我们可能会冲着这点去做；

<a id="p0054"></a>
**P0054** • 但如果你的CPA比较接近于毛利（定价毛利 − CPA是一个比较小的数值），还有另外一个目的是带动自然单的利润。

<a id="p0055"></a>
**P0055** 所以在推广层面来讲，我们打广告的打法有很多不一样，是因为不同的卖家所做的广告本身可能有些人是投资型广告，有些人是盈利型广告。

<a id="p0056"></a>
**P0056** （五）广告活动的细分

<a id="p0057"></a>
**P0057** 我们现在讲的"投资型广告"指的是整体的广告数据，但实际上来讲，我们的广告可以再去细分。比如说后台是这样子的——假设我们的产品A定价毛利是25%，在这个情况下：

<a id="p0058"></a>
**P0058** • 框成绿色的活动：CPA低于毛利，属于盈利型广告；

<a id="p0059"></a>
**P0059** • 框成红色的活动：CPA高于毛利，是亏损的，叫投资型广告。

<a id="p0060"></a>
**P0060** 那么单个产品里面会再去做细分：

<a id="p0061"></a>
**P0061** 总单量 = 自然单 + 盈利型广告单 + 投资型广告单

<a id="p0062"></a>
**P0062** 总利润 = 自然单利润 + 盈利型广告利润 + 投资型广告利润

<a id="p0063"></a>
**P0063** 不同卖家的情况：

<a id="p0064"></a>
**P0064** • 有些卖家广告全是亏的，没有一条是赚的，那么你就只有"投资型广告"这一块；

<a id="p0065"></a>
**P0065** • 有的卖家有部分是盈利的，那么由这三块去构成；

<a id="p0066"></a>
**P0066** • 还有的卖家广告全是盈利的，那么由前两部分构成。

<a id="p0067"></a>
**P0067** 总体来讲这三部分构成总利润。

<a id="p0068"></a>
**P0068** （六）盈利型广告与投资型广告的优化方向

<a id="p0069"></a>
**P0069** 盈利型广告：做大广告单，并拉大CPA和毛利之间的差距

<a id="p0070"></a>
**P0070** 后台有一些ACOS特别低的广告——比如最下面一条ACOS控制13%的广告，这种广告出一单盈利比较多，那么我们需要把它的单量做大。但像有一些ACOS在23%这种是出单利润比较低的情况下，我们要么把它的ACOS拉得更低，要么让这条广告少放点量，把它视作一种"平本型广告"，这样就可以了。

<a id="p0071"></a>
**P0071** 投资型广告：利用广告做大自然单，并控制广告亏损比例

<a id="p0072"></a>
**P0072** 让广告实现投资的功能。也就是说现在你的广告会分成"CPA大于毛利""CPA等于毛利"这两种叫做投资型广告。如果不会看CPA的话，你看ACOS就行了——当ACOS大于毛利率，那也就代表着这个模式是投资型广告（CPA大于定价毛利意味着它俩一起除以一个price，CPA/price 也是一样的，这就是ACOS）。

<a id="p0073"></a>
**P0073** 简单说：CPA跟毛利对比，或者ACOS跟毛利率对比就可以了。

<a id="p0074"></a>
**P0074** （七）实战提醒：不要做亏爆的投资型广告

<a id="p0075"></a>
**P0075** 一般来说，我们产品在亚马逊上面卖的定价毛利率（不算广告的毛利率）大部分在20%~40%之间。也就是说现在如果ACOS整体偏高（比如60%、80%、90%），花费来说都是亏损严重的。

<a id="p0076"></a>
**P0076** ACOS 230% 的广告 = 亏爆了的广告，绝对不要拿它去放量。

<a id="p0077"></a>
**P0077** 第一个原因：数据很差，相当于在反向刷单——反向刷单的话你的自然位会越刷越差。

<a id="p0078"></a>
**P0078** 第二个原因：买这种类型的广告，假设你定价毛利30%，那么出一单是亏200%的，这种情况下你得出多少自然单才能抵得上一单的亏损？我们算一笔：

<a id="p0079"></a>
**P0079** • 假设广告单出一单是 −200%

<a id="p0080"></a>
**P0080** • 自然单出一单是 +30%

<a id="p0081"></a>
**P0081** • 那么1个广告单需要多少自然单来养？约7个自然单 = 1个广告单的亏损

<a id="p0082"></a>
**P0082** 所以如果你的单量比例做到7:1才能打平。你如果想要挣钱，比例还得做更大，比如做10倍。但是大部分的产品如果是这样的比例：第一，你需要做的自然单量非常大；第二，广告多出几单亏损会非常严重。

<a id="p0083"></a>
**P0083** 所以所有推广的前提，即使是投资型广告，咱们一单也尽量让他少亏一点。亏成这个样子是不用放量的，要控制广告的亏损比例，让广告实现投资的功能。

<a id="p0084"></a>
**P0084** 一般我见到比较正常的就是：低客单价、红海标品这类型的产品，它ACOS可能是80%左右、七八十——它就是你别的产品也基本没法更高了，更高的话广告表现是有问题的，得去优化。

<a id="p0085"></a>
**P0085** 总结：

<a id="p0086"></a>
**P0086** • 投资型广告的目的就是做自然单。如果广告又亏了钱、自然单又做不出来的话，你的广告是白打。

<a id="p0087"></a>
**P0087** • 如果广告本身能盈利，你也得把它做大。

<a id="p0088"></a>
**P0088** 这些是我们后续广告放量的最基本的原则。

<a id="p0089"></a>
**P0089** 二、亚马逊站内广告流量通道盘点

<a id="p0090"></a>
**P0090** 接下来跟大家盘点一下我们站内的广告流量通道。站内广告流量通道大致分为4种：SP、SB、SBV、SD。

<a id="p0091"></a>
**P0091** （一）SP广告（Sponsored Products）

<a id="p0092"></a>
**P0092** 1. SP广告的位置

<a id="p0093"></a>
**P0093** SP广告位置在两个地方：搜索结果页面 + 商品详情页。

<a id="p0094"></a>
**P0094** 搜索结果页面：

<a id="p0095"></a>
**P0095** 都是有板块名字的，比如"Result"——分为TOS（Top of Search）和ROS（Rest of Search）两个位置，它俩属于一个板块。如果你的广告在TOS出现，在ROS就出现不了。

<a id="p0096"></a>
**P0096** 再往下是独立板块——比如Highly Rated、Featured from Our Brands、Most Wished For、Trending Now，这些都是比较常见的独立板块。一个词下面有几个独立板块，你的广告就能出现几次，它们都属于SP的广告位。

<a id="p0097"></a>
**P0097** 商品详情页：

<a id="p0098"></a>
**P0098** 也很简单，它也有板块名字，比如Featured from Our Brands、Top Deals、各种Pop板块等等，这些全部都是板块名称。一个商品详情页大概会有2-3个广告板块，你的广告能出现2-3次。

<a id="p0099"></a>
**P0099** 2. SP广告的投放方式

<a id="p0100"></a>
**P0100** SP广告的投放目标有两种（手动）：关键词投放和商品投放。

<a id="p0101"></a>
**P0101** 先说关键词投放：里面有广泛、词组、精准等等，他们都能跑到词下面。

<a id="p0102"></a>
**P0102** 重点澄清一个误区：有的卖家会因为"广告位置是搜索结果页和商品详情页"、"广告是关键词投放和商品投放"，就误以为"关键词投放就是跑到搜索结果页，商品投放就是跑到商品详情页"——这个想法是不对的。

<a id="p0103"></a>
**P0103** 当你投关键词投放（比如AB精准）的时候，你会跑到：

<a id="p0104"></a>
**P0104** • AB相关的搜索词的搜索结果页面

<a id="p0105"></a>
**P0105** • 搜索后点开的商品详情页

<a id="p0106"></a>
**P0106** 什么意思？现在我搜showerhead这个词，搜了以后我们先看，你的广告如果打了showerhead精准，那么广告位可能出现在Result和ROS的位置。它也可能出现在——比如我点开一个商品页，当我点开这个商品页面以后，你看顶上是不是还是个showerhead？顶上还是个showerhead，就意味着这个页面也是被showerhead这个词所触发的。

<a id="p0107"></a>
**P0107** 包括我们看这条链接的构成，把链接复制下来，链接里面也是带着 t-words=showerhead 出现的。所以当你的广告投的是 showerhead 精准的时候，你也会在这个页面出现。

<a id="p0108"></a>
**P0108** 所以你们在后台广告位里面会看到有"头部""其余"还有"商品页面"——商品页面就是这些地方，而且商品页面曝光不会小，是因为搜索页面可能排得不是很好，但是商品页面它会很容易出现。

<a id="p0109"></a>
**P0109** 再说商品投放：可以投类目节点，也可以投各个ASIN，它其实也跟广泛/自动/精准是一样的——一个是大范围，一个是小范围。投ASIN精准也好、ASIN拓展也好，都是在跑ASIN。

<a id="p0110"></a>
**P0110** 当你投了商品投放以后，会出现的广告位在商品详情页和搜索结果页面，但它俩会有区别：

<a id="p0111"></a>
**P0111** • 投ASIN（商品投放）：出现在ASIN的商品详情页（固定）+ 该ASIN反查词的搜索结果页（不固定）。

<a id="p0112"></a>
**P0112** 3. 关键词投放 vs 商品投放的区别

<a id="p0113"></a>
**P0113** 它俩主要触发的是什么不同：

<a id="p0114"></a>
**P0114** • 投关键词AB（精准）：搜索结果页固定（在AB上固定）；商品详情页不固定（可能在ASIN1、ASIN2、ASIN3上面）。

<a id="p0115"></a>
**P0115** • 投ASIN（商品投放）：商品详情页固定（在ASIN1的商品详情页出现）；搜索结果页不固定（在该ASIN的反查词出现）。

<a id="p0116"></a>
**P0116** 举个例子：

<a id="p0117"></a>
**P0117** • 如果想要在某个词的搜索结果页面出现 → 投关键词投放（KT）

<a id="p0118"></a>
**P0118** • 如果想要控制在某个商品详情页 → 投商品投放（PT）

<a id="p0119"></a>
**P0119** 但它俩之间广告位是互相存在的，所以这点上面大家不要觉得"我投关键词一定在搜索结果页面出现"就可以了。

<a id="p0120"></a>
**P0120** 4. 自动广告

<a id="p0121"></a>
**P0121** 自动广告里头有"紧密、宽泛、同类、关联"：

<a id="p0122"></a>
**P0122** • 紧密、宽泛：跑的是词

<a id="p0123"></a>
**P0123** • 同类、关联：跑的是ASIN

<a id="p0124"></a>
**P0124** 它们也会跑搜索结果页和商品详情页：

<a id="p0125"></a>
**P0125** • 紧密和宽泛：主要跑词包，以及这些词包对应的商品页面；

<a id="p0126"></a>
**P0126** • 同类和关联：主要跑ASIN，并跑到这ASIN的反查词。

<a id="p0127"></a>
**P0127** 所以你的自动广告的搜索词报表里面，即使你跑的是"同类"也一样会出很多词——就是因为它会跑到反查词。所以自动其实就看你想要限定准的词还是限定准的ASIN。

<a id="p0128"></a>
**P0128** 自动广告其实跟下面的手动差别并不大。

<a id="p0129"></a>
**P0129** 5. 关键词包（Keyword Group）

<a id="p0130"></a>
**P0130** 手动里面关键词投放还会有一个叫"关键词包"——叫做Keyword Group。投这个的话——也就是现在亚马逊后台有什么"Keywords related to your"之类的关键词包，这些关键词包其实跟你投关键词也是一样的效果，跟投自动紧密和直接投关键词都是一样的效果，都是在投词。

<a id="p0131"></a>
**P0131** 为什么会有关键词包存在？因为亚马逊本质上就是卖广告的广告商，他希望你更便捷地去买广告。以前你要做关键词调研，现在他会给你推荐关键词；再到后来连关键词他都不给你推荐了，你不用调研，直接来投关键词包就行——也是为了让你更容易花出去钱。

<a id="p0132"></a>
**P0132** 所以这里的SP广告不管你怎么投，它的位置也就是在这些位置。即使你投AB投100遍，他也在搜索页SP广告位有几个板块就出几次，不可能出100次。

<a id="p0133"></a>
**P0133** （二）SB广告（Sponsored Brands，头条广告）

<a id="p0134"></a>
**P0134** SB广告的位置：搜索结果页的页头和页尾，以及在商品详情页里面。

<a id="p0135"></a>
**P0135** 如果你是品牌旗舰店的话，呈现的样子是"自定义图片+品牌Logo"；如果投的是商品集，作用就是在商品集也出商品集。

<a id="p0136"></a>
**P0136** SB广告的投放方式：和SP一样，关键词投放和商品投放。

<a id="p0137"></a>
**P0137** 但这里跟SP一样：投关键词它也会跑到关键词相关的商品页面。比如你看到showerhead的商品页面里面的SB广告位，可能是由对方投了showerhead精准跑出来的。所以无论如何你都会互相跑的。

<a id="p0138"></a>
**P0138** 重要建议：

<a id="p0139"></a>
**P0139** • 想跑到固定的词下面 → 投SB的关键词投放；

<a id="p0140"></a>
**P0140** • 投SB的商品投放：会跑到固定的商品和不固定的反查词，但由于商品页面的SB广告位很少，所以投SB的商品投放时大部分跑的还是反查词。

<a id="p0141"></a>
**P0141** 所以不建议大家专门去投SB的商品投放，因为它跑的可能效果并不如人意。但建议你们去跑页头位置，因为页头位置的CTR和CVR都是非常不错的。

<a id="p0142"></a>
**P0142** （三）SBV/视频广告

<a id="p0143"></a>
**P0143** SBV分为两种：

<a id="p0144"></a>
**P0144** 1. **SB视频（头条视频广告）**：在SB里面选了视频以后，选到品牌旗舰店，就可以实现投到搜索结果页顶部的功能。这个旁边也会有个旗舰店的入口，可以放1-3个商品。

<a id="p0145"></a>
**P0145** • 位置：搜索结果页顶部为主；商品详情页偶尔能看到。

<a id="p0146"></a>
**P0146** 2. **SBV视频广告（Sponsored Brands Video）**：广告位置在搜索结果页的中部位置——中间穿插每页1-2个空位，还有商品详情页里面有，也是SBV的位置。

<a id="p0147"></a>
**P0147** 如果想要拿这些位置，也尽量通过关键词投放去拿，不投SBV的商品投放——因为商品页面里面的广告位太少，大部分还是会跑到搜索结果页的。

<a id="p0148"></a>
**P0148** （四）SD广告

<a id="p0149"></a>
**P0149** SD广告位主要在商品详情页，搜索结果页有一点，但是不多——主要在商品详情页。它会显示成一个小框框框起来的样子。

<a id="p0150"></a>
**P0150** SD广告的两种投放方式：

<a id="p0151"></a>
**P0151** 1. **内容相关**（被动投放）：买家搜AB，触发我的广告——别人触发我才出现。

<a id="p0152"></a>
**P0152** 2. **受众**（主动投放）：比如投"再营销浏览定向（Views Remarketing）""购买定向"——主动跑到别人面前，不需要别人搜什么。

<a id="p0153"></a>
**P0153** 举例：你甚至可以在淋浴头页面看到别的品类的商品跟着出现——这个叫主动投放（不过这儿现在没有，你用移动端说不定能看到别的产品在这个地方出现）。

<a id="p0154"></a>
**P0154** SD广告的具体投放方式后面讲广告类型的时候再展开，现在你们只需要知道：我要什么位置、该怎么投、能怎么投就可以了。

<a id="p0155"></a>
**P0155** 三、亚马逊站内自然流量通道

<a id="p0156"></a>
**P0156** 我们做这些广告流量目的可能是为了广告流量本身，也可能是为了自然流。接下来说一下自然流量通道：

<a id="p0157"></a>
**P0157** （一）搜索结果页的自然位

<a id="p0158"></a>
**P0158** 这是第一个位置。和SP流量一样：一个板块能拿一个自然位。现在搜索结果页面里面所有词都有Result的板块（最上面的伪造的板块），但是下面那些比如Featured、CFP（CPF）、Customers also Style，这些都是少见的——你会发现偶尔亚马逊会放出来一个"编辑推荐"。

<a id="p0159"></a>
**P0159** 当你有了这些板块以后，你的自然位理论上来说就能多存在一个。比如搜索结果页面里面有一个Result，又有一个CPF，那么你就可以有两个自然位；如果没有别的板块，就只有一个自然位。

<a id="p0160"></a>
**P0160** （二）商品详情页的自然位

<a id="p0161"></a>
**P0161** 这些不是我们的重点。

<a id="p0162"></a>
**P0162** （三）类目榜单

<a id="p0163"></a>
**P0163** 类目榜单也可以拿自然流量，但是流量少，所以不会为了做类目榜单而舍弃别的东西。我们不会亏着钱去猛打销量去做类目榜单，它没有结果的。

<a id="p0164"></a>
**P0164** 小结：为什么亚马逊推广困难？

<a id="p0165"></a>
**P0165** • 第一：花钱的地方多——广告流量下面有一这一堆都是广告流量；

<a id="p0166"></a>
**P0166** • 第二：自然流量很少——你想要拿大头就只有这几个地方。

<a id="p0167"></a>
**P0167** 所以推广方面你可能花掉很多预算在这里，但又出不来结果，自然流量上又出不来结果。

<a id="p0168"></a>
**P0168** 我们整体教大家做推广，主要是为了教怎么去做高投产——给到什么地方预算、给多少预算、给什么广告类型预算，最后获得一个结果。这个结果怎么去量化、怎么去看我投资是不是成功的。

<a id="p0169"></a>
**P0169** 四、广告与自然流量的关系

<a id="p0170"></a>
**P0170** 既然我们已经知道广告流有很多、自然流很少，那么广告跟自然流的关系要怎么去平衡？我的广告怎么去拉动自然位？前面说的投资型广告，广告怎么做大自然单——就是这个问题。

<a id="p0171"></a>
**P0171** （一）核心结论：广告排名 ≠ 自然排名

<a id="p0172"></a>
**P0172** 首先：广告位/广告排名跟自然排名不存在必然联系。

<a id="p0173"></a>
**P0173** 你能看到很多产品广告位高，但是它没有自然排名；或者自然排名高，但是没有什么广告位。这都很正常，因为它俩排名就不是一个必然关系。

<a id="p0174"></a>
**P0174** 所以经常听到一些卖家问："老师，我的自然位在广告位的后面，我广告要不要往前提？"——都不用，因为你的自然位跟广告位没有必然关系，各管各的。

<a id="p0175"></a>
**P0175** （二）广告带动自然位的逻辑

<a id="p0176"></a>
**P0176** 广告的本质很简单——合规刷单。所以大家现在听我的逻辑，不管你做刷单还是做白帽推广都是通用的。

<a id="p0177"></a>
**P0177** 我们用广告做的事情——广告行为的本质就是人为干预相关性，去把数据投喂给平台，让平台认识到我是一个还不错的产品。

<a id="p0178"></a>
**P0178** 举个例子：现在买家搜关键词AB，搜完以后：

<a id="p0179"></a>
**P0179** • 如果他去到搜索结果页自然位点了→买了→我就在AB加权

<a id="p0180"></a>
**P0180** • 如果他去广告搜索结果页（广告位）点了→买了→我也在AB加权

<a id="p0181"></a>
**P0181** • 如果他去某一个商品页面里面的商品详情页广告位买了→我也在AB加权

<a id="p0182"></a>
**P0182** 所以你在哪出单、用什么广告、在哪出单其实没关系——只要是买家搜什么词最后买了你，都可以在这个词增加相关性。

<a id="p0183"></a>
**P0183** （三）相关性与权重

<a id="p0184"></a>
**P0184** 这指的是相关性和权重。也就是你得让平台认识到我跟AB这个词的关系很大。我跟AB这个词的关系越大，权重越高。亚马逊怎么衡量你跟这个词的关系有多大呢？

<a id="p0185"></a>
**P0185** 第一步：埋词 —— 这是收录的基础。后面会跟大家讲收录。埋词是最基础的——起码你的这些词是能有曝光的；如果你这个词都没埋，可能就没有曝光。

<a id="p0186"></a>
**P0186** 第二步：曝光、点击、加购、购买的归因数据：

<a id="p0187"></a>
**P0187** • 这个词有了曝光 → 相关性加强一点；

<a id="p0188"></a>
**P0188** • 有了点击 → 亚马逊认为你跟这个词相关性又强一点；

<a id="p0189"></a>
**P0189** • 产生了加购 → 又强了一点；

<a id="p0190"></a>
**P0190** • 最后产生了购买 → 相关性又变强了。

<a id="p0191"></a>
**P0191** 所以整体来讲，做广告的本质是为了去干预曝光、点击、加购、购买这些数据，把数据喂给平台，告诉他"我跟这个词相关"。

<a id="p0192"></a>
**P0192** （四）后台搜索绩效表现页面

<a id="p0193"></a>
**P0193** 那么相关性的最基础体现，我们后台是有一个可量化的地方——这个页面今天一定要进，因为我后面会反复讲到，很重要。

<a id="p0194"></a>
**P0194** 路径：品牌分析 → 搜索分析（现在叫"搜索绩效表现"）

<a id="p0195"></a>
**P0195** 这个页面里面有品牌视图和ASIN视图，可以看到你的产品跟什么词有关系。

<a id="p0196"></a>
**P0196** ASIN视图操作：反查自己的ASIN，能获得一些数据。

<a id="p0197"></a>
**P0197** 字段含义：

<a id="p0198"></a>
**P0198** • 搜索查询分数（Search Query Score）：当反查单个ASIN时，这个数字是从1排到100的。它不是指这个词最大、最差或者怎么样，指的是在你链接里面的权重排名——会反查出100个最相关的词，并根据相关性帮你从1排到100。

<a id="p0199"></a>
**P0199** • 搜索查询数量：这个词在搜的周期内被搜了多少次。比如查一个星期，那就是一个星期被搜索了11,000次。

<a id="p0200"></a>
**P0200** • 我前面为什么说西柚的数据是最准的？因为西柚里面的周搜索量跟这个数字是一致的，这个数字是最准的词的搜索量。

<a id="p0201"></a>
**P0201** 注意：这里的1、2、3...10不是哪个词越大它排名就越高。你可以看到有一些搜索量182的词，它排名比1500的词还高。

<a id="p0202"></a>
**P0202** 继续往右看，按"曝光→点击→加购→购买"的顺序：

<a id="p0203"></a>
**P0203** • 搜索漏斗展示量ASIN计数：你的ASIN在这个词展示了多少次（ASIN计数的意思）；

<a id="p0204"></a>
**P0204** • 搜索漏斗点击量ASIN计数：你的ASIN在这个词下被点了多少次；

<a id="p0205"></a>
**P0205** • 搜索漏斗加购ASIN计数：被加购了多少次；

<a id="p0206"></a>
**P0206** • 搜索漏斗购买次数（购买ASIN计数）：被买了多少次。

<a id="p0207"></a>
**P0207** 所以这些是你跟关键词相关性的体现——你的产品不管是曝光、点击、加购、购买都可以跟这个词产生相关性。

<a id="p0208"></a>
**P0208** （五）历史回顾：关键词上首页服务的演变

<a id="p0209"></a>
**P0209** 我们之前大家记得以前服务商有一个服务叫做"关键词上首页"对不对？关键词上首页他怎么做的？加购对吧？具体是这样做的——搜这个词加购你的产品，那么其实就是完成了我前面三个流程（搜索、点击、加购）。

<a id="p0210"></a>
**P0210** 但是现在你会发现加购不管用了，对吧？加购没有办法帮你上首页。为啥？因为加购本身不为平台带来收益。所以现在你如果真的想要去拉动自然排名的话，必须得有"购买"这一步。

<a id="p0211"></a>
**P0211** 所以你们现在知道，有些卖家现在要做关键词上首页，得做免评单——这个词得有出单才行，必须得有出单才能够拉排名。

<a id="p0212"></a>
**P0212** 简单来讲：

<a id="p0213"></a>
**P0213** • 想让产品跟这个词相关 → 曝光、点击、加购就够了；

<a id="p0214"></a>
**P0214** • 想要拉自然排名 → 必须得有购买。

<a id="p0215"></a>
**P0215** （六）收录与排名的应用

<a id="p0216"></a>
**P0216** 所以这里我们对于关键词的相关性会有几个应用：

<a id="p0217"></a>
**P0217** 应用一：收录

<a id="p0218"></a>
**P0218** 如果想要收录的话，得先埋词。怎么具体做收录？通过曝光、点击、加购就能够对这个词有收录——你在这个词就能出数据。

<a id="p0219"></a>
**P0219** 应用二：拉排名

<a id="p0220"></a>
**P0220** 如果想要拉排名，得有"购买"这一步才行。

<a id="p0221"></a>
**P0221** 所以现在咱们做广告的最基本的逻辑就是：让我的广告在我想要的词产生曝光、点击、加购、购买。而且曝光到点击有个"点击率"，点击到加购有个"加购率"，加购到购买有个"购买率"——这些比例是亚马逊衡量你跟这个词相关性有多大的非常重要的基数。

<a id="p0222"></a>
**P0222** 因为如果单纯看购买量的话，新链接永远都推不上去。但实际上不是只看购买量，而是看各个层级之间的转化比例——就是漏斗里面的比例。

<a id="p0223"></a>
**P0223** 所以我们这样讲：广告本质就是在投喂给平台数据，告诉他这些数据。

<a id="p0224"></a>
**P0224** 五、广告投放的四大目的

<a id="p0225"></a>
**P0225** 接下来说我们投广告大概会有4种目的。现在你们不管是投任何的广告、花任何的钱，必须得符合这4种之一，否则就是浪费。

<a id="p0226"></a>
**P0226** 目的一：提高关键词权重（合规刷单）

<a id="p0227"></a>
**P0227** 用广告做合规刷单——相当于你现在刷单的时候刷的是免评单，广告也是一样，得去做这个词的单量、做这个词的数据。

<a id="p0228"></a>
**P0228** 如果想做合规刷单，必须用SP广告。

<a id="p0229"></a>
**P0229** 为什么？因为后台的搜索绩效表现里面，只计入SP广告和自然流量的归因数据。

<a id="p0230"></a>
**P0230** 为什么SB不能做合规刷单？

<a id="p0231"></a>
**P0231** 举例：买家搜了AB这个词：

<a id="p0232"></a>
**P0232** • 通过SP的页面点了我、买了我 → 可以在AB增加点击、加购、购买归因；

<a id="p0233"></a>
**P0233** • 通过SB点我、买我 → 在这个词不加数据。

<a id="p0234"></a>
**P0234** 为什么这样？我们看：现在搜了showerhead这个词：

<a id="p0235"></a>
**P0235** 点开SP广告位：顶上是有个showerhead，链接里面带着showerhead词（t-words=showerhead）。如果这个链接被触发了，那么你的产品在showerhead词就增加一次点击归因；加购、购买也都算到这个词头上。

<a id="p0236"></a>
**P0236** 从自然位点进来也是一样：带着keywords=showerhead这个词，在这个页面点击、加购、购买都算到这个词头上。

<a id="p0237"></a>
**P0237** SB视频广告：点进商品后看链接，链接里没带词。所以即使我搜了showerhead看到SB的视频广告了、看到SB广告了，那么他被触发了，但是我点进去以后跟这个词没关系，我出单跟这个词也没关系。所以用SB广告是没有办法直接增加你跟这个词的相关性，没有办法实现合规刷词的效果。

<a id="p0238"></a>
**P0238** 很简单：你想要把这个词刷上去，是不是在这个词上面有人买？如果链接出单跟这个词没关系，这个词是上不去的。

<a id="p0239"></a>
**P0239** 结论：要提高自然位、做权重、买数据进来给词增加相关性 → 用SP广告。

<a id="p0240"></a>
**P0240** 目的二：占坑型广告

<a id="p0241"></a>
**P0241** 不管自然位，只要把这个坑位给占住。比如：

<a id="p0242"></a>
**P0242** • 做防御型广告，打自己的品牌名；

<a id="p0243"></a>
**P0243** • 作为头部卖家，已经推到高位了，但是不想别人再推上来，把头部位置占住。

<a id="p0244"></a>
**P0244** 占坑的目的是为了挤走别人。SP、SB、SBV、SD都可以去占坑——因为它们各有各的坑位，在一个词上面各有各的坑位。

<a id="p0245"></a>
**P0245** 目的三：出单（盈利型广告）

<a id="p0246"></a>
**P0246** 让广告去买盈利单。这个时候所有类型的广告都可以，因为它们出一单都是可以挣一单的。

<a id="p0247"></a>
**P0247** 目的四：长期投资（品牌曝光）

<a id="p0248"></a>
**P0248** 我们一般会倾向于SBV、SB、SD广告——对品牌有露出。做长期投资短期内是看不到效果的，但是时间久了以后，你就能看到你的品牌名是有人搜的。

<a id="p0249"></a>

<a id="p0250"></a>
**P0250** 第二方面：如果你做了品牌效应，那么后续大家会直接通过品牌词去搜你——这些流量入口就是你自己的，不会被别人分掉。相当于本来有1万次搜索在showerhead这个词里面，其中有100次是搜你的品牌词，那么相当于从大流量池子里面瓜分出来100次到自己的品牌名下面。

<a id="p0251"></a>
**P0251** 这种是需要长期投资的，短期内没法实现，但一旦实现了，后续推广会容易得很多。

<a id="p0253"></a>
**P0253** 举例：搜"II Soso"这个品牌名，看右边搜索量没人搜，所以目前这个品牌缺乏品牌效应，因为没有人搜它，而且旗舰店也出不来。但是OPPO Pro就会好一点。大家去搜自己的就知道了。

**P0278** 六、A9算法下的坑产逻辑

**P0279** 接下来跟大家说一下我们想要去做自然位的话，广告怎么样去拉动自然位。

<a id="p0280"></a>
**P0280** （一）货架电商的本质

<a id="p0281"></a>
**P0281** 先说A9算法。在A9算法下，亚马逊的搜索——搜一个词以后下面呈现的这些坑位，其实就是一个搜索电商（货架电商）上面的坑位。如果你是亚马逊，你会让谁排到前面？

<a id="p0282"></a>
**P0282** 说话人1 47:19

<a id="p0283"></a>
**P0283** 对，那么是最小的坑，收益。

<a id="p0284"></a>
**P0284** 说话人2 47:21

<a id="p0285"></a>
**P0285** 最高了，对，没错。

<a id="p0286"></a>
**P0286** 有人会觉得说"我销量上去了，自然位自然就上去了"——这不对。

<a id="p0287"></a>
**P0287** 还有人会说"我持续打这个词，累积权重上去了，自然位才会上去"——也不对。因为如果是看累积权重的话，新品是不可能往上推的，新品权重不可能好过老品。但你们有一些链接，可能一两个月推起来，三四个月推起来，他依赖的不是累积权重，而是平台的收益。

<a id="p0288"></a>
**P0288** （二）坑产的本质：先有坑位，后有产出

<a id="p0289"></a>
**P0289** 我们说一下平台收益，也就是我们所说的"坑产"。

<a id="p0290"></a>
**P0290** 有些卖家可能会曲解"坑产"这个词："我单量出得多、销售额高，我的坑产不就高吗？"——它不是这样子的，是先有的坑位，再有的产出，不是先有的产出再有的坑位。

<a id="p0291"></a>
**P0291** 假设搜一个词以后出来的是几排货架，这个货架就是现在你这个超市老板，怎么去摆货架上的商品呢？

<a id="p0292"></a>
**P0292** 货架上面分为几类产品：

<a id="p0293"></a>
**P0293** 1. **亚马逊自营**的东西

<a id="p0294"></a>
**P0294** 2. **VC账号**的东西

<a id="p0295"></a>
**P0295** 3. **SC账号**的东西

<a id="p0296"></a>
**P0296** 作为超市老板：

<a id="p0297"></a>
**P0297** • 自营一定会放前面（自营出单有利润）；

<a id="p0298"></a>
**P0298** • VC账号也会往前摆（VC账号出单也有利润）；

<a id="p0299"></a>
**P0299** • SC账号相当于"作为超市老板，SC账号的产品往上摆，不需要垫付什么东西，不需要去采购，是直接往上摆，根据你的出单经营收益"。

<a id="p0300"></a>
**P0300** 那SC账号的收益从哪来呢？SC账号的产品在这些坑位上面，自然位是免费的——凭什么这个位置给你？看你的收益——这就是坑位产出。

<a id="p0301"></a>
**P0301** （三）坑产计算公式

<a id="p0302"></a>
**P0302** 核心原理：一个坑位的曝光量是恒定的（X）

<a id="p0303"></a>
**P0303** 比如showerhead这个词，搜索量是151万——这个曝光量在这儿是平台的，归平台所有。进来这151万的流量，自然位你在这儿是151万，别人在这是不是也是151万？谁在这都是151万。所以现在平台要决定151万要给谁。

<a id="p0304"></a>
**P0304** X 是恒定的，不由你的意志转移。X该给谁就看平台怎么挣钱。

<a id="p0305"></a>
**P0305** 平台靠什么挣钱？

<a id="p0306"></a>
**P0306** 1. **佣金**

<a id="p0307"></a>
**P0307** 2. **配送费**

<a id="p0308"></a>
**P0308** 坑产计算公式：

<a id="p0309"></a>
**P0309** 佣金 = X × CTR × CVR × 售价 × 佣金比例

<a id="p0310"></a>
**P0310** 配送费 = X × CTR × CVR × 配送费

<a id="p0311"></a>
**P0311** 也就是说订单量 = X × CTR × CVR，再乘以售价拿佣金，乘以配送费拿配送费。

<a id="p0312"></a>
**P0312** 你也可以理解为FBM做不做得过FBA——做FBM不可能做得过FBA的，因为做FBA的平台挣得多。所以可以再把配送费加进来——让平台挣钱和不让平台挣钱，这就是FBM和FBA的区别。

<a id="p0313"></a>
**P0313** 整个坑位你给平台带来的收益就是这样去算的。

<a id="p0314"></a>
**P0314** 重点：这个计算跟广告费没有任何半毛钱关系——是你自己本身的表现，X给到你你能算出多大数字，你越能拿这个位置。

<a id="p0315"></a>
**P0315** （四）举例：如何抢自然位

<a id="p0316"></a>
**P0316** 举个例子：同样两个产品（OPPO Pro链接和另外一条链接），平台给的曝光量X一样，但是产生不同的收益——谁收益高谁就留在这里，谁收益低谁就不能留在这里。

<a id="p0317"></a>
**P0317** 如果想要把链接往上推，就得拿更大的X。

<a id="p0318"></a>
**P0318** 我们前面跟大家看的数据是同个道理：showerhead这个词总搜索量30万，那么当你排到107位的时候，可能就只剩3万；当在前25位的时候，可能还有十几万——这就是位置排得越高，能拿的X越多。

<a id="p0319"></a>
**P0319** 实际曝光量不一样，点击率也不一样。

<a id="p0320"></a>
**P0320** 如果想把一个词往上推，就代表你希望亚马逊在这个词给你更大的X。要给你更大的X，得用什么去说服他？

<a id="p0321"></a>
**P0321** 说话人1 53:01

<a id="p0322"></a>
**P0322** 不是。

<a id="p0323"></a>
**P0323** 说话人2 53:03

<a id="p0324"></a>
**P0324** 订单量吗？后面这些东西你得去证明：CTR、CVR这几个数据。配送费是恒定的、佣金比例是恒定的，所以你得去证明"我这三者叠加，这三者的数据是好的"，那么你的X就会变大。

<a id="p0325"></a>
**P0325** （五）预期坑产 vs 实际坑产

<a id="p0326"></a>
**P0326** 预期坑产

<a id="p0327"></a>
**P0327** 预期坑产的意思：现在我假设我去刷单，我就刷showerhead这个词——假设刷的话，一天可能刷个十几二十单、30单左右，连刷个七八天、刷个10天，这个词就上去了。为什么？

<a id="p0328"></a>
**P0328** 不是因为我单量给得够——我一天就给30单，不是因为给得够；是因为我刷的时候表现就是好，给到了一个高CTR、高CVR——告诉亚马逊"我这个数据好"，亚马逊就给你更高的X，把你位置往上拉。位置越高，X越大。

<a id="p0329"></a>
**P0329** 但是有一点：你往上走，是要把别人踢掉的。现在这些坑位上都有人，想要到前排的位置就得把别人踢掉。把他踢掉的前提是：我比他好。我要向亚马逊证明"我在这个位置能给你带来收入比他还多"，这样的话就能把他踢掉。

<a id="p0330"></a>
**P0330** 但是如果你使劲买广告，买了半天证明"我比他差多了"——你就不可能上去。所以用广告买数据时要注意：做预期增长 = 我有高性价比所以你给我高位置。

<a id="p0331"></a>
**P0331** 预期增长的逻辑：先有好CTR/CVR数据 → 亚马逊得到数据反馈后，给你好的位置、好的曝光、好的细分展示。

<a id="p0332"></a>
**P0332** 所以做预期增长就是像大家平时常规打广告一样：买点这个词的数据，买的数据好，曝光量、自然位就变高。但如果买的数据不够好，就相当于在反向刷单——比如这个链接广告排名很高，但自然位出不来。为啥？广告排名高只能证明你广告数据买得多，不能代表你广告数据好。所以等于说买了大量的不怎么样的数据，自然位一点都出不来。

<a id="p0333"></a>
**P0333** 新链接做预期坑产不是冲着大曝光去买，而是冲着好数据去买。

<a id="p0334"></a>
**P0334** 刷单的卖家如果要刷词的话也不会刷到多少——一个词下面可能一天5单这个样子，这就是预期坑产。

<a id="p0335"></a>
**P0335** 实际坑产

<a id="p0336"></a>
**P0336** 实际坑产的意思：假设你产品是刚上架的，上架以后一直出单，亚马逊也不知道从哪出的，但你就是出单——你就会发现自然位会到一个单量匹配的位置——这就是实际坑产。

<a id="p0337"></a>
**P0337** 这点上面后面会展开跟大家讲，这两个分别怎么做。

<a id="p0338"></a>
**P0338** （六）总结：关键词权重如何影响自然排名

<a id="p0339"></a>
**P0339** 关键词累积权重跟自然排名没有必然联系。

<a id="p0340"></a>
**P0340** 自然排名是由"坑产"来决定的——这个坑位给到你，你做多少产出。

<a id="p0341"></a>
**P0341** 还有一个退货率的问题：退货率越高，买家退货以后佣金要还给你（佣金要还的）。所以这个钱要么挣不了了——如果你出100单退70单的话，相当于只出30单。所以退货率越高的产品，自然位越难拉上去，因为给你的流量也浪费。

<a id="p0342"></a>
**P0342** 自然排名是关键词短期内的坑产体现，跟累积权重没有必然联系。所以拉动一个词的站位：短的话只需要5-7天，长的话大概14天。如果做了14天还没有拉上去的话，这个词你干预的时间还没上去的话，可能你干预的数据不太好，后面再展开讲。

<a id="p0343"></a>
**P0343** （七）干预坑产的两种方式

<a id="p0344"></a>
**P0344** 方式一：干预预期坑产 → 投喂CTR、CVR

<a id="p0345"></a>
**P0345** 通过广告表现去干预预期坑产，从而干预自然排名——也就是投喂CTR、CVR数据就可以了。而且你投喂的是定向的词——这一堆词里面，想要干预哪个词，就去给那个词投喂CTR、CVR数据。

<a id="p0346"></a>
**P0346** 干预预期坑产 = 刷CTR、CVR证明自己是有潜力的，有潜力以后亚马逊会给你更大的X。这是通过SP广告去实现的。

<a id="p0347"></a>
**P0347** 方式二：做实际单量 → 干预实际坑产

<a id="p0348"></a>
**P0348** 举例：假设上下游先做个0元购，先在站外做个0元购——你今天送出去200单，明天你的站位就到第一页。大家做过没有？没有是吧？我直接跟你讲结果就是这样子——你今天送出去100单、200单，明天就直接到第一，后天就直接到第一。这叫做实际坑产。

<a id="p0349"></a>
**P0349** 实际坑产的意思：不管你从什么出单渠道，你只要出到这么多单，你就能有这么大量的自然排名——干预实际坑产就是搞单量。搞单量的话证明自己有实力，你也会有一个高位置。这种广告SP、SB、SBV、SD都可以。

<a id="p0350"></a>
**P0350** （八）刷单与白帽的本质类比

<a id="p0351"></a>
**P0351** 我们说广告是合规刷单，但是大家如果了解刷单的话，你就会知道刷单跟刷单是不一样的——

<a id="p0352"></a>
**P0352** • 有些刷单是在刷词的权重（对应：干预预期坑产）；

<a id="p0353"></a>
**P0353** • 有些刷单是在刷总单量（对应：干预实际坑产）。

<a id="p0354"></a>
**P0354** 打广告也是一样，可以选择这两个方式去做自然排名。后面会展开讲具体要怎么做。

<a id="p0355"></a>
**P0355** 七、坑产具象化：售价、CTR、CVR的乘积

<a id="p0356"></a>
**P0356** 先跟大家具象化一下，什么叫自然排名的坑产情况：

<a id="p0357"></a>
**P0357** 自然坑产 = 坑位曝光量 × 点击率（CTR）× 转化率（CVR）× [售价 × 佣金比例] + 单量 × 配送费

<a id="p0358"></a>
**P0358** 由于别的东西不太变化，所以可以整体理解为：计算坑产总值是不是达标，拿三个数据计算——售价、CTR、CVR。

<a id="p0359"></a>
**P0359** 把这三者相乘，得到的数字越大，坑产就越高，位置就会越好。

<a id="p0360"></a>
**P0360** 不同售价怎么排位？

<a id="p0361"></a>
**P0361** 你会发现一个搜索词下也有售价低的、有售价高的——为什么呢？

<a id="p0362"></a>
**P0362** 如果只看CTR、CVR的话，那么一定是低价往前走。但是低价往前走对于亚马逊来说没有什么太大好处，因为他要拿佣金。所以你能看到自然位上面高价也有低价也有——这一排自然位有69的、19的、35的。

<a id="p0363"></a>
**P0363** 举例：

<a id="p0364"></a>
**P0364** • 产品A：售价 $19.99 × CTR 2% × CVR 20%

<a id="p0365"></a>
**P0365** • 产品B：售价 $39.99 × CTR 1.5% × CVR 15%

<a id="p0366"></a>
**P0366** 它俩应该位置差不多——因为A的售价涨幅低于CTR×CVR的跌幅，所以这种产品也能推。

<a id="p0367"></a>
**P0367** 最怕的是：你卖 $39.99，CTR 1%、CVR 10% —— 你这就拉不回来了。因为你的单价比前面高一倍，但CTR、CVR比下面的低（下面是第四位，是1/4），所以下面自然位是拉不到上面更高的。

<a id="p0368"></a>
**P0368** 所以后面讲所有的自然位坑产，我都会用 price × CTR × CVR 这个数据去具象化地讲。

<a id="p0369"></a>
**P0369** 广告坑产的特殊性

<a id="p0370"></a>
**P0370** 刚刚讲的是自然位。再说广告位——有些卖家会觉得广告位的数据得跟自然位叠加，比如"我这个词的坑产 = 自然单量 + 广告单量"——这个不对，因为这对坑产是没有足够理解的。

<a id="p0371"></a>
**P0371** 因为你要知道：广告坑位跟自然坑位是两个坑位。

<a id="p0372"></a>
**P0372** • 自然坑位是免费给你的，你广告不打都行；

<a id="p0373"></a>
**P0373** • 但广告坑位是要花钱的。

<a id="p0374"></a>
**P0374** 广告坑产公式：

<a id="p0375"></a>
**P0375** 广告坑位收益 = Y（广告坑位曝光量）× 广告点击率 × [广告转化率 × 佣金 × 配送费 + CPC（广告花费）]

<a id="p0376"></a>
**P0376** 但广告还有个大头叫"广告花费"——广告费才是这个广告坑位坑产的重点。

<a id="p0377"></a>
**P0377** 广告花费 = Y × 点击率 × CPC

<a id="p0378"></a>
**P0378** 那么亚马逊更愿意卖给"总单量高的人"还是"广告花费高的人"？

<a id="p0379"></a>
**P0379** 一定是广告花费高的人。

<a id="p0380"></a>
**P0380** 实战案例对比：同曝光下的产出对比

<a id="p0381"></a>
**P0381** 我们拿两个同类产品推同一个词，给他俩相近的曝光量（一个7900、一个7600），看坑产差距：

<a id="p0382"></a>
**P0382** 先看自然位（佣金+配送费）：

<a id="p0383"></a>
**P0383** • 产品A：曝光7900 → 16单 + 销售额$472

<a id="p0384"></a>
**P0384** • 产品B：曝光7600 → 25单 + 销售额$594

<a id="p0385"></a>
**P0385** 如果你是亚马逊，会给谁？一定给产品B——配送费多、佣金多，碾压。

<a id="p0386"></a>
**P0386** 再看广告位（广告花费）：

<a id="p0387"></a>
**P0387** • 产品A：曝光7900 → 花费$125

<a id="p0388"></a>
**P0388** • 产品B：曝光7600 → 花费$146

<a id="p0389"></a>
**P0389** 亚马逊广告费愿意给谁？还是B。

<a id="p0390"></a>
**P0390** 对比它们的竞价：

<a id="p0391"></a>
**P0391** • 产品A竞价：$1.52

<a id="p0392"></a>
**P0392** • 产品B竞价：$1.31

<a id="p0393"></a>
**P0393** 你会发现：竞价低的，广告费反而花得更多。亚马逊愿意卖给谁？还是B（竞价低）。

<a id="p0394"></a>
**P0394** CTR决定CPC的潜力

<a id="p0395"></a>
**P0395** 不是竞价越高就一定能拿广告位。因为亚马逊的财产是曝光量，要靠曝光量花费就靠点击率。

<a id="p0396"></a>
**P0396** • 产品A：CPC $1.52、CTR 1.04% → 7900曝光只消化了1.04%，很难花出去钱；

<a id="p0397"></a>
**P0397** • 产品B：CPC $1.31、CTR较高 → 花了$146更多。

<a id="p0398"></a>
**P0398** 所以你的竞价高一点没关系，你花得多就行。

<a id="p0399"></a>
**P0399** 结论：CTR越高的产品，CPC可以越低。

<a id="p0400"></a>
**P0400** 回到广告坑产：广告花费 = Y × CTR × CPC。如果点击率低的话，CPC就得高，不然亚马逊不愿意卖给你——卖给你的话坑位收益都少了。

<a id="p0401"></a>
**P0401** 每一个客户都有它的价值和价格。

<a id="p0402"></a>
**P0402** 广告位跟自然位是两个不一样的坑位：

<a id="p0403"></a>
**P0403** • 自然位给你，重点在于你出的佣金、配送费；

<a id="p0404"></a>
**P0404** • 广告位给你，除了佣金、配送费还有广告费。广告费非常重要——亚马逊的广告团队每年都在致力于研究"怎么让卖家花得更多"。

<a id="p0405"></a>
**P0405** 所以在这个地方花不出去钱，就不可能上得来。比如同样一个位置：

<a id="p0406"></a>
**P0406** • 这一款CTR 3%、CPC 3.0；

<a id="p0407"></a>
**P0407** • 第二款CTR 6%、CPC 1.5。

<a id="p0408"></a>
**P0408** 你自己拿垂直类目的同类产品试一下——你会发现表现差的反而CPC更高。竞价高不是因为这个位置值钱，而是因为你得弥补亚马逊把这个曝光卖给你的损失——他本来可以卖给别人的，要卖给你你就得给这么高，不然他就不卖给你。

<a id="p0409"></a>
**P0409** 广告坑产与自然坑产的关系

<a id="p0410"></a>
**P0410** 广告坑产跟自然坑产没有关系，是单独的两个坑位。

<a id="p0411"></a>
**P0411** 但是我们这样讲：如果你的新品表现得很差，会导致几个结果：

<a id="p0412"></a>
**P0412** 结果一：自然位拉不上去 —— 因为你向亚马逊证明"我表现很烂"。

<a id="p0413"></a>
**P0413** 结果二：CPC会越来越高 —— 亚马逊本来卖给你的，发现卖给你真亏，就给你提竞价。你不提竞价就跑不出来。很多新品就是这样，上来以后竞价越给越高、越给越高，因为不给竞价跑不出来——就是因为表现差，CTR和CVR偏低。

<a id="p0414"></a>
**P0414** 回到CPA和ACOS的公式里：如果新品表现差：

<a id="p0415"></a>
**P0415** • CPC比别人高（这是一定的）；

<a id="p0416"></a>
**P0416** • CVR比别人低；

<a id="p0417"></a>
**P0417** • 分子大、分母小，整个ACOS会爆掉。

<a id="p0418"></a>
**P0418** 像前面看到的200%的ACOS，大概就这个情况。

<a id="p0419"></a>
**P0419** 案例：表现差导致ACOS爆掉

<a id="p0420"></a>
**P0420** 举例：

<a id="p0421"></a>
**P0421** • 产品A：CPC $2.0、转化率20% → CPA = $10

<a id="p0422"></a>
**P0422** • 产品B（表现差）：CPC被提到$4.0、转化率被压到10% → CPA = $40

<a id="p0423"></a>
**P0423** 它俩的CPA差距：一个出一单10块钱，一个出一单40块钱。假设售价都是$40：

<a id="p0424"></a>
**P0424** • A的ACOS = 25%

<a id="p0425"></a>
**P0425** • B的ACOS = 100%

<a id="p0426"></a>
**P0426** 所以你ACOS如果爆了的话，大概率是因为数据是爆的、表现差——CPC高、CVR低。

<a id="p0427"></a>
**P0427** 战略性亏损 ≠ 纯亏损

<a id="p0428"></a>
**P0428** 所以总结来讲：如果一条新链接，要买"垃圾数据"就不要买"烂的数据"。买烂的数据的话，最后广告出一单亏得多、自然流量出不来。

<a id="p0429"></a>
**P0429** 有回到我们前面"总利润 = 自然单利润 + 广告单利润"——你的自然单出不来没利润、广告单出一单亏很多，总体来说就是亏的。

<a id="p0430"></a>
**P0430** 我们初期所有的产品都是愿意接受亏损的——很多链接初期亏没关系，因为初期没有自然流，所以愿意初期给他亏；而且初期得给更多广告拉动自然流。所以很多链接讲"战略性亏损"——

<a id="p0431"></a>
**P0431** 战略性亏损的前提是你得有"战略"：

<a id="p0432"></a>
**P0432** • 战略应该是你的表现是好的；

<a id="p0433"></a>
**P0433** • 往投资型广告去亏；

<a id="p0434"></a>
**P0434** • 亏了以后拉动出来自然流；

<a id="p0435"></a>
**P0435** • 慢慢的就滚雪球滚出来。

<a id="p0436"></a>
**P0436** 但如果你表现差的话，就不是战略性亏损了——它就是纯亏损。

<a id="p0437"></a>
**P0437** 八、案例：同品类三个产品的同批次投放对比

<a id="p0438"></a>
**P0438** 到现在为止，坑产大家都能理解了：给你恒定的曝光量，你能产出多少、给平台带来多少收益。

<a id="p0439"></a>
**P0439** 有了这个点以后，大家就可以知道什么是预期坑产——我现在的表现好，给你带来的预期收益高，他就会愿意给我更多曝光量。

<a id="p0440"></a>
**P0440** 接下来再给大家对比几个同品类的三个产品投放同批次的不同表现。

<a id="p0441"></a>
**P0441** 这三个产品都是灯具类目的，分别是三个不同定价的链接。时间都是1月1号到1月7号这7天。

<a id="p0442"></a>
**P0442** 产品1：

<a id="p0443"></a>
**P0443** • 竞价：$1.7-1.8左右

<a id="p0444"></a>
**P0444** • 能不能买到Top位？买不到（太零散了）

<a id="p0445"></a>
**P0445** • 1.8的竞价，亚马逊不太愿意卖Top位，主要卖商品页面

<a id="p0446"></a>
**P0446** 产品2：

<a id="p0447"></a>
**P0447** • 竞价：$1.3左右

<a id="p0448"></a>
**P0448** • 能买到一点Top位（比产品1好一点）

<a id="p0449"></a>
**P0449** • 数据能让亚马逊愿意卖一点TOS位，因为CTR能花出去钱

<a id="p0450"></a>
**P0450** • 假设给300个曝光：产品1能花约$7-8（4倍，竞价$1.8）；产品2能花$18

<a id="p0451"></a>
**P0451** 所以即使产品2竞价$1.3，亚马逊也愿意卖给它，不愿意卖给产品1——因为产品1点击率太低（一点几），产品2点击率三点几，收益太低。

<a id="p0452"></a>
**P0452** 产品3（老链接）：

<a id="p0453"></a>
**P0453** • 竞价：$1.0左右

<a id="p0454"></a>
**P0454** • 曝光量1200，花费$82

<a id="p0455"></a>
**P0455** • CTR 7.09%

<a id="p0456"></a>
**P0456** • 同样1200曝光卖给产品1，能花约$70多（也是4倍）；产品3即使$1.0竞价还能花$80多

<a id="p0457"></a>
**P0457** 所以亚马逊更愿意卖给产品3。降竞价的实质就是讲价——你给平台带来这么多收益，跟平台共赢。竞价降了以后愿意花更多钱，那平台就愿意卖给你。

<a id="p0458"></a>
**P0458** 产品3表现最好：从单位坑位产出来讲，不管自然产出还是广告坑位产出都是最好的，竞价自然也是最低的。

<a id="p0459"></a>
**P0459** 九、CTR的横向比较（不要纵向比较）

<a id="p0460"></a>
**P0460** 强调另外一点——很多卖家比较CTR时这样看：你看三个广告位，TOS位置点击率是不是最高的？

<a id="p0461"></a>
**P0461** 是最高的——所有产品的TOS点击率都高于其他位置。所以很多卖家会说"我就是要去打TOS位、就要打Top位"。

<a id="p0462"></a>
**P0462** 但这种纵向比较没有意义。

<a id="p0463"></a>
**P0463** CTR计算方式的差异

<a id="p0464"></a>
**P0464** CTR = 点击次数 ÷ 曝光量

<a id="p0465"></a>
**P0465** TOS位置CTR一定高——因为它的曝光量接近于真实露出量（在头部加载出来一定能被看到）。

<a id="p0466"></a>
**P0466** ROS位置CTR偏低——假设搜了showerhead，广告位在最底下：

<a id="p0467"></a>
**P0467** • 你的广告算不算曝光？算（因为加载了就算曝光）。

<a id="p0468"></a>
**P0468** • 但买家看不到它，没有人一定会拉到最底下。

<a id="p0469"></a>
**P0469** • ROS位置：曝光量 = 加载次数，但 实际露出次数 < 加载次数。

<a id="p0470"></a>
**P0470** • 所以CTR偏低（曝光1000次但实际露出可能只有500次）。

<a id="p0471"></a>
**P0471** PP（商品详情页）位置CTR最低：

<a id="p0472"></a>
**P0472** • 在商品页面，比如Deals only the products有三页，这三页都被加载了，但你没露出；

<a id="p0473"></a>
**P0473** • 同样这里有5-8页都被加载了；

<a id="p0474"></a>
**P0474** • 移动端只能看到前三个广告位，再往下底下一排广告位也巨多；

<a id="p0475"></a>
**P0475** • PP位置很容易有曝光，但这个曝光是没露出的。

<a id="p0476"></a>
**P0476** • 所以PP点击率一定低，但这个低是由计算方式导致的，是加载次数 ≠ 露出次数导致的。

<a id="p0477"></a>
**P0477** 结论：所有产品都是 TOS > ROS > PP。

<a id="p0478"></a>
**P0478** 怎样横向比较CTR？

<a id="p0479"></a>
**P0479** 不能纵向比较（因为不公平），要横向比较——拿你的TOS（比如1.16%）跟别的产品对比：

<a id="p0480"></a>
**P0480** • 别的产品TOS是3.63%

<a id="p0481"></a>
**P0481** • 还有别的产品TOS是7.09%

<a id="p0482"></a>
**P0482** • 你的1.16% 是好还是不好？巨差。

<a id="p0483"></a>
**P0483** 如果这个时候你冲着TOS去买会有什么结果？没意义，反而向亚马逊证明"我多烂"——别人在这儿是8%，你在这儿是1%。那你这辈子要么就不太愿意卖给你这个位置了，加价加得再高都不愿意卖给你。

<a id="p0484"></a>
**P0484** 像竞价加到$1.8，其实是因为：一开始$1.3给到$1.5，然后$1.5以后亚马逊又不想卖了，又卖到$1.8他又不想卖了——如果卖家轴一点的话会到二点几、三点几、四点几，加上去以后他可能会卖给你，但是你的竞价是对自己低点击率的一个补偿。

<a id="p0485"></a>
**P0485** 其实你即使买了这个位置，也不可能出自然位——亚马逊愿意加价卖给你，但是自然位给你那就是很亏。然后结果就会像这样：你如果执着于买高位的差数据，自然位更出不来。

<a id="p0486"></a>
**P0486** 优秀产品的特征

<a id="p0487"></a>
**P0487** 所以做点击率对比，尽量横向对比，不要纵向对比。

<a id="p0488"></a>
**P0488** 观察：一个产品如果点击率有优势的话，它在所有位置都是有优势的。比如某产品ROS位置1.52%，跟别的链接对比（1.02%、0.32%）都是高的。

<a id="p0489"></a>
**P0489** 所以如果你产品表现好，跟在哪个广告位出单是没有所谓的——除非你有广告位特别差（ACOS特别差），可以刨掉。但表现好的产品其实不太挑位置（光从加权角度来说），在所有位置都是好的；表现差的产品在所有位置都是差的，也不挑位置。

<a id="p0490"></a>
**P0490** 何时挑选广告位？

<a id="p0491"></a>
**P0491** 我们一般挑广告位是挑选CPA更低的广告位——当三个广告位有明显的转化率差异，且这个差异是由广告位带来的。

<a id="p0492"></a>
**P0492** 比如某产品固定竞价$1.0左右：

<a id="p0493"></a>
**P0493** • TOS位置：CPA $15

<a id="p0494"></a>
**P0494** • 别的位置：$24、$21

<a id="p0495"></a>
**P0495** 这时候我们会去挑选——你全跑TOS位置就可以只要$15了。可以基于这个去挑选，但千万不能基于CTR挑选——因为这没什么意义，差的你再怎么挑也是差。

<a id="p0496"></a>
**P0496** 理解为赛马机制：TOS跟别人的TOS比、ROS跟别人的ROS比就可以了。

**P0497** 十、本节总结

<a id="p0498"></a>
**P0498** 以上就是关于A9算法下的坑产逻辑——你的自然位是怎么被影响的。

<a id="p0499"></a>

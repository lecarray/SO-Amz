**P0005** 一、商品投放（PT）的广告架构搭建

<a id="p0006"></a>
**P0006** （一）商品投放的层级结构

<a id="p0007"></a>
**P0007** 商品投放的架构比关键词投放更简单，核心只有两个层级：

<a id="p0008"></a>
**P0008** 层级 1：范围投放（大范围拓 ASIN）

<a id="p0009"></a>
**P0009** 包含三种投放方式（三选一或都开均可，它们范围几乎一致）：

<a id="p0010"></a>
**P0010** • Auto 里的"同类"和"关联"（竞价 0.7-0.8X）；

<a id="p0011"></a>
**P0011** • ASIN 拓展（范围与类目相似）；

<a id="p0012"></a>
**P0012** • 直接投类目节点；

<a id="p0013"></a>
**P0013** 层级 2：定向投放（ASIN 精准）

<a id="p0014"></a>
**P0014** 把范围投放里表现好的 ASIN 拎出来，定向精准投放（竞价 0.9X 左右，不要高于关键词竞价）。

<a id="p0015"></a>
**P0015** （二）定向投放的分组管理

<a id="p0016"></a>
**P0016** 采用"海选 → 面试 → 录用"的三阶段管理：

<a id="p0017"></a>
**P0017** ```

<a id="p0018"></a>
**P0018** 范围投放（海选）—— 竞价最低，范围最大

<a id="p0019"></a>
**P0019** ↓ 出过单/表现还行的 ASIN

<a id="p0020"></a>
**P0020** ASIN Test Group（面试间）—— 竞价中等

<a id="p0021"></a>
**P0021** ↓ 表现好的 ASIN（出过 2 单以上 + 转化率正常）

<a id="p0022"></a>
**P0022** ASIN Performance Group（表现组）—— 竞价较高

<a id="p0023"></a>
**P0023** ↓ 表现特别好的 ASIN

<a id="p0024"></a>
**P0024** 单 ASIN 单组（最高优先级）

<a id="p0025"></a>
**P0025** ```

<a id="p0026"></a>
**P0026** 流动规则：

<a id="p0027"></a>
**P0027** • 范围投放每周定期筛一批出过单的 ASIN → 移入 Test Group 面试；

<a id="p0028"></a>
**P0028** • Test Group 里表现好的 → 移入 Performance Group；

<a id="p0029"></a>
**P0029** • Test Group 里表现差的 → 关闭投放，让它回到范围投放继续跑；

<a id="p0030"></a>
**P0030** • Performance Group 满了（花不出去）→ 拆成 Performance Group 2/3/4……；

<a id="p0031"></a>
**P0031** • Performance Group 里表现特别好的 → 单 ASIN 单组放量；

<a id="p0032"></a>
**P0032** • Performance Group 里表现变差的 → 回到 Test Group 再面试；

<a id="p0033"></a>
**P0033** （三）商品投放的定价原则

<a id="p0034"></a>
**P0034** 商品投放竞价 ≤ 关键词投放竞价，绝对不能高于关键词。

<a id="p0035"></a>
**P0035** 竞价层级：

<a id="p0036"></a>
**P0036** • 范围投放（Auto 同类/类目）：0.7-0.8X；

<a id="p0037"></a>
**P0037** • Test Group：0.85-0.9X；

<a id="p0038"></a>
**P0038** • Performance Group：0.9X；

<a id="p0039"></a>
**P0039** • 单 ASIN 单组：0.9-1.0X（不超过一级词广泛）；

<a id="p0040"></a>
**P0040** （四）商品投放的用途定位

<a id="p0041"></a>
**P0041** 商品投放主要用于：

<a id="p0042"></a>
**P0042** 1. **做盈利型/纯利型广告**（竞价低、CPA 相对低）；

<a id="p0043"></a>
**P0043** 2. **不定向拓词**（跑到 ASIN 的反查词，可以拿到泛词收录）；

<a id="p0044"></a>
**P0044** 3. **不定向加权**（但不是定向给某个词加权，是散的）；

<a id="p0045"></a>
**P0045** 商品投放不适合做：

<a id="p0046"></a>
**P0046** • 定向关键词加权（它跑到的词是散的，你没法控制）；

<a id="p0047"></a>
**P0047** • 投隔壁节点的产品（初始权重不足，很难跑出数据，建议用 SD 广告去打跨类目）；

<a id="p0048"></a>
**P0048** 注意：Auto 里面"同类"的曝光量 >> "关联"的曝光量，同竞价下同类好跑很多。因为关联是跨类目，初始权重不够，很难跑出数据。

<a id="p0049"></a>
**P0049** 二、竞价结构诊断与修复

<a id="p0050"></a>
**P0050** （一）诊断第一步：排查重复投放

<a id="p0051"></a>
**P0051** 三种重复投放类型的排查方法：

<a id="p0052"></a>
**P0052** | 重复类型 | 排查方式 |

<a id="p0053"></a>
**P0053** |---|---|

<a id="p0054"></a>
**P0054** | 广泛：单复数/乱序/介词 | 透视表按匹配类型→投放词排序，肉眼找相似词 |

<a id="p0055"></a>
**P0055** | 精准：单复数/介词 | 同上 |

<a id="p0056"></a>
**P0056** | 词组：单复数/介词 | 同上 |

<a id="p0057"></a>
**P0057** | 广泛 + 词组同投 | 透视表按投放词→匹配类型排序，展开看同词是否有两种匹配 |

<a id="p0058"></a>
**P0058** | 同投放词在多活动 | 透视表按投放词→活动名称排序，展开看同词是否在多个活动 |

<a id="p0059"></a>
**P0059** 处理原则：

<a id="p0060"></a>
**P0060** • 花费少/表现差的那个 → 关掉或降竞价直到花不出去；

<a id="p0061"></a>
**P0061** • 故意的层级差异重复（如主推 ASIN + 非主推 ASIN 分别在不同活动精准同词）→ 可以保留；

<a id="p0062"></a>
**P0062** • 广泛和词组同时投同词 → 留一个，不要同时投；

<a id="p0063"></a>
**P0063** 关于广泛 vs 词组：

<a id="p0064"></a>
**P0064** • 同一个词投广泛和投词组，效果几乎相同，留一个即可；

<a id="p0065"></a>
**P0065** • 可以接受的组合：广泛 + 精准、或词组 + 精准（有层级差）；

<a id="p0066"></a>
**P0066** • 不接受的组合：广泛 + 词组（重复）；

<a id="p0067"></a>
**P0067** （二）诊断第二步：检查竞价层级结构

<a id="p0068"></a>
**P0068** 正确的竞价层级：精准 > 词组 ≈ 广泛 > Auto ≥ 商品投放

<a id="p0069"></a>
**P0069** 问题 1：所有层级竞价一样（无差异）

<a id="p0070"></a>
**P0070** 表现： 词组花费大头，其余层级全部 ACoS 爆掉（100%+），CPA 翻倍。

<a id="p0071"></a>
**P0071** 原因： 运营没有竞价层级意识，用同一个竞价投所有匹配方式。

<a id="p0072"></a>
**P0072** 修复步骤：

<a id="p0073"></a>
**P0073** 1. 花费大头的匹配方式作为基准竞价不动（如词组 $0.76）；

<a id="p0074"></a>
**P0074** 2. 精准竞价提高到 $0.9+；

<a id="p0075"></a>
**P0075** 3. Auto 竞价降低到 $0.7 以下；

<a id="p0076"></a>
**P0076** 4. 广泛与词组二选一，关掉花费少的那个；

<a id="p0077"></a>
**P0077** 问题 2：Auto 竞价 > 广泛竞价

<a id="p0078"></a>
**P0078** 表现： Auto 花费大头，广泛/精准花不出去。

<a id="p0079"></a>
**P0079** 修复：

<a id="p0080"></a>
**P0080** • 方案 A：降 Auto 竞价到广泛以下；

<a id="p0081"></a>
**P0081** • 方案 B：提高广泛/精准竞价到 Auto 以上（= 放量）；

<a id="p0082"></a>
**P0082** • 选择取决于 TACoS 是否还有空间；

<a id="p0083"></a>
**P0083** 问题 3：精准 ≈ 广泛竞价（层级未拉开）

<a id="p0084"></a>
**P0084** 表现： 精准和广泛分摊花费，精准"捡漏"变得 CPA 极高。

<a id="p0085"></a>
**P0085** 修复：

<a id="p0086"></a>
**P0086** • 把精准竞价提高到广泛以上 10%+（= 放量但花费集中）；

<a id="p0087"></a>
**P0087** • 或把广泛竞价降低到精准以下（= 缩量）；

<a id="p0088"></a>
**P0088** （三）诊断第三步：实际竞价 vs 市调竞价对比

<a id="p0089"></a>
**P0089** 正确竞价结构 ≠ 竞价合理（结构对但整体给高了也不行）。

<a id="p0090"></a>
**P0090** 操作：

<a id="p0091"></a>
**P0091** 1. 拉出市调竞价三档（C服低/中/高）；

<a id="p0092"></a>
**P0092** 2. 对比实际各层级竞价；

<a id="p0093"></a>
**P0093** 3. 全部偏高 → 先排查是"大方"还是"表现差"；

<a id="p0094"></a>
**P0094** 4. 表现好（CTR/CVR 正常，自然位不错）→ 可以压竞价；

<a id="p0095"></a>
**P0095** 5. 表现差 → 先不放量，先优化表现；

<a id="p0096"></a>
**P0096** 压竞价的优先顺序：

<a id="p0097"></a>
**P0097** 1. **先压花费小的层级（如 Auto）**，再逐级往上压；

<a id="p0098"></a>
**P0098** 2. 不要一上来就压花费大头（精准）→ 花费突然大幅下降会影响自然位；

<a id="p0099"></a>
**P0099** 3. 先把中间层级压下去 → 再动精准层级 → 整体平滑下降；

<a id="p0100"></a>
**P0100** 三、老链接的竞价试探方法

<a id="p0101"></a>
**P0101** （一）核心原理

<a id="p0102"></a>
**P0102** 同一个搜索词同时触发两个层级的投放词时，根据两个层级的花费比例，可以推断这个词的实际价值。

<a id="p0103"></a>
**P0103** 判断逻辑：

<a id="p0104"></a>
**P0104** | 花费分布情况 | 说明 |

<a id="p0105"></a>
**P0105** |---|---|

<a id="p0106"></a>
**P0106** | 高竞价层级花 $13,000，低竞价层级花 $625 | 正常捡漏结构，高竞价约等于词的真实价值 |

<a id="p0107"></a>
**P0107** | 高竞价层级花 $1,800，低竞价层级花 $900 | 低竞价层级花了高竞价一半 → 低竞价就够了，高竞价给多了 |

<a id="p0108"></a>
**P0108** | 两个层级花费接近对半分 | 两个竞价都够买这个词 → 取低竞价即为词的真实价值 |

<a id="p0109"></a>
**P0109** （二）实操举例

<a id="p0110"></a>
**P0110** 案例 1：pen for iPad

<a id="p0111"></a>
**P0111** • 精准 $1.91 花费 $13,000 → 大头；

<a id="p0112"></a>
**P0112** • 精准 $1.62 花费 $625 → 捡漏；

<a id="p0113"></a>
**P0113** • 结论：$1.91 定价合理（低层级只捡到少量漏）；

<a id="p0114"></a>
**P0114** 案例 2：electric toothbrush

<a id="p0115"></a>
**P0115** • 高层级 $2.9 花费 $700；

<a id="p0116"></a>
**P0116** • 低层级 $2.64 花费 $400+；

<a id="p0117"></a>
**P0117** • 结论：两者花费接近对半分 → $2.64 就够了，$2.9 给高了；

<a id="p0118"></a>
**P0118** 案例 3：cat water fountain

<a id="p0119"></a>
**P0119** • 精准 $2.34 花费 $1,000+；

<a id="p0120"></a>
**P0120** • 广泛 $1.45 花费 $700+；

<a id="p0121"></a>
**P0121** • 结论：$1.45 就够买到大量花费 → 实际竞价不需要超过 $1.5；

<a id="p0122"></a>
**P0122** （三）竞价试探的使用场景

<a id="p0123"></a>
**P0123** 适用于：已有一段时间数据的老链接。

<a id="p0124"></a>
**P0124** 操作步骤：

<a id="p0125"></a>
**P0125** 1. 在 ERP 出单词库或透视表中找到花费最高的搜索词；

<a id="p0126"></a>
**P0126** 2. 展开其投放路径，看该词在哪些层级有花费；

<a id="p0127"></a>
**P0127** 3. 对比各层级竞价和花费比例；

<a id="p0128"></a>
**P0128** 4. 低竞价层级花费占比 > 30% → 说明高竞价给高了，可以压；

<a id="p0129"></a>
**P0129** 5. 低竞价层级花费极少 → 高竞价合理；

<a id="p0130"></a>
**P0130** 注意：拉近期 7 天数据最准（长期数据可能包含已关闭的历史活动）。

<a id="p0131"></a>
**P0131** 四、全面压竞价的两种策略

<a id="p0132"></a>
**P0132** 策略 1：逐级压竞价（推荐）

<a id="p0133"></a>
**P0133** 从低层级开始，逐级往上压：

<a id="p0134"></a>
**P0134** 1. 先压 Auto / 商品投放（竞价最低的层级）；

<a id="p0135"></a>
**P0135** 2. Auto 压下去后 → 压广泛竞价；

<a id="p0136"></a>
**P0136** 3. 广泛压下去后 → 压精准竞价；

<a id="p0137"></a>
**P0137** 4. 每次压完一个层级，等 2-3 天稳定后再动下一个；

<a id="p0138"></a>
**P0138** 好处：花费大头（精准）最后动，花费波动最小。

<a id="p0139"></a>
**P0139** 策略 2：直接搭更低竞价结构（保守）

<a id="p0140"></a>
**P0140** 不动原有广告，在原有层级之下搭新的更低竞价结构：

<a id="p0141"></a>
**P0141** 举例：

<a id="p0142"></a>
**P0142** • 原有精准 $6.65 → 不动；

<a id="p0143"></a>
**P0143** • 新搭精准 $4.0 + 广泛 $3.0 + Auto $2.5；

<a id="p0144"></a>
**P0144** • 新结构逐渐抢走花费 → 原有高竞价结构逐渐花不出去 → 再关闭原有高竞价活动；

<a id="p0145"></a>
**P0145** 好处：不影响原有广告，新结构验证有效后再替换，风险极低。

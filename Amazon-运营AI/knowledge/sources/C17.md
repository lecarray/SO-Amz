<a id="p0005"></a>
**P0005** 一、多变体广告架构搭建

<a id="p0006"></a>
**P0006** （一）有无主推的第一步判断

<a id="p0007"></a>
**P0007** 搭建多变体广告架构之前，第一步：确认是否有主推 ASIN。

<a id="p0008"></a>
**P0008** • 无主推（或无法确定主推）→ 走"无主推多变体"路线；

<a id="p0009"></a>
**P0009** • 有主推（且能锁定）→ 走"有主推多变体"路线（分单一主推和多主推）；

<a id="p0010"></a>
**P0010** （二）无主推多变体广告架构

<a id="p0011"></a>
**P0011** 适用三种情况：

<a id="p0012"></a>
**P0012** 1. **广告本身盈利**：每出一单都赚，不需要靠某个变体推自然位，所有变体出单均可；

<a id="p0013"></a>
**P0013** 2. **无法控制买家购买行为的非标品**：如星座/月份/颜色花色款式等，买家进来买什么由他自己决定，无法引导；

<a id="p0014"></a>
**P0014** 3. **定价偏高导致自然位无法上升**：依靠广告出单盈利，不追求自然流；

<a id="p0015"></a>
**P0015** 架构策略：以低 CPA 出单为唯一目的，所有变体全部投放。

<a id="p0016"></a>
**P0016** • SP 广告：Auto（拓词加收录）+ 广泛/词组（低 CPA 词根投放）+ 精准（CPA 低的词放量出单）；

<a id="p0017"></a>
**P0017** • SB/SBV/SD：也可以试，看 CPA 高不高；

<a id="p0018"></a>
**P0018** • 所有变体都投，在优化过程中关掉 CPA 高/ACoS 高的变体或广告活动；

<a id="p0019"></a>
**P0019** • 不同变体之间不要互相竞争广告位（同组可以同时开多变体，但要保证层级顺序不乱）；

<a id="p0020"></a>
**P0020** 反面案例： 某手机壳链接（定价 $20+，通常只卖 $10+），所有变体全是广告流，没有自然流。这就是定价偏高、只能靠广告出单的典型无主推结构。这类产品不要使劲推自然位，越努力越亏。

<a id="p0021"></a>
**P0021** 无主推多变体的核心要点总结：

<a id="p0022"></a>
**P0022** • 盈利型广告为主；

<a id="p0023"></a>
**P0023** • 多占广告坑位；

<a id="p0024"></a>
**P0024** • 多出盈利单；

<a id="p0025"></a>
**P0025** • 不同变体互不干扰（不抢广告位）；

<a id="p0026"></a>
**P0026** • 表现差的变体/广告活动及时关闭；

<a id="p0027"></a>
**P0027** （三）有主推多变体广告架构

<a id="p0028"></a>
**P0028** 1. 有主推的基本原则

<a id="p0029"></a>
**P0029** 实现以下四项统一：

<a id="p0030"></a>
**P0030** | 项目 | 要求 |

<a id="p0031"></a>
**P0031** |---|---|

<a id="p0032"></a>
**P0032** | 目标主推 ASIN | 明确确定 |

<a id="p0033"></a>
**P0033** | 定价倾斜 | 主推变体定价最具竞争力（用定价引导买家购买主推）|

<a id="p0034"></a>
**P0034** | 实际投放 ASIN | 至少投主推变体 |

<a id="p0035"></a>
**P0035** | 实际出单 ASIN | 大多数为主推变体（这才是真正的主推）|

<a id="p0036"></a>
**P0036** 注意： 主推不是"你想推谁"，而是"买家实际在买谁"。如果广告投了黑色但买家都买白色，那白色才是真正的主推。

<a id="p0037"></a>
**P0037** 2. 尺码变体不区分主推

<a id="p0038"></a>
**P0038** 有款式和尺码之分时：

<a id="p0039"></a>
**P0039** • 款式可以确定主推（如黑色）；

<a id="p0040"></a>
**P0040** • 尺码（M/L/XL）不区分主推——买家自己选，你可以把所有尺码都投广告；

<a id="p0041"></a>
**P0041** • 最终加权的是买家实际购买的那个尺码；

<a id="p0042"></a>
**P0042** 3. 单一主推的广告架构

<a id="p0043"></a>
**P0043** 架构设计：

<a id="p0044"></a>
**P0044** ```

<a id="p0045"></a>
**P0045** 主推变体（如黑色）：

<a id="p0046"></a>
**P0046** ├── Auto（拓词/捡漏，竞价最低，如 0.7X）

<a id="p0047"></a>
**P0047** ├── 一级词广泛（基准 1.0X）

<a id="p0048"></a>
**P0048** ├── 二级词广泛（1.2X）

<a id="p0049"></a>
**P0049** ├── 精准单词单组（1.4X）

<a id="p0050"></a>
**P0050** └── 商品投放（≤ 0.9X）

<a id="p0051"></a>
**P0051** 辅推变体（如白色/粉色）：

<a id="p0052"></a>
**P0052** ├── Auto（竞价低于主推最低层，如 0.6X）

<a id="p0053"></a>
**P0053** └── 精准（某关键词，竞价略低于主推精准，如 1.1X）

<a id="p0054"></a>
**P0054** ```

<a id="p0055"></a>
**P0055** 辅推的作用：

<a id="p0056"></a>
**P0056** • 占坑：让辅推跟在主推后面，主推占第一页，辅推占第二页；

<a id="p0057"></a>
**P0057** • 盈利型广告：辅推广告本身能盈利，出单赚钱；

<a id="p0058"></a>
**P0058** • 辅推的竞价必须低于主推所有层级；

<a id="p0059"></a>
**P0059** 注意两点：

<a id="p0060"></a>
**P0060** 1. 辅推预算不要超过主推预算——如果主推预算花完了辅推还在花，辅推会抢到高广告位，反而在推辅推；

<a id="p0061"></a>
**P0061** 2. 辅推广告不能亏损——无论是占坑还是买订单，都不能让辅推亏钱；

<a id="p0062"></a>
**P0062** 4. 多主推（不同词下不同变体承接）

<a id="p0063"></a>
**P0063** 适用： 不同词根对应不同变体（如平衡车的绿色推中性词/男孩词，粉色推女孩词）。

<a id="p0064"></a>
**P0064** 广告架构搭建步骤：

<a id="p0065"></a>
**P0065** 1. **确定变体功能分类：**

<a id="p0066"></a>
**P0066** • 绿色 → 占所有通用词（中性词/男孩词）的自然流量入口；

<a id="p0067"></a>
**P0067** • 粉色 → 占 girl 词根的长尾词自然流量入口；

<a id="p0068"></a>
**P0068** • 白色等 → 占广告坑位（辅推占坑）；

<a id="p0069"></a>
**P0069** 2. **主推 1（绿色）广告架构：**

<a id="p0070"></a>
**P0070** • 正常搭 Auto + 广泛词组 + 精准；

<a id="p0071"></a>
**P0071** • 词组否掉 "girl" 和 "pink" 词根（避免绿色出现在 girl/pink 相关词下）；

<a id="p0072"></a>
**P0072** 3. **主推 2（粉色）广告架构：**

<a id="p0073"></a>
**P0073** • 只推 girl 词根 + 礼物/玩具词根的组合；

<a id="p0074"></a>
**P0074** • 例：核心词 + girl → 投精准或广泛；

<a id="p0075"></a>
**P0075** 4. **其余辅推变体（白色等）广告架构：**

<a id="p0076"></a>
**P0076** • 开 Auto（竞价低于绿色 Auto）；

<a id="p0077"></a>
**P0077** • 广泛词组全词通投（竞价低于所有主推层级）；

<a id="p0078"></a>
**P0078** • 目的：低竞价占所有词的后面坑位；

<a id="p0079"></a>
**P0079** 架构效果（balance bag 案例）：

<a id="p0080"></a>
**P0080** • 搜索 "balance bag"（中性词）→ 自然位和广告位均为绿色，SBV/SB 有绿色+粉色+白色分布（占坑）；

<a id="p0081"></a>
**P0081** • 搜索 "1 year old girl toy"（女孩词）→ 自然位和广告位均为粉色，绿色不出现（因为否掉了 girl）；

<a id="p0082"></a>
**P0082** 搭建前务必先画思维导图，再在后台操作，否则非常容易乱掉。

<a id="p0083"></a>
**P0083** 5. 多色系/多款式服装的多主推架构

<a id="p0084"></a>
**P0084** 以连衣裙为例（黑色通用款 + 多颜色款 + 万圣节款等）：

<a id="p0085"></a>
**P0085** ```

<a id="p0086"></a>
**P0086** 黑色主推（通用词 + black 长尾词）：

<a id="p0087"></a>
**P0087** ├── Auto、广泛、精准正常搭；

<a id="p0088"></a>
**P0088** ├── 搭防御性广告（自己 ASIN 的商品投放）；

<a id="p0089"></a>
**P0089** ├── 搭进攻性广告（竞品 ASIN 商品投放）；

<a id="p0090"></a>
**P0090** └── 词组否定 "red"、"white"、"pink" 等其他颜色词根；

<a id="p0091"></a>
**P0091** 红色款：

<a id="p0092"></a>
**P0092** ├── 投 red 词根 + 核心词的长尾；

<a id="p0093"></a>
**P0093** └── 投红色竞品 ASIN 商品投放；

<a id="p0094"></a>
**P0094** 白色款：

<a id="p0095"></a>
**P0095** └── 投 white 词根 + 核心词，以及白色竞品；

<a id="p0096"></a>
**P0096** ```

<a id="p0097"></a>
**P0097** 多链接组合（跨链接投放 SB 广告）：

<a id="p0098"></a>
**P0098** 品牌有多条链接时，可以把相关链接组合一起做 SB 广告，覆盖更多词根：

<a id="p0099"></a>
**P0099** • 链接 A（黑色/白色/红色短袖）+ 链接 B（黑色/白色高领）→ 组合投"黑色连衣裙"；

<a id="p0100"></a>
**P0100** • 链接 C（白色短袖）+ 链接 D（白色高领）→ 组合投"白色连衣裙"；

<a id="p0101"></a>
**P0101** 这种跨链接组合不影响各链接自己的主推加权，可以实现拿到更多词的广告流量。

<a id="p0102"></a>
**P0102** （四）多变体反面案例

<a id="p0103"></a>
**P0103** 案例一（童装黑色主推）：

<a id="p0104"></a>
**P0104** • 想推黑色变体，开了黑色广告；

<a id="p0105"></a>
**P0105** • 实际自然位是白色/红色/黄色（买家不买黑色童装）；

<a id="p0106"></a>
**P0106** • 问题：主推颜色选错了——儿童服装不适合推黑色；

<a id="p0107"></a>
**P0107** • 教训：先用数据测试主推，不要凭空想象；

<a id="p0108"></a>
**P0108** 案例二（台灯粉色主推失败）：

<a id="p0109"></a>
**P0109** • 粉色原本一天出 100 单，后来加了灰色变体；

<a id="p0110"></a>
**P0110** • 加了灰色后：粉色 50 单 + 灰色 50 单，粉色出单量下降 → 自然位下降；

<a id="p0111"></a>
**P0111** • 问题：灰色是男女通用色，切走了一半粉色买家；

<a id="p0112"></a>
**P0112** • 教训：新增变体要考虑是否会抢走主推的销量；

<a id="p0113"></a>
**P0113** 二、主推测款方法

<a id="p0114"></a>
**P0114** （一）为什么不能把所有变体一起测

<a id="p0115"></a>
**P0115** 把所有变体扔进同一个广告活动一起测，会出现以下问题：

<a id="p0116"></a>
**P0116** • 预算分配不可控（体量大的变体花钱多）；

<a id="p0117"></a>
**P0117** • 互相抢广告位（多变体互斥，一个在好位置另一个必定在差位置）；

<a id="p0118"></a>
**P0118** • 导致点击率有高有低，不是产品本身的差异，而是广告位的差异；

<a id="p0119"></a>
**P0119** 这样测出来的数据严重不公平，不能作为选主推的依据。

<a id="p0120"></a>
**P0120** （二）控制变量测款法

<a id="p0121"></a>
**P0121** 核心原则：让每个变体在同等条件下分别单独测，再横向比较。

<a id="p0122"></a>
**P0122** 固定条件：

<a id="p0123"></a>
**P0123** • 固定竞价（不开"只降低"或"提高降低"，保持固定竞价或动态竞价的条件相同）；

<a id="p0124"></a>
**P0124** • 每个变体花同样的预算（或测同样长的时间）；

<a id="p0125"></a>
**P0125** • 投同样的投放词；

<a id="p0126"></a>
**P0126** • 均能覆盖到所有广告位；

<a id="p0127"></a>
**P0127** 操作方式：

<a id="p0128"></a>
**P0128** 1. 第一天：只开变体 A 的广告，给约 $130 预算；

<a id="p0129"></a>
**P0129** 2. 第二天：关闭变体 A，只开变体 B，给约 $130 预算；

<a id="p0130"></a>
**P0130** 3. 第三天：关闭变体 B，只开变体 C，给约 $130 预算；

<a id="p0131"></a>
**P0131** 4. 对比三天的转化率、CVR 和 CPA；

<a id="p0132"></a>
**P0132** 测款案例（运动裤 4 色）：

<a id="p0133"></a>
**P0133** | 变体 | 花费 | 点击 | 出单 | CVR |

<a id="p0134"></a>
**P0134** |---|---|---|---|---|

<a id="p0135"></a>
**P0135** | 黑色 | $130 | 77 次 | 1 单 | 1.3%（很差）|

<a id="p0136"></a>
**P0136** | 灰色 | $130 | 107 次 | 5 单 | 4.7%（不错）|

<a id="p0137"></a>
**P0137** | 浅灰色 | $130 | 104 次 | 9 单 | 8.7%（很好）|

<a id="p0138"></a>
**P0138** 结论：浅灰色 CVR 最高 → 确定浅灰色为主推。

<a id="p0139"></a>
**P0139** 注意事项：

<a id="p0140"></a>
**P0140** • 建议先测竞价（确定合理竞价区间），再测款；

<a id="p0141"></a>
**P0141** • 测款时间不要求多久，花同样的钱就可以对比；

<a id="p0142"></a>
**P0142** • 新链接先搭主推结构，跑够数据后再换款测试，每次单独开一个变体，避免互相干扰；

<a id="p0143"></a>
**P0143** • 测款过程中买家点进来买了别的变体，也算广告订单——所以最后要看实际出单是哪个变体，那个才是真正的主推；

<a id="p0144"></a>
**P0144** 三、链接流量增长方向

<a id="p0145"></a>
**P0145** （一）自然流量增长的四个方向

<a id="p0146"></a>
**P0146** 方向 1：推到更高自然位

<a id="p0147"></a>
**P0147** 方法：预期坑产 or 实际坑产（已在前面讲完）。

<a id="p0148"></a>
**P0148** 方向 2：拿到更多流量词

<a id="p0149"></a>
**P0149** 优先顺序：

<a id="p0150"></a>
**P0150** • 初期：8-10 分准词；

<a id="p0151"></a>
**P0151** • 成长期：6 分泛词；

<a id="p0152"></a>
**P0152** • 成熟期：4 分更泛词；

<a id="p0153"></a>
**P0153** 注意：没有单量的时候不要拓词，拓了也没用（实际坑产带不起来）；有单量才有意义。

<a id="p0154"></a>
**P0154** 方向 3：往更大的流量词走

<a id="p0155"></a>
**P0155** 两种方式：

<a id="p0156"></a>
**P0156** 方式 A：季节性产品蹲守流量增长节点

<a id="p0157"></a>
**P0157** • 季节性词在旺季前会出现"搜索量爆发斜率"；

<a id="p0158"></a>
**P0158** • 最佳入场时机 = 搜索量斜率开始上升前 1-2 周；

<a id="p0159"></a>
**P0159** • 一般推广发力节点 = 旺季前 3-4 周（含测款、测定价时间）；

<a id="p0160"></a>
**P0160** • 推得太早没有流量（钱白花），推得太晚被别人占了坑；

<a id="p0161"></a>
**P0161** 万圣节产品案例：

<a id="p0162"></a>
**P0162** • 8 月初：搜索量开始有，但极低；

<a id="p0163"></a>
**P0163** • 9 月中旬：搜索量斜率开始上升（这是发力节点）；

<a id="p0164"></a>
**P0164** • 9 月下旬：搜索量爆发高峰；

<a id="p0165"></a>
**P0165** • 建议 8 月底测款/测定价 → 9 月初备货 → 9 月中旬正式发力广告；

<a id="p0166"></a>
**P0166** 参考竞品的推广节奏也能验证：优秀竞品基本都是 9 月 12 号左右开始投广告，9 月 16 号开始加大投入。

<a id="p0167"></a>
**P0167** 方式 B：挖掘潜力词（搜索量正在上涨的词）

<a id="p0168"></a>
**P0168** • 在西柚找词里，找本词群里搜索量近期突然大幅上涨的词；

<a id="p0169"></a>
**P0169** • 原理类比"买股票"：在它刚开始涨的时候入场；

<a id="p0170"></a>
**P0170** • 这类词未来流量会更大，现在入场竞争少，CPC 低，投产极高；

<a id="p0171"></a>
**P0171** • 旺季前建议提前拓一批这类词的收录，即使自然位暂时出不来，做活动/降价时会有额外的出单惊喜；

<a id="p0172"></a>
**P0172** 已有收录但暂时没自然位的泛词，每次做活动/降价时都有机会冒出来，这些词是链接的隐藏流量潜力，务必拓好收录。

<a id="p0173"></a>
**P0173** 方向 4：利用变体拓充流量入口

<a id="p0174"></a>
**P0174** 三种变体拓词思路：

<a id="p0175"></a>
**P0175** 1. **已有变体未被充分利用**：检查现有变体有没有对应词没有覆盖，比如有红色变体但没打 red 长尾词；

<a id="p0176"></a>
**P0176** 2. **人为开发新变体拿新词**：

<a id="p0177"></a>
**P0177** • 加尺码 → 拿 plus size 词根；

<a id="p0178"></a>
**P0178** • 加节日款（万圣节/圣诞/独立日等）→ 拿节日词；

<a id="p0179"></a>
**P0179** • 加颜色 → 拿颜色长尾词；

<a id="p0180"></a>
**P0180** • 加场景（如旅行款/户外款）→ 拿场景词；

<a id="p0181"></a>
**P0181** 3. **节日变体案例（衬衫/裙子）**：

<a id="p0182"></a>
**P0182** • 加圣诞红绿款 → 圣诞词；

<a id="p0183"></a>
**P0183** • 加独立日红蓝白款 → 独立日词；

<a id="p0184"></a>
**P0184** • 加万圣节图案款 → 万圣节词；

<a id="p0185"></a>
**P0185** 以上变体拓词不影响主推链接的正常推广，且在旺季能带来额外的流量峰值。

<a id="p0186"></a>
**P0186** 另外还可以补充：回去检查 Keep Shopping For 里面的词有没有埋进文案，确保最大化自然流量入口。

<a id="p0187"></a>
**P0187** （二）广告流量增长的三个方向

<a id="p0188"></a>
**P0188** | 广告类型 | 说明 |

<a id="p0189"></a>
**P0189** |---|---|

<a id="p0190"></a>
**P0190** | 投资型广告 | 亏损，不建议为"拿流量"而加投；保持原有投入，拉出更多自然流即可 |

<a id="p0191"></a>
**P0191** | 盈利型广告 | 可以放量，每出一单都赚，适当放宽 CPA 要求直接放量 |

<a id="p0192"></a>
**P0192** | 纯利型广告 | 任何阶段都可以放量，ACoS 低于目标 TACoS，出单直接增加纯利 |

<a id="p0193"></a>
**P0193** 搭建盈利型/纯利型广告的三种方式：

<a id="p0194"></a>
**P0194** 1. **在已有广告框架下加捡漏/纯利型广告**：根据转化率倒推竞价，凡是接得到的就赚；

<a id="p0195"></a>
**P0195** 2. **利用变体投放拿盈利型广告流量**：

<a id="p0196"></a>
**P0196** • 非标/半标产品广告通常不会太亏；

<a id="p0197"></a>
**P0197** • 把所有变体投到大范围词，低竞价下竞价很便宜，容易做到盈利型；

<a id="p0198"></a>
**P0198** 3. **商品投放（PT）**：竞价低、CVR 也不差，最容易做出盈利型广告的通道；

<a id="p0199"></a>
**P0199** 另：其他广告类型（SB/SBV/SD） 如果SP广告本身不亏，那 SB/SBV/SD 大概率都可以做成盈利型。后续视频会详细讲解，这次课程时间有限。

**P0200** 四、旺季推广节奏建议

<a id="p0201"></a>
**P0201** 当前是 9 月下旬，距离旺季还有约 5-6 周时间，建议：

<a id="p0202"></a>
**P0202** 1. **立刻把旺季相关词拓进收录**：gift 词、toy 词、holiday 词，以及去年旺季出现过的词；

<a id="p0203"></a>

**P0206** 总结：旺季前要做的三件事：拓词 → 收录 → 等流量涨，等流量涨了再给广告发力。

<a id="p0207"></a>
**P0207** 五、本节总结

<a id="p0208"></a>
**P0208** 多变体广告架构：

<a id="p0209"></a>
**P0209** • 有主推 → 主推统一（目标/定价/投放/出单四统一），辅推低竞价跟在后面；

<a id="p0210"></a>
**P0210** • 无主推 → 所有变体出单为目的，关掉 CPA 高的；

<a id="p0211"></a>
**P0211** • 多主推 → 不同词根对应不同变体，互相否词根不冲突；

<a id="p0212"></a>
**P0212** • 搭架构前先画思维导图，否则容易乱；

<a id="p0213"></a>
**P0213** 主推测款：

<a id="p0214"></a>
**P0214** • 控制变量法（一次测一个变体，花同样的钱，再横向比较 CVR）；

<a id="p0215"></a>
**P0215** • 先测竞价，再测款；

<a id="p0216"></a>
**P0216** 链接流量增长：

<a id="p0217"></a>
**P0217** • 自然流：推更高自然位 / 拿更多词 / 季节性词蹲守 / 变体拓流量入口；

<a id="p0218"></a>
**P0218** • 广告流：搭建盈利型/纯利型广告（商品投放/变体大范围投/捡漏广告）；

**P0005** 一、准词表常见问题与纠偏复习

<a id="p0006"></a>
**P0006** （一）找竞品 ASIN 的注意事项

<a id="p0007"></a>
**P0007** 如果要做准词表，首先得先去收集你的竞品 ASIN。

<a id="p0008"></a>
**P0008** 竞品 ASIN 不要要求太严格。

<a id="p0009"></a>
**P0009** 举例：驱狗器产品——有类目节点就去类目节点里找，没有类目节点就搜准词去找（分散几个准词去搜）。

<a id="p0010"></a>
**P0010** 放 ASIN 的数量原则：

<a id="p0011"></a>
**P0011** • 如果找不到太多竞对 → 三个就行（三个竞对 + 一个主 ASIN 放在第一个位置）；

<a id="p0012"></a>
**P0012** • 找不到合适竞品时后面放得越多 → 分数会被拉得越低；

<a id="p0013"></a>
**P0013** • 宁可少放也不要多放——但少放不能太偏颇，起码 3 个；

<a id="p0014"></a>
**P0014** • 没有经验的情况下只放三个。

<a id="p0015"></a>
**P0015** （二）网页端排序检查

<a id="p0016"></a>
**P0016** 放到网页端查询后，第一步：把搜索量排成倒序。

<a id="p0017"></a>
**P0017** > 很多卖家导出来的准词表没法识别哪些是准词和大词——因为搜索量排的是小词在前面。

<a id="p0018"></a>
**P0018** （三）倒序后检查步骤

<a id="p0019"></a>
**P0019** 1. **筛 6 分以上**——看这堆词；

<a id="p0020"></a>
**P0020** 2. **把鼠标放在"相对排名"这里**——能看到每个 ASIN 的自然位；

<a id="p0021"></a>
**P0021** 3. **检查有没有特别差的 ASIN**：

<a id="p0022"></a>
**P0022** • 有 → 删掉重新查；

<a id="p0023"></a>
**P0023** • 部分差 → 引入新 ASIN 来综合数据；

<a id="p0024"></a>
**P0024** • 没有 → 没问题；

<a id="p0025"></a>
**P0025** 初始操作建议：

<a id="p0026"></a>
**P0026** • 初始放得少、慢慢再加（更安全）；

<a id="p0027"></a>
**P0027** • 初始放得多、慢慢删（也可以）；

<a id="p0028"></a>
**P0028** • 不会删就初始少放一点。

<a id="p0029"></a>
**P0029** （四）确认表格无问题后再导出

<a id="p0030"></a>
**P0030** 在网页端先做一遍检查——没问题了再导出。

**P0031** （五）导出后：移动列 + 筛选

<a id="p0032"></a>
**P0032** 导出表格后：

<a id="p0033"></a>
**P0033** 1. **把竞品表现得分和各竞对 ASIN 的自然排名列移到前面**；

<a id="p0034"></a>
**P0034** 2. **筛 6-10 分词**；

<a id="p0035"></a>
**P0035** 3. 看 6 分词有没有偏低：

<a id="p0036"></a>
**P0036** • 排名方差不大 → 维持 6 分；

<a id="p0037"></a>
**P0037** • 排名方差大 → 调整；

<a id="p0038"></a>
**P0038** （六）确定得分阈值

<a id="p0039"></a>
**P0039** 用积木查大词的目标排位建议：

<a id="p0040"></a>
**P0040** • 目标排位 8-35 → 用 8-10 分词就够了；

<a id="p0041"></a>
**P0041** • 目标排位到 100+ → 可以筛到 6 分词；

<a id="p0042"></a>
**P0042** 没有积木软件的话：

<a id="p0043"></a>
**P0043** • 标品 → 无脑 8-10 分；

<a id="p0044"></a>
**P0044** • 非标/半标 → 可能得上到 6 分甚至 4 分；

<a id="p0045"></a>
**P0045** （七）搜索量占比的正确计算

<a id="p0046"></a>
**P0046** 分母必须是"你要的这些准词的总搜索量"，不是全部词的总搜索量。

<a id="p0047"></a>
**P0047** 举例：

<a id="p0048"></a>
**P0048** • 全部词搜索量 236 万 → 不要用这个数；

<a id="p0049"></a>
**P0049** • 8-10 分词搜索量 258,000 → 用这个数；

<a id="p0050"></a>
**P0050** 准词搜索量占比加在一起必须 = 100%。

<a id="p0051"></a>
**P0051** （八）学员问题答疑

<a id="p0052"></a>
**P0052** 问题 1：竞品一定要一模一样吗？

<a id="p0053"></a>
**P0053** 不用。找受众一样的就行。

<a id="p0054"></a>
**P0054** 举例：驱狗器——形态有点不一样没关系，功能和售价差不多就算竞品。

<a id="p0055"></a>
**P0055** 判断标准："买他的人也会买我"——这么简单。

<a id="p0056"></a>
**P0056** 问题 2：低销量产品找竞品

<a id="p0057"></a>
**P0057** 找不到太多竞品：

<a id="p0058"></a>
**P0058** • 小众产品 → 先找同市场的产品（条件放宽）；

<a id="p0059"></a>
**P0059** • 实在不行 → 功能放宽、价格放宽都能找到。

<a id="p0060"></a>
**P0060** 问题 3：汽车配件、太阳能摄像头等小众产品

<a id="p0061"></a>
**P0061** 做两种调研：

<a id="p0062"></a>
**P0062** 1. 同品类整体调研（如"户外安防摄像头"）；

<a id="p0063"></a>
**P0063** 2. 细分功能调研（如"太阳能户外摄像头"）；

<a id="p0064"></a>
**P0064** 对比两种调研的排名差异 → 判断推广上限。

<a id="p0065"></a>
**P0065** 问题 4：价格差异大的竞品

<a id="p0066"></a>
**P0066** 举例：手链产品——你卖 $20 多，竞品都卖 $10 多。

<a id="p0067"></a>
**P0067** 也只能拿它作为竞品——因为找不到 $20 多的竞品。

<a id="p0068"></a>
**P0068** 但要知道：竞品表现得分不仅反映词的准确性，还反映产品未来能到的最高位置。

<a id="p0069"></a>
**P0069** > 选品时也可以做——估算自己能到多高。

<a id="p0070"></a>
**P0070** 问题 5：品牌词得分高怎么处理？

<a id="p0071"></a>
**P0071** 判断方法：放的 ASIN 中有没有好几个是这个品牌的——

<a id="p0072"></a>
**P0072** • 有 → 品牌词得分被人为抬高 → 改低；

<a id="p0073"></a>
**P0073** • 只有 1 个 → 品牌词得分就是真的高 → 不改。

<a id="p0074"></a>
**P0074** 品牌词要不要拿？

<a id="p0075"></a>
**P0075** • 搜一下这个品牌词 → 看下面是不是大量别的品牌在占位；

<a id="p0076"></a>
**P0076** • 如果是 → 这个品牌词好拿 → 可以要。

<a id="p0077"></a>
**P0077** 问题 6：广告曝光量大于搜索量？

<a id="p0078"></a>
**P0078** 正常。

<a id="p0079"></a>
**P0079** 原因：买家搜一次 → TOS 位可能出 1 个曝光，ROS 也出 1 个，PP 位置可能出 6 个 → 一次搜索 = 8 个曝光。

<a id="p0080"></a>
**P0080** 想对比广告露出次数 → 必须拿单个广告位对比。

<a id="p0081"></a>
**P0081** 二、关键词权重原理与效果

<a id="p0082"></a>
**P0082** （一）加权的基本动作

<a id="p0083"></a>
**P0083** 想要在关键词加权 → 需要让产品在这个词产生曝光、点击、加购、出单。

<a id="p0084"></a>
**P0084** • 4 个动作都能加权，越到后面加权越高；

<a id="p0085"></a>
**P0085** • 收录：曝光、点击、加购就能做到收录（不一定有自然位）；

<a id="p0086"></a>
**P0086** • 影响自然位：必须靠出单。

<a id="p0087"></a>
**P0087** （二）自然出单 vs SP 广告出单

<a id="p0088"></a>
**P0088** 两种方式都可以增加关键词累积权重。

<a id="p0089"></a>
**P0089** 注意：只有 SP 广告出单能加权，SB/SBV/SD 不能。

<a id="p0090"></a>
**P0090** （三）关键词权重的两种外在体现

<a id="p0091"></a>
**P0091** 1. 自然排名

<a id="p0092"></a>
**P0092** 自然排名 = 累积权重 + 短期坑产（短期坑产占主导）

<a id="p0093"></a>
**P0093** • 累积权重高 ≠ 自然排名高；

<a id="p0094"></a>
**P0094** • 但累积权重高 → 短期内更容易把站位撬出来；

<a id="p0095"></a>
**P0095** • 老链接比新链接好推 → 就是因为历史数据好、累积分数高。

<a id="p0096"></a>
**P0096** 2. 广告排名

<a id="p0097"></a>
**P0097** 广告排名 = Bid（竞价）× 关键词质量得分

<a id="p0098"></a>
**P0098** 关键词质量得分可理解为累积权重。

<a id="p0099"></a>
**P0099** 广告排名的三个影响因素：

<a id="p0100"></a>
**P0100** 1. **关键词累积权重（质量得分）**；

<a id="p0101"></a>
**P0101** 2. **广告预期坑产（近期广告表现）**：近期表现越好 → 同竞价下广告位越好；

<a id="p0102"></a>
**P0102** 3. **广告活动的累积权重**：同产品用老壳子 vs 新壳子 → 同竞价两种广告位。

<a id="p0103"></a>
**P0103** 三个因素都好 → CPC 可以压得很低，用便宜竞价买到别人高价的位置。

<a id="p0104"></a>
**P0104** （四）核心结论

<a id="p0105"></a>
**P0105** 不管是自然排名还是广告排名，最重要的还是短期坑产。

<a id="p0106"></a>
**P0106** • 自然排名 → 自然位的短期坑产；

<a id="p0107"></a>
**P0107** • 广告排名 → 广告的短期坑产；

<a id="p0108"></a>
**P0108** 不要想着用广告去影响累积权重——累积权重对你的影响没有这么大。

<a id="p0109"></a>
**P0109** （五）收录 vs 权重 vs 自然位的关系

<a id="p0110"></a>
**P0110** 有累积权重 = 有收录。

<a id="p0111"></a>
**P0111** 有收录以后，刺激收录词出自然位有几种方式：

<a id="p0112"></a>
**P0112** 1. **实际坑产**——做了实际坑产后收录词的自然位都可以被刺激出来；

<a id="p0113"></a>
**P0113** 2. **短期活动**——大幅降价 / LD / BD → 短期内高 CTR 高 CVR → 刺激收录词占位；

<a id="p0114"></a>
**P0114** 建议：

<a id="p0115"></a>
**P0115** • 收录可以不打（不投这个词），但不能没有收录；

<a id="p0116"></a>
**P0116** • 没有收录 → 做活动时无法刺激这个词。

<a id="p0117"></a>
**P0117** 收录怎么确认？

<a id="p0118"></a>
**P0118** 方法 1：后台 ABA（搜索绩效表现页面）反查

<a id="p0119"></a>
**P0119** • 能排到前 1-100 → 权重不错。

<a id="p0120"></a>
**P0120** 方法 2：H10 Index Checker（收录检查器）

<a id="p0121"></a>
**P0121** • 输入自己的 ASIN + 要检查的词；

<a id="p0122"></a>
**P0122** • 显示"✓" → 已收录；

<a id="p0123"></a>
**P0123** • 显示"—" → 有待收录；

<a id="p0124"></a>
**P0124** 案例：驱狗器产品

<a id="p0125"></a>
**P0125** • 发现 "silence" 词根全是横杠 → 没收录；

<a id="p0126"></a>
**P0126** • "buckle" 词根也没收录；

<a id="p0127"></a>
**P0127** • 原因：词根太多，有些词根没埋或没打；

<a id="p0128"></a>
**P0128** 处理方法：回去埋词 + 打广告（哪怕只是 Auto 跑一下收录就行）。

<a id="p0129"></a>
**P0129** 三、词根之间的互相加权原理

<a id="p0130"></a>
**P0130** （一）加权不是只对单个词

<a id="p0131"></a>
**P0131** 目标关键词是 AB → 不是只能通过 AB 出单加权。

<a id="p0132"></a>
**P0132** 很多词都可以给 AB 加权，但加权效果不同：

<a id="p0133"></a>
**P0133** | 方式 | 加权效果 |

<a id="p0134"></a>
**P0134** |---|---|

<a id="p0135"></a>
**P0135** | CAD、CBD（AB 的某个词根的长尾） | 很少 |

<a id="p0136"></a>
**P0136** | 带 A 词根和 B 词根的乱序词 | 约 30% |

<a id="p0137"></a>
**P0137** | CABD（AB 连在一起的长尾词） | 约 50% |

<a id="p0138"></a>
**P0138** | ABS / AB（精准或 +s） | 约 90%-100% |

<a id="p0139"></a>
**P0139** 所以调研出来 1000 个词不需要都打——很多小词不需要打。

<a id="p0140"></a>
**P0140** 举例：给大词 AB 出单 → 自然给 CABD 加权 → 给 EFG（小词）也加权。

<a id="p0141"></a>
**P0141** 同词根的词会互相加权。

<a id="p0142"></a>
**P0142** （二）为什么检查收录时看到同词根全部没收录？

<a id="p0143"></a>
**P0143** 举例：驱狗器产品

<a id="p0144"></a>
**P0144** • "buckle" 词根没收录 → "buckle for dogs" 也没收录；

<a id="p0145"></a>
**P0145** • 原因：这个词根从来没埋、没打；

<a id="p0146"></a>
**P0146** • 但凡打了其中一个词，其他同词根的词大概率也能出来。

<a id="p0147"></a>
**P0147** （三）小词怎么处理？

<a id="p0148"></a>
**P0148** • 同词根小词 → 不需要单推，大词带出来；

<a id="p0149"></a>
**P0149** • 不同词根的小词 → 打收录 + 实际坑产带；

<a id="p0150"></a>
**P0150** • 搜索量几百的小词 → 不单推，用广泛/词组批量覆盖，或用 Auto 跑，或大词出单带；

<a id="p0151"></a>
**P0151** （四）推广洞察表验证

<a id="p0152"></a>
**P0152** 案例：Air Duster（吹尘器）

<a id="p0153"></a>
**P0153** 在推广洞察表中对照花费与自然位：

<a id="p0154"></a>
**P0154** • 很多搜索量 800 多的小词 → 自然位第 5、第 10 → 从来没花过钱；

<a id="p0155"></a>
**P0155** • 这些词的自然位怎么来的？

<a id="p0156"></a>
**P0156** 两种方式：

<a id="p0157"></a>
**P0157** 1. **词根互相加权（预期坑产）**：比如打了 "BW100"/"Blue Word" → 带起了同词根的小词 → 到第 3-5 位；

<a id="p0158"></a>
**P0158** 2. **实际坑产**：打完收录后靠总单量 → 到第 19、30 位这种中间位置。

<a id="p0159"></a>
**P0159** 四、大词带小词 vs 小词带大词

<a id="p0160"></a>
**P0160** （一）大词带小词

<a id="p0161"></a>
**P0161** 适用条件：

<a id="p0162"></a>
**P0162** 1. **流量词集中且大词足够大**：

<a id="p0163"></a>
**P0163** • 举例：纸巾配套套子——大词占 50%+ → 大词出单可以带动所有同词根长尾；

<a id="p0164"></a>
**P0164** • 举例：流量相对分散 → 也有大词，大词合计 40% → 也能带；

<a id="p0165"></a>
**P0165** 2. **大词和小词同词根**：

<a id="p0166"></a>
**P0166** • 举例：showerhead → 几乎所有词都带 "showerhead" → 大词可以带所有长尾；

<a id="p0167"></a>
**P0167** • 反例：驱狗器 → 词根有 deterrent、device、repeller、silence、buckle、stop barking、sonic → 太散 → 带不动；

<a id="p0168"></a>
**P0168** 3. **大词干预量足够 + 正向干预**：

<a id="p0169"></a>
**P0169** • 大词 CPR 800 → 一天给 50 单 → 正向干预 → 小词同时加权被带上自然位；

<a id="p0170"></a>
**P0170** • 大词 CPR 800 → 一天只给 10 单 → 正向干预 → 只能带动很小的词（效率很低，不如直接给小词）；

<a id="p0171"></a>
**P0171** • 大词干预量完全不够 or 反向干预 → 大词小词都上不去；

<a id="p0172"></a>
**P0172** 最适合大词带小词的产品：

<a id="p0173"></a>
**P0173** • 流量集中 + 词根单一 + 同质化标品 → 非常适合刷单（刷单容易白帽难）；

<a id="p0174"></a>
**P0174** （二）小词带大词

<a id="p0175"></a>
**P0175** 适用条件：

<a id="p0176"></a>
**P0176** 1. **小词和大词词根相同**；

<a id="p0177"></a>
**P0177** 2. **小词单量足量 + 正向干预**；

<a id="p0178"></a>
**P0178** 优点：比大词带小词更保险——大词即使推不上去，起码小词推出来了。

<a id="p0179"></a>
**P0179** 个人更建议：想推得保守/稳健 → 走小词带大词的路线。

<a id="p0180"></a>
**P0180** 不适合的情况：

<a id="p0181"></a>
**P0181** 1. **流量高度集中**（小词加起来只有 40%，带不动 60% 的大词）；

<a id="p0182"></a>
**P0182** 2. **小词词根分散**（词根太散，没法集中出单）；

<a id="p0183"></a>
**P0183** （三）推荐策略

<a id="p0184"></a>
**P0184** • 流量集中 → 大词带小词（但新品白帽很难）；

<a id="p0185"></a>
**P0185** • 流量相对分散 → 两种都可以（预算多推大词，预算少推小词，互相带动）；

<a id="p0186"></a>
**P0186** • 流量非常分散 → 只能打收录 + 实际坑产引爆（大词带不动小词，小词也带不动大词）；

<a id="p0187"></a>
**P0187** 个人不是很喜欢大词带小词 → 如果非要做，一定要做好收录。

<a id="p0188"></a>
**P0188** 五、新品期的正确理解

<a id="p0189"></a>
**P0189** （一）亚马逊官方新品期定义

<a id="p0190"></a>
**P0190** 3 个月 → 进入 New Release 榜单的资格。

<a id="p0191"></a>
**P0191** （二）推广角度的新品期

<a id="p0192"></a>
**P0192** 新品上架后 = 一张白纸 → 起始得分约 60 分（及格分）。

<a id="p0193"></a>
**P0193** 这个起始分由你的类目节点决定——没有节点 → 广告跑不出来。

<a id="p0194"></a>
**P0194** 表现好 → 60 分往上走 → 80 分 90 分 → 新品很好推；

<a id="p0195"></a>
**P0195** 表现差 → 60 分往下降 → 30、40 分 → 新品又很难推。

<a id="p0196"></a>
**P0196** （三）关键注意事项

<a id="p0197"></a>
**P0197** 1. 产品一定要放对节点 → 放错节点 → 相关词跑不出来。

<a id="p0198"></a>
**P0198** 2. 上架后不推也没关系 → 只要没进数据 → 还算"白纸"、还算新品（应届生身份可以保留）。

<a id="p0199"></a>
**P0199** 3. 不要着急进差数据：

<a id="p0200"></a>
**P0200** • 没评论就大开 Auto 买一堆数据 → 自毁链接（把 60 分拉到 40 分）；

<a id="p0201"></a>
**P0201** • 等评论准备好了再推 → 但你得从 40 分开始（失去新品优势）；

<a id="p0202"></a>
**P0202** 4. 上架后 7 天内进了大量数据 → 不算新品了（已经有了表现）。

<a id="p0203"></a>
**P0203** 六、断货恢复与累积权重

<a id="p0204"></a>
**P0204** （一）断货期间累积权重不受影响

<a id="p0205"></a>
**P0205** 断货时没有流量进入 → 累积权重不变。

<a id="p0206"></a>
**P0206** 自然坑位掉了 ≠ 权重掉了 → 只是短期内没坑产。

<a id="p0207"></a>
**P0207** （二）断货恢复案例

<a id="p0208"></a>
**P0208** 案例 1：短期断货（半个月到一个月）

<a id="p0209"></a>
**P0209** 产品断货前在第 5-6 位 → 断货接近一个月 → 上架后马上回到第 8 位。

<a id="p0210"></a>
**P0210** 案例 2：降价刺激快速恢复

<a id="p0211"></a>
**P0211** 断货期间数据做得很烂 → 补完货后大降价 → 价格骤降刺激高 CTR 高 CVR → 自然位穿到第 6 位 → 再调回来。

<a id="p0212"></a>
**P0212** 案例 3：长期断货（季节性产品）

<a id="p0213"></a>
**P0213** 季节性产品断了大半年 → 第二年季节前重推 → 依然能恢复（累积权重在）。

<a id="p0214"></a>
**P0214** （三）断货期间的操作建议

<a id="p0215"></a>
**P0215** 1. 不要买垃圾数据：

<a id="p0216"></a>
**P0216** • 所有会拉低 CTR 的数据都不要；

<a id="p0217"></a>
**P0217** • 不要提价 → 提价 = 进垃圾数据（CTR 降低）；

<a id="p0218"></a>
**P0218** • 建议：降价断货（在好数据的状态下断掉）；

<a id="p0219"></a>
**P0219** 2. 预售期间不要开广告：

<a id="p0220"></a>
**P0220** • 预售期间配送时间长 → 物流差 → 短期坑产差 → 自然位差；

<a id="p0221"></a>
**P0221** • 这个时候再买数据 = 向亚马逊证明自己有多差；

<a id="p0222"></a>
**P0222** • 果断把广告全停掉；

<a id="p0223"></a>
**P0223** 3. 最佳做法：

<a id="p0224"></a>
**P0224** • 在高位停售（或在高位消失）→ 不进数据；

<a id="p0225"></a>
**P0225** • 补完货后再开始买数据 → 7 天内恢复。

<a id="p0226"></a>
**P0226** 4. 新品在任何时期都不要进大量垃圾数据：

<a id="p0227"></a>
**P0227** • 没评论就大开 Auto → 买一堆差数据 → 要避免；

<a id="p0228"></a>
**P0228** • 评论又少又差还开广告 → 不要买；

<a id="p0229"></a>
**P0229** 七、广告活动权重

<a id="p0230"></a>
**P0230** （一）老活动的价值

<a id="p0231"></a>
**P0231** 同样产品打同样的词 → 用数据好的老活动 vs 新活动 → 老活动更容易跑出高广告位 + 降竞价。

<a id="p0232"></a>
**P0232** 建议：花费高的活动不要归档 → 用暂停 → 后续可复用。

<a id="p0233"></a>
**P0233** （二）老活动壳子的复用规则

<a id="p0234"></a>
**P0234** 1. **同品类新品可以用老壳子**；

<a id="p0235"></a>
**P0235** 2. **操作方式**：把老活动里的产品 A 换成产品 B（不是同时放 A 和 B）；

<a id="p0236"></a>
**P0236** 3. **前后产品必须同节点**（打的是同样类型的东西）；

<a id="p0237"></a>
**P0237** 4. **勺子的老壳子不能给叉子用**（不同节点 → 没帮助）；

<a id="p0238"></a>
**P0238** 5. **可以换词**——打同类型的东西就行。

<a id="p0239"></a>
**P0239** 案例：老活动 + 高权重产品 → 正常竞价 $1.0 → 压到 $0.6。

<a id="p0240"></a>
**P0240** （三）养活动的方法

<a id="p0241"></a>
**P0241** 目的：养出一个表现好的老活动 → 做盈利型广告。

<a id="p0242"></a>
**P0242** 超级高效的养活动方式：

<a id="p0243"></a>
**P0243** 1. 投"品牌名 + 勺子"（品牌名精准匹配）；

<a id="p0244"></a>
**P0244** 2. 品牌没人搜 → 表现必定好（转化率必定高）；

<a id="p0245"></a>
**P0245** 3. 但"勺子"这个词被带起来了 → 活动对"勺子"有了权重；

<a id="p0246"></a>
**P0246** 4. 花费一定金额 + 数据不错 → 关掉品牌名投放；

<a id="p0247"></a>
**P0247** 5. 只跑"勺子"投放 → 竞价可以往低给 → 做成盈利型广告。

<a id="p0248"></a>
**P0248** 已有品牌名活动的卖家 → 直接拿来开别的东西。

<a id="p0249"></a>
**P0249** 八、关键词自然坑位特征总结

<a id="p0250"></a>
**P0250** （一）预期坑产 vs 实际坑产的识别

<a id="p0251"></a>
**P0251** | 特征 | 预期坑产 | 实际坑产 |

<a id="p0252"></a>
**P0252** |---|---|---|

<a id="p0253"></a>
**P0253** | 生效速度 | 5-7 天到 14 天 | 次日见效 |

<a id="p0254"></a>
**P0254** | 自然位表现 | 波浪抖动上升 | 直接闪现（突然到位） |

<a id="p0255"></a>
**P0255** | 判定依据 | 给了广告 → 5-7 天自然位恢复原位 | 今天做单量 → 明天就有位置 |

<a id="p0256"></a>
**P0256** 旺季着急时 → 更建议用实际坑产（只要单量就够了，不需要表现好）。

<a id="p0257"></a>
**P0257** （二）影响自然坑位的短期因素

<a id="p0258"></a>
**P0258** • 近期价格变动；

<a id="p0259"></a>
**P0259** • 评分变动；

<a id="p0260"></a>
**P0260** • 在库数量不同；

<a id="p0261"></a>
**P0261** • FBA 配送退货率高低；

<a id="p0262"></a>
**P0262** • 预售期间/断货刚上架 → 自然位都非常差；

<a id="p0263"></a>
**P0263** 注意：这不代表权重差 → 只代表短期内坑产低。

<a id="p0264"></a>
**P0264** （三）最快速激活方式

<a id="p0265"></a>
**P0265** 不管什么情况 → 用实际坑产最快（次日见效）。

<a id="p0266"></a>
**P0266** 但大部分情况下不着急 → 跟感冒一样，不管它 7 天也就恢复了。

<a id="p0267"></a>
**P0267** （四）累积权重高的词

<a id="p0268"></a>
**P0268** 累积权重高的词 → 预期坑产非常容易被撬动。

<a id="p0269"></a>
**P0269** 断货久的产品 → 如果累积权重高 → 自然位大概 3-7 天恢复。

<a id="p0270"></a>
**P0270** 九、本节总结

<a id="p0271"></a>
**P0271** 几个核心结论

<a id="p0272"></a>
**P0272** 1. **想推自然位不一定要靠广告打本词 / 也不一定要打相关词**——很多词可以通过词根互相带、实际坑产带；

<a id="p0273"></a>
**P0273** 2. **自然排名和广告排名都由多个因素影响**；

<a id="p0274"></a>
**P0274** 3. **做好累积权重——不要做差了**；

<a id="p0275"></a>
**P0275** 4. **短期坑产好 → 自然位就好；短期坑产差 → 自然位就差**。

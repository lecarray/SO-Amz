<a id="p0004"></a>
**P0004** 一、广告位放量的底层规律

<a id="p0005"></a>
**P0005** （一）广告位的四个区域

<a id="p0006"></a>
**P0006** 买家搜一个词后，你的广告可能出现在以下四个位置：

<a id="p0007"></a>
**P0007** | 广告位 | 说明 | 坑位数量 | 竞价难度 |

<a id="p0008"></a>
**P0008** |---|---|---|---|

<a id="p0009"></a>
**P0009** | TOS（Top of Search） | 搜索结果页头部 | 最少（3-5 个，可能被自营占掉）| 最难（需要 Ad Rank 前 3-5）|

<a id="p0010"></a>
**P0010** | ROS（Rest of Search） | 搜索结果页其余位置 | 每页 8-12 个 | 中等 |

<a id="p0011"></a>
**P0011** | 独立板块 | 如 Trending Now 等 | 每页约 5 个 | 需符合板块条件 |

<a id="p0012"></a>
**P0012** | PP（Product Pages） | 用户点开的商品详情页 | 每个商品页 2-4 个板块 | 最容易（加载即曝光）|

<a id="p0013"></a>
**P0013** 核心规律：在不做任何广告位加价的情况下，曝光量分布为：PP >> ROS > TOS

<a id="p0014"></a>
**P0014** 原因：

<a id="p0015"></a>
**P0015** • TOS 坑位最少，需要很高的 Ad Rank 才能排进；

<a id="p0016"></a>
**P0016** • PP 位置最多，加载即算曝光，不需要买家真正翻到这里；

<a id="p0017"></a>
**P0017** （二）为什么要调广告位？

<a id="p0018"></a>
**P0018** 你实际购买的是广告坑位所对应的曝光量。

<a id="p0019"></a>
**P0019** 三个广告位的价值顺序：TOS > ROS > PP

<a id="p0020"></a>
**P0020** 但默认情况下曝光量顺序是：PP >> ROS > TOS

<a id="p0021"></a>
**P0021** → 需要通过广告位加价/竞价策略，让高价值位置获得更多曝光（=花费）。

<a id="p0022"></a>
**P0022** 举例： 某活动共花费 $2,000，其中 $1,500 在 TOS，$500 在其他位置。如果能把 $2,000 全放到 TOS，投产比会提升很多 → 这就是广告位放量调控的目的。

<a id="p0023"></a>
**P0023** （三）实际竞价的构成公式

<a id="p0024"></a>
**P0024** 实际广告位竞价 = 底价（Bid）× 竞价策略系数 × (1 + 广告位加价%)

<a id="p0025"></a>
**P0025** 这三个因素相互叠加，影响每个广告位的实际出价。

<a id="p0026"></a>
**P0026** 二、三种竞价策略详解

<a id="p0027"></a>
**P0027** （一）只降低（Down Only）

<a id="p0028"></a>
**P0028** 亚马逊说明： 当广告不太可能带来销量时，实时降低你的竞价。

<a id="p0029"></a>
**P0029** 实际含义：

<a id="p0030"></a>
**P0030** • 不降低你的底价（Bid）；

<a id="p0031"></a>
**P0031** • 亚马逊在排序阶段，若认为某广告位卖给你不划算（Ad Rank 预期坑产低），会主动降低该位置的实际出价；

<a id="p0032"></a>
**P0032** • 降到极端情况 = 该位置没有曝光（因为价格降到 0，买不到这个坑）；

<a id="p0033"></a>
**P0033** 各广告位实际竞价：

<a id="p0034"></a>
**P0034** • TOS：0 ~ X 之间（表现差时被降到极低）；

<a id="p0035"></a>
**P0035** • ROS：0 ~ X 之间；

<a id="p0036"></a>
**P0036** • PP：0.8X ~ X 之间（PP 最容易跑出，即使降也保留一些）；

<a id="p0037"></a>
**P0037** CPC 的幸存者偏差： CPC = 有曝光有点击才被扣费，所以看到的 CPC 都是"活下来的"，不代表被降的那些位置 → 表现上 CPC 和 Bid 接近。

<a id="p0038"></a>
**P0038** 适用情况：

<a id="p0039"></a>
**P0039** • 老活动 + 表现稳定的产品（历史数据正常）；

<a id="p0040"></a>
**P0040** • 想要自动砍掉垃圾曝光（在差位置上节省花费）；

<a id="p0041"></a>
**P0041** • 所有老链接均可使用；

<a id="p0042"></a>
**P0042** 不适用情况：

<a id="p0043"></a>
**P0043** • 新品新活动（容易被亚马逊"不卖给你"→ 跑不出数据）；

<a id="p0044"></a>
**P0044** • 需要测试的活动（数据失真）；

<a id="p0045"></a>
**P0045** • 卡位需求（表现不好时 TOS 卡不住）；

<a id="p0046"></a>
**P0046** > 关键结论：只要表现正常，只降低不会改变 CPC，只会减少垃圾曝光。

<a id="p0047"></a>
**P0047** （二）固定竞价（Fixed Bids）

<a id="p0048"></a>
**P0048** 说明： 亚马逊不对竞价做任何调整，跑什么数据就是什么数据。

<a id="p0049"></a>
**P0049** 各广告位实际竞价： 三个位置均为底价 X，不被动态调整。

<a id="p0050"></a>
**P0050** 适用情况：

<a id="p0051"></a>
**P0051** • 新品新活动（必须用固定）；

<a id="p0052"></a>
**P0052** • 测试活动（测词根、测款式、测竞价）；

<a id="p0053"></a>
**P0053** • 卡位广告（确保卡住 TOS 不被系统降权）；

<a id="p0054"></a>
**P0054** • 老链接也可以一直用（不会有什么问题）；

<a id="p0055"></a>
**P0055** 测试时必用固定竞价：

<a id="p0056"></a>
**P0056** • 测词根表现；

<a id="p0057"></a>
**P0057** • 测准词/泛词表现；

<a id="p0058"></a>
**P0058** • 测竞价（ABCD 四档）；

<a id="p0059"></a>
**P0059** • 测主推变体；

<a id="p0060"></a>
**P0060** （三）提高降低（Dynamic Bids - Up and Down）

<a id="p0061"></a>
**P0061** 说明： 在只降低的基础上，对更有可能转化的点击实时提高竞价。

<a id="p0062"></a>
**P0062** 实际规则（后台官方说明）：

<a id="p0063"></a>
**P0063** • TOS 位置：最多提高 100%（即 2X）；

<a id="p0064"></a>
**P0064** • ROS / PP 位置：最多提高 50%（即 1.5X）；

<a id="p0065"></a>
**P0065** 关键结论：

<a id="p0066"></a>
**P0066** • TOS 只要有曝光 → 实际竞价一定是 2X；

<a id="p0067"></a>
**P0067** • ROS / PP 只要有曝光 → 实际竞价一定是 1.5X；

<a id="p0068"></a>
**P0068** • 亚马逊要么不卖，要么提到上限卖，不会给中间值；

<a id="p0069"></a>
**P0069** 旺季特别提示： 去年旺季亚马逊曾临时通知把 ROS/PP 的提高上限从 50% 调整为 100%，今年旺季可能再次如此，需留意。

<a id="p0070"></a>
**P0070** 目标竞价折算： 如果希望实际 CPC ≈ $3，使用提高降低时底价应给：

<a id="p0071"></a>
**P0071** • TOS：$3 ÷ 2 = $1.5；

<a id="p0072"></a>
**P0072** • ROS：$3 ÷ 1.5 = $2；

<a id="p0073"></a>
**P0073** 适用情况：

<a id="p0074"></a>
**P0074** • 佛系管理的卖家（懒得精细调控，让亚马逊帮你加）；

<a id="p0075"></a>
**P0075** • 店群运营（活动多，不想逐个调广告位）；

<a id="p0076"></a>
**P0076** • 捡漏广告、漏斗最底层广告（给低底价 + 提高降低，更容易花出去）；

<a id="p0077"></a>
**P0077** • 辅推占坑广告；

<a id="p0078"></a>
**P0078** 不适用情况：

<a id="p0079"></a>
**P0079** • 精细化管理（与广告位加价叠加时非常难算）；

<a id="p0080"></a>
**P0080** • 需要控制每个广告位单独竞价时；

<a id="p0081"></a>
**P0081** > 提高降低 + 广告位加价叠加计算示意：

<a id="p0082"></a>
**P0082** > 底价 $2 × 提高降低（TOS 2X）= $4 → 再加 TOS 100% → $8

<a id="p0083"></a>
**P0083** > 极端情况可达 16X，建议不要把提高降低和广告位加价叠在一起用；

<a id="p0084"></a>
**P0084** （四）基于规则的竞价（Rule-Based Bidding）

<a id="p0085"></a>
**P0085** 建议：不要用。

<a id="p0086"></a>
**P0086** 原因：

<a id="p0087"></a>
**P0087** • 四年来一直是"测试版"，规则经常变；

<a id="p0088"></a>
**P0088** • RoAS 目标设置后，实际竞价难以预测（基于 CVR 动态调整）；

<a id="p0089"></a>
**P0089** • 如果 CVR 低，会帮你把竞价给到不合理的高位；

<a id="p0090"></a>
**P0090** 理解：可以看作"基于 CVR 的提高降低"（普通提高降低是基于 CTR），上限更高（可达 5X），更难控制。

<a id="p0091"></a>
**P0091** 可以拿一两个捡漏活动试试，但主力广告不建议使用。

<a id="p0092"></a>
**P0092** 三、广告位加价

<a id="p0093"></a>
**P0093** （一）三个广告位均可加价

<a id="p0094"></a>
**P0094** 公式：

<a id="p0095"></a>
**P0095** • TOS 实际竞价 = 底价 × (1 + TOS 加价%)

<a id="p0096"></a>
**P0096** • ROS 实际竞价 = 底价 × (1 + ROS 加价%)

<a id="p0097"></a>
**P0097** • PP 实际竞价 = 底价 × (1 + PP 加价%)

<a id="p0098"></a>
**P0098** 三个值各自独立，分别控制各广告位的出价。

<a id="p0099"></a>
**P0099** （二）PP 位置一般不加价

<a id="p0100"></a>
**P0100** PP 位置曝光量已经最多，不需要通过加价放量。

<a id="p0101"></a>
**P0101** 唯一加 PP 价的情况： 后续单独讲广告位缩量时会涉及。

<a id="p0102"></a>
**P0102** 常见误区： 有些卖家给 PP 位置加价，认为"PP 表现差是进价不够"——错！竞价只能改变曝光量，无法改变表现质量；表现差是产品本身决定的。

<a id="p0103"></a>
**P0103** （三）无效加价示例

<a id="p0104"></a>
**P0104** • 底价 $2.05，TOS 加 30% → 实际 TOS 竞价约 $2.6 → 根本买不起 TOS → 无效；

<a id="p0105"></a>
**P0105** • 三个广告位都加价但差距很小（如 TOS +100%，ROS +100%，PP +50%）→ 等于没加；

<a id="p0106"></a>
**P0106** • 有效加价 = 能够让目标广告位实际跑出曝光；

<a id="p0107"></a>
**P0107** （四）不同竞价策略不要叠加

<a id="p0108"></a>
**P0108** 以下三种不要混合使用（会指数级叠加竞价，极难计算）：

<a id="p0109"></a>
**P0109** • 提高降低；

<a id="p0110"></a>
**P0110** • 广告位加价；

<a id="p0111"></a>
**P0111** • 受众加价；

<a id="p0112"></a>
**P0112** • B2B 加价；

<a id="p0113"></a>
**P0113** 建议：一个活动只选一种竞价调控方式。

<a id="p0114"></a>
**P0114** 四、ABCD 竞价四档判定体系

<a id="p0115"></a>
**P0115** 核心原理： 根据三个广告位的曝光量比例，判断当前竞价处于哪个层级，从而倒推出各广告位的合理竞价。

<a id="p0116"></a>
**P0116** （一）基本规律

<a id="p0117"></a>
**P0117** 买家搜 1 次：

<a id="p0118"></a>
**P0118** • TOS 出 0-1 个曝光；

<a id="p0119"></a>
**P0119** • ROS 出 0-1 个曝光；

<a id="p0120"></a>
**P0120** • 独立板块出 0-1 个曝光；

<a id="p0121"></a>
**P0121** • PP 出约 6 个曝光（买家平均点开 3 个商品页，每页约 2 个适合的广告坑位）；

<a id="p0122"></a>
**P0122** 正常竞价下的 PP : ROS 曝光比例 = 2-5 倍（近年因商品页广告位减少，这个倍数已缩小）

<a id="p0123"></a>
**P0123** （二）四档竞价定义

<a id="p0124"></a>
**P0124** | 档位 | 名称 | 特征 | 含义 |

<a id="p0125"></a>
**P0125** |---|---|---|---|

<a id="p0126"></a>
**P0126** | A 竞价 | PP 竞价 | PP 大量曝光，ROS 曝光极少或几乎没有，TOS 无曝光；PP: ROS 比例 >> 5 倍 | 只能跑 PP 位置的进价；进价偏低 |

<a id="p0127"></a>
**P0127** | B 竞价 | ROS 竞价 | ROS 与 PP 曝光成正常比例（2-5 倍），TOS 无曝光或极少 | 能跑正常 ROS 位置（第一页中下部）；无法稳定跑 TOS |

<a id="p0128"></a>
**P0128** | C 竞价 | TOS 不稳定竞价 | 开始有一定 TOS 曝光，TOS : ROS 约 1:3 ~ 1:5；ROS 曝光随加价而减少（转移到 TOS）| 能到 TOS 但卡不住，偶尔到 TOS |

<a id="p0129"></a>
**P0129** | D 竞价 | TOS 卡位竞价 | TOS 曝光 ≥ ROS 曝光；PP 曝光比例正常或偏小 | 能稳定卡住 TOS 位置 |

<a id="p0130"></a>
**P0130** （三）判断步骤

<a id="p0131"></a>
**P0131** 第一步： 打开后台一个广告活动（固定竞价 + 不加价），看曝光量数据；

<a id="p0132"></a>
**P0132** 第二步： 计算 PP 曝光 / ROS 曝光的比值：

<a id="p0133"></a>
**P0133** • 比值 >> 5 → A 竞价（进价偏低）；

<a id="p0134"></a>
**P0134** • 比值 2-5，TOS 无曝光或极少 → B 竞价；

<a id="p0135"></a>
**P0135** • 比值正常，TOS 占 ROS 的 1/5-1/3 → C 竞价；

<a id="p0136"></a>
**P0136** • TOS ≥ ROS → D 竞价；

<a id="p0137"></a>
**P0137** 第三步（加价/提高降低情况下）： 当 PP 曝光被压制（预算不足导致 PP 被亚马逊压制，转移到搜索结果页位置），直接看 TOS 与 ROS 的比例来判断；

<a id="p0138"></a>
**P0138** （四）各档曝光示例

<a id="p0139"></a>
**P0139** A 竞价：

<a id="p0140"></a>
**P0140** • TOS 几乎 0，ROS 几十次，PP 几千次 → 进价不够跑 ROS；

<a id="p0141"></a>
**P0141** B 竞价：

<a id="p0142"></a>
**P0142** • TOS 无或极少（如 168 次/7天），ROS 4,800 次，PP 20,000 次

<a id="p0143"></a>
**P0143** • PP/ROS ≈ 4 → 成比例 → B 竞价；

<a id="p0144"></a>
**P0144** C 竞价：

<a id="p0145"></a>
**P0145** • TOS 1,300，ROS 6,400，PP 正常 → TOS 分到约 1/5 的曝光 → C 竞价；

<a id="p0146"></a>
**P0146** • 此时 ROS 曝光从加价前的 1,500 减少（转移 600 到 TOS）；

<a id="p0147"></a>
**P0147** D 竞价：

<a id="p0148"></a>
**P0148** • TOS 1,400，ROS 950 → TOS > ROS → 卡位竞价；

<a id="p0149"></a>
**P0149** • TOS 3.3 万，ROS 4.4 万 → 两者接近或 TOS > ROS → D 竞价；

<a id="p0150"></a>
**P0150** （五）ABCD 的实用对应关系

<a id="p0151"></a>
**P0151** | 档位 | 对应位置 | 后续投放应用 |

<a id="p0152"></a>
**P0152** |---|---|---|

<a id="p0153"></a>
**P0153** | A 竞价 | 只跑 PP 位置的最低竞价 | 捡漏广告底层竞价；PP 专属竞价 |

<a id="p0154"></a>
**P0154** | B 竞价 | 跑正常 ROS 位置 | 基准竞价（所有放量活动的起始竞价）|

<a id="p0155"></a>
**P0155** | C 竞价 | 能到 TOS 但卡不住 | ROS 高位竞价；TOS 竞价下限 |

<a id="p0156"></a>
**P0156** | D 竞价 | 稳定卡 TOS 位置 | TOS 卡位竞价 |

<a id="p0157"></a>
**P0157** 五、竞价测试方法

<a id="p0158"></a>
**P0158** （一）测试目标

<a id="p0159"></a>
**P0159** 找到产品的基准竞价（B 竞价） → 后续所有投放以此为锚点：

<a id="p0160"></a>
**P0160** • 一级词广泛用 B 竞价；

<a id="p0161"></a>
**P0161** • 二级词广泛用 B + 10%；

<a id="p0162"></a>
**P0162** • 精准用 B + 20%；

<a id="p0163"></a>
**P0163** • Auto 用 B - 20%；

<a id="p0164"></a>
**P0164** （二）测试前提条件

<a id="p0165"></a>
**P0165** 1. **必须用固定竞价**（不用提高降低，避免数据失真）；

<a id="p0166"></a>
**P0166** 2. **不要同时开其他活动**（其他活动的曝光会干扰判断）；

<a id="p0167"></a>
**P0167** 3. **测试活动预算 = 预估 CPA 的 3-5 倍**（够花出去就行）；

<a id="p0168"></a>
**P0168** （三）两种测试方式

<a id="p0169"></a>
**P0169** 方式 1：开 Auto 广告（前置否词）

<a id="p0170"></a>
**P0170** • 目的：快速跑一批准词，观察曝光比例；

<a id="p0171"></a>
**P0171** • 设置：Auto + 紧密匹配 + 否定掉不需要的词根 + 固定竞价；

<a id="p0172"></a>
**P0172** 方式 2：开手动广泛/词组/精准

<a id="p0173"></a>
**P0173** • 找 5-10 个大词，同进价开精准；

<a id="p0174"></a>
**P0174** • 或投一个一级词广泛，覆盖所有长尾词同进价跑；

<a id="p0175"></a>
**P0175** （四）判断竞价是否合理的两个指标

<a id="p0176"></a>
**P0176** 1. **搜索词曝光量与搜索量成正比**：大词（搜索量高）的曝光量要 > 小词（搜索量低）的曝光量；若出现长尾词曝光 > 大词曝光 → 进价偏低；

<a id="p0177"></a>
**P0177** 2. **广告位曝光结构呈现 B 或 C 档**：PP 曝光量正常，ROS 有曝光，不是 PP 独占；

<a id="p0178"></a>
**P0178** （五）测试流程

<a id="p0179"></a>
**P0179** 1. 从低竞价开始，逐步向上加价（每次加 10-20%）；

<a id="p0180"></a>
**P0180** 2. 每个价格观察 1-3 天；

<a id="p0181"></a>
**P0181** 3. 直到出现以下特征时停止：搜索词曝光量成正比 + 广告位曝光结构为 B 或 C；

<a id="p0182"></a>
**P0182** 4. 该竞价即为基准竞价；

<a id="p0183"></a>
**P0183** 老链接： 不用重新测，直接从历史广告数据推算 ABCD 即可（看某个活动的三个广告位曝光比例）。

<a id="p0184"></a>
**P0184** （六）ABCD 判定的不适用情况

<a id="p0185"></a>
**P0185** 以下情况看到的数据不准，不能用于判断：

<a id="p0186"></a>
**P0186** • 使用了"只降低"的新链接/低权重链接（曝光被砍，数据失真）；

<a id="p0187"></a>
**P0187** • 开了多个定向组的 Auto 广告（混合数据）；

<a id="p0188"></a>
**P0188** • 商品投放活动（PP 比例规律不适用）；

<a id="p0189"></a>
**P0189** • 同一活动大词小词混开（大词小词的广告位分布互相影响）；

<a id="p0190"></a>
**P0190** • 新链接从高竞价往下测（正确是从低到高往上探）；

<a id="p0191"></a>
**P0191** 六、本节总结

<a id="p0192"></a>
**P0192** | 主题 | 核心结论 |

<a id="p0193"></a>
**P0193** |---|---|

<a id="p0194"></a>
**P0194** | 广告位放量本质 | 控制各广告位曝光量，高价值位置（TOS）花费更多 |

<a id="p0195"></a>
**P0195** | 只降低 | 砍垃圾曝光，表现好的情况下 CPC 不变；适合老链接 |

<a id="p0196"></a>
**P0196** | 固定竞价 | 不受干预，适合新品/测试/卡位 |

<a id="p0197"></a>
**P0197** | 提高降低 | TOS 提到 2X，ROS/PP 提到 1.5X；适合佛系管理 |

<a id="p0198"></a>
**P0198** | 广告位加价 | 精细控制各广告位竞价；不与提高降低叠用 |

<a id="p0199"></a>
**P0199** | ABCD 竞价四档 | A=PP、B=ROS 基准、C=TOS 不稳定、D=TOS 卡位 |

<a id="p0200"></a>
**P0200** | 基准竞价 | 找到 B 竞价，以此为锚点搭建所有层级竞价结构 |

<a id="p0011"></a>

<a id="p0012"></a>
**P0012** 步骤 1：先找 10 分词

<a id="p0013"></a>
**P0013** 10 分词在你这儿一定是准的——把 10 分词拎出来到积木里查询有效自然位。

<a id="p0014"></a>
**P0014** 举例：balance bag 这个词——有效自然位是 4-19 位，下面同市场的别的词是 8-36 位。

<a id="p0015"></a>
**P0015** 步骤 2：根据有效位置定阈值

<a id="p0016"></a>
**P0016** 这个产品如果想拿自然流量，要找几分词？

<a id="p0017"></a>
**P0017** 10 分词。

<a id="p0018"></a>
**P0018** 为什么？这种产品有效位置很少：

<a id="p0019"></a>
**P0019** • 如果推 8 分词——8 分词的意思是你卖得最好的这一批竞品平均排名在 40 左右；

<a id="p0020"></a>
**P0020** • 拿 8 分词的话，你不能保证自己一定能到 40，你只能说最好到 40；

<a id="p0021"></a>
**P0021** 所以面对这种流量排名的情况，我们一般会直接找 10 分词——这就叫你的准词。

<a id="p0022"></a>
**P0022** （二）误判排查

<a id="p0023"></a>
**P0023** 接下来我们会去判断"有没有 8 分词被误判成 10 分词、有没有 10 分词被误判成 8 分词"。

<a id="p0024"></a>
**P0024** 直接到 8 分词层级找误判：

<a id="p0025"></a>
**P0025** • 如果产品 8-10 分词都是准词的话，往 6 分去找有没有误判即可。

<a id="p0026"></a>
**P0026** （三）方差大词的处理

<a id="p0027"></a>
**P0027** 找 8 分词后看有哪些词的方差特别大。

<a id="p0028"></a>
**P0028** 举例："one year old boy gift" 这个词——方差比较大。

<a id="p0029"></a>
**P0029** 判断方法：

<a id="p0030"></a>
**P0030** • 你觉得得分偏低还是偏高？

<a id="p0031"></a>
**P0031** • 有高有低综合 → 还是 8 分；

<a id="p0032"></a>
**P0032** • 觉得拉低了 → 抬到 10 分；

<a id="p0033"></a>
**P0033** • 反之同理；

<a id="p0034"></a>
**P0034** 进阶技巧：你们自己加一个方差公式去算几个数字之间的方差——找方差大的词直接处理。

**P0035** （四）准词的最终定义

<a id="p0036"></a>
**P0036** 其他词搜索量从高到低大致看一眼，问题不大就到这儿结束。

<a id="p0037"></a>
**P0037** 这个产品（平衡车）的最终定义：

<a id="p0038"></a>
**P0038** • 10 分词 = 准词；

<a id="p0039"></a>
**P0039** • 8 分词 = 也算是准词（但不能拿到高流量，推广时不要花太多亏损预算）；

<a id="p0040"></a>
**P0040** （五）多类型词的处理（玩具/礼物词）

<a id="p0041"></a>
**P0041** 这个产品的词有两个特性：

<a id="p0042"></a>
**P0042** 1. 准词（balance bag、stroller bag 等）；

<a id="p0043"></a>
**P0043** 2. 礼物词；

<a id="p0044"></a>
**P0044** 把礼物词也拿过来判断——是两类词。

<a id="p0045"></a>
**P0045** 礼物词的流量范围比较宽——这个产品如果拿准词的话能拿到前 20 是有效的，但是拿泛词（8 分词）的话这些位置都是有效的。

<a id="p0046"></a>
**P0046** 所以 8-10 分词都要——可以理解为 8-10 分词都要。

<a id="p0047"></a>
**P0047** 6 分词能不能要？6 分词其实算偏泛的，但也可以要——这些 6 分词的有效自然位也比较宽松，其实都是礼物词和玩具词等等。

<a id="p0048"></a>
**P0048** 把礼物词、玩具词都拿过来——比如 "ride on toys" 这些词。

<a id="p0049"></a>
**P0049** 6 分词的范围更宽广（223、53）——所以这些 6 分词其实你也能要。

<a id="p0050"></a>
**P0050** （六）平衡车的最终词库定义

<a id="p0051"></a>
**P0051** 这个产品分为两类词：

<a id="p0052"></a>
**P0052** 1. **准词**：全部在 10 分词里面（叫 baby bag、各种 bag、小孩的学步车）；

<a id="p0053"></a>
**P0053** 2. **泛词**：到 6 分词左右；

<a id="p0054"></a>

**P0056** 学员问题 1：低销量产品

<a id="p0057"></a>
**P0057** > 低销量产品跟低销量产品有什么关系？

<a id="p0058"></a>
**P0058** 不管销量是高还是低，你找的竞品是准的——它的 6 分不代表销量高低。6 分代表你的竞品都排在第 60 位左右——它没有 10 分词。

<a id="p0059"></a>
**P0059** 排查方法：

<a id="p0060"></a>
**P0060** 1. 看竞品 ASIN 的自然排名是不是有特别低的；

<a id="p0061"></a>
**P0061** 2. 找的是不是完全对标的竞品？

<a id="p0062"></a>
**P0062** 3. 是不是太苛刻了？条件可以适当放宽。

<a id="p0063"></a>
**P0063** 举例：汽车配件产品（车型专用座椅套）

<a id="p0065"></a>
**P0065** 回答：如果是汽车配件，你一定会有 10 分词——因为它一定有准的产品描述词（比如某某车型的某某座椅套）。虽然搜索量很小，但它是 10 分。

<a id="p0066"></a>
**P0066** 没有这样的词吗？——一定是你表格上面制作出了问题。

<a id="p0067"></a>
**P0067** 汽车配件有准词、有泛词：

<a id="p0068"></a>
**P0068** • 准词：具体车型 + 产品；

<a id="p0069"></a>
**P0069** • 泛词：seat（这种泛词）；

<a id="p0070"></a>
**P0070** 所以 seat 类泛词的 6 分正常，但准词得 6 分就不正常。

**P0096** （六）这个方法的局限性

<a id="p0097"></a>
**P0097** 为什么只适用于同质化标品？

<a id="p0098"></a>
**P0098** 举例：童车里面有 12-24 个月使用的（一两岁），也有大的车 2-5 岁使用的——

<a id="p0099"></a>
**P0099** 当把所有 ASIN 放进去时，1-2 岁得分高、2-5 岁得分也高——但它俩是两个东西。

<a id="p0100"></a>
**P0100** 举例：

<a id="p0101"></a>
**P0101** • "Stroller 1-3 岁"：显示高相关 → 都是学步车；

<a id="p0102"></a>
**P0102** • "Stroller 3-5 岁"：显示高相关 → 都是有点像自行车了；

<a id="p0103"></a>
**P0103** 两个词都显示高相关——其实没办法排掉真正的高相关，没办法找出真正的高相关。

<a id="p0104"></a>
**P0104** 所以调研方式是"类目流量词调研"，而不是"单品流量词调研"。

<a id="p0105"></a>
**P0105** 适用条件：除非这个类目的产品都是同质化的——比如 showerhead 手持花洒，相对都同质化，只有部分词不对，刨掉就行。

<a id="p0108"></a>
**P0108** 1. **Cerebro 多 ASIN 反查**（H10）→ 通用、适合所有产品；

<a id="p0109"></a>
**P0109** 2. **Keyword Research 多竞品拓词**（H10）→ 简单粗糙、适合同质化标品；

<a id="p0111"></a>
**P0111** 三、流量词调研的实际应用

<a id="p0112"></a>
**P0112** （一）应用 1：估算市场容量

<a id="p0113"></a>
**P0113** 市场容量 = 你理论上来说可占有的流量词入口的总搜索量 = 词的容量。

<a id="p0114"></a>
**P0114** 操作方法：选出能打的准词 → 在搜索量这一栏把鼠标框起来求和。

<a id="p0115"></a>
**P0115** 举例：

<a id="p0116"></a>
**P0116** • 平衡车（balance bike）：求和 169 万 → 算是大市场；

<a id="p0117"></a>
**P0117** • showerhead：157 万 → 也算大市场；

<a id="p0118"></a>
**P0118** • 1-2 万的 → 非常小的市场；

<a id="p0119"></a>
**P0119** 注意：季节性产品的市场容量会变。

<a id="p0120"></a>
**P0120** 如果用 H10 钻石版可以看到去年的某个月份搜索量。我现在用的是铂金版没有这个功能——你们如果用钻石版的话就可以。

<a id="p0121"></a>
**P0121** 两种容量预估：

<a id="p0122"></a>
**P0122** • 推不了泛词只能拿 8-10 分词 → 总量比较小；

<a id="p0123"></a>
**P0123** • 把泛词都算上 → 总量更大；

<a id="p0124"></a>
**P0124** 举例：

<a id="p0125"></a>
**P0125** • 平衡车 8-10 分词 → 40 万；

<a id="p0126"></a>
**P0126** • 平衡车（包含泛词） → 102 万；

<a id="p0127"></a>
**P0127** • 单纯 "balance bike" 这类核心准词的市场 → 22 万（不大）；

<a id="p0128"></a>
**P0128** 所以如果想要拿大市场，可能得往 6-8 分词去拿，这样才会有大点的体量。

<a id="p0129"></a>
**P0129** > 用这个功能也可以做选品调研——估算某个款式的市场容量。

<a id="p0130"></a>
**P0130** （二）应用 2：流量占比与主推方向

<a id="p0131"></a>
**P0131** 把准词表筛选 6-10 分词，会发现排布呈现一定规律。

<a id="p0132"></a>
**P0132** 类型 1：标品（10 分词为主）

<a id="p0133"></a>
**P0133** 举例：书灯（Book Light）

<a id="p0134"></a>
**P0134** 筛 6-10 分词以后大部分都是 10 分词，小部分是 6 分词。

<a id="p0135"></a>
**P0135** 这种产品就是非常典型的标品——打的词都很固定，泛词容量比较少。

<a id="p0136"></a>
**P0136** 推广策略：标品词居多 → 做投资型广告为主 → 推自然位为主。

<a id="p0137"></a>
**P0137** 类型 2：泛词准词各占一半

<a id="p0138"></a>
**P0138** 举例：锅碗瓢盆置物架 / 平衡车

<a id="p0139"></a>
**P0139** 透视表分析方法：

<a id="p0140"></a>
**P0140** 1. 全选数据；

<a id="p0141"></a>
**P0141** 2. 做数据透视表；

<a id="p0142"></a>
**P0142** 3. 表现得分放左边；

<a id="p0143"></a>
**P0143** 4. 搜索量放右边；

<a id="p0144"></a>
**P0144** 5. 计算各表现得分的搜索量总和；

<a id="p0145"></a>
**P0145** 举例：平衡车总量 102 万，其中 8-10 分词占比较低，6 分词占比相对较高 → 接近 60% 泛词、40% 准词。

<a id="p0146"></a>
**P0146** 类似产品：锅碗瓢盆置物架：6 分词占 40%、8-10 分词占 60%。

<a id="p0147"></a>
**P0147** 推广策略：得打准词也得打泛词。

<a id="p0148"></a>
**P0148** 核心顺序：

<a id="p0149"></a>
**P0149** 1. 推自然位时**先拿准词**（准词能拿自然位）→ 靠准词去拿流量和单量；

<a id="p0150"></a>
**P0150** 2. 有了单量以后 → **有了实际坑产、有了总单量**；

<a id="p0151"></a>
**P0151** 3. 靠总单量去拿泛词（靠实际坑产或某次活动把泛词打出来）；

<a id="p0152"></a>
**P0152** 关键点：

<a id="p0153"></a>
**P0153** • 泛词不会在初期去打，也不会在你没有单量的时候去打——这个时候泛词都拉不动；

<a id="p0154"></a>
**P0154** • 做得成功的话，你跟腰部产品的单量差距就拉开了——腰部产品基本没法超过你（他们没有实际单量、打不了泛词）。

**P0173** 第 17 名：差词、差位置、差宽度、差深度——以及词的体量大小都偏低。

<a id="p0174"></a>
**P0174** 第 1 名怎么滚出来的？原先月销 2 万多 → 滚到 3 万多 → 4 万多——一步一步去滚越来越泛的词。

<a id="p0175"></a>
**P0175** 核心打法（针对此类产品）：

<a id="p0176"></a>
**P0176** 如果你属于第 17 名的状态——先拿准词攒单量：

<a id="p0177"></a>
**P0177** • 没攒够单量 → gift、toy 这些词拿不到自然位（没有实际坑产）；

<a id="p0178"></a>
**P0178** • 攒够单量 → 像第 10 名一样——准词拿到了，泛词也拿到一些；

<a id="p0179"></a>
**P0179** • 这些 gift 词不需要打广告——前面说过这些词靠实际坑产自然吊在高位；

<a id="p0180"></a>
**P0180** 记住：广告不要努力推泛词——越推会越烂。广告干脆就不要推这些泛词。

<a id="p0181"></a>
**P0181** 核心规律：实际坑产能让自然位一直吊在高位。

<a id="p0182"></a>
**P0182** 如果是这类产品但推广方向乱——会很糟糕。

<a id="p0183"></a>
**P0183** 如果初始就把一半预算花在泛词上——会很糟糕。

<a id="p0184"></a>
**P0184** 但如果先把准词推上来再推泛词——非常容易、非常简单，而且很容易跟竞对拉开差距。

<a id="p0185"></a>
**P0185** 类型 3：泛词为主（准词非常少）

<a id="p0186"></a>
**P0186** 举例：玩具（火箭发射器）

<a id="p0187"></a>
**P0187** 准词非常少：

<a id="p0188"></a>
**P0188** • "Stomp Rocket"（踩火箭）是个准词；

<a id="p0189"></a>
**P0189** • "Rocket Launcher" 是个准词；

<a id="p0190"></a>
**P0190** • 但其他几岁小孩的玩具全部都是泛词；

<a id="p0191"></a>
**P0191** 比例：6 分词 20 多万 vs 8-10 分词 8 万——泛词比准词大多了。

<a id="p0192"></a>
**P0192** 这种产品有没有办法靠准词带动实际坑产？带不动。因为准词太小了，准词拿满总单量也就这么一点。

<a id="p0193"></a>
**P0193** 核心打法（针对此类产品）：

<a id="p0194"></a>
**P0194** 1. **打收录 + 实际坑产引爆**（最快的方式）：

<a id="p0195"></a>
**P0195** • 用 SP Auto 或广泛把想拿的词批量收录完；

<a id="p0196"></a>
**P0196** • 收录完后做单量；

<a id="p0197"></a>
**P0197** 2. **做单量的方法**：

<a id="p0198"></a>
**P0198** • 站内单量：做盈利型广告——通过广告随便买 100 单，所有收录词都能起来（因为词都不大）；

<a id="p0199"></a>
**P0199** • 站外单量：站外放量——这种产品（玩具）其实蛮好送的，打一波收录站外送，送完后自然位就会很高；

<a id="p0200"></a>
**P0200** 3. **维稳取决于评论数量和款式**——评论数量足够高或款式不错，自然位就能稳在还不错的位置。

<a id="p0201"></a>
**P0201** 4. **广告类型选择**：

<a id="p0202"></a>
**P0202** • SP 投放对这种产品效果不是很大——就是打收录；

<a id="p0203"></a>
**P0203** • 想买单量 → ASIN 投放（PT）最有效；

<a id="p0204"></a>
**P0204** • 原因：

<a id="p0205"></a>
**P0205** • ASIN 投放竞价偏低；

<a id="p0206"></a>
**P0206** • 找对标产品转化率比较高（5% 以内 → 10% 以上）；

<a id="p0207"></a>
**P0207** • ASIN 投放可以跑到 ASIN 的反查词，也可以打词的收录；

<a id="p0208"></a>
**P0208** （三）流量结构总结：三种类型的推广策略

<a id="p0209"></a>
**P0209** | 类型 | 特征 | 推广策略 |

<a id="p0210"></a>
**P0210** |---|---|---|

<a id="p0211"></a>
**P0211** | 类型 1：准词为主 | 标品，10 分词为主 | 直接打准词；流量集中→竞价高，流量分散→竞价低 |

<a id="p0212"></a>
**P0212** | 类型 2：准词泛词各半 | 半标 | 先打准词攒单量 → 实际坑产带泛词 |

<a id="p0213"></a>
**P0213** | 类型 3：泛词为主 | 非标/玩具 | 打收录 + 实际坑产引爆，重点用 PT |

<a id="p0252"></a>
**P0252** 对于泛词为主的产品：千万不要希望通过打准词把泛词翻出来——翻不出来（单量不够）。要么直接打泛词，要么通过实际坑产把泛词拎出来。

<a id="p0253"></a>
**P0253** （四）应用 3：流量离散程度

<a id="p0254"></a>
**P0254** 流量离散程度：我们想推的词的流量是否集中。

<a id="p0255"></a>
**P0255** > 平时区分大词和小词没有绝对标准，是相对自己产品而言的。

<a id="p0256"></a>
**P0256** 计算方法：搜索量占比 = 该词搜索量 ÷ 总搜索量。

<a id="p0257"></a>
**P0257** 类型 A：流量高度集中

<a id="p0258"></a>
**P0258** 特征：1-2 个大词占大部分流量。

<a id="p0259"></a>
**P0259** 案例 1：纸巾配套套子

<a id="p0260"></a>
**P0260** • 头两个词（单复数）合计占 50% 多；

<a id="p0261"></a>
**P0261** • 剩下都是 2%、1%、0.X% 的散词；

<a id="p0262"></a>
**P0262** 案例 2：成人电动牙刷

<a id="p0263"></a>
**P0263** • 头两个词占 65%；

<a id="p0264"></a>
**P0264** • 下面词占 35% 左右；

<a id="p0265"></a>
**P0265** 特点：

<a id="p0266"></a>
**P0266** • 新品白帽打法非常难推；

<a id="p0267"></a>
**P0267** • 刷单容易，白帽难：

<a id="p0268"></a>
**P0268** • 刷单可以保证好数据 + 控单量；

<a id="p0269"></a>
**P0269** • 白帽控单量很难；

<a id="p0270"></a>
**P0270** • 大词只有这么几个 → 所有竞争都冲着这两个大词怼 → 同质化产品 TOS 竞价爆高；

<a id="p0271"></a>
**P0271** • 优点：推上头部坑位以后比较难掉下来——因为大词自然流量加持很多，每天不需要输入多少广告单量，自然流足够大；

<a id="p0272"></a>
**P0272** • 占坑收益：会拿利润占头部坑位 → 新品更难打。

<a id="p0273"></a>
**P0273** 这类产品白帽新品不建议做——尤其是同质化标品。

<a id="p0274"></a>
**P0274** 几种应对策略：

<a id="p0275"></a>
**P0275** 1. **避开大市场，做标品里的细分小市场**（如纸巾——做竹制纸巾、三折纸巾、Bamboo 类的特殊配方）；

<a id="p0276"></a>
**P0276** 2. **冲着盈利型广告做，不卷自然位**——选择高单价的细分品（如台灯类目卷，但卖 $60 单价的台灯广告出一单就盈利）；

<a id="p0277"></a>
**P0277** 3. **直接做高单价标品**（避免被卷死）。

<a id="p0278"></a>
**P0278** 类型 B：流量相对分散

<a id="p0279"></a>
**P0279** 特征：头部几个大词占 35% 左右，下面一堆散词。

<a id="p0280"></a>
**P0280** 案例：

<a id="p0281"></a>
**P0281** • 儿童平板：头两个词占 35%；

<a id="p0282"></a>
**P0282** • 电动牙刷刷头：头两个词占 35%；

<a id="p0283"></a>
**P0283** • showerhead：头两个词占 43%；

<a id="p0284"></a>
**P0284** 特点：

<a id="p0285"></a>
**P0285** • 比较好推——拿头部大词吃不完整个市场，拿下面散词也吃不完；

<a id="p0286"></a>
**P0286** • 高预算推大词，低预算推小词都不耽误；

<a id="p0287"></a>
**P0287** • 不像类型 A 那样"非拿大词不可"。

<a id="p0288"></a>
**P0288** 反例（运营误区）：

<a id="p0289"></a>
**P0289** > 很多运营推广时只会盯着大词："我这个类目就这么两个大词"

<a id="p0290"></a>
**P0290** 判断方法：看大词流量占比。如果两个大词只占 40% 流量占比 → 小词不能忽视，都得要。

<a id="p0291"></a>
**P0291** 类型 C：流量非常分散

<a id="p0292"></a>
**P0292** 特征：最大的词也只占 8% 左右的流量占比。

<a id="p0293"></a>
**P0293** 案例：电动清洁刷

<a id="p0294"></a>
**P0294** • 最大词 8%；

<a id="p0295"></a>
**P0295** • 总市场体量 100 万 → 但每个词都只占很少（8 万、4 万、3 万、1 万多）；

<a id="p0296"></a>
**P0296** 形成原因：

<a id="p0297"></a>
**P0297** 原因 1：买家没有统一叫法

<a id="p0298"></a>
**P0298** 举例：电动清洁刷

<a id="p0299"></a>
**P0299** • 有人叫 "Spin"

<a id="p0300"></a>
**P0300** • 有人叫 "Electric Spin"

<a id="p0301"></a>
**P0301** • 有人叫 "Scrubber"

<a id="p0302"></a>
**P0302** • 有人叫 "ELERX Scrubber"

<a id="p0303"></a>
**P0303** • 还有 80 种 CK28 等等；

<a id="p0304"></a>
**P0304** 举例：吹尘器（Duster Blower）

<a id="p0305"></a>
**P0305** • 迷你小吹风；

<a id="p0306"></a>
**P0306** • 吹尘器；

<a id="p0307"></a>
**P0307** • 电脑清洁套装；

<a id="p0308"></a>
**P0308** 原因 2：核心词较长

<a id="p0309"></a>
**P0309** 有统一叫法但核心词很长。

<a id="p0310"></a>
**P0310** 举例：苹果手表 9 代 44 毫米的框

<a id="p0311"></a>
**P0311** • 核心词 = "Apple Watch + 几代 + 多少尺寸 + cover/protector"；

<a id="p0312"></a>
**P0312** • 买家搜索顺序如果是乱的 → 词也是零散的；

<a id="p0313"></a>
**P0313** 特点：

<a id="p0314"></a>
**P0314** 优点：

<a id="p0315"></a>
**P0315** • 新品每个词都很好推——CPC 都很低（词多 + 竞争分散）；

<a id="p0316"></a>
**P0316** • 比较快的打法：打一波收录 → 做实际坑产；

<a id="p0317"></a>
**P0317** • 实际坑产因为收录完了以后，每个词都不需要多 → 每个词都能很快起来；

<a id="p0318"></a>
**P0318** 缺点：

<a id="p0319"></a>
**P0319** • 流量很分散，不会调研流量入口的话非常容易遇到销量瓶颈：

<a id="p0320"></a>
**P0320** • 冲着大词去打很尴尬——大词很小；

<a id="p0321"></a>
**P0321** • 跟我说就打这两个词——总单量不可能上去（流量不在这儿）；

<a id="p0322"></a>
**P0322** • 广告占比下不来：

<a id="p0323"></a>
**P0323** • 每个词你好打、别人也好打；

<a id="p0324"></a>
**P0324** • 上去以后容易被新品打下来；

<a id="p0325"></a>
**P0325** • 对进攻好，对防守不好：

<a id="p0326"></a>
**P0326** • 流量集中型产品好防守（一直守在高位）；

<a id="p0327"></a>
**P0327** • 流量分散型产品好进攻；

<a id="p0328"></a>
**P0328** 实际坑产怎么做：站外、站内、低价都可以。

<a id="p0329"></a>
**P0329** 四、季节性词与"潜力词"调研

<a id="p0330"></a>
**P0330** （一）准词表会变

<a id="p0331"></a>
**P0331** 建议大家一两个月做一次准词表——因为流量词的流量会变。

<a id="p0332"></a>
**P0332** 举例：

<a id="p0333"></a>
**P0333** • "1 岁男孩的礼物" → 23 年搜索量 2.5 万 → 24 年低位维持 → 25 年突然涨上来（比前两年都高）；

<a id="p0334"></a>
**P0334** • "totally surprise" → 原先 4,000 → 现在 7 万（一个中等体量的词突然变成很大的词）；

<a id="p0335"></a>
**P0335** 这种词的价值：如果原先就占着一个还不错的位置，就非常容易推、非常容易拿到大流量。

<a id="p0336"></a>
**P0336** （二）找潜力词的实操方法

<a id="p0337"></a>
**P0337** 方法 1：从对标 ASIN 反查中找

<a id="p0338"></a>
**P0338** 操作：用西柚反查竞品时——右边浅色（去年）vs 紫色（今年）周搜索量对比，找搜索量暴涨的词。

<a id="p0339"></a>
**P0339** 很多产品想做流量增长的话——就是在找这种突涨的词，"跟你买股票是一个道理——看准它会涨、它开始往上涨一点了，你就开始入手"。

<a id="p0340"></a>
**P0340** 这种词不亏——因为是在它第一次走量的时候买进的。

<a id="p0341"></a>
**P0341** 方法 2：从搜索框联想词找

<a id="p0342"></a>
**P0342** 搜你的大流量词，看搜索框联想词。

<a id="p0343"></a>
**P0343** 正常情况：联想词搜索量从高到低排序（卖家精灵插件显示上个月搜索量）。

<a id="p0344"></a>
**P0344** 异常情况（潜力词）：本应是第二高搜索量的位置，却出现一个上个月搜索量偏小的词——那它就是即将变大的词。

<a id="p0345"></a>
**P0345** 操作步骤：

<a id="p0346"></a>
**P0346** 1. 找到这个词；

<a id="p0347"></a>
**P0347** 2. 拿到西柚的"关键词分析"功能，输入查看周搜索量趋势；

<a id="p0348"></a>
**P0348** 3. 如果在搜索框里位置很高 + 原来体量小 + 现在上升 → 赶紧打这个词；

<a id="p0349"></a>
**P0349** 4. **投产会很高**——达到一个高位，搜索量自己往上走，相当于"考上一个二本，等二本自己升成一本，你就赚了"。

<a id="p0350"></a>
**P0350** 方法 3：季节性产品（重点应用）

<a id="p0351"></a>
**P0351** 季节性产品经常有这样的搜索量变化。

<a id="p0352"></a>
**P0352** 案例：连衣裙

<a id="p0353"></a>
**P0353** • "Anthropologie 风格的礼服"；

<a id="p0354"></a>

**P0446** 关键洞察 1：流量离散 vs 广告集中

<a id="p0447"></a>
**P0447** • 产品流量是离散型的；

<a id="p0451"></a>
**P0451** • 准词里面大片显示 "NA"（没花费）；

<a id="p0452"></a>
**P0452** • "NA" 区域 = 你的推广盲区；

<a id="p0453"></a>
**P0453** 怎么解决？

<a id="p0454"></a>
**P0454** 1. **看广告集中是否带来效果**：

<a id="p0455"></a>
**P0455** • 集中精力怼几个词——这周怼这三个，下周怼那三个也可以；

<a id="p0456"></a>
**P0456** • 但要看自然位情况。

<a id="p0457"></a>
**P0457** 2. **加 CPA 数据判断盈亏**：

<a id="p0458"></a>
**P0458** • 假设产品利润 $12；

<a id="p0459"></a>
**P0459** • 高于 $12 的 CPA 都是亏损的；

<a id="p0460"></a>
**P0460** • 加条件格式标识；

<a id="p0461"></a>
**P0461** 3. **既然是亏损又集中，咱们要看结果——自然位**：

<a id="p0462"></a>
**P0462** • 要么推上去了；

<a id="p0463"></a>
**P0463** • 要么正在推；

<a id="p0464"></a>
**P0464** • 要么推完了（可以往回撤）；

<a id="p0465"></a>
**P0465** 4. **导入西柚自然位**。

<a id="p0466"></a>
**P0466** 自然位判断

<a id="p0467"></a>
**P0467** 不要简单看当前自然位——某词当前看是第 10 位，但用小时趋势看：他平时在前两位，只是今天突然波动到第 10 位。

<a id="p0468"></a>

<a id="p0469"></a>
**P0469** 推广策略调整

<a id="p0470"></a>
**P0470** 如果某个词自然位已经到第 2 位但广告还亏损：

<a id="p0471"></a>
**P0471** • 打广告的目的不存在了：

<a id="p0472"></a>
**P0472** • 拉自然位 ✗（已经在前 2）；

<a id="p0473"></a>
**P0473** • 占坑 ✓（但 CPA 要低）；

<a id="p0474"></a>
**P0474** • 不能为占坑亏损太多；

<a id="p0475"></a>
**P0475** 结论：把预算从亏损又卡住的大词腾挪到没在推的盲区词。

**P0542** 关键原则：单优势 vs 多优势

<a id="p0543"></a>
**P0543** • 只有 1 个优势维度 → 投放转化率优势不大；

<a id="p0544"></a>

**P0545** （六）商品投放的几种方式（后台层级）

**P0554** （七）ASIN 精准投放分组实操

<a id="p0555"></a>
**P0555** 举例：瘦脸相机产品

<a id="p0556"></a>
**P0556** 主要维度：价格、配置、功能（还有评分等其余维度）。

<a id="p0557"></a>
**P0557** 测试结果：

<a id="p0558"></a>
**P0558** • 分组 1：价格更高 + 配置更低（两个优势）→ 表现最好；

<a id="p0559"></a>
**P0559** • 分组 X：价格更低 + 配置更低 → 表现最差（对方价格比我低）；

<a id="p0560"></a>
**P0560** 找优势维度做好分类——优势维度很简单：

<a id="p0561"></a>
**P0561** • 竞品标题里面写了它的功能参数；

<a id="p0562"></a>
**P0562** • 找到符合我们要求的竞对；

<a id="p0563"></a>
**P0563** • 看图片有没有问题；

<a id="p0564"></a>
**P0564** • 找销量比较好的竞对（销量不好的竞对你投他 ASIN 他也没曝光）；

<a id="p0565"></a>
**P0565** 收集的标准：

<a id="p0566"></a>
**P0566** • 实际上他商品里面有流量；

<a id="p0567"></a>
**P0567** • 你对比它有优势（你不是没优势的）；

<a id="p0568"></a>
**P0568** （八）商品投放表现差的几个常见原因

<a id="p0569"></a>
**P0569** 原因 1：CPC 给太高

<a id="p0570"></a>
**P0570** 商品投放 CPC 不要给太高——也不需要做广告调价。

<a id="p0571"></a>
**P0571** 因为你并不是在定向地给某个词加权，所以尽量不要在这里亏钱。

<a id="p0572"></a>
**P0572** 原因 2：商品投放与关键词投放抢广告位

<a id="p0573"></a>
**P0573** 商品投放的竞价不要给得比关键词高。

<a id="p0574"></a>
**P0574** 反面案例：

<a id="p0575"></a>
**P0575** • 通过领星出单搜索词反查；

<a id="p0576"></a>
**P0576** • 看到搜索词对应的反查词 + ASIN 投放也跑出来了；

<a id="p0577"></a>
**P0577** • ASIN 投放竞价 $3.28 → 比关键词还高；

<a id="p0578"></a>
**P0578** 结果：ASIN 投放在这个词抢预算 → 关键词投放在这个词花了 $300 多，ASIN 投放也花了 $285，且 ACoS 还很高（位置不好）。

<a id="p0579"></a>
**P0579** 所以商品投放要投得好：

<a id="p0580"></a>
**P0580** • 竞价不能给得高；

<a id="p0581"></a>
**P0581** • 把它当作平本型广告就行；

<a id="p0582"></a>
**P0582** 原因 3：CVR 太低

<a id="p0583"></a>
**P0583** 情况 A：直接投类目、ASIN 拓展、Auto——不挑 ASIN，不挑就投什么。

<a id="p0584"></a>
**P0584** 情况 B：用心做了类目细分，但维度太粗：

<a id="p0585"></a>
**P0585** • 举例：你卖 9.99（一个装），投到 $12.9（两个装）的 → 你其实更贵；

<a id="p0586"></a>
**P0586** • 亚马逊后台的类目细分维度太粗；

<a id="p0587"></a>
**P0587** 结论：做细的维度全部都自己把竞品收集起来，自己做维度区分——这样 ASIN 投放表现不可能比商品投放差。

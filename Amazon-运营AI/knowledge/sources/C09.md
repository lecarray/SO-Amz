**P0012** （二）推广洞察表的三个大方向

<a id="p0013"></a>
**P0013** 做推广洞察表，先确定自己后续推广的大方向：

<a id="p0014"></a>
**P0014** 1. **增销量**；

**P0015** 2. **降 ACoS**；

<a id="p0016"></a>

<a id="p0017"></a>
**P0017** （三）推广洞察表的分析步骤

<a id="p0018"></a>
**P0018** 第一步：判断每条词的 CPA 是否高于定价毛利

<a id="p0019"></a>
**P0019** • CPA > 毛利 → 投资型广告；

<a id="p0020"></a>
**P0020** • CPA < 毛利 → 盈利型广告；

<a id="p0021"></a>
**P0021** 第二步：投资型广告的判断

<a id="p0022"></a>
**P0022** 投资型广告（SP 广告做预期坑产干预）需要满足以下三个条件，才值得继续维持：

<a id="p0023"></a>
**P0023** 1. **正向干预**：通过 CVR 和 CTR 判断（是否在提升自然位）；

<a id="p0024"></a>
**P0024** 2. **足量干预**：通过 CPR 对照广告单量判断；以及自然位小时趋势是否在波动上升；

<a id="p0025"></a>
**P0025** 3. **未到瓶颈位**：如果已卡到瓶颈，不必再亏损投入；

<a id="p0026"></a>
**P0026** 三个条件不满足 → 降低投资型广告的亏损

<a id="p0027"></a>
**P0027** 降亏损的两种方式：

<a id="p0028"></a>
**P0028** • 直接降花费：同样的 CPA 水平，但整体花费减少（从 17,000/月降到 12,000/月）；

<a id="p0029"></a>
**P0029** • 降 CPA：把亏损程度压缩到可接受的平本或微亏区间；

<a id="p0030"></a>
**P0030** 第三步：盈利型广告根据公司需求放量/缩量

<a id="p0031"></a>
**P0031** • 纯利型广告（ACoS < 目标 TACoS）→ 所有产品均可放量；

<a id="p0032"></a>
**P0032** • 盈利型广告（ACoS < 毛利率）→ 公司不限 TACoS 要求时放量；

<a id="p0033"></a>
**P0033** • 全部广告放量 → 公司不计亏损只求单量时使用；

<a id="p0034"></a>
**P0034** （四）推广洞察表示例分析

<a id="p0035"></a>
**P0035** 观察维度：

<a id="p0036"></a>
**P0036** • 花费占比偏向大词 → 小词没有预算花 → TACoS 是否用满？

<a id="p0037"></a>
**P0037** • 没用满 → 直接给小词放量；

<a id="p0038"></a>
**P0038** • 用满了 → 先缩大词花费，再给小词放量；

<a id="p0039"></a>
**P0039** • 高 CPA 词（标红部分） → 投资型广告：

<a id="p0040"></a>
**P0040** • 看自然位是否已卡住；

<a id="p0041"></a>
**P0041** • 看 CVR 是否正向干预；

<a id="p0042"></a>
**P0042** • 两者都不满足 → 降花费或降 CPA；

<a id="p0043"></a>
**P0043** > 接下来的内容，将教大家在缩放量之前，如何先界定广告成本（CPC/CVR/CTR），判断数据是好是坏，以及有没有压缩空间。

<a id="p0044"></a>
**P0044** 二、竞价（CPC）市调体系

<a id="p0045"></a>
**P0045** （一）CPC 的决定因素

<a id="p0046"></a>
**P0046** CPC 由三个因素共同决定：

<a id="p0047"></a>
**P0047** 1. **竞对出价**：竞对决定该类目大致的基准 CPC；

<a id="p0048"></a>
**P0048** 2. **自身表现**：表现越好，CPC 可以压得越低；表现越差，需要给得越高；

<a id="p0049"></a>
**P0049** 3. **广告活动权重**：老活动权重高，CPC 更低；

<a id="p0050"></a>
**P0050** 推论：想要压低 CPC，三个方向：

<a id="p0051"></a>
**P0051** • 了解竞对出价区间；

<a id="p0052"></a>
**P0052** • 提升自身表现（CTR/CVR）；

<a id="p0053"></a>
**P0053** • 使用高权重老活动；

<a id="p0054"></a>
**P0054** （二）为什么不能参考后台建议竞价？

<a id="p0055"></a>
**P0055** 后台建议竞价存在"价格歧视"和"信息茧房"：

<a id="p0056"></a>
**P0056** • 同个产品在不同店铺的后台建议竞价不一样（因为根据各自表现定价）；

<a id="p0057"></a>
**P0057** • 亚马逊自己说明：建议竞价是根据"类似广告的一组中标竞价"计算——本质是"给你单独定的挂牌价"；

<a id="p0058"></a>
**P0058** 导致后台建议竞价偏高的原因：

<a id="p0059"></a>
**P0059** 1. **自己大方**：给得越高 → 后台建议价跟着涨；

<a id="p0060"></a>
**P0060** 2. **表现差（CTR/CVR 低）**：表现差 → 后台抬高建议价补偿；

<a id="p0061"></a>
**P0061** 3. **内部重复投放**：互相竞价 → 抬高实际 CPC；

<a id="p0062"></a>
**P0062** 4. **卡位软件**：强制卡高位 → 拉高 CPC；

<a id="p0063"></a>
**P0063** 注意：表现差导致的抬价会同时影响同品牌/同店铺的所有产品——被抬是"一抬全抬"。

<a id="p0064"></a>
**P0064** （三）客观竞价的调研方法

<a id="p0065"></a>
**P0065** 调研目标：找到"空白账号竞价"（未被杀熟的客观市场价）

<a id="p0066"></a>
**P0066** 工具推荐：Sellics（Cerebro，即"C服"）

<a id="p0067"></a>
**P0067** 操作路径：选词 → 关键词转化率 → 把准词放进去查询 → 下载结果

<a id="p0068"></a>
**P0068** 数据字段：

<a id="p0069"></a>
**P0069** • 建议竞价最低；

<a id="p0070"></a>
**P0070** • 建议竞价推荐（中位数）；

<a id="p0071"></a>
**P0071** • 建议竞价最高；

<a id="p0072"></a>
**P0072** 注意：同一个词在不同节点建议竞价不同 → 选择自己产品对应的节点。

<a id="p0073"></a>
**P0073** 为什么推荐 C服而非其他工具？

<a id="p0074"></a>
**P0074** | 工具 | 问题 |

<a id="p0075"></a>
**P0075** |---|---|

<a id="p0076"></a>
**P0076** | 卖家精灵 | 只抓词组匹配竞价，不准 |

<a id="p0077"></a>
**P0077** | H10 | 只抓一栏（精准），但实测与 C服差距较多 |

<a id="p0078"></a>
**P0078** | C服（Sellics） | 数据最全：同时给出低/中/高三档，且按节点区分 |

<a id="p0079"></a>
**P0079** H10 的准词表导出后也会带竞价数据，可以辅助参考（通过 API 接口抓取，相对准确），但建议以 C服为主。

<a id="p0080"></a>
**P0080** 竞价三档的后台逻辑

<a id="p0081"></a>
**P0081** 后台给出的三个数字实际上是：

<a id="p0082"></a>
**P0082** • 建议竞价最低 = 后台竞价区间低档；

<a id="p0083"></a>
**P0083** • 建议竞价（蓝色大数字） = 低档和高档的中位数；

<a id="p0084"></a>
**P0084** • 建议竞价最高 = 后台竞价区间高档；

<a id="p0085"></a>
**P0085** 举例：最低 $1.28、最高 $2.20 → 中位数 = $1.59（后台显示的蓝色建议竞价）。

<a id="p0086"></a>
**P0086** 所以后台蓝色建议竞价并不是某种"推荐价"，只是一个中位数——不要盲目跟随。

<a id="p0087"></a>
**P0087** （四）竞价调研的操作步骤

<a id="p0088"></a>
**P0088** 步骤 1：选 5-10 个准词（尽量选 10 分准词）

<a id="p0089"></a>
**P0089** 步骤 2：放入 C服 "关键词转化率" → 查询 → 下载

<a id="p0090"></a>
**P0090** 步骤 3：拿到低/中/高三档竞价，取中位数

<a id="p0091"></a>
**P0091** 操作方法（以除尘器产品为例）：

<a id="p0092"></a>
**P0092** • 最低档：去掉最大值和最小值 → 取中位数 ≈ $2.6；

<a id="p0093"></a>
**P0093** • 推荐档（中位数竞价）：去掉最大最小 → 取中位数 ≈ $3.7；

<a id="p0094"></a>
**P0094** • 最高档：去掉最大最小 → 取中位数 ≈ $4.9；

<a id="p0095"></a>
**P0095** → 该产品的客观竞价范围：$2.6 ~ $4.9

<a id="p0096"></a>
**P0096** 这个范围是该类目所有词通用的参考竞价：

<a id="p0097"></a>
**P0097** • 实际 CPC > $4.9 → 一定给高了；

<a id="p0098"></a>
**P0098** • 实际 CPC 在 $2.6 ~ $4.9 内 → 正常；

<a id="p0099"></a>
**P0099** • 实际 CPC < $2.6 → 高权重老品，或在做捡漏型广告；

<a id="p0100"></a>
**P0100** （五）三组数据的对比体检

<a id="p0101"></a>
**P0101** 建立三个对比基准：

<a id="p0102"></a>
**P0102** | 数据来源 | 含义 | 获取方式 |

<a id="p0103"></a>
**P0103** |---|---|---|

<a id="p0104"></a>
**P0104** | 工具软件竞价（空白账号竞价） | 客观市场批发价 | C服导出 |

<a id="p0105"></a>
**P0105** | 账号内建议竞价 | 亚马逊给你的挂牌价（含杀熟） | 后台投放页面导出（低/中/高三档） |

<a id="p0106"></a>
**P0106** | 实际投放竞价 | 你当前实际在用的竞价 | ERP 按匹配方式筛选 |

<a id="p0107"></a>
**P0107** 三个对比及结论

<a id="p0108"></a>
**P0108** 对比 1：工具软件竞价 vs 账号内建议竞价

<a id="p0109"></a>
**P0109** • 两者接近 → 账号层面无问题；

<a id="p0110"></a>
**P0110** • 账号内建议竞价明显偏高 → 账号层面有问题（杀熟/同品牌/同店铺有差链接拉高了）；

<a id="p0111"></a>
**P0111** 对比 2：账号内建议竞价 vs 实际投放竞价

<a id="p0112"></a>
**P0112** • 实际竞价 < 账号建议竞价 → 产品权重高，还有下压空间；

<a id="p0113"></a>
**P0113** • 实际竞价 ≈ 账号建议竞价（且账号建议竞价已偏高）→ 运营根据虚高价格跟着给了，问题较大；

<a id="p0114"></a>
**P0114** 对比 3：工具软件竞价 vs 实际投放竞价

<a id="p0115"></a>
**P0115** • 实际竞价 > 工具软件竞价 → 给高了；

<a id="p0116"></a>
**P0116** • 实际竞价 ≈ 工具软件竞价 → 正常；

<a id="p0117"></a>
**P0117** • 实际竞价 < 工具软件竞价 → 高权重；

<a id="p0118"></a>
**P0118** 只做最简单对比

<a id="p0119"></a>
**P0119** 如果没有时间做三个对比，只做对比 3（工具软件竞价 vs 实际竞价）即可。

<a id="p0120"></a>
**P0120** （六）三个案例分析

<a id="p0121"></a>
**P0121** 案例一：电子相框（正常产品）

<a id="p0122"></a>
**P0122** • 工具软件竞价：$3.3 ~ $6.0；

<a id="p0123"></a>
**P0123** • 账号内建议竞价：与工具软件一致；

<a id="p0124"></a>
**P0124** • 实际竞价：$2.5 ~ $3.5（低于工具软件）；

<a id="p0125"></a>
**P0125** 结论：账号层面无问题；产品权重高，实际竞价低于批发价，可以继续尝试降价（讲价）。

<a id="p0126"></a>
**P0126** 这种情况下，后台建议竞价已无参考价值，建议直接隐藏这一栏，不让它干扰判断。

<a id="p0127"></a>
**P0127** 案例二：宠物用品（账号问题）

<a id="p0128"></a>
**P0128** • 工具软件竞价：$1.7 ~ $3.5；

<a id="p0129"></a>
**P0129** • 账号内建议竞价：$2.8 ~ $4.6（明显偏高）；

<a id="p0130"></a>
**P0130** • 实际竞价：商品投放 $2.23、广泛 $3.5、精准 $4.3；

<a id="p0131"></a>
**P0131** 结论：

<a id="p0132"></a>
**P0132** • 对比 1 → 账号层面竞价偏高，有高竞价行为或差链接存在；

<a id="p0133"></a>
**P0133** • 对比 2 → 实际竞价低于账号建议竞价，运营自控得还行；

<a id="p0134"></a>
**P0134** • 对比 3 → 实际竞价高于工具软件，有继续下压空间；

<a id="p0135"></a>
**P0135** 行动：排查账号内是否有高竞价行为，同时尝试逐步压低实际竞价。

<a id="p0136"></a>
**P0136** 案例三：笔记本电脑 + 分屏版（店铺混合问题）

<a id="p0137"></a>
**P0137** 分屏版（无问题产品）：

<a id="p0138"></a>
**P0138** • 工具软件竞价：$0.6 ~ $1.2；

<a id="p0139"></a>
**P0139** • 账号内建议竞价：$1.75 ~ $2.82（明显偏高）；

<a id="p0140"></a>
**P0140** • 实际竞价：$0.7；

<a id="p0141"></a>
**P0141** 结论：这个产品本身没问题，但同店铺的笔记本电脑把账号建议价拉高了。

<a id="p0142"></a>
**P0142** 笔记本电脑（有问题产品）：

<a id="p0143"></a>
**P0143** • 工具软件竞价：$0.4 ~ $1.1；

<a id="p0144"></a>
**P0144** • 账号内建议竞价：$2.0 ~ $3.12；

<a id="p0145"></a>
**P0145** • 实际竞价：$3.1（接近建议竞价最高档）；

<a id="p0146"></a>
**P0146** 结论：运营根据偏高的建议价给了高竞价，且实际竞价已接近建议价上限 → 自己抬价了。

<a id="p0147"></a>
**P0147** > 亚马逊会跟着你给的价格逐步抬高建议竞价——给 $3.1，后台会慢慢涨到 $4.1……形成恶性循环。

<a id="p0148"></a>
**P0148** （七）判断竞价是否给高了的三种特征

<a id="p0149"></a>
**P0149** 特征 1：广告位偏向 PP（商品详情页）

<a id="p0150"></a>
**P0150** 在固定竞价且无广告位加价的情况下：

<a id="p0151"></a>
**P0151** • 花费大部分偏向 TOS → 权重高（好事）；

<a id="p0152"></a>
**P0152** • 花费大部分偏向 PP → 表现差（百分百是差的）；

<a id="p0153"></a>
**P0153** 举例：固定竞价 $1.3，花费 $136 中 $125 在 TOS → 权重高。

<a id="p0154"></a>
**P0154** 特征 2：建议竞价远高于实际竞价但依然在跑

<a id="p0155"></a>
**P0155** 举例：后台建议竞价 $1.47 ~ $2.45，实际只给 $1.37（低于最低档），但依然在 TOS 大量出现 → 权重非常高，可以继续往下压。

<a id="p0156"></a>
**P0156** 特征 3：实际 CPC 明显低于 Bid（出价）

<a id="p0157"></a>
**P0157** Bid（出价）和 CPC（实际点击费用）是两回事。

<a id="p0158"></a>
**P0158** • 如果你 Bid 给 $2.0，但实际 CPC 跑出来 $1.6（低了 20% 以上）→ 一定给高了，可以降价；

<a id="p0159"></a>
**P0159** • 实际 CPC < Bid 20%+ → 百分百可以下压竞价；

<a id="p0160"></a>
**P0160** （八）如何压低竞价（讲价）

<a id="p0161"></a>
**P0161** 可以压价的两种情况：

<a id="p0162"></a>
**P0162** 1. **竞价虚高**（自己或同账号别的产品抬高了）；

<a id="p0163"></a>
**P0163** 2. **产品高权重**（表现好，CPC 天然可以低）；

<a id="p0164"></a>
**P0164** 不能压价的情况：表现差（CTR/CVR 低） → 压了亚马逊就不卖给你。

<a id="p0165"></a>
**P0165** 压价方式

<a id="p0166"></a>
**P0166** • 表现好 / 虚高 → 逐步压价或快速压价；

<a id="p0167"></a>
**P0167** • 表现差 → 只能慢速压价，且效果有限，得先调整表现；

<a id="p0168"></a>
**P0168** 案例：慢速压价

<a id="p0169"></a>
**P0169** 某产品从 $2.0 逐步压，每周降约 $0.1，花费 1 个多月从 $2.0 压到 $1.4。

<a id="p0170"></a>
**P0170** 案例：快速压价（高权重产品）

<a id="p0171"></a>
**P0171** | 时间 | CPC | CVR | ACoS | CPA | 客单价 | 花费 |

<a id="p0172"></a>
**P0172** |---|---|---|---|---|---|---|

<a id="p0173"></a>
**P0173** | 1月下旬（初始） | $1.71 | 1.2% | 20% | $55 | $270 | $1,400/周 |

<a id="p0174"></a>
**P0174** | 2月下旬（1个月后） | $0.43 | 2.6% | 5.96% | $16 | $270 | $1,800/周 |

<a id="p0175"></a>
**P0175** CPC 从 $1.71 压到 $0.43，CVR 从 1.2% 提升到 2.6%，ACoS 从 20% 降到 6%，CPA 从 $55 降到 $16——广告从投资型变成了纯利型！

<a id="p0176"></a>
**P0176** 且花费不降反升（$1,400 → $1,800），说明压竞价不是为了省钱，而是花更聪明的钱。

<a id="p0177"></a>
**P0177** 旺季压价

<a id="p0178"></a>
**P0178** 旺季属性越强的产品，旺季的竞价越容易压低。

<a id="p0179"></a>
**P0179** • 旺季流量增大 → 单位流量变便宜 → CPC 自然可以压低；

<a id="p0180"></a>
**P0180** • 淡季流量减少 → 僧多粥少 → 一般需要抬竞价维持花费；

<a id="p0181"></a>
**P0181** 举例：旺季某产品 ACoS 从 100% 降到 30% 再降到 10%，同时广告单量持续增长，最终 ACoS 降到纯利型区间 → 花费无限放量。

<a id="p0182"></a>
**P0182** （九）竞价体检总结

<a id="p0183"></a>
**P0183** | 步骤 | 操作 |

<a id="p0184"></a>
**P0184** |---|---|

<a id="p0185"></a>
**P0185** | 1. 工具软件竞价调研 | C服查 5-10 个准词，导出低/中/高三档竞价，取各档中位数 |

<a id="p0186"></a>
**P0186** | 2. 与实际 CPC 对比 | 看推广洞察表或搜索词汇总表里的 CPC，判断是否偏高 |

<a id="p0187"></a>
**P0187** | 3. 偏高时排查原因 | 先排查 CVR（见下节）；不是 CVR 问题的就是自己给高了（重复投放/竞价策略/卡位盲目卡位等） |

<a id="p0188"></a>
**P0188** | 4. 合理时看下压空间 | 淡旺季趋势 + 产品表现 → 判断是否可以逐步讲价 |

<a id="p0189"></a>
**P0189** 三、转化率（CVR）判定方法

<a id="p0190"></a>
**P0190** （一）为什么要判断 CVR？

<a id="p0191"></a>
**P0191** • CPA = CPC ÷ CVR

<a id="p0192"></a>
**P0192** • 要降 CPA，要么降 CPC，要么提升 CVR；

<a id="p0193"></a>
**P0193** • 需要先知道我的 CVR 是否达标（正向干预的标准）；

<a id="p0194"></a>
**P0194** （二）每个类目有自己的 CVR 基准范围

<a id="p0195"></a>
**P0195** CVR 的判断标准：对照同类目的 CVR 正常范围，而不是和其他品类横向比较。

<a id="p0196"></a>
**P0196** （三）有明确节点的标品/半标：用后台品牌指标

<a id="p0197"></a>
**P0197** 路径：广告后台 → 洞察和规划 → 品牌指标

<a id="p0198"></a>
**P0198** 操作步骤：

<a id="p0199"></a>
**P0199** 1. 点击"更改品类"；

<a id="p0200"></a>
**P0200** 2. 选到**最小节点**（如：电子相框）；

<a id="p0201"></a>
**P0201** 3. 点击"在此品类中查看品牌的详细指标"；

<a id="p0202"></a>
**P0202** 4. 看"顾客转化率"：

<a id="p0203"></a>
**P0203** | 指标 | 含义 |

<a id="p0204"></a>
**P0204** |---|---|

<a id="p0205"></a>
**P0205** | 您的品牌 | 你品牌旗下所有产品的综合转化率 |

<a id="p0206"></a>
**P0206** | 品类中位数 | 该类目所有产品转化率的中位数 |

<a id="p0207"></a>
**P0207** | 首要品类（高位数） | 该类目头部卖家的转化率 |

<a id="p0208"></a>
**P0208** 判断基准：自己的 CVR 不要低于品类中位数。

<a id="p0209"></a>
**P0209** 举例：电子相框节点 → 品类中位数 13%，首要品 20% → 推广过程中广告 CVR 尽量不低于 13%。

<a id="p0210"></a>
**P0210** 注意：

<a id="p0211"></a>
**P0211** • 不同店铺/品牌看同一节点，品类中位数和首要品数据是一致的（这是类目客观数据）；

<a id="p0212"></a>
**P0212** • 单价/类目节点差异大的产品，这个数据不那么准；

<a id="p0213"></a>
**P0213** （四）节点不明确或非标产品：三种替代方法

<a id="p0214"></a>
**P0214** 方法 1：购买竞品广告报表

<a id="p0215"></a>
**P0215** • 购买头部卖家 + 腰部卖家各一个全店铺广告报表；

<a id="p0216"></a>
**P0216** • 推荐买垂直品类的店铺（多个同类产品的数据更有参考价值）；

<a id="p0217"></a>
**P0217** • 可以直接看到竞品的 CPC、CVR、ACoS 等核心数据；

<a id="p0218"></a>
**P0218** • 价格波动较大，便宜时甚至不到 1,000 元；

<a id="p0219"></a>
**P0219** 方法 2：跟卖 + 等待后台数据

<a id="p0220"></a>
**P0220** • 在前台跟卖某竞品（库存设为 0）；

<a id="p0221"></a>
**P0221** • 约两周后，后台会出现该品类的品牌指标（节点数据）；

<a id="p0222"></a>
**P0222** • 适用于还没推广过的产品想提前了解数据；

<a id="p0223"></a>
**P0223** 方法 3：工具软件估算

<a id="p0224"></a>
**P0224** C服"关键词转化率"功能：

<a id="p0225"></a>
**P0225** • 操作路径与查竞价相同，同一页面；

<a id="p0226"></a>
**P0226** • 数据来源：后台 ABA（点击量准，但购买量只算 24 小时内）；

<a id="p0227"></a>
**P0227** C服转化率偏低的原因：

<a id="p0228"></a>
**P0228** 1. ABA 里的购买量只统计点击后 **24 小时内**的购买，单价较高的产品决策周期更长 → 购买量低估；

<a id="p0229"></a>
**P0229** 2. 多变体产品：买家点了变体 A 买了变体 B → 不计入该变体的购买量 → 严重低估；

<a id="p0230"></a>
**P0230** 适用范围：中低客单价 + 无变体（或少变体）的产品 → C服数据相对准。

<a id="p0231"></a>
**P0231** 西柚"点击转化率"功能：

<a id="p0232"></a>
**P0232** • 采用"自研算法 + 全周期转化率"计算方式；

<a id="p0233"></a>
**P0233** • 相对其他工具更准；

<a id="p0234"></a>
**P0234** • 缺点：数据不全，很多词是空的；

<a id="p0235"></a>
**P0235** • 适用范围：中高客单价 / 有变体的产品；

<a id="p0236"></a>
**P0236** （五）四种产品的 CVR 查询建议

<a id="p0237"></a>
**P0237** | 产品类型 | 推荐方法 |

<a id="p0238"></a>
**P0238** |---|---|

<a id="p0239"></a>
**P0239** | 有明确节点的标品/半标 | 后台品牌指标（洞察和规划）|

<a id="p0240"></a>
**P0240** | 中低客单价、无变体 | C服关键词转化率 |

<a id="p0241"></a>
**P0241** | 中高客单价或多变体 | 西柚点击转化率 |

<a id="p0242"></a>
**P0242** | 以上都搞不清楚 | 购买竞品全店铺广告报表（头部 + 腰部各一份）|

<a id="p0243"></a>
**P0243** 四、本节小结

<a id="p0244"></a>
**P0244** 本节介绍了在广告放量/缩量之前需要做的三项关键"体检"工作：

<a id="p0245"></a>
**P0245** 体检 1：竞价（CPC）市调

<a id="p0246"></a>
**P0246** 1. 用 C服查 5-10 个准词的低/中/高三档建议竞价，取中位数确定竞价范围；

<a id="p0247"></a>
**P0247** 2. 与自己实际 CPC 对比，判断是否偏高；

<a id="p0248"></a>
**P0248** 3. 偏高时：排查 CVR（看是不是表现差导致的）；

<a id="p0249"></a>
**P0249** 4. 不是表现差 → 就是自己给高了 → 可以压价；

<a id="p0250"></a>
**P0250** 体检 2：转化率（CVR）判定

<a id="p0251"></a>
**P0251** 1. 查同类目品类中位数 CVR；

<a id="p0252"></a>
**P0252** 2. 自己广告 CVR 是否不低于品类中位数；

<a id="p0253"></a>
**P0253** 3. 明显偏低 → 表现差 → 投资型广告不能正向干预 → 考虑暂停或优化链接再打；

<a id="p0254"></a>
**P0254** 4. 达标 → 投资型广告可能是有效干预 → 看单量是否足量；

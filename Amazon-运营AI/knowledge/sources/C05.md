<a id="p0007"></a>
**P0007** 一、广告预算规划：TACoS 是关键

<a id="p0008"></a>
**P0008** （一）什么是 TACoS？

<a id="p0009"></a>
**P0009** 我们推广的本质是一种做投入产出的行为。所以我们在做任何推广前，对于产品都会有"我对这个产品愿意投入多少"的规划。

<a id="p0010"></a>
**P0010** 这个投入基本上不会是一个绝对值，而是一个相对值——我们管它叫 TACoS（Total Advertising Cost of Sales），也就是广告花费占总销售额的比例。

<a id="p0011"></a>
**P0011** 这个比例你可以理解为叫做"广告利润损耗"——也有些卖家叫它"广销比"或"费比"，反正全都是这个东西。

<a id="p0012"></a>
**P0012** TACoS 数字越大代表你广告损耗的花费就越多。

<a id="p0013"></a>
**P0013** 所以现在不管你的广告一天花费是 1000 美金、1万美金还是 200 美金都无所谓，反正看的是 TACoS 数值是多高：

<a id="p0014"></a>
**P0014** • TACoS 高 → 利润损耗就高；

<a id="p0015"></a>
**P0015** • TACoS 低 → 利润损耗就低。

<a id="p0016"></a>
**P0016** 所以对于一个产品推广之前需要先做一个 TACoS 的规划：

<a id="p0017"></a>
**P0017** • 对于某些新品完全没有销量的产品，会先给一个总亏损的额度；

<a id="p0018"></a>
**P0018** • 对于已经有销量的产品，都会去规划这样一个东西。

<a id="p0019"></a>
**P0019** （二）链接整体亏损的几大原因

<a id="p0020"></a>
**P0020** 现在有些公司跟我讲："老师我的推广是亏钱的，我的整个产品都是亏钱的"——但凡你的产品是亏钱的，要么因为是在新品期/刚上架的产品，如果不是新品期的话，一定是因为你没有做好 TACoS 制定。

<a id="p0021"></a>
**P0021** 整条链接亏损的几大原因：

<a id="p0022"></a>
**P0022** 原因一：没有制定 TACoS

<a id="p0023"></a>
**P0023** 根本就没有这个概念——但这种问题在一些成熟卖家里面是很少的。

<a id="p0024"></a>
**P0024** 原因二：制定了 TACoS，但是跟绩效不挂钩

<a id="p0025"></a>
**P0025** 也就是说你 TACoS 制定了以后跟没制定一样——反正运营花超了也无所谓，反正他拿的可能是利润总利润的提成，而不是拿这个跟 TACoS 没关系。

<a id="p0026"></a>
**P0026** 所以你可能定下来 TACoS 是 10%，但是运营就往 15、20、30 去花都有可能——因为无所谓。

<a id="p0027"></a>
**P0027** 所以你得跟绩效挂钩起来才行。

<a id="p0028"></a>
**P0028** 原因三：TACoS 定得太死板

<a id="p0029"></a>
**P0029** 比如一个新品，你硬要人家 TACoS 控制在 10 个点以内、或 8 个点、5 个点以内不太现实——因为人家没有自然单。所以当 TACoS 太死板、没办法达成的时候，运营也就放飞了，就无所谓了。

<a id="p0030"></a>
**P0030** 结论：如果产品 TACoS 定好了，且跟绩效挂钩、运营严格去执行的，链接是不太可能会亏到一个你预想不到的数字的。

<a id="p0031"></a>
**P0031** （三）TACoS vs ACoS

<a id="p0032"></a>
**P0032** 首先 TACoS 跟我们的 ACoS 不一样，大家知道吧？

<a id="p0033"></a>
**P0033** • ACoS = 广告花费 ÷ 广告销售额。ACoS 高低只能代表你广告本身亏损多还是少还是盈利的。

<a id="p0034"></a>
**P0034** • TACoS = 广告花费 ÷ 总销售额。TACoS 能代表整条链接是盈利的还是亏的。

<a id="p0035"></a>
**P0035** 所以总体来讲我们去看推广的话，不需要太注重定死 ACoS 是多少，而是需要定死 TACoS 多少。

<a id="p0036"></a>
**P0036** 在很多工具软件里面，TACoS 会写成 "ACOAS" 这个指标——很多软件都是这样子的。

<a id="p0037"></a>
**P0037** （四）TACoS 怎么定？

<a id="p0038"></a>
**P0038** TACoS 由两个数值决定：

<a id="p0039"></a>
**P0039** 1. **定价毛利**

<a id="p0040"></a>
**P0040** 2. **店铺层面的产品纯利**

<a id="p0041"></a>
**P0041** 很多卖家跟我讲"毛利"的时候其实讲的是店铺里扣了广告费的毛利。我们现在讲的"毛利"全部都是定价毛利。最后店铺层面我们管它叫纯利。

<a id="p0042"></a>
**P0042** 举例：

<a id="p0043"></a>
**P0043** • 产品定价毛利 30%；

<a id="p0044"></a>
**P0044** • 店铺层面要留 15 个点的纯利；

<a id="p0045"></a>
**P0045** • 那么 TACoS = 30% − 15% = 15%

<a id="p0046"></a>
**P0046** （五）不同时期的 TACoS 规划

<a id="p0047"></a>
**P0047** 1. 新品期

<a id="p0048"></a>
**P0048** • 第一种公司：随便打——你要的是总单量，比如总单量给我放到 50-100，不管你亏多少先放出去，过了两三个月以后再要求空下来；

<a id="p0049"></a>
**P0049** • 第二种公司：可以亏，但整体亏损不超过 20%。

<a id="p0050"></a>
**P0050** • 假设定价毛利 30%，TACoS 可以定到 50%（因为店铺要亏 20%，所以 30% − (−20%) = 50%）。

<a id="p0051"></a>
**P0051** 2. 放量期（成长期）

<a id="p0052"></a>
**P0052** 单量要增长到某个目标单量。

<a id="p0053"></a>
**P0053** • 大方公司：TACoS 没有任何要求；

<a id="p0054"></a>
**P0054** • 一般公司：可以亏损但不能超过 10 个点 → TACoS 40%；

<a id="p0055"></a>
**P0055** • 平本要求 → TACoS 30%；

<a id="p0056"></a>
**P0056** • 留 5% 纯利 → TACoS 25%；

<a id="p0057"></a>
**P0057** • 留 15% 纯利 → TACoS 15%。

<a id="p0058"></a>
**P0058** 3. 维稳期

<a id="p0059"></a>
**P0059** 现在我的单量要维稳，但是利润要优化。

<a id="p0060"></a>
**P0060** • 平本（亏损做到平稳）；

<a id="p0061"></a>
**P0061** • 微盈利；

<a id="p0062"></a>
**P0062** • 15% 纯利。

<a id="p0063"></a>
**P0063** 不同公司要求不一样，不同品类的情况也不一样。

<a id="p0064"></a>
**P0064** 4. 盈利期

<a id="p0065"></a>
**P0065** 产品比较稳定，单量稳定——不需要再优化单量，只需要把整体利润做大。

<a id="p0066"></a>
**P0066** • 一般 10-20 个点的纯利要求；

<a id="p0067"></a>
**P0067** • 最差最低也要求 5 个点。

<a id="p0068"></a>
**P0068** > 这些点数还不包含人工、场地等成本，所以一般来说有些卖家把它叫做毛利，但你最后到手还要扣别的东西，所以 5 个点算是比较少的了。

<a id="p0069"></a>
**P0069** （六）TACoS 与广告的挂钩公式推导

<a id="p0070"></a>
**P0070** 制定好 TACoS 以后，怎么跟广告挂钩？这就很重要了。

<a id="p0071"></a>
**P0071** 错误公式

<a id="p0072"></a>
**P0072** 通常错误的写法：

<a id="p0073"></a>
**P0073** ACoS = 广告花费 ÷ 总销售额 = (CPC × 点击) ÷ (售价 × 点击 × 转化)

<a id="p0074"></a>
**P0074** 这样写不对——因为上面这个"点击"是广告点击，下面这个"点击"是总点击；下面"转化率"是总转化率。所以这样其实有 5 个变量存在，会让变量变得更多——这是 ACoS 的公式，不是 TACoS 的公式。

<a id="p0075"></a>
**P0075** 正确推导

<a id="p0076"></a>
**P0076** 我们要怎么把数据变量缩小？

<a id="p0077"></a>
**P0077** 先把总单量拉出来：

<a id="p0078"></a>
**P0078** • 广告单设成 X；

<a id="p0079"></a>
**P0079** • 自然单设成 Y；

<a id="p0080"></a>
**P0080** 总销售额 = (X + Y) × 售价

<a id="p0081"></a>
**P0081** 广告花费需要跟 X、Y、Price 产生联系：

<a id="p0082"></a>
**P0082** 由前面已知公式：CPA = CPC ÷ CVR

<a id="p0083"></a>
**P0083** 所以：广告花费 = 广告单 X × CPA

<a id="p0084"></a>
**P0084** TACoS 公式：

<a id="p0085"></a>
**P0085** ```

<a id="p0086"></a>
**P0086** TACoS = (CPA × X) ÷ [(X + Y) × Price]

<a id="p0087"></a>
**P0087** ```

<a id="p0088"></a>
**P0088** 根据乘法交换律变形：

<a id="p0089"></a>
**P0089** ```

<a id="p0090"></a>
**P0090** TACoS = (CPA ÷ Price) × [X ÷ (X + Y)]

<a id="p0091"></a>
**P0091** ```

<a id="p0092"></a>
**P0092** 简化后：

<a id="p0093"></a>
**P0093** ```

<a id="p0094"></a>
**P0094** TACoS = ACoS × 广告单占比

<a id="p0095"></a>
**P0095** ```

<a id="p0096"></a>
**P0096** > CPA ÷ Price = ACoS（前面讲过：ACoS = CPA ÷ 售价）

<a id="p0097"></a>
**P0097** > X ÷ (X + Y) = 广告单占比

<a id="p0098"></a>
**P0098** 所以 TACoS 的总公式很简单：TACoS = ACoS × 广告单占比

<a id="p0099"></a>
**P0099** （七）数据验算方法

<a id="p0100"></a>
**P0100** 在 ERP 里面：

<a id="p0101"></a>
**P0101** • TACoS 就是 ACOAS；

<a id="p0102"></a>
**P0102** • 广告单占比在 ERP 里面应该叫 SOS（广告销售额占比）。

<a id="p0103"></a>
**P0103** 验算公式：TACoS ≈ ACoS × SOS

<a id="p0104"></a>
**P0104** 举例：

<a id="p0105"></a>
**P0105** • ACoS 22% × SOS 19% ≈ TACoS 4%（实际 4.8%）

<a id="p0106"></a>
**P0106** • ACoS 31% × SOS 31% ≈ TACoS 10%

<a id="p0107"></a>
**P0107** 注意 SOS 是广告销售额占比，并不严格是广告单占比，所以是简化值，不会完全相等，但数值是接近的。

<a id="p0108"></a>
**P0108** > 如果你把红色这两列相乘 ≈ 蓝色这一列，验算就过了。

<a id="p0109"></a>
**P0109** （八）TACoS 公式的三个核心结论

<a id="p0110"></a>
**P0110** 结论 1：当 TACoS 固定时，ACoS 与广告单占比成反比

<a id="p0111"></a>
**P0111** 举例：当 TACoS 固定为 10% 时，可能的组合：

<a id="p0112"></a>
**P0112** • ACoS 30% × 广告单占比 33%

<a id="p0113"></a>
**P0113** • ACoS 27% × 广告单占比 39%

<a id="p0114"></a>
**P0114** • ACoS 57% × 广告单占比 23%

<a id="p0115"></a>
**P0115** 最极端的情况：ACoS 10% × 广告单占比 100%

<a id="p0116"></a>
**P0116** 所以广告单占比其实没有一个绝对要求的数值。

<a id="p0117"></a>
**P0117** > 如果有人告诉你"广告单占比一定要做到 50% 以下"——他也在扯淡，是因为他的经验太窄。如果经验宽一点，你就要知道：广告单占比其实没关系，只要 TACoS 定死了以后，ACoS 跟广告单占比成反比就可以了。

<a id="p0118"></a>
**P0118** 结论 2：TACoS ≤ ACoS（必定）

<a id="p0119"></a>
**P0119** 由于广告单占比必定 ≤ 100%，所以 TACoS 必定 ≤ ACoS。

<a id="p0120"></a>
**P0120** 应用：

<a id="p0121"></a>
**P0121** • 如果公司要求 TACoS 是 15%，且你能把 ACoS 做到 15% → 广告单可以随便花！

<a id="p0122"></a>
**P0122** • 因为广告单出一单就已经满足公司要求的纯利了。

<a id="p0123"></a>
**P0123** • 当 ACoS 小于目标 TACoS 的时候 → 广告可以随意花。

<a id="p0124"></a>
**P0124** 举例：公司要求 TACoS 20%，但我们 ACoS 都是 11%——广告真的可以随便放飞了，因为 ACoS 在 11% 的时候，即使广告单占比占到 100%，TACoS 也不可能超过 11%。

<a id="p0125"></a>
**P0125** 结论 3：ACoS 越接近目标 TACoS，广告单占比可以越高

<a id="p0126"></a>
**P0126** ACoS 越接近 TACoS → 广告单占比可以越高

<a id="p0127"></a>
**P0127** 反例：

<a id="p0128"></a>
**P0128** • 公司要求 TACoS 10%，你 ACoS 100%；

<a id="p0129"></a>
**P0129** • 那么广告单只能是 10% 占比；

<a id="p0130"></a>
**P0130** • 广告单 10% : 自然单 90%；

<a id="p0131"></a>
**P0131** • 10 个广告单能不能撬起 90 个自然单？大部分情况下很困难。

<a id="p0132"></a>
**P0132** 所以你的 ACoS 距离 TACoS 越远，代表你后续推广越麻烦、越难。

<a id="p0133"></a>
**P0133** 如果你能把 ACoS 做到 30% → 广告单占比能做到 33% → 自然单 66 + 广告单 33 → 这样轻松很多。

<a id="p0134"></a>
**P0134** 类比：单休 vs 双休

<a id="p0135"></a>
**P0135** 这两个的关系有点像单休跟双休——差的不是一天：

<a id="p0136"></a>
**P0136** • 单休：上 6 天休 1 天；

<a id="p0137"></a>
**P0137** • 双休：上 5 天休 2 天；

<a id="p0138"></a>
**P0138** • 它俩差的不是一天的休息日。

<a id="p0139"></a>
**P0139** 自然单跟广告单也是一样——是此消彼长的状态：

<a id="p0140"></a>
**P0140** • 90 + 10 → 你要用 10 个广告单撬 90 个自然单（很难）；

<a id="p0141"></a>
**P0141** • 66 + 33 → 33 个广告单撬 66 个自然单（轻松）。

<a id="p0142"></a>
**P0142** 所以尽量让你的 ACoS 接近 TACoS——TACoS 差的越小，你推得越简单、越主动。

<a id="p0143"></a>
**P0143** 二、广告的三种类型分类

<a id="p0144"></a>
**P0144** （一）三种类型定义

<a id="p0145"></a>
**P0145** 根据 ACoS 与毛利率/TACoS 的关系，将广告分为三类：

<a id="p0146"></a>
**P0146** 1. 投资型广告

<a id="p0147"></a>
**P0147** ACoS ≥ 毛利率——出一单是亏损或不盈利的。

<a id="p0148"></a>
**P0148** 2. 盈利型广告

<a id="p0149"></a>
**P0149** ACoS < 毛利率——出一单是盈利的。

<a id="p0150"></a>
**P0150** 3. 纯利型广告

<a id="p0151"></a>
**P0151** ACoS < 目标 TACoS——出一单是直接增加纯利的。

<a id="p0152"></a>
**P0152** > 当单条广告的 ACoS 低于目标 TACoS 的时候，单条广告就可以随意花费——这是放量的广告。

<a id="p0153"></a>
**P0153** （二）案例：根据公司目标选择放量广告

<a id="p0154"></a>
**P0154** 某产品定价毛利 25%——代表 ACoS 低于 25% 的广告是盈利型广告。

<a id="p0155"></a>
**P0155** 但这些广告能不能随便出？不能——因为公司要求的 TACoS 不是 25%。

<a id="p0156"></a>
**P0156** 如果公司要求 TACoS 是 15%——这一堆广告里面只有 ACoS 13% 这一条能随便放。

<a id="p0157"></a>
**P0157** （三）四种公司目标对应的广告策略

<a id="p0158"></a>
**P0158** | 公司目标 | 可以无限花费的广告 |

<a id="p0159"></a>
**P0159** |---|---|

<a id="p0160"></a>
**P0160** | 单量最大化且不计亏损 | 所有广告都可以直接放量 |

<a id="p0161"></a>
**P0161** | 不亏损（保本） | ACoS ≤ 毛利率的广告（即盈利型广告） |

<a id="p0162"></a>
**P0162** | 利润最大化（保有纯利） | ACoS < 目标 TACoS 的广告（即纯利型广告） |

<a id="p0163"></a>
**P0163** 所有公司最终的目标应该都是在保有纯利率的情况下，做利润最大化——这个情况下你就只有 ACoS < 目标 TACoS 的广告可以随便花，这就是纯利型广告。

<a id="p0164"></a>
**P0164** （四）推广不同阶段的建议

<a id="p0165"></a>
**P0165** • 初期：建议把盈利型广告搭出来——让 ACoS < 毛利率；

<a id="p0166"></a>
**P0166** • 成熟期：建议把纯利型广告全部都做出来——不管你是不是做实际坑产类型的广告，都可以帮你直接做单量。

<a id="p0167"></a>
**P0167** 你现在可能链接卡住了、单量放不上去——是因为你执着在追求自然单，但我们可以不用管这个自然单。当你把纯利型广告去放量的时候，会发现：

<a id="p0168"></a>
**P0168** • 广告单占比涨了；

<a id="p0169"></a>
**P0169** • 总利润增加了；

<a id="p0170"></a>
**P0170** • TACoS 不变；

<a id="p0171"></a>
**P0171** • 纯利不变。

<a id="p0172"></a>
**P0172** （五）三个结论小结

<a id="p0173"></a>
**P0173** 1. 当 TACoS 为固定值时，ACoS 和广告单占比成反比；

<a id="p0174"></a>
**P0174** 2. ACoS 离 TACoS 越远，自然单推广压力越大；

<a id="p0175"></a>
**P0175** 3. 由于 TACoS 必定 ≤ ACoS，如果整体 ACoS < 目标 TACoS，广告出单占比是随意的。

<a id="p0176"></a>
**P0176** 广告分为三类：投资型、盈利型、纯利型。根据公司当前的目标不同，咱们去放量的广告类型也会不一样。

<a id="p0177"></a>
**P0177** （六）实战观察

<a id="p0178"></a>
**P0178** 回去把自己 ERP 里面这三类数据拉出来对比：

<a id="p0179"></a>
**P0179** • 同样 TACoS 4% 左右；

<a id="p0180"></a>
**P0180** • 有的产品做到 ACoS 20% × 广告单占比 20%；

<a id="p0181"></a>
**P0181** • 有的产品做到 ACoS 10% × 广告单占比 35%；

<a id="p0182"></a>
**P0182** • 下面这个产品的推广更轻松——因为广告单占比可以做得更高。

<a id="p0183"></a>
**P0183** 在总单量恒定的情况下，自然单推广压力更小。

<a id="p0184"></a>
**P0184** 回去看问题出在哪里：

<a id="p0185"></a>
**P0185** • 有的产品 TACoS 控不下来 → ACoS 太高；

<a id="p0186"></a>
**P0186** • 有的产品 TACoS 控不下来 → 广告单占比太高；

**P0187** 然后去优化对应部分。

**P0225** （一）亚马逊广告的触发流程

<a id="p0226"></a>
**P0226** 亚马逊的广告主要是被动触发性的广告，而非主动触发。

<a id="p0227"></a>
**P0227** 所以现在是买家搜什么，我们要决定我们先看买家搜什么，再想办法被他触发。

<a id="p0228"></a>
**P0228** 举例：现在买家搜索 ABC 这个词——我们的广告可以通过 ABC 精准、ABC 广泛、ABC 词组、Auto 全部都可以被它触发出来。

<a id="p0229"></a>
**P0229** 关键问题：买家搜了 ABC，触发了你的 ABC 广泛出单了——是 ABC 加权还是 ABC 广泛加权？

<a id="p0230"></a>
**P0230** 直接答案：ABC 加权。

<a id="p0231"></a>
**P0231** 买家搜什么、买了你，你就在什么词加权——跟你投什么关系并不大。即使你投的是 Auto，买家搜 ABC 通过 Auto 买了你，也在 ABC 加权。

<a id="p0232"></a>
**P0232** 所以我们的目标是搜索词，所以要去找搜索词，而不是先找投放词。

<a id="p0233"></a>
**P0233** 投放词会根据 BSR/竞价做排序，接下来广告形成曝光，被点击以后收费。

**P0352** 举例：放了 6 个 ASIN，5 个在打这个词的广告，平均排名第 9 → 大家都在推这个词。

<a id="p0353"></a>
**P0353** 如果 0 个 ASIN 在打 → 没人推这个词。

<a id="p0354"></a>
**P0354** 3. 推荐排名（平均 + 数量）

<a id="p0355"></a>
**P0355** 不用看，直接略过。

<a id="p0356"></a>
**P0356** 4. 自然排名

<a id="p0357"></a>
**P0357** • 第一个 ASIN（你的）的自然排名；

<a id="p0358"></a>
**P0358** • 主 ASIN 对其他竞品的相对排名；

<a id="p0359"></a>
**P0359** 主 ASIN 就是你放的第一个 ASIN——加粗显示。

<a id="p0360"></a>
**P0360** 5. 排名竞品的数量 + 竞品平均排名 ⭐ 重要

<a id="p0361"></a>
**P0361** 这两个数字非常重要：

<a id="p0362"></a>
**P0362** • 排名竞品数量：除主 ASIN 以外，有几个竞品在这个词排了名（最大值 = 总数 − 1）；

<a id="p0363"></a>
**P0363** • 竞品平均排名：他们的平均排名是多少；

<a id="p0364"></a>
**P0364** 类比：拉了几个学霸来考试——有几个学霸考出分数 + 他们平均分考了多少。

<a id="p0365"></a>
**P0365** • 数量越大越好；

<a id="p0366"></a>
**P0366** • 平均排名越小越好。

<a id="p0367"></a>
**P0367** 6. 竞品表现得分（最右边一列）⭐ 核心

<a id="p0368"></a>
**P0368** H10 直接帮你给这个词打分——分数越高代表综合表现越好。

<a id="p0369"></a>
**P0369** 举例：

<a id="p0370"></a>
**P0370** • showerhead 这个词：5 个竞品有排名，平均排名 7.4 → 10 分词（学霸来考试考了满分）；

<a id="p0371"></a>
**P0371** • 没分的 → 错词，根本考不出分数；

<a id="p0372"></a>
**P0372** • 8 分词 → 也算准词；

<a id="p0373"></a>
**P0373** • 0.8 分 → 错词（得分太低）。

<a id="p0374"></a>
**P0374** （五）评估标准

<a id="p0375"></a>
**P0375** | 得分 | 含义 |

<a id="p0376"></a>
**P0376** |---|---|

<a id="p0377"></a>
**P0377** | 10 分词 | 多个竞品有排名，平均排名在前 20 |

<a id="p0378"></a>
**P0378** | 8 分词 | 多个竞品有排名，平均排名在前 40 |

<a id="p0379"></a>
**P0379** | 6 分词 | 平均排名在前 60 |

<a id="p0380"></a>
**P0380** | 4 分词 | 平均排名在前 100 |

<a id="p0381"></a>
**P0381** 所以你的产品要筛几分词，取决于你的有效位置有多少个。

<a id="p0382"></a>
**P0382** （六）筛选准词

<a id="p0383"></a>
**P0383** 举例：showerhead 产品

<a id="p0384"></a>
**P0384** 筛选 6 分及以上的词 → 出来 2,055 个词。

<a id="p0385"></a>
**P0385** 为什么 6 分？6 分词的平均自然排位大概在 60 左右，是偏泛的。

<a id="p0386"></a>
**P0386** • showerhead 产品的有效位置在 22-95 → 6 分词也能拿到流量；

<a id="p0387"></a>
**P0387** • 反例：shock collar for dog 产品有效位置只有 27/6 → 只有 10 分词能保证推得动，8 分词都不一定。

<a id="p0388"></a>
**P0388** 所以筛词阈值取决于链接的阈值（有效位置）：

<a id="p0389"></a>
**P0389** • 有效位置多的产品 → 可以筛 6 分；

<a id="p0390"></a>
**P0390** • 有效位置少的产品 → 只能筛 8-10 分；

<a id="p0391"></a>
**P0391** 新品期 vs 成熟期：

<a id="p0392"></a>
**P0392** • 新品期：6 分词可能不会去拿；

<a id="p0393"></a>
**P0393** • 成熟链接：6 分词就要去拿。

<a id="p0394"></a>
**P0394** （七）导出表格

<a id="p0395"></a>
**P0395** 导出全表（11,000 个词都要导出，因为后面有他用）。

<a id="p0396"></a>
**P0396** 表格微调步骤：

<a id="p0397"></a>
**P0397** 把"竞品表现得分"和各 ASIN 自然排名移到前面。

<a id="p0398"></a>
**P0398** 为什么要纠偏？表现得分不一定是准的——表现得分是被动地根据这几个 ASIN 算出来的，可能会有偏差。

<a id="p0399"></a>
**P0399** 举例：showerhead with 某词 = 8 分——是因为有个 96 名（某个 ASIN 排很差）拉低了平均分。

<a id="p0400"></a>
**P0400** 纠偏方法：

<a id="p0401"></a>
**P0401** • 找方差比较大的排名；

<a id="p0402"></a>
**P0402** • 人为干预去判断是否准词；

<a id="p0403"></a>
**P0403** • 准词 → 改成 10 分；

<a id="p0404"></a>
**P0404** • 错词 → 降到 4 分；

<a id="p0405"></a>
**P0405** 纠偏例子：filter（带过滤器）

<a id="p0406"></a>
**P0406** 某个产品没有滤芯，filter 词就是 4 分以下；

<a id="p0407"></a>
**P0407** 但如果产品带滤芯，filter 词就应该是 8 分；

<a id="p0408"></a>
**P0408** → 把所有 filter 长尾词筛出来全部改成 8 分。

<a id="p0409"></a>
**P0409** 更好的方式：删掉那些不带滤芯的对比 ASIN，重新查一遍。

<a id="p0410"></a>
**P0410** （八）词库判断与对标分析

<a id="p0411"></a>
**P0411** 筛完 6-10 分词以后，导出剩下 2,300 个词——这就是你的准词表。

<a id="p0412"></a>
**P0412** 判断头部链接的拓词情况

<a id="p0413"></a>
**P0413** 筛 8-10 分词得到 1,690 个词 → 用这个数据对比竞品：

<a id="p0414"></a>
**P0414** 头部链接（如 BS2）：

<a id="p0415"></a>
**P0415** • 用西柚反查它的流量词 1,724 个；

<a id="p0416"></a>
**P0416** • 基本相符——他拿的流量词跟我们调研出的准词重叠 → 8-10 分词他都拿完了。

<a id="p0417"></a>
**P0417** 腰部链接：

<a id="p0418"></a>
**P0418** • 流量词 1,392 个；

<a id="p0419"></a>
**P0419** • 流量词数量不太够；

<a id="p0420"></a>
**P0420** • 自然位也都不太高；

<a id="p0421"></a>
**P0421** 所以你的链接想要做流量增长有两个方向：

<a id="p0422"></a>
**P0422** 1. **拿更多的词**（拓词）；

<a id="p0423"></a>
**P0423** 2. **已有的词去往更高的位置去跑**（拉自然位）；

<a id="p0424"></a>
**P0424** 看哪个更方便就做哪个事情。

<a id="p0425"></a>
**P0425** （九）筛词时的常见问题排查

<a id="p0426"></a>
**P0426** 问题 1：放的 ASIN 太多

<a id="p0427"></a>
**P0427** 如果放 10 个 ASIN 满，得分会被拉低，准词无法判断 → 3-5 个最合理。

<a id="p0428"></a>
**P0428** 问题 2：某个 ASIN 在拉低排名

<a id="p0429"></a>
**P0429** 判断方法：把鼠标放在"相对排名"这里，看哪个 ASIN 拖后腿。

<a id="p0430"></a>
**P0430** 举例：96 这个 ASIN 在拉低排名 → 看几个词如果它都在拉低 → 直接把它删掉重新查一遍。

<a id="p0431"></a>
**P0431** 但如果只是部分词在拉低，就保留。

<a id="p0432"></a>
**P0432** 问题 3：品牌名词差异大

<a id="p0433"></a>
**P0433** 某词 "Wonderland WiFi" → Wonderland 是品牌名 → 排名差异很大（一个无排名，另两个第 1、第 16）。

<a id="p0434"></a>
**P0434** → 品牌名一般我们不会给太高的得分。

<a id="p0435"></a>
**P0435** 问题 4：所有得分都不高

<a id="p0436"></a>
**P0436** 举例：笔记本电脑产品——MAC 词只有 2 分。

<a id="p0437"></a>
**P0437** 不代表这个词不准——代表所有竞品在这个词下自然位都推到 100 多了，最好就是 100 多平均排名。

<a id="p0438"></a>
**P0438** 这种产品在推广前就要做个预期：词是准的，但是排名是推不高的。

<a id="p0439"></a>
**P0439** 怎么办？

<a id="p0440"></a>
**P0440** 1. **放弃**——也是一种选择；

<a id="p0441"></a>
**P0441** 2. **拿广告流**：上架以后全靠广告买单——能不能买到盈利的广告？买不到的话产品确实不用做了；

<a id="p0442"></a>
**P0442** 3. **靠旗舰店带流量**：链接不推自然流也不打广告，放在旗舰店里——前提是产品是完整产品线 + 品牌已经有一定品牌效应 → 这种产品可以作为利润款。

<a id="p0443"></a>
**P0443** 问题 5：账号类型与价位

<a id="p0444"></a>
**P0444** 筛竞品时要区分：

<a id="p0445"></a>
**P0445** • 国际大牌 vs 第三方品牌；

<a id="p0446"></a>
**P0446** • VC 账号 vs SC 账号；

<a id="p0447"></a>
**P0447** • 自营 vs 第三方；

<a id="p0448"></a>
**P0448** • 价位（卖 $39 不要找 $19 的对比）；

<a id="p0449"></a>
**P0449** 这些都会影响自然排位的结果。

<a id="p0450"></a>
**P0450** 举例：作为 SC 账号去找 VC 账号的竞品——它的排名整体会算出来偏高。

<a id="p0451"></a>
**P0451** 所以竞品找得准的话，竞品表现得分这一栏是非常准的——能算出来你在哪些词能推、哪些词不能推。

<a id="p0452"></a>
**P0452** 六、Cerebro 完整操作流程示例

<a id="p0453"></a>
**P0453** 案例：平衡车

<a id="p0454"></a>
**P0454** 步骤 1：确定产品形态

<a id="p0455"></a>
**P0455** 我的产品做的是某一款平衡车——找跟它形态一样的：第 1-3 名、第 6 名（看款式、年纪等）、第 10 名。

<a id="p0456"></a>
**P0456** 收集这些 ASIN 放到收集表单里：

<a id="p0457"></a>
**P0457** • 把最差的（或自己的）放到最前面；

<a id="p0458"></a>
**P0458** • 把这些 ASIN 按顺序排好。

<a id="p0459"></a>
**P0459** 步骤 2：放入 Cerebro 反查

<a id="p0460"></a>
**P0460** 步骤 3：判断阈值

<a id="p0461"></a>
**P0461** 定好得分以后导出总表 → 从大到小排序。

<a id="p0462"></a>
**P0462** 回到网页端查出 18,000 个词——搜索量倒序。

<a id="p0463"></a>
**P0463** 步骤 4：筛 6 分词

<a id="p0464"></a>
**P0464** 筛 6 分以后没出来什么词就有问题。

<a id="p0465"></a>
**P0465** 正常：

<a id="p0466"></a>
**P0466** • 标品：10 分左右的准词，起码有几百到 1,000 个；

<a id="p0467"></a>
**P0467** • 半标/非标：可能有几千个。

<a id="p0468"></a>
**P0468** 步骤 5：纠偏

<a id="p0469"></a>

<a id="p0470"></a>

<a id="p0472"></a>
**P0472** 总结：Cerebro 准词调研步骤

<a id="p0473"></a>
**P0473** 1. **确定产品形态**；

<a id="p0474"></a>
**P0474** 2. **收集 3-5 个精品对标 ASIN**（标品从 BS 找，半标/非标从词里找，3-5 个就够，不要超过 6 个）；

<a id="p0475"></a>
**P0475** 3. **第一个位置放自己**（不计入竞品表现得分）；

<a id="p0476"></a>
**P0476** 4. **放入 Cerebro 反查**；

<a id="p0477"></a>
**P0477** 5. **根据产品阈值定筛选得分**（一般 6-10 分起步，但部分产品 8 分都够呛，部分产品 6 分也能筛进来）；

<a id="p0478"></a>
**P0478** 6. **从大到小排序导出全表**；

<a id="p0479"></a>
**P0479** 7. **去除拖后腿的 ASIN，重新反查**；

<a id="p0480"></a>
**P0480** 8. **导出最终表格做细加工纠偏**；

<a id="p0017"></a>
**P0017** 学员问题分类——四种思维层次

<a id="p0018"></a>
**P0018** 首先跟大家讲一下，大家来这边上课一定都是带着问题来的。在今天的第一天，大家需要先把这个问题理一下。这边因为我经常开答疑直播，会收到很多卖家的问题，大概可以归为几类：

<a id="p0019"></a>
**P0019** 第一类：泛性问题

<a id="p0020"></a>
**P0020** 比如说"服装类目怎么布局广告""同款类目怎么做""高客单价产品怎么推""季节性产品怎么做""新品怎么办"等等，这些问题都是非常泛的问题。为什么说泛呢？是因为它的变量过多——这个变量比如不确定因素里面，你链接本身的基础、定价区间、预算、资金、目标都不一样，所以其中产生任何一个变量都会导致你的推广方向完全不一样。

<a id="p0021"></a>
**P0021** 如果说你能问出来的最细的问题是这样子的话，那么当前来说你大概率是没有任何推广思路的。

<a id="p0022"></a>
**P0022** 第二类：点性思维问题

<a id="p0023"></a>
**P0023** 我们再说第二种好一点的问题，比如"怎么卡Top位""怎么提高广告曝光""投精准好还是投广泛好""出单词我要不要继续投""分时竞价有没有必要开"。这种问题我们称之为"点性思维"的问题。

<a id="p0024"></a>
**P0024** 为什么称之为点性思维？我们在推广过程当中有三个步骤：第一定方向，第二定策略，第三定执行。这类问题是属于执行层面的问题——比如"我怎么卡Top位"，这是执行层面；"我怎么提高曝光"，也是执行层面。但是我一般会问大家：你为什么要做这个事情？做这个事情的目的是什么？比如说你现在新品上来以后表现不怎么样，你说要去卡Top位，但这对你的新品表现没有任何帮助。所以咱们在做这些事情之前，先想一下：我想要定什么样的策略，我想要达成一个什么样的目的。

<a id="p0025"></a>
**P0025** 第三类：线性思维问题

<a id="p0026"></a>
**P0026** 再接下来一种是"线性思维"，也就是说它是有策略和执行的，比如"自然排名掉下来要不要用广告去稳住""同一个词在三个广告位出单是哪里加权更好"。这种问题代表你们是有一个目的的——比如目的是不想让自然位掉下来，或者目的是想要加权加得更好。那么这些都是你的目的，然后我们再由此来定执行。

<a id="p0027"></a>
**P0027** 第四类：面性思维问题

<a id="p0028"></a>
**P0028** 最后是"面性思维"的问题，是我个人最喜欢听到的问题，比如"老师，我怎么用7天秒杀来降低广告CPA？秒杀过程当中什么时候降比较好？需要注意什么？"当你问出这种问题的时候，说明你是有方向、有策略的，你的问题在于执行该怎么执行。

<a id="p0029"></a>
**P0029** 所以今天第一天，我希望大家都能够提出一个你们来这里想要解决的问题，而且越细越好。如果你问的是一个比较泛的问题，你能得到一个方向性的解答；如果你能问出一个具体的问题，你能得到方向、策略和执行三个层面的解答。所以你越有经验的卖家，越有经验的运营，你能问出来的问题越细，那么你在这里能得到的收获会越多。

<a id="p0030"></a>
**P0030** 推广逻辑：演绎法 vs 归纳法

<a id="p0031"></a>
**P0031** 再接下来说一下，在课前要跟大家提的一点：我们做推广有两种逻辑形式，第一种叫演绎法，第二种叫归纳法。

<a id="p0032"></a>
**P0032** 归纳法就是感性经验的归纳；演绎法就是理性思维的归纳。

<a id="p0033"></a>
**P0033** 大部分运营做得并不好，或者说做了很长的时间却没有自己的一套打法，大概率是因为你们用的是归纳法。归纳法是什么意思？比如说我之前推一个品，是这样推爆了，现在我换另外一个品的时候，也用一样的方法去推，然后你发现推不爆，就开始急了，从0开始试，又试出来一套方案觉得可行，到了第三个产品又不可行了。

<a id="p0034"></a>
**P0034** 所以归纳法的问题在于：你总结出的经验，未来出现一个特例，你的整个经验就会被推翻。现在市面上大部分告诉你们产品该怎么打的讲师，或者一些传授经验的卖家，大部分使用的都是归纳法，而归纳法比较碰运气——除非你遇到一个一模一样、能贴合的产品，否则就不适用了。

<a id="p0035"></a>
**P0035** 比如我们遇到一些运营，原先在做标品的公司，现在换了一家公司做的是非标品，但他用的是标品的打法在打非标品，注定打不起来。同样，你用非标品的打法打标品也是有问题的。

<a id="p0036"></a>
**P0036** 所以我们整个课程里面跟大家讲的是前面一种——演绎法的逻辑，从一般到特殊的推理，我们有大前提、小前提和结论三个部分。

<a id="p0037"></a>
**P0037** 我前面跟大家讲的，第一天会跟大家讲方向性和策略性的问题，到了第二天的中旬和第三天，我们才会开始讲具体的后台投放的执行。但是我讲的打法白帽和黑帽是通用的，所以不管在座各位是白帽、黑帽还是灰帽，前面的一天半对于你们的帮助都是很大的。

<a id="p0038"></a>
**P0038** 三、站内推广核心思路：流量来源全盘点

<a id="p0039"></a>
**P0039** 好，前面的前提就是这样子。接下来我们就正式进入"站内推广"的部分。

<a id="p0040"></a>
**P0040** 第一部分是关于站内推广的核心思路。这个核心思路指的是：我们想要做站内推广，是希望从站内获取到更多的流量，或者高性价比地获取到更多流量。我们的流量分为站内流量和站外流量两块。在做站内推广的过程当中，重点在于做站内，所以我们把站内流量区分一下，大概可以分为以下几块：

<a id="p0041"></a>
**P0041** （一）BS榜单流量

<a id="p0042"></a>
**P0042** 第一个就是BS（Best Seller）榜单可以给你带流量，对不对？流量大不大？这里说实话不大。从BS榜单来到你链接的流量是不大的，因为BS榜单是一个结果体现，而并不是过程体现。

<a id="p0043"></a>
**P0043** 如果想要验证BS榜单来不来流量，很简单：我今天做一个LD（Lightning Deal），把单量冲上去以后，BS榜单排名就上去了，那么这个单量能不能持续？如果可以的话，BS榜单就是来流量的；如果不可以，BS榜单就是不来流量的。所以这是个过程体现的话，我们就要努力去做这个过程——也就是我拉总销量，把BS拉上去就行了，这是第一个过程点。但如果我拉上去以后，单量并没有增长，这就是个结果值。

<a id="p0044"></a>
**P0044** 我这样讲BS榜单它的入口：在前台这里，如果想要进入BS榜单，可能从前面的Best Seller点进去，点进Best Seller以后，要一级级地找。但是大部分买家在知道自己要什么的情况下，他会直接去搜；不知道自己要什么的情况下，现在有Rufus可以帮他，所以他完全可以直接问Rufus"我应该买什么东西"或者"我想要什么样的东西，让他给我推荐"。所以现在来讲，BS榜单一级一级地找的人没有了。基本上卖家在选品的时候才会回到这一来找，这是第一个入口。

<a id="p0045"></a>
**P0045** 第二个入口：买家先搜一个词，比如随便搜一个词，搜完以后想要进到BS榜单。第一种方案：我点开一个BS Tag（Best Seller标签），第一个就是BS。点开这个BS以后，顶上现在没有了。以前BS Tag顶上会有一个入口给你进入到榜单，但现在如果没有的话，可能还得往下拉，拉到"iPhone GPS"里面，拉到这个地方把它点开，然后才能进入到榜单。所以现在进入榜单的路径会比较曲折，也比较麻烦。

<a id="p0046"></a>
**P0046** 所以你可以理解为：榜单基本上是卖家在看，买家不怎么看这个地方，所以这不是你要追求的地方。之前有卖家跟我说："老师，我BS榜单排名推到前20、推到前15，我不就有流量了吗？"不是的——是你先有流量才能推到BS榜单前15、前20。所以公司可以以BS榜单的排名为一个目标，但它绝对不是一个过程。

<a id="p0047"></a>
**P0047** （二）搜索结果页流量

<a id="p0048"></a>
**P0048** 接下来说第二种流量来源——搜索结果页流量。搜索结果页流量指的是：现在我搜了"showerhead"这个词，下面所出现的这些东西都叫搜索结果页流量。

<a id="p0049"></a>
**P0049** 搜索结果页流量有两个分布，一个叫自然流，一个叫广告流。

<a id="p0050"></a>
**P0050** 1. 自然流

<a id="p0051"></a>
**P0051** 自然流的核心逻辑：每个词下理论上你最多只能有一个自然位，不管你是做单链接还是多变体，你都只有一个自然位。所以如果想要获得更多的自然流量，有几个方式：

<a id="p0052"></a>
**P0052** 第一个方式：拓词（增加获得流量的词的数量）

<a id="p0053"></a>
**P0053** 也就是很多产品，尤其在新链接的时候，你会说要"拓词、打收录"；老链接也得拓词。新链接更多拓的是准词，老链接拓词会往泛词去拓。这个东西后面会再展开讲，现在你只需要知道流量词的数量很重要就可以了。

<a id="p0054"></a>
**P0054** 我们一般用Cerebro（H10）或者西柚找词去做对比。比如这边找第一个产品，把你想要查的ASIN放到西柚找词或Cerebro，去反查对方。反查以后，首先点击"附体（变体）"，然后往下拉，左上角会显示"变体在前三页的关键词有多少个"。现在这个产品前3页的词有1805个，也就是说我能获得流量的词有1805个，这是第一点。

<a id="p0055"></a>
**P0055** 我再换一个销量比较低的ASIN。刚刚查的ASIN月销量是26,000，我换一个月销在4,200的产品给大家查一下它的流量词数量。我们也往下拉，看一下左上角是1102个。它俩的差距：一个是1800，一个是1100。这就是流量词的宽度，差了700个词。

<a id="p0056"></a>
**P0056** 所以如果想要获得更多自然流的话，可以考虑往宽度去拓。这个宽度一般是跟你的竞对去对比的。有些新品你会发现只能查出来几十个词、100多个词或者500多个词，相比这些头部产品的1800个词来讲，差别都是非常大的。

<a id="p0057"></a>
**P0057** 第二个方式：推动流量词的自然位

<a id="p0058"></a>
**P0058** 因为你的自然位只有一个，自然位越高，能获得这个词下的流量就越大。所以我们会考虑：能不能把这个词下面的位置推得更高？

<a id="p0059"></a>
**P0059** 推得更高的话，自然位是有一个阈值的，就是你能占有的有效自然位的范围。这个数据指标我们一般通过另外一个软件叫"积木"去查（这个软件初期我没有让大家注册和下载，有最好，没有也没关系）。

<a id="p0060"></a>
**P0060** 举个例子：showerhead产品，我现在做的是淋浴头。我的自然位在106位，它是否是一个有效自然位？我在这能不能获得流量？有些人觉得不可以，有些人觉得可以——这个数值太模糊了。或者我往下拉到39位能不能有自然排名？也有觉得有的吧？大家都只能靠猜。

<a id="p0061"></a>
**P0061** 所以我们会把这些模棱两可的数字放到积木软件里面，有个叫"关键词查询"的地方，把这个词直接放进去反查"showerhead"，查出来以后会显示一个叫"目标排位建议"。这个建议有两行数字：第一行指的是90%的买家会在前几个产品当中完成查看，第二行大概50%的买家会在前几个产品当中查看。也就是说这个词我想要获得自然流，最起码要到107位；想要获得大头的流量，得推进前25。

<a id="p0062"></a>
**P0062** 说话人1 16:14

<a id="p0063"></a>
**P0063** 这个。

<a id="p0064"></a>
**P0064** 说话人3 16:15

<a id="p0065"></a>
**P0065** 就是你的自然排位目标，不同产品的目标自然排位不一样。现在我查的是淋浴喷头。如果换一个词，比如我搜一个"shock collar for dog"（狗的止吠器、狗的电击项圈），往下拉，你能看到这个目标排位建议是27和6。如果你的产品是这种"27和6"这样的有效自然位的话，那么它的推广会变得比较困难。

<a id="p0068"></a>
**P0068** 自然流量大小三要素总结：

<a id="p0069"></a>
**P0069** 1. 流量词的数量

<a id="p0070"></a>
**P0070** 2. 自然排位

<a id="p0071"></a>
**P0071** 3. 流量词的体量大小

<a id="p0072"></a>
**P0072** 这三者叠加共同决定。然后这三者里面你现在缺什么，就可以去补什么。

<a id="p0073"></a>
**P0073** 举个例子：有的卖家上来以后，先打流量词的数量，先广撒网，这是第一种策略。广撒网以后他想要重点培养，也就是去拉自然位。在拉自然位的过程当中，他可能发现大词拉不动，于是先去拉小词，先把小词拉了以后再去拉大词，这就是词的体量大小的问题。

<a id="p0074"></a>
**P0074** 但是不管怎么样，你用任意一个方式：比如我上来以后只推单一的大词，只推大词占位，你也可以——一个大词可能抵过100个小词；同理，100个小词也可以抵过一个大词。这是我们获得自然流增长的入口。

<a id="p0075"></a>
**P0075** 所以我们一般在对比流量的时候，比如现在对比月销2万多和月销4000多的产品。第一个区别是流量池的数量，一个是1800，一个是1100；再看流量池的体量，从上往下看，其实发现它们体量区别并不大，都是这些词——26万、20万、26万、2万、1万多，看这一些20万、12万、3万多、2万多，其实体量差别并不大，因为他们都已经拿了很多次了。接下来差别就在于你的自然位置有多高。

<a id="p0076"></a>
**P0076** 第一个产品自然位44、63、585，都是相对来说比较高、中高的位置；第二个产品的位置都是中低的、偏低的位置，基本上都在偏低的位置。所以它俩的单量差距来自于自然位的差距和流量词的差距，这两个差距。

**P0077** 第二个产品想要去追赶第一个产品的话，你就复刻流量通道，去追赶数量或者追赶位置就可以了。至于怎么追赶，后面会再展开讲，方向是这样子的。

<a id="p0078"></a>
**P0078** 2. 广告流

<a id="p0079"></a>
**P0079** 好，再说第二个，搜索结果页面里面除了自然流量以外，还有广告流量。广告流量是现在我们搜完一个词，下面所看到的所有付费的位置都叫广告流量。

<a id="p0080"></a>
**P0080** 那么这个广告流量在一个词下面：你的自然位只有一个，但你的广告位有很多个，不止一个。比如我们现在看到顶部的这一条是属于SB广告，往下拉，头部这一排属于SP广告，再往下面拉，还会有一排SP广告——Trending Now里面的SP广告，然后再往下面，你还能看到一堆SP广告在中间，最后往底下去拉，最底部也有一个SB广告。还有中间还会有SBV视频广告，会有一个SBB（品牌商品集广告）。所以在一个词下面，每种类型的广告都有自己的位置。

**P0081** 如果想要获得更大的广告流量，很简单：要获得更多词下的广告流量、更大的词下的广告流量，以及更好的广告位。

<a id="p0082"></a>
**P0082** ##### 广告类型展开

<a id="p0083"></a>
**P0083** 广告类型分为：SP、SBV、SBB和SB。在搜索结果页面里面SD是很少见的，所以把这个去掉，我们只看SP、SB和SBB这三种。

<a id="p0084"></a>
**P0084** SP广告（Sponsored Products）

<a id="p0085"></a>
**P0085** 一个词下面能有几个SP广告位？

<a id="p0086"></a>
**P0086** 说话人2 22:08

<a id="p0087"></a>
**P0087** 一个词下面只有一个，这。

<a id="p0088"></a>
**P0088** 说话人3 22:10

<a id="p0089"></a>
**P0089** SP广告位是这样的：SP分板块。首先你左上角能看到SP的板块叫什么——这个叫"Result"，热闹的是一个板块；然后往下拉，又看到一个叫"Trending Now"，Trending Now也是一个板块；再往下面会有一个"Most Wished For"，Most Wished For也是个板块。

<a id="p0090"></a>
**P0090** 我们一般来说一个页面里面会有一个Result和另外一个独立板块。比如Trending Now，再往下面拉，出现一个"Brands Influencers"——亚马逊影响者计划，这些板块都得有一个加入条件。

<a id="p0091"></a>
**P0091** SP广告板块分类：

<a id="p0092"></a>
**P0092** • 第一个："唯一的板块"——所有词下面都有的板块叫Result。Result会被分割成两个东西：一个叫Result（Top of Search/TOS位），一个叫Rest of Search（ROS位），一个是Top位，一个是其余位。

<a id="p0093"></a>
**P0093** 这两个位置是互相冲突的——当你的广告出现在Top位以后，就不可能出现在Rest里了，不管第几页都不可能出现。同理，如果你在下面出现，上面就不可能出现。所以Result这里你最多拥有一个广告坑位，出现一次（除非是多变体，多变体后面另讲，现在我们讲单变体单链接）。

<a id="p0094"></a>
**P0094** • 第二个：独立板块——指的是除了Result以外的其他有别的名字的板块。如果你们平时用Cerebro的话，可能会管它叫"推荐流量"，但它不是推荐流量，它就是SP广告位。

<a id="p0095"></a>
**P0095** 独立板块里面比较常见的有：Trending Now、Customers also viewed、Picks from Amazon Influencers等。一般来说一个词下面会搭配1-2个独立板块。所以你的词下面基本上最少有一个Trending Now，或者有一个Highly Rated的，或者是Featured的、Most Wished For的，最起码有一个，多的话有两个。

<a id="p0096"></a>
**P0096** 你的产品在每个板块都能出现一次。首先Result可以出现一次；独立板块每个也都可以出现。我们现在在这个词下面能看到这一家在这里，然后我们往上拉，看到在Top位（TOS位）里面也有BSR（这家），它的Result里面出现了一次，独立板块里又出现了一次。再往下拉，再看Trending Now独立板块也出现了一次（这是另外一个变体——变体我们后面讲，但这里先给大家提一点：如果你是多变体的话，每个变体都可以在这个板块出现一次，但变体不可以在同一页出现）。所以现在它金色出现在了Trending Now，就意味着银色的主推不可能在第一页再出现了，他只能去到第二页。

<a id="p0097"></a>
**P0097** 所以这点上面你们大致理解为：同一个ASIN在一个板块最多出现一次就可以了。

<a id="p0098"></a>
**P0098** 现在这个词下面：自然位有一个，SP广告有三个（Result + 两个独立板块）。

**P0099** SB广告（Sponsored Brands）

<a id="p0100"></a>
**P0100** 再看SB广告位，往顶上去看，SB广告位顶上能出现一次，再往下拉，最底下的SB广告位也能出现。你们能看到现在底下最左边的德尔塔跟顶上那个是一样的，它在顶上和底下同时出现了，而且我们翻到第二页它可以再出现，翻页可再出现（不过现在没看到，往底下去拉看它在不在）。

<a id="p0101"></a>
**P0101** 底下它没有，但它可以再出现，你往第三页去翻，它可能第三页又出现了，但这里我就没法保证它在了。这样你们就看：现在底下这两个是同一个店铺、同一个旗舰店，但它是两条不同的广告，是两条不同的自定义图片、不同的场景图。

<a id="p0103"></a>
**P0103** 所以在搜索一个词以后，你的SB广告可以出现很多回，它的位置和曝光量都可以比你的自然流量来得大。

<a id="p0104"></a>
**P0104** SBV（视频广告）

<a id="p0105"></a>
**P0105** 再说SBV——我们现在讲的指的是单纯的在搜索结果页中部的这种小流量广告，V60型的广告。不是顶上的那种，那种我们称之为SBV头条视频广告。但是SBV指的是在页面中部出现的，像这种叫SBV。SBV广告也是一样：它没有板块区分，一页会有1-2个SBV坑位，且翻页可重复。所以你的SBV广告起码能出现一回，甚至是多回。

<a id="p0106"></a>
**P0106** ##### 广告流量大小决定因素

<a id="p0107"></a>
**P0107** 这指的是搜索结果页面里面的广告流量能获得这么几块。决定广告流量获得的有几个方向：

<a id="p0108"></a>
**P0108** 1. **词的大小**：词越大，广告位置越好，在这个词下面的广告量就越大；

<a id="p0109"></a>
**P0109** 2. **广告位置高低**；

<a id="p0110"></a>
**P0110** 3. **流量词数量**（获得广告流量的流量词数量）；

<a id="p0111"></a>
**P0111** 4. **广告时长**：广告相比自然流量会有个差距，在于你的广告时长。你的广告不一定是全天在的，所以广告时长越短，广告流量也会越小。

**P0126** 流量词数据来源

<a id="p0127"></a>
**P0127** 再往下拉，就能看到这个东西的数据来源在哪了。

<a id="p0128"></a>
**P0128** 前面讲过你的自然流和广告流都是根据流量词的数量、词的大小等共同决定的。所以我们这儿看：流量词1805个里面能获取到流量。每个词左边都会有一个"流量"数据，这个数字会比卖家精灵的数字要准很多——卖家精灵不太准，Cerebro也没有这个准。

<a id="p0129"></a>
**P0129** 我先讲一下这是怎么算的：

<a id="p0130"></a>
**P0130** 第一个词（showerhead），流量你点开是42万。这42万你可以理解为他获得的曝光量是这么多。怎么算的？根据你在这个词下面所获得的广告位和自然位，再叠加上它的搜索量，这两个数据相乘获得。

<a id="p0131"></a>
**P0131** 举个例子：这个词的周总搜索量是26万。假设我的自然位一直顶在第一位、广告位也一直顶在第一位，那么我在这个词能获得多少曝光量？52万，对吧？很简单——26万×2=52万。

<a id="p0132"></a>
**P0132** 那么同理，现在它算出来是42万，是因为我们没有去拿完。为什么没拿完？我们点进数据指标里面看：左上角全选所有的ASIN（因为不同的ASIN拿的流量不一样），然后就能看到在showerhead单个词里面，我们现在所获得的自然流和广告流是1:1的状态。再点进展示位流量也是一样，能看到自然流广告流是怎么分布的，卖家在这个词下面打了什么类型的广告都能看到。

<a id="p0133"></a>
**P0133** 你看现在能看到的是他原先会打SBB，现在慢慢不打了，大概率是因为SBB效果不好或者数据不好。然后我们还会点几个指标在上面：流量获得率、自然流量获得率和广告流量获得率都点开。

<a id="p0134"></a>
**P0134** 我这边把鼠标放在任意一天，看这个词下面，他在8月21号这天一共获得63,000的综合流量。这63,000由这些东西构成，然后我们看：

<a id="p0135"></a>
**P0135** • 流量获得率：158%——指的是买家搜了这个词100次，能看到他158次。为什么会有158%？因为流量获得率由"自然流量获得率+广告流量获得率"算出来。

<a id="p0136"></a>
**P0136** • 自然流量获得率：45%——指的是买家搜100次，看到它45次。它的自然位好不好？肯定不是太好的自然位，不在高位。

<a id="p0137"></a>
**P0137** • 广告流量获得率：113%——下面显示有3个ASIN，指的是这3个ASIN一起去拿广告流量，买家搜了100次看到他113次。

<a id="p0138"></a>
**P0138** 这两个数字相加，就能获得158%的流量获得率。

<a id="p0139"></a>
**P0139** 这里的话其实你在一个词下的流量由自然流和广告流共同构成：自然流由自然位和体量大小决定，广告流由广告位、广告时长和词的大小决定。

<a id="p0140"></a>
**P0140** 然后这里我们还会涉及到多个广告流，比如这个页面里面你能看到它的广告流是SP+SP（独立板块）+SBV，那也就是说SP和SP（独立板块）这两个一起都是SP，再加少量的SBV构成整个广告流。所以它的广告流是通过多种广告一起获取的。

<a id="p0141"></a>
**P0141** 广告流是否要追求最大化？

<a id="p0142"></a>
**P0142** 但是咱们的链接要不要获取大量的广告流，取决于你的广告本身能否盈利。

<a id="p0143"></a>
**P0143** • 如果广告是亏损的，我们一定不会追求广告流的大小，不会冲着广告流变大去做，只会冲着自然流变大去做；

<a id="p0144"></a>
**P0144** • 如果广告是盈利的，我们也会冲着盈利的广告流变大去做。

<a id="p0145"></a>
**P0145** 所以这点上面你们去调研竞品的时候，不需要太执着于"竞品在自家获得这么多广告流，我也要"，这个不用去比。因为你的广告越盈利，可以获得越多广告流；但如果广告是亏损的，流量是越小越好的——因为我们需要用这个广告去做到自然流。

<a id="p0146"></a>
**P0146** 西柚找词案例分析

<a id="p0147"></a>
**P0147** 通过西柚找词这个软件，我们能比较清晰地看到，比如这个产品总共获得流量情况，以及它在不同词下分别做了什么。

<a id="p0148"></a>
**P0148** 第一个产品（showerhead）：在showerhead这个词下面已经获得了右边这个展示位置的一堆流量——自然流、SP流量、SP（独立板块）流量、SB、SBV，还有一个AC（AC标——它有AC标）。

<a id="p0149"></a>
**P0149** 第二个产品：流量情况是怎么样？有自然流和SP广告流（这个展示位置里面就只有SP和SP独立板块），所以你能推断卖家只打了SP广告，以及在小部分的词里面打了一点SB广告。具体打了多少，点开来看每日趋势，或者看90天，能看到为什么它能抓出来SB——不是因为他打得多，他就是闪现了一下：这一天7月31号SB广告闪现了一下，以及前面6月份的时候SP打了几天。

<a id="p0150"></a>
**P0150** 所以这个地方即使抓出来是有SB的，也不代表他SB打得多。西柚是根据你的广告的曝光时长去算你的广告流量的，他不会说你但凡出现就给你算上算满。

<a id="p0151"></a>
**P0151** 回到前面这个产品，虽然说他广告打满了所有的位置，但位置也不一定是拿得多。比如我们说第二个"high pressure showerhead"这个词里面，点开来看它的展示位流量，能看到卖家这里跟大家讲一个新的——这里有一种柱子上面是肉色的部分，西柚把它算成一个流量，但它其实不是流量，它是AC（上面写的是AC流量）。AC不给你带来流量——以前AC是有专门的入口的，现在没有了。所以这个词下面流量是算多了的，你们自己刨掉就可以了。

<a id="p0152"></a>
**P0152** 也就是说，现在它在这个词下面虽然显示是SB和SP广告，但实际上SB广告占比极低，就是这么一小块，黄黄的一小块曾经出现过，其他时候都没有。所以SB其实不是它的大头。同样的，SBB每天的流量占比不太一样、流量大小不太一样，但总体来讲都小于SP广告。所以这个链接如果广告流量做满的话，会有什么效果？

<a id="p0153"></a>
**P0153** 链接广告流量做满的展示

<a id="p0154"></a>
**P0154** 你们可以看一下：如果链接的广告流量做满的话，理论上来说有这么多的自然流。

<a id="p0155"></a>
**P0155** 我画一条曲线：横轴是时间，纵轴是流量大小。如果我们把一个词的流量拿满的话，你大概率会看到：

<a id="p0156"></a>
**P0156** • 自然流拿了这么多

<a id="p0157"></a>
**P0157** • SP广告流能拿一模一样的长度

<a id="p0158"></a>
**P0158** • SB能拿这么多

<a id="p0159"></a>
**P0159** • SBV也能拿这么多

<a id="p0160"></a>
**P0160** • SP独立板块也能拿这么多

<a id="p0161"></a>
**P0161** 所以在一个词下面最多能获得400%的流量——画不下了，最多能获得400%的流量获得率，这就是拿满。

<a id="p0162"></a>
**P0162** 所以你如果现在想要知道说"我在这个词下面还有没有流量增长的空间"，你就看：

<a id="p0163"></a>
**P0163** • 自然流量获得率有没有到100%？

<a id="p0164"></a>
**P0164** • 广告流量获得率有没有到300%？

<a id="p0165"></a>
**P0165** 如果按占坑的角度来讲的话，这样就算占满了——400%就算占满了。

<a id="p0166"></a>

**P0263** (1) Previously Viewed

<a id="p0264"></a>
**P0264** 第一个指标叫"Previously Viewed"，就是你曾经点开过的链接。我现在清洁刷点开过两个链接，它就会直接把这两个链接呈现在我面前。

<a id="p0265"></a>
**P0265** (2) For You

<a id="p0266"></a>
**P0266** 再往下面，会显示"For You"，就是猜你喜欢。这个猜你喜欢的机制是基于你点过的这两个商品在猜你喜欢，所以它跟我们现在前台的自然排位是两回事儿。

<a id="p0267"></a>
**P0267** 你的产品如果点的价位是35、37，款式是这样子的话，那么他给你推荐的时候也会给你推荐类似的款式或者类似的价位，都会比较类似。

<a id="p0268"></a>
**P0268** 或者我给大家看一下：如果搜词，我搜一个"household"，大家可以看一下搜索结果页里面会有很多种刷子，包括手动的和电动的；现在我在Keep Shopping For里面，他基本上就只会推电动的了，他就不会推手动了。这是根据我看的款式去给我推荐的。

<a id="p0269"></a>
**P0269** 那么如果你们想要在For You里面获得推荐流量，第一个：你的产品描述得非常的精准——比如这个竞品有什么标签，你也得有什么标签。举个很简单的例子：竞品是电动的，你也是电动的，这就是一个标签。

<a id="p0270"></a>
**P0270** 但是这个文案里面我们都会写有些细致的标签，可能你没有注意到的，那我建议你们来到For You这里——For You这里有一堆的筛选框。把一个框点开来看，你符合哪个就要写哪个。

<a id="p0271"></a>
**P0271** 比如售价：售价现在分为20、20-40、40-60，这是售价（直接的定价）；以及星级——这两个是最基础的。后面这一堆就会有更多的东西了。

<a id="p0272"></a>
**P0272** 比如有一个叫"Recommended Use for Product"，就是推荐在什么地方使用，也就是使用场景。这个使用场景里面，比如有Sink（水槽）、Tub（浴缸）、Floor（地板）、Window（窗户）等等。现在卖家这个标签你但凡能贴得上，全部都埋到你链接里面去。

<a id="p0273"></a>
**P0273** 是因为现在买家会在这儿筛选。比如我在这儿筛一个"浴缸"，点了浴缸以后，点"Show Without Sorry Out"，你就会发现里面的产品会变少，这里筛出来的东西会变少。那么你怎么保证自己能被筛出来？就是你得让亚马逊知道——你不能说自己知道，"我自己知道能给浴缸用"有什么用，你得让亚马逊知道你能给浴缸用。所以你需要：

<a id="p0274"></a>
**P0274** 第一：在文案里面埋进"浴缸"这个词。

<a id="p0275"></a>
**P0275** 第二：你如果能在"Cover for Tub"这种词出单那是最好的——有收录有出单那是最好的。

<a id="p0276"></a>
**P0276** 所以这里面的词应埋尽埋。然后除了使用场景以外，还有很多——比如材质里面有什么写清楚，还有Style里面有什么（可更换的头、可延展、什么Cordless无线等等），有的话也埋进去。

<a id="p0277"></a>
**P0277** 所以这个地方相当于是：你现在写文案很多时候是给系统看的，不是给买家看的，你需要首先让系统知道你是什么东西。

<a id="p0278"></a>
**P0278** 这里的话不仅是要适配于For You的筛选框，让系统认识到你是什么东西，以后Rufus也会给你很大的推荐。因为Rufus主要是通过直接推荐出口词和直接推荐商品给你引流的，所以你要让Rufus认识到你是什么东西，然后他就会推到你。

<a id="p0279"></a>
**P0279** For You这里不多讲了。

<a id="p0280"></a>
**P0280** (3) Top Picks for You

<a id="p0281"></a>
**P0281** 再说"Top Picks for You"——这是推荐相似商品的。除了推荐相似商品以外，还有第二个叫"Best Sellers"。

<a id="p0282"></a>
**P0282** 在这个地方Best Seller榜单就是有用的——我前面讲Best Seller榜单它没什么流量、是不是它很不好进，但在Keep Shopping For里面Best Seller榜单它就是很好进入的。

<a id="p0283"></a>
**P0283** 这个产品它就会显示Household的一个Best Seller榜单，会显示前15-20位（如果是移动端的话显示前15位）。所以如果你希望获得BS榜单带来的流量，就得在前20位。如果你现在不在前20，你在30、40、50都不是很重要了，区别不大。

<a id="p0284"></a>
**P0284** 然后这里还有个"Bought Together"，但这个一般是相关类目的推荐，所以这个地方对你们来说帮助并不大。你们只需要去顾及两个：一个是For You，一个是Best Sellers，这样就可以了。

<a id="p0285"></a>
**P0285** 然后尽量让买家点过你，因为买家点过你的话，他在这个页面还能再看到你。

<a id="p0286"></a>
**P0286** 再给大家看上面有个裙子——女士的裙子。我这里显示有20个Build，指的是我看过20个商品。这20个商品可能是各种各样的，但他们会不会同？基本上来说你大概看一下这个规律，一般来说是个长裙，对吧？短袖或者长袖的长裙。那么我们往下拉去看For You里面的推荐也会是短袖或者长袖的长裙。

<a id="p0287"></a>
**P0287** 所以这个地方还是比较根据你过往的点击去分析出来你想要买什么，然后给你推荐的。

<a id="p0288"></a>
**P0288** 下面像这种非标的产品，区分的标签就很多。所以大家埋词的时候一定要埋好这个地方——比如这些场景：Adult、Baby、儿童的什么各种都要埋进去，不然筛不出来。

<a id="p0289"></a>
**P0289** 我知道大家埋词的时候，很多时候就只冲着大词去埋，根本不埋这些标签词。这标签很重要，不仅在For You里面，还在Rufus里面。

<a id="p0290"></a>
**P0290** （六）Rufus（如粉丝）

<a id="p0291"></a>
**P0291** 那么接下来回来说一下Rufus。Rufus现在主要有两个作用：一个是提供搜索词，一个是提供商品。

<a id="p0292"></a>
**P0292** 怎么讲？你们现在一定自己要去试着使用Rufus——就是你要模拟买家的购物路径。

<a id="p0293"></a>
**P0293** (1) 在首页的Rufus

<a id="p0294"></a>
**P0294** 第一个是买家在首页的时候，他不知道要搜什么、不知道要买什么的时候，那么你点进Rufus，他会先推荐——你看到第一排叫做"Keep Shopping For Hand-Held Showerheads"，我前面搜过了，刚搜过淋浴头，他就在这儿继续。他会先给我推荐淋浴头，意识到我没买（对吧？我没买，他就会感觉我买的有问题），就会给我提供几个建议的问题。

<a id="p0295"></a>
**P0295** 比如有没有什么淋浴头是手持的、带着这种可调节水压的功能的——他就会直接推荐了。这里的推荐它是根据什么推荐的？根据几个标签：

<a id="p0296"></a>
**P0296** 第一个标签：Hand-Held Showerheads——你得是手持的；

<a id="p0297"></a>
**P0297** 第二个标签：功能型的标签。

<a id="p0298"></a>
**P0298** 所以你的产品贴合这个功能就会被推出来。贴了这个功能以后，我们往下拉看一下，它对推进的产品有几个分类：

<a id="p0299"></a>
**P0299** 第一个分类：你看到这里有个叫"High Pressure Multi-Mode"，就是多种模式的；

<a id="p0300"></a>
**P0300** 第二个：再往下面拉会有一种叫"Budget Friendly"，他会推便宜的和贵的——便宜的就要Budget Friendly（预算友好型），是18块这种；19块；然后往上拉这种是25块、29块。所以它会分成这两种方式去推荐。

<a id="p0301"></a>
**P0301** 所以你的产品如果像上面这个贵的是52的，下面这种便宜的是18的——你的产品如果想贴得上的话，首先得去贴合Adjustable这种标签，其次要看这个标签里面还细分什么。

<a id="p0302"></a>
**P0302** 现在我们看到这几个直接推荐商品可能点进去就买了，跟自然排名就没关系了。然后再往下面看，你可以再筛选——有什么是重类似的，虽然说有最强的水压的，还有就是说"Low Water Pressure"——有适合于低水压的家庭的。

<a id="p0303"></a>
**P0303** 比如点进低水压的家庭，他就会又推荐几个。如果你想要被推荐的话，需要贴合的词是什么？需要贴合的词是Low Water Pressure——你得贴这个词，让亚马逊知道你的产品是适用于这种场景的，你就可能被推荐。

<a id="p0304"></a>
**P0304** 我们在这儿看，看到有些产品它可能评论数量很少，像230几个评论。你像顶上这两个是2700和22,000，但这里230个评论也可以在这被推荐，是因为他会写得非常清楚——我现在就是增压的增压花洒。

<a id="p0305"></a>
**P0305** 包括我们再往下拉，它会再去区分一个叫"Hand Held"（手持的），另外一个就是固定的（Fixed）。所以你要如果说你想被推荐也是一样：在固定的基础上，比如你是固定的，你就写"Fixed"，然后再写一个增压就可以了——把你的所有的东西去做组合。

<a id="p0306"></a>
**P0306** 下面还有很多问题我就不继续问了。这是一个在买家已经搜过一个词以后，亚马逊会让他可以直接问亚马逊我要的东西，以及问他我该买什么，亚马逊会给他推荐的。

<a id="p0307"></a>
**P0307** (2) 搜词时的Rufus

<a id="p0308"></a>
**P0308** 第二点是在我们搜一个词的时候，比如我还是一样在搜showerhead。我搜showerhead的时候，能看到下面出现几个问题——搜索框里面底下就出现几个问题。比如"什么是用来增加Water Conditioner、增加储水的""有什么是最持久的材料""安装的程序是不是很简单"之类的。

<a id="p0309"></a>
**P0309** 如果你们想贴，现在最简单的方式就是找一个大词下面的推荐问题，往这个问题去贴。

<a id="p0310"></a>
**P0310** 比如我想贴第一个问题，我该怎么写？你文案里面埋这个词就好了，对吧？文案里面埋这个词。

<a id="p0311"></a>
**P0311** 一般来说这些问题是出现在一些比较大的、比较短尾的词里面。比如我现在搜一个showerhead它会出来；我现在再换一个，比如换成bucket这样子大词，搜bucket它下面一样的会出现这些问题——什么"Different Types"、"Features"，你们都点进去看就可以了。

<a id="p0312"></a>
**P0312** 我这点进去看，它就不弹出来搜索结果页面，会给我出来解答。

<a id="p0313"></a>
**P0313** 又会开始这些东西，比如现在问的是省水（不是神水），他就问省水。他就会有什么——这个不知道什么意思，出现一个结果，下面又出现一个结果，你就把这拿进去："To Service高效的省水的"这个东西。再往下拉看，再往下对比，所以这些问题就是高频问题了。

<a id="p0314"></a>
**P0314** (3) Rufus的另一个作用：推荐词

<a id="p0315"></a>
**P0315** 然后再回来说，Rufus还有一些作用是给你推荐词。不过现在亚马逊推荐词这个动作越来越少，因为他更希望买家一步到位地把东西买了。

<a id="p0316"></a>
**P0316** (4) 商品页面的Rufus问题

<a id="p0317"></a>
**P0317** 然后我们再换一个链接：现在点进一个链接，这个链接下面也会有Rufus的问题。这个问题你们自己也要问，因为你们现在写的文案就是给Rufus去看的，买家不会去一个个字看的，他会直接问。

<a id="p0318"></a>
**P0318** 比如这个产品可不可以机洗——他不会看你文案里面说可不可以机洗，会让亚马逊去抓取这个产品可不可以机洗，然后他就写"可以机洗的，因为什么东西"——他写原因就是根据你的文案来的。

<a id="p0319"></a>
**P0319** 然后再说"我应该买什么尺码的""这个是不是很透的衣服"。

<a id="p0320"></a>
**P0320** 接下来看他的问题。这个回答是基于你的评论或者基于你的文案来写的。现在亚马逊Rufus回答的问题就是"Based on Customer Reviews"——通过买家的评论我们知道它是不太透的，所以不太透。

<a id="p0321"></a>
**P0321** 如果买家关心的比较多，有些时候他搜了这个问题以后，搜出问题以后其实是没有回答的——如果"我不清楚，评论也没写、文案也没写"，那么这里你就需要自己去往里补充。

<a id="p0322"></a>
**P0322** 所以你的现在咱们去做文案的要点在于：你得让Rufus帮你提炼出来各个问题的答案。

<a id="p0323"></a>
**P0323** 这是关于转化率的，我就不多讲。我们现在讲的大头在于流量来源——如果你想要贴流量，那就是往Rufus里面推荐的词去贴。比如这里有"Best for Apartment and Rentals"，那么你的文案你就得写：Apartment的话源头就是出租屋，出租屋适用的你就得写进去。你不一定要去广告投这个词，但你得埋。

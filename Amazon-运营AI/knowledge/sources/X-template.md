# X — 搜索词透视表模板检查记录

原始文件：`course/搜索词透视表模板-新.xlsx`。检查日：2026-11-11；只读检查，未改动文件。

## X01 · 范围与数据性质

工作簿包含两个可见工作表，无隐藏表。原始表「搜索词报告（SP）- 每日」尺寸3199行×24列，但非空单元格仅24个，全部是第1行标题，**没有店铺明细数据**。3199行是存储/格式范围，不能理解成3198条广告记录。

「搜索词透视表」尺寸15行×14列，非空29格，A4:M6为透视输出；I5:M6为缓存的 `#DIV/0!`，源表为空时不能解释为运营异常。未发现普通单元格公式，但透视缓存含5个计算字段。缓存记录仅1条空白记录，不是历史销售数据。

## X02 · 原始表字段（A1:X1）

日期、广告组合名称、货币、广告活动名称、广告组名称、零售商、投放、匹配类型、客户搜索词、展示量、点击量、点击率(CTR)、每次点击成本(CPC)、花费、7天总销售额、广告投入产出比(ACOS)总计、总广告投资回报率(ROAS)、7天总订单数(#)、7天总销售量(#)、7天的转化率、7天内广告SKU销售量(#)、7天内其他SKU销售量(#)、7天内广告SKU销售额、7天内其他SKU销售额。

模板的7天列名是**此文件的口径**，不是所有广告产品、账户或未来导出的通用归因窗口。订单数、件数、广告SKU、其他SKU须分开；不能把其他SKU归因都当成目标ASIN销量。

## X03 · 透视结构与公式

透视表名 `数据透视表3`；源范围为 `'搜索词报告（SP）- 每日'!A1:X1048576`（整列接近百万行，刷新可能较慢）。筛选：广告组合、日期；当前行顺序：客户搜索词→广告活动名称→投放→匹配类型。课程不同问题会改变排列顺序，不能用一个视图解决所有问题。

可加总基础量：展示量、点击量、花费、7天总订单数。计算字段定义位于 `xl/pivotCache/pivotCacheDefinition1.xml`：

|字段|文件中的公式|正确解读|
|---|---|---|
|cpc|花费/点击量|汇总花费÷汇总点击|
|cvr|'7天总订单数(#)'/点击量|汇总广告订单÷汇总点击|
|ctr|点击量/展示量|汇总点击÷汇总曝光|
|cpa|花费/'7天总订单数(#)'|汇总花费÷汇总订单|
|acos|花费/'7天总销售额'|汇总花费÷汇总归因销售额|

输出标题中的「求和项:cpc」等是透视字段显示名，**不应据此手工累加逐行CPC或CVR**。更换软件或转换格式后，应以一组非空样例独立复算聚合比率，确认计算字段行为。本次没有实际数据，未实测Excel/WPS交互刷新。

## X04 · 使用SOP与风险

1. 复制模板为工作副本，原始课程模板保持不变。
2. 按站点、币种、ASIN及时间窗口分别准备导出；原表无明确站点或目标ASIN列，需在副本增列或按文件隔离。
3. 从第2行填入数据，核对表头、数值类型、去重键、日期及归因成熟度；整份报告去重后再汇总。
4. 刷新透视缓存；先验算总花费、点击、订单、销售额，再验算比率。
5. 依问题变换行层级：找预算去向以搜索词为首；查重复以匹配方式→投放词→活动；查广泛/词组重叠以投放词→匹配方式→活动。
6. 将准词表和聚合搜索词报表按清洗后的搜索词连接，报告未匹配项，不能把未匹配全部当成无价值词。
7. 分母为0显示NA/样本不足，不按0%好坏作决策；保留无订单花费作为待诊断项。

本模板没有自然排名、实际总销售额、采购/FBA/退货费用，也没有独立广告位报告，无法单独完成TACoS、净利润、排名增量或广告位优化诊断。课程关联：[S081](S-slides.md#page-081)、[S116](S-slides.md#page-116)、[S181](S-slides.md#page-181)、[S188–190](S-slides.md#page-188)。

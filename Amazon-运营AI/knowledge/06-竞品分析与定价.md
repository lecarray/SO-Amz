# 竞品分析与定价

因果主线：**确认同一需求与可比竞品 → 拆需求、流量入口、价格和信任差异 → 核查点击/转化与获客成本 → 选择走量或利润假设 → 小步试价并比较总贡献利润 → 决定扩量、恢复售价或退出**。【顾问推论】排名、竞价和点击中位价格帮助组织假设，不能代替成交意愿、净利或价格弹性的实际验证。

证据说明：【课程观点】包括算法、工具准确性和固定折扣/周期，均待验证；【课程案例】多为匿名口述，不是独立审计；【数学定义/条件恒等式】须统一分母、币种、时间与归因；【顾问推论】是本页对实验与经营约束的补充。本页没有现行官方规则核验。依据第1–4章全文深读，并定向阅读第9章CPC/CVR市调、第10章CTR与定价原文及[课件S120–S136](sources/S-slides.md#page-120)；完整阅读覆盖分别在[01–04笔记](reading/01-04-深读笔记.md)与[09–12笔记](reading/09-12-深读笔记.md)登记。

## M06-01｜先匹配需求和商品条件，再比较竞品销量

1. **核心思想**：【课程观点】竞品比较的单位应尽量落到同词、同用途、相近商品和同阶段；销量差距要拆成流量宽度、体量、位置与转化差异。
2. **底层原理**：同外观不同价格的商品可能服务不同人群、流量通道或品牌需求；评价、品牌、配送、功能、季节与款式影响可替代性。
3. **适用场景**：找目标竞品、判断价格区间、分析头腰部差距、开发差异化款或新主题变体。
4. **指标/判断**：站点/时间/币种、规格和套装、价格/优惠、评分/评价量、品牌、库存/配送、核心词与自然位、广告结构；推广难度再看需求集中度、入口垄断、迭代速度与CPA/贡献毛利。
5. **操作步骤**：列需求和硬规格 → 分头部/腰部/新进入者 → 保留价格及功能可比组 → 对齐同词/周期比较 → 区分商品优势和流量投入差距 → 明确缺什么证据再下结论。
6. **风险限制**：第三方销量/流量是估算；不能把竞品各项优点拼成不存在的“平均竞品”；“集中流量更难推”“产品本身占70%”等是课程经验，非量化权重。其他站点竞品不能直接作本地价格基准。
7. **课程案例**：26,000月销/1805词与4,200月销/1102词的淋浴头；$24、15评钱包面对同价Levi's与低价多评品；$21.9自然流充电器和约$45–46广告流款说明流量模式可能不同，未证明两者净利相等。
8. **来源**：[C01 P0054–P0077](sources/C01.md#p0054)，原稿[R01同段](sources/R01.md#p0054)；[C03 P0200–P0208](sources/C03.md#p0200)，原稿[R03 P0078–P0080](sources/R03.md#p0078)；[C04 P0268–P0272](sources/C04.md#p0268)，原稿[R04 P0092–P0094](sources/R04.md#p0092)；[S135–S136](sources/S-slides.md#page-135)。

## M06-02｜用三组竞价与可比转化建立成本区间，再用真实投放检验

1. **核心思想**：【课程观点】把工具建议、账号建议和实际投放分开比较，避免看见建议价就照出；预估CPA须同时考虑CPC与CVR。
2. **底层原理**：【数学定义/条件恒等式】CPA=实际CPC/CVR。【课程观点/待验证】工具价被称“空白账号批发价”，账号建议高被解释为“杀熟”，老活动权重能压价；这些不是已证实定价机制，三组不同也可能来自样本、类目、时点与流量构成。
3. **适用场景**：新品获客成本预估、老品CPC偏高诊断、定价前利润承受力检查。
4. **指标/判断**：5–10个高相关核心词及其低/中/高建议，实际bid、实际CPC、位置、CVR、CPA、样本量；品牌品类转化与单ASIN广告CVR分母不同，不可直接当同一指标。conversion share是订单占比，不是CVR。
5. **操作步骤**：同站同节点选核心词 → 保存工具和账号建议的日期/定义 → 各档分布取稳健统计 → 收集实际CPC而非bid → 按词、位置、价格和周期分层匹配CVR → 算CPA情景 → 用真实投放小步校准，不把区间当硬上限。
6. **风险限制**：工具数据不证明“客观市场价”，一条区间不能通用于所有泛词/广告类型；不采用来源不明的竞品账户报表或为取数而未经核实的跟卖。ABA购买窗、多变体跨购、工具全周期算法等说法需官方与数据核验；“仅非CVR问题就一定自己给高”过强。
7. **课程案例**：吹尘器5–10准词提取低/中/高约$2.6/$3.7/$4.9；电子相框品类转化口述13%–20%。若用18%估CVR，CPA应$14.44–27.22；原稿R10 P0052随后改用约20%，则$13–24.50，较接近课堂13–25。必须记录所用假设，不能两种混算。
8. **来源**：[C09 P0044–P0118](sources/C09.md#p0044)、[P0189–P0242](sources/C09.md#p0189)，原稿[R09 P0028](sources/R09.md#p0028)、[P0041/P0050–P0054](sources/R09.md#p0041)、[P0108–P0125](sources/R09.md#p0108)；[C10 P0051–P0062](sources/C10.md#p0051)，原稿[R10 P0052](sources/R10.md#p0052)；[S120–S130](sources/S-slides.md#page-120)。工具名“Sellics=Cerebro=C服”的整理混淆不作为已核准名称。

## M06-03｜用同查询点击价格与CTR建立走量/利润假设

1. **核心思想**：【课程观点】先判断商品是以价格竞争获取自然量，还是以较高单均贡献购买盈利流量；不要只凭“材质更好”就把更高价格当买家认可。
2. **底层原理**：查询价格分布是已发生行为的描述，不等于所有买家的支付意愿。【课程观点/待验证】课程建议以点击商品价格中位数附近/约八折作流量款测试入口，高价利润款更依赖盈利广告或品牌需求。
3. **适用场景**：新品初定价、同类不同价格带、细分人群筛选、判断高价款CPA恶化。
4. **指标/判断**：同查询同漏斗的商品/ASIN价格中位数、ASIN CTR=ASIN点击/曝光、大盘CTR=总点击/总曝光、CVR、单均贡献与CPA。点击价格中位数不能作购买价格中位数；大盘CTR有位置构成混杂。
5. **操作步骤**：确认主推ASIN和查询 → 导出完整字段并核口径 → 分别查看展示/点击/加购/购买价格列 → 按真实可比商品分组 → 形成低/中/高价格与流量来源假设 → 核算底价和贡献 → 小步测试，不自动套八折。
6. **风险限制**：八折不是最优价保证；品牌视图、ASIN视图、不同漏斗不可混合。整理版省略了原稿“除非准词和泛词”的CTR差异例外；不能用一个词代表所有词。“SB/SD不受CTR影响而不涨价”等是待验证机制说法。
7. **课程案例**：商品价格中位数$34.66，课程流量款约$24–32、八折$27.728；利润款略高约$38–45、显著高约$55–90。大码普通裙约$29.99与礼服款$59.99/89.99说明产品与价格定位可能不同，未给销量/成本/利润对照。
8. **来源**：[C10 P0006–P0048](sources/C10.md#p0006)、[P0074–P0114](sources/C10.md#p0074)，原稿[R10 P0002–P0025](sources/R10.md#p0002)、[P0031–P0044](sources/R10.md#p0031)，开讲00:00；[S131–S134](sources/S-slides.md#page-131)。字段现行定义需另查官方数据字典。

## M06-04｜价格调整比较乘积与贡献利润，不追求最低价

1. **核心思想**：【课程观点】降低价格只是提高点击/转化的一种手段，涨价也可能提升利润；要看价格与两率、订单、费用如何共同变化。
2. **底层原理**：【数学定义/条件恒等式】同一漏斗销售额=曝光×CTR×CVR×均价；每曝光销售额q=P×CTR×CVR。将q当排序函数则是【课程观点/待验证】。若降价d、两率乘积增g，q上升须(1−d)(1+g)>1。
3. **适用场景**：降价仍无排名/销量、判断促销让利与广告成本替代、提价后CPA变化。
4. **指标/判断**：q、订单与销售额、广告后单贡献、全量贡献利润、退货、库存消耗；降10%须CTR×CVR增>11.11%才让q上升。q升仍不保证利润升。
5. **操作步骤**：保存现价基线 → 核算新价佣金/优惠/履约与毛利 → 设有限试价幅度与期限 → 尽量保持广告及商品其他条件 → 比较同词/同位及全店结果 → 按净利、现金与库存目标作决策。
6. **风险限制**：排名和CTR互相影响；竞争活动、需求与配送混杂。折扣影响全部成交，不只广告单；不能把广告CPA直接当作每自然单可让利金额。促销资格与参考价影响须按站点规则核实。
7. **课程案例**：竞品$11.99、自品9.99前4卡位，降8.99排名升，再降7.99反跌。教学对比19.99×2%×20%=0.07996，39.99×1.5%×15%=0.0899775，后者每曝光销售额高12.53%，不是净利润。
8. **来源**：[C02 P0357–P0366](sources/C02.md#p0357)，原稿[R02 P0134–P0136](sources/R02.md#p0134)；[C03 P0220–P0237](sources/C03.md#p0220)，原稿[R03 P0082–P0085](sources/R03.md#p0082)。另[C10 P0067–P0068](sources/C10.md#p0067)把40×2%×20%和45×1.5%×10%算为.016/.00675，正确为.16/.0675；原稿[R10 P0017](sources/R10.md#p0017)没有给这两个计算结果。

## M06-05｜低价或季节刺激后，分步恢复售价并检查实际承接

1. **核心思想**：【课程观点】老品低价和旺季前促销可作为激活假设；峰值排名不是收益，恢复价格后的落点才决定可持续性。
2. **底层原理**：【课程观点/待验证】价格提升点击/转化可带动多个相关词；排名稳定后小步提价比无观察地连续提价更有机会保留承接。低价/促销无成本与“百分百起位”均不成立为证据结论。
3. **适用场景**：中低价、高CPA、有真实评价/词基础的老链接、季节恢复及清货；新品未证明可恢复售价，慎套。
4. **指标/判断**：自然和付费访问、排名、总订单、单均与总贡献、库存覆盖、自然稳定性；课程1–4位小幅波动、约3天刺激均为示例，无统一阈值。
5. **操作步骤**：确认已收录且真实相关词 → 核可承受让利和备货 → 对齐旺季需求窗口 → 有限期试价 → 稳定后小步提价 → 若转化/利润/库存出现问题暂停并复盘 → 不承接则接受合理位置或退出。
6. **风险限制**：一次促销图表不能拆清订单和价格的因果；不能只凭曲线断言竞品刷单或合并评论。不给虚假订单、评论、历史价操纵等操作建议。低价的全量毛利损失须与广告投资共同核算。
7. **课程案例**：阔腿裤16–17降9.99，不开广告后自然50–60逐步到前5；圣诞冰箱门把手装饰低价后逐步到19.99/20.99，黑五后缺货。两稿均已自纠1000多评论来自去年旧链接，不能截取前半句继续指为合并。
8. **来源**：[C03 P0345–P0398](sources/C03.md#p0345)、[P0415–P0480](sources/C03.md#p0415)，原稿[R03 P0113–P0123](sources/R03.md#p0113)、[P0128–P0146](sources/R03.md#p0128)；[C04 P0273–P0283](sources/C04.md#p0273)、[P0321–P0345](sources/C04.md#p0321)，原稿[R04 P0095–P0096](sources/R04.md#p0095)、[P0107–P0112](sources/R04.md#p0107)。

## M06-06｜价格梯度与新变体应扩需求或利润，不能只制造低价入口

1. **核心思想**：【课程观点】可用主推获取入口、其他真实变体承担更高价格和需求；是否有效取决于实际购买流向与整个商品组合的利润。
2. **底层原理**：【数学定义/条件恒等式】组合均价=Σ(订单×售价)/Σ订单，组合贡献=Σ子体贡献−广告与其他成本；均价上升不自动代表利润改善。【课程观点/待验证】主推价格决定自然承接、购买子体独立获得权重。
3. **适用场景**：低价标品难直接提价、多件装、颜色/主题/尺码、扩主推人群入口。
4. **指标/判断**：子体价格与成本、订单份额、投放/购买ASIN、CVR、利润、库存；同词意图是否有真实差异。先看变体关系是否符合现行站点规范。
5. **操作步骤**：给每个子体写用户需求与角色 → 建价格/毛利梯度 → 小量测试购买分布 → 检查低价子体是否仍能供货/承接 → 比较新增净利与库存成本 → 无边际收益则不扩。
6. **风险限制**：课程$8.99主推与10.99/12.99辅推不保证仍保住主推购买；C/D高价广告引到A低价是设想，未给成交率。数量套装、主题变体均须独立核实合法关系；不为操控排名虚构变体。
7. **课程案例**：主推8.99、辅推10.99/12.99，综合均价约9.99为课堂设想；主推5.99配多件装7/8/11/14/19。裙子颜色和蜡烛礼物主题扩入口属于另外一类需求分工，不应与纯价格梯度混为一谈。
8. **来源**：[C04 P0410–P0429](sources/C04.md#p0410)、[P0493–P0502](sources/C04.md#p0493)、[P0533–P0551](sources/C04.md#p0533)、[P0648–P0653](sources/C04.md#p0648)，原稿[R04 P0128–P0133](sources/R04.md#p0128)、[P0163–P0164](sources/R04.md#p0163)、[P0176–P0179](sources/R04.md#p0176)、[P0205–P0207](sources/R04.md#p0205)。

本专题关键数值复核：34.66×80%=27.728；2.6/18%=14.444、4.9/18%=27.222；2.6/20%=13、4.9/20%=24.5；40×2%×20%=0.16；45×1.5%×10%=0.0675。建议竞价低1.28、高2.20并不能推出中位数1.59，若只算两端中点应1.74；若1.59来自完整样本分布，则必须取得样本，不能把它定义为低高两端中位。[C09 P0085](sources/C09.md#p0085)，原稿[R09 P0041](sources/R09.md#p0041)。

边界：本页不提供用户当前最优价格、目标CPC、广告预算或竞品名单，因为没有实时商品/成本/流量数据。US打印机与JP乒乓球发球机需要分别选竞品、分别核币种税费与配送、分别设计试价；不可套用课堂美元价格或转化基准。实际应用最小数据是：站点/ASIN与规格、目标/阶段、近期开价与优惠历史、完整单位成本、广告及业务订单/销售/访问数据、归因窗、库存与退货、可比竞品价格/评分及观察日期。当前规则、促销参考价、变体关系和广告资格必须另查官方来源并记核实日；本页只建设知识，不执行真实价格或广告修改。
